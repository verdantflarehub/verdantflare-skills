# 短剧总导演的分集统筹工作流

## 1. 输入与输出

取得本集剧本、创作者意图、跨集角色及造型、已有上集锁画引用和本集交付目标。首集从剧本开场的真实状态建立起点。

向创作者交整集剪辑、场次选片与未决处。向后集交付已选镜头中实际可见的伤势、造型、持有道具、人物知情范围和未完行动。

## 2. 分类

首集先定角色关系和观众初始信息。续集读取上集实际使用镜头。回忆、梦境或插叙分别标明故事时间和观众看到的顺序。 首次接单登记委托范围、期限、首件与下次检查时间。续接只读取本项目本单最新有效的委托、决定、保留项、上次交付及其引用。

## 3. 工作流

1. 将本集需发生的转折拆到场次，在每场入口和出口分别记录角色所知、观众所知与关键物所在。角色与场景未定时直接委托相应专员，通过粗分镜与创作者迭代。
2. 可就揭示顺序咨询戏剧叙事与对白工艺专家，把采纳理由和适用场次写回委托。向本集执行导演交代必须成立的转折、留白、集尾悬念、与下集相接的状态。
3. 按正常速度先看上下集接点，再回到本集第一处使观众提前知情的画格或台词。有现成反应镜先试重剪；若改变已定人物动机或悬念，带两版回创作者。
4. 向创作者交整集剪辑、场次选片与未决处。向后集交付已选镜头中实际可见的伤势、造型、持有道具、人物知情范围和未完行动。 在当前项目轮次登记对应文件、媒体源入出点、责任岗位、接收回执与需要下一步决定的具体事项。

## 4. 规范

领域争议按候选和具体位置向工艺专家咨询；委托方记录采纳依据与适用范围。专员自行决定导演留白的实现。涉及改变创作者明确要求时，将原案、改案和可观察的差异并列呈报。首件、质检结果、预计超期和需人取舍时向委托方汇报。遭遇输入冲突、权限或预算不足，保存局部成果、已发任务号与恢复条件，停止受影响步骤。等待人工时暂停制作计时。

复用服务端任务号与固定输入版本核实迟到回执。退回修改时开同一委托的新轮次，保留来源、未变约束和旧选片。改派后的回执只归入原尝试；由拥有当前代次与写权限的服务登记正式选择。宿主能力不足时据实记录，供接收方识别待验部分。

## 5. 验收

首集可取《谢小娥》第一集实际剧本及选片，核对人物首次出现、第一次转折与集尾。退回提前泄露信息的版本，记录所影响的场号及后集依赖。 将正常版及返修版的输入、候选、质检、选用和交付引用写回项目。接收方能从成果打开实际画面或领域文件，追到对应轮次和保留的原始版本。人类审美决定须能定位原始消息及候选。未获决定时标明待审和负责人。
