# 提示词抓取、出图预览与 VF Center 分步沉淀（01.ingest-publish）

## 1. 输入与输出

- **输入**：公开 X/网页链接或用户直接提供的提示词；扩充多图场景另提供既有作品组 `resource_id`、目标模型或 Edit 迭代指令。
- **输出**：落盘至 `/var/lib/assistant/drive/prompts/` 的干净标题与纯净提示词、经真实像素解码与内容分级门禁的出图成片、以及回读核验无缺图后的 VF Center 详情链接 `https://hub.verdantflare.ai/prompts/images/<resource_id>`（或 `/prompts/videos/<resource_id>`）。

## 2. 分类

按入库模式与业务分类双维度界定：

- **新建作品（单图或首批多图）**：用户发送公开 X/网页链接或提示词，要求沉淀提示词、出图并发布到 VF Center；先建作品组并上传首图，若为首批多图再逐张追加。
- **单图扩充为多图**：用户对既有作品组（`resource_id`）要求用 Nano Banana 再跑一张或用 Edit 换姿势/换穿搭追加到该组；无需迁移数据，直接向原 `resource_id` 追加第 2..N 张图即可自动变为多图。
- **三类强制业务分类（`subject_category`）**：仅允许 `beauty`（美女）、`handsome`（帅哥）、`animal`（动物）三项枚举，建组前必须明确归类。

## 3. 工作流

1. **抓取与清洗（复用 `verdantflare-download`）**：抓取公开推文或网页正文，剥离“提示词在这里：”之前的感叹口水话，生成精炼 `title`（`<= 36` 字）与纯净 `prompt`，同步写入 `/var/lib/assistant/drive/prompts/`。
2. **受控出图（复用 `verdantflare-image`）**：默认使用 `engine="codex"`、`model="gpt-image-2.6-sunburst"`；用户指定 Nano Banana 时使用 `engine="gemini"`、`model="gemini-nano-banana-2.1"`。下载成图后从图片头部解码真实像素 `WxH` 并完成内容分级门禁。
3. **D6 预览确认（必停点）**：将生成预览图与拟入库的分类（美女 / 帅哥 / 动物）、新建或追加目标 `resource_id`、标题、模型与 Edit 词明确呈报 Mengsk，获得确认无误后才执行入库。
4. **分步原子上传与回读核验**：新建作品先调用 `POST /internal/assistant/resources` 建组并上传首图；扩充多图或上传第 2..N 张时，逐张调用 `POST /internal/assistant/resources/{resource_id}/items` 幂等追加；上传完成后回读作品详情核验 `itemCount` 与每张图 `imageSha256`，确认零缺图后返回 VF Center 详情 URL。

## 4. 规范

两级上传参数必须严格满足以下强契约，防漏参、防大包超时：

### 4.1 作品组级参数（建组传一次）

| 参数                           | 规则                                                                 |
| :----------------------------- | :------------------------------------------------------------------- |
| `media_type`                   | 必填，`image` 或 `video`                                             |
| `subject_category`             | 必填强制枚举：`beauty`（美女）/ `handsome`（帅哥）/ `animal`（动物） |
| `title`                        | 必填，自动剥离原帖口水话后的精炼标题（`<= 36` 字）                   |
| `prompt`                       | 必填，纯净基准/母版提示词（已去口水话）                              |
| `prompt_origin`                | `extracted`（原帖提取）或 `adapted`（二次改编）                      |
| `source_url` / `source_author` | 公开原帖链接与 `@作者`（自研可留空）                                 |

### 4.2 媒体项级参数（每张图独立分步提交）

| 参数                          | 规则                                                                           |
| :---------------------------- | :----------------------------------------------------------------------------- |
| `item_id`                     | 必填幂等键（断点重试不重复插入）                                               |
| `label`                       | 必填展示标签（如 `GPT Image 2.6`、`Nano Banana 2.1`、`换穿搭 · 绯红马面裙`）   |
| `step_label`                  | 可选步骤号（如 `① 母版 v1`、`② 换姿势`）                                       |
| `engine` / `model_name`       | 必填真实引擎与模型编码（如 `codex` / `gpt-image-2.6-sunburst`）                |
| `aspect_ratio` / `resolution` | 画幅（如 `3:4`）与从图片头部解码出的真实像素（如 `1024 × 1536`）               |
| `edit_prompt`                 | 可选，仅 Edit 迭代图填写；有值时详情页自动在「提示词」上方高亮展示「编辑指令」 |
| `image_mime` / `image_base64` | 单张原始图片字节（严禁把多张 2K 图塞进同一个请求体）                           |

- **分包与幂等红线**：每张图独立提交并携带稳定 `item_id`，断点重试不重复插入；严禁单请求打包多张 2K 原图导致超时。
- **模型与审核红线**：不得跳过内容分级门禁，不得跳过 D6 预览确认直接入库；`resolution` 必须来自真实图片头解码，不得估算填报。

## 5. 验收

- 提示词已清洗口水话、`title <= 36` 字并已落盘 `/var/lib/assistant/drive/prompts/`。
- D6 预览已明确呈报分类、目标 `resource_id`、标题、模型与 Edit 词并取得 Mengsk 确认。
- 回读作品详情核验 `itemCount` 与每张图的 `imageSha256` 全部匹配、零缺图，且返回准确可访问的 `https://hub.verdantflare.ai/prompts/images/<resource_id>`（或 `/prompts/videos/<resource_id>`）。
