# H3 控制项与证据等级

设计或评审 Prompt 时，把控制项分为四类，不能混称“模型参数”。

## 硬控制

当前官方本地请求明确包含 `task`、`prompt`、`conditions`、`target.short_edge`、`target.aspect_ratio`、`target.duration_seconds` 和 `seed`。领域 MCP 只暴露批准契约中的模型、时长、画幅、Prompt 和引用；运行时没有暴露的采样步数、CFG、灯光数值或镜头路径不能由 Skill 虚构。

硬控制只保证请求规格。例如画幅和时长可验收，但不保证人物构图或动作质量。

Provider Schema 不是全局模型契约。fal H3 Max 另公开 T2V、首帧/首尾帧、全参考、Prompt Expansion 和部分 LoRA 能力；它们只证明 fal endpoint 接收这些输入，不能自动视为当前成都 Runtime 或领域 MCP 已支持。模式和 Provider 差异见 [input-modes.md](input-modes.md)。

## 参考控制

- I2VA 图片锚定首帧；FL2VA 图片锚定首尾；L2VA 图片锚定尾帧。
- Ref2VA 图片可参考身份、服装、场景或构图；视频可参考连续动作和摄影轨迹；音频可参考声线、表演节奏或复用音轨。
- 参考控制强于纯文字，但必须写明每个输入的唯一职责和保留策略。

## Prompt 软控制

Shot 切点、主体动作、摄影机运动、灯光、声音、对白、身份保留和负面约束均属于模型解释的软控制。可信度按以下原则判断：

- 一次只控制一个主要动作链和一个主要摄影行为，可信度高于堆叠多个行为；
- 状态变化、接触、位移、视差和结束状态可观察，可信度高于抽象风格词；
- 官方格式只证明语法受到支持，不证明时间戳能逐帧兑现；
- 创作者 Prompt 与结果配对可以证明“这次发生过”，不能证明稳定成功率；
- 没有配套结果的 Prompt 只能作为写作样本，不能作为有效性证据。

## 非直接控制

精确剪辑点、歌词字幕、最终歌曲同步、最终调色和 200 秒 MV 节奏属于上层 MV 与后期时间线。H3 候选中的原生音轨只供审核，最终必须静音并挂载批准 Master。

## 当前经验等级

| 项目 | 经验等级 | 决策 |
| --- | --- | --- |
| 时长、画幅、分辨率、输入模式 | 高 | 按接口硬校验 |
| 首帧/首尾帧锚定 | 中高 | 使用官方对齐格式，仍审核中间过程 |
| 简单身份、单一状态链、总体光色 | 中高 | 可用于生产候选，必须人工审核 |
| 2–3 个内部切镜 | 中高 | 可用，切点只作意图而非帧级保证 |
| 单一跟拍/环绕/推拉行为 | 中 | 完整播放并核对视差和主体尺度 |
| 复杂步态、驾驶物理、多物体交互 | 中 | 优先等长视频参考，失败即停止批量 |
| 多人物、多造型、密集动作蒙太奇 | 中低 | 外部拆分，减少每单元职责 |
| 精确文字、数字、歌词字幕 | 低 | 不在 H3 画面内生成，交给后期 |
| 负面 Prompt 独立纠错 | 低 | 只作辅助，不能替代正向路径与参考 |

这些等级来自官方规范、100 条 H3 Prompt 语料和 28 条创作者结果的逐秒接触表审查，不是统计成功率。未经本地配对 A/B 验证，不把“可能有效”升级为“稳定控制”。
