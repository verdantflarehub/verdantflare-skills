# 参考特征指导的音色设计

## 1. 两条结果都保留

参考复用是让原声音读新文字，走[新声线登记](new-voice.md)。音色设计是根据原参考的可用特征和修改要求，创造新的声音候选；用户需要两种时给原参考和设计候选独立 voice_id，保留各自版本与试听，不用新候选覆盖原声线。

先核对 Studio 工具与 `speech.capabilities`。截至 2026-10-17，当前 IndexTTS2 没有音色设计字段；开发中的 VoxCPM2 候选运行器尚未通过 GPU 验证，也未作为 Studio 工具开放。不要向现行 `speech.create` 发送 `target_description`、年龄或性别参数；本技能不启动集群任务、不安装模型、不直连内部运行器。

## 2. 固定设计输入

沿用已有参考与来源记录，保存其固定 ContentRef、大小和 SHA-256。保留三项文字：参考中实际可判断的音色特征、用户要求改变的特征、综合后明确的目标音色描述。没有听到参考时，不声称已听辨；可使用用户提供的描述，并标明依据。用户已明确两条路线后不重复要求二选一。

例如参考特征为“低沉、沉稳、略沙哑”，修改为“更年轻、更清亮”，目标可写“年轻男性，清亮而沉稳，轻微沙哑”。描述音色与表演分开；保留原台词和模型实际输入，不能让年龄或语气说明混进正式台词。

VoxCPM2 的文字设计模式不消费原参考波形，原参考通过特征描述提供创作依据；不能承诺保持原身份或百分比相似度。带参考的克隆模式消费波形，但自然语言指令主要控制表演，不承诺改变身份。模型标签、参考条件方式和实际输入必须随候选保存。

## 3. 生成、试听与固定复用

工具实际开放后按发现的 Schema 提交；尚未开放时保存上述输入与缺口，继续已授权的参考登记、对白和配乐准备。不能把开发运行器当成已安装的用户能力，也不以其他收费模型静默替换。

收到候选后核对原始音频、派生参考、请求、来源、模型版本和摘要。VoxCPM2 开发运行器给出的 `reference_technically_eligible` 只说明参考格式可用；不表示台词完整、听感通过或已登记。疑似截尾、过长或超出字节限制时保留原件，不截尾字凑长度。听审覆盖错漏词、描述是否被念出、目标音色、自然度与身份差异。

选择的候选按[新声线登记](new-voice.md)导入 Artifact／Project，在固定修订回读，再用不同文稿试音。候选生成模型与后续朗读模型分别绑定：用于 IndexTTS2 的 profile 取当前实际 `speech.capabilities` 模型摘要，VoxCPM2 来源单独保留。不要将新模型摘要直接塞进旧后端配置。

候选归档不自动选用、批准或发布。换声只生成受影响台词的新 take；保留原无声画面与配乐轨，按实际时长重新检查对白窗口和混音。
