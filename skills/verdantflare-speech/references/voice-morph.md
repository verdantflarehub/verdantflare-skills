# 实验性参考声线融合

## 1. 适用范围

用于用户明确要求“以 A 声音为主，融入 B 的音色，形成新参考”的候选试验。已有同文声谱融合参考成功登记并生成另一句文本的技术案例；尚无通用身份融合模型或稳定性听审保证。只借鉴语气与节奏时用[旁白方向](narration-direction.md)，普通录音复用用[新声线登记](new-voice.md)。

算法用 WORLD 分析同文音频，声学对齐后插值声谱包络与非周期成分，保留主声音音高曲线、时序和清辅音。权重是声谱插值权重，不是“某人占多少”的身份相似度。可能产生声码器感、错对齐与背景音乐残留；不支持自然语言指定年龄、性别、多个身份比例或自动音色验收。

## 2. 准备匹配的源

优先复用两种 voice profile 已有的相同文本 `original.wav` 与实际 `generation.json`。没有同文音频时，在用户已授权的试音范围内经 Studio 为两种声音生成同一句短文，分别保存原任务和产物。现有录音内容不同不能直接拼接当作同文输入；不得改写 provenance 来通过检查。

选择完整、清楚、无配乐的同文说话源。工具目前只接受 1–15 秒、相同采样率、单声道 PCM16/24 WAV；以原产物摘要核对 generation.json。默认保留全部原件。技术通过不证明输入的错漏词、实际对齐或音色正确，仍需试听。

## 3. 在开发环境制作

`scripts/morph_voice_reference.py` 是复用工具，不是新 MCP 接口。依赖 `numpy/scipy/soundfile/pyworld`，运行前检查已授权 5090 dev 执行环境中的实际版本；技能不自行安装系统包、启动服务或重建镜像，本机只做静态和单元测试。

在有依赖的开发执行环境中运行，输入已核验的同文源，输出目录必须全新：

```sh
python3 scripts/morph_voice_reference.py \
  --base source-a/original.wav \
  --base-generation source-a/generation.json \
  --donor source-b/original.wav \
  --donor-generation source-b/generation.json \
  --weight 0.35 \
  --out morph-candidate-v1
```

`0.35` 是一个候选试验值，用户有指定就沿用，不固定所有任务采用此值或生成多档。脚本拒绝不同文本、摘要不符、静音、采样率不一致、无共同浊音和覆盖旧目录；不自动重采样或补齐源内容。音高分析范围为 65–450 Hz，不承诺高音演唱或极端表演。

输出 `reference.wav` 和 `morph-report.json`，记录源 SHA-256、任务 ID、真实依赖版本、参数、对齐成本、源/输出满幅、时长及 pending 听审状态。保持主声音采样数；只衰减到最多 −3 dBFS 的余量，不通过降音量宣称修复源削波。失败时保留诊断，不把部分输出当作成功候选。

## 4. 登记与跨文本验证

先试听候选的可懂度、清辅音、声码器感与音色方向。沿用用户已授权的试音范围可继续技术验证，但不自动选用为全片声音。按[新声线登记](new-voice.md)将参考、处理报告和 profile 保存到同一固定修订，以新 voice_id 回读，再用**另一句不同文本**生成试听。

记录原融合参考与新句的差异、自然度、错漏词和实际时长；跨文本能推理不等于稳定新身份。没有听审依据保持 candidate/pending，不训练或发布虚假 World 权重，不覆盖原 A/B 声线及其已选对白。
