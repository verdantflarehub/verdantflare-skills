# 剧组专员接单与回交

## 1. 接单与读取

从派单读取项目、委托号、轮次、输入修订、接收方、期限、允许变更和必须保留的条件。按引用打开实际文件，以任务号和修订确认接单。前一轮 Session 的回忆和其他作品的候选需回查来源才能使用。资料缺失时报告具体字段与被阻塞的步骤。

## 2. 试作与质检

保存首件或可复看的实质进展。在本单内完成专业工作流，导演明确的要求若需改变，提交带证据的建议。工艺咨询指明候选文件、时间码或图像区域，将意见附回同轮，由承接人登记是否采纳。保留原候选，局部返修只修改指定内容并复核其余约束。

## 3. 汇报与停止

按派单期限累计主动工时、单列外部任务等待时间。接单、可比首件、质检、重大阻塞和超期风险均回写任务。本单等待人工决定时停止生产并暂停主动工时。连续两次修正同一缺陷仍失败时交回两次证据与可选处置。角色设计首轮缺少显式时限可采用 5 分钟接单检查、15 分钟无进展检查、30 分钟首件及 60 分钟主动工时上限；其他专业依任务工作量约定。

## 4. 写回与恢复

用项目实际支持的受控服务和当前任务身份提交进展、候选和质检。提交保存项目修订、委托号、轮次、输入来源、可审文件及版本、缺陷与接收方。允许选用的角色和真实决定由项目记录核验。受控写入尚未接通的宿主只产出工作副本及待提交清单，标明尚待正式登记。断线先查询原任务及原生运行号。改派后的旧候选关联原轮次。项目同步契约见[Project / World 接入规则](project-world.md)。
