# 按文档主类型编写与重构（02.author-doc）

## 1. 输入与输出

- **输入**：待新建、实质修改或结构重构的 Markdown 目标文件路径、所在仓库及目录的 `AGENTS.md` 契约、原始素材或业务上下文。
- **输出**：符合对应文档主类型必填字段、章节结构与通用排版规范的 Markdown 文档，以及交由 [01.format-check.entrypoint.md](01.format-check.entrypoint.md) 验证的明确交付清单。
- **公共约束**：遵循 [00.common.rules.md](00.common.rules.md) 中的规则优先级、标题分层、顶格代码块与表格及链接规范。

## 2. 分类

文档兼有多种职责时只确定一个主类型，其余职责通过相对链接拆到对应类型的独立文档。每次任务按主类型只加载对应的一份主题专册：

| 路径与内容特征                                   | 主类型与主题专册              |
| :----------------------------------------------- | :---------------------------- |
| `README.md`；用途、快速开始、常用操作、目录导航  | [README 规范](readme.md)      |
| `docs/plan/*.plan.md`；负责人、任务清单、勾选    | [计划文档规范](plan.md)       |
| `docs/changes/change_*.md`；执行记录、验证证据   | [变更文档规范](change.md)     |
| `docs/reviews/review_*.md`；架构与工程细节评审   | [研发评审规范](rd-review.md)  |
| `docs/acceptance/accept_*.md`；锁卷与验收锚点    | [研发验收规范](acceptance.md) |
| `docs/bugs/bug_*.md`；现象、复现、根因、修复验证 | [缺陷文档规范](bug.md)        |
| `skills/*/SKILL.md` 及 `references/`；触发与流程 | [技能文档规范](skill.md)      |
| 多轮素材持续评审；待审/不合格标记、媒体预览表格  | [评审文档规范](review.md)     |
| 其他 `docs/*.md`；背景、方案、契约、取舍、研究   | [设计文档规范](design.md)     |
| 以上均不适用的稳定新文档类型及跨类型规范沉淀     | [业务规范沉淀](business.md)   |

## 3. 工作流

1. **前置取证与主类型判定**：先核对目标文件相对路径，再核对文首元数据（负责人、助手、状态、YAML front matter）与章节特征；路径与内容特征矛盾时以实际内容为准并在交付说明写明判定依据。
2. **仓库契约与基线探针**：读取目标仓库及目标目录 `AGENTS.md`，记录强制模板、脚本同步区域与媒体表格契约；编辑存量文件前先运行 `md_format.py --check` 记录原始格式化状态。
3. **加载唯一主类型专册**：从上表加载对应的一份主题专册，记录原有改动、代码块内容、链接锚点及生成器契约；生成文档优先修改来源再重新生成。
4. **编写与结构重构**：按目标业务规范组织内容并落盘；三层及以上嵌套列表、列表内长段落/代码块/表格改用连续编号标题承载，超宽文字表格缩词/移说明至表下/改列表。
5. **交接格式化与验收**：转 [01.format-check.entrypoint.md](01.format-check.entrypoint.md) 执行 Prettier 格式化、差异复核与 `check_md.py` 量化检查；涉及人工检查点时交付已落盘、已 Format、已检查版本。

## 4. 规范

- 仅在新增或实质修改、长列表重构或缩进排查时应用全套重构；仅改错字与链接时不顺带重排全文。
- 格式化处理排版，不代替事实核验或章节设计；不把文档整理扩展为业务设计重做或全仓重排。
- 发现稳定新文档类型或跨仓库通用规范时，按 [business.md](business.md) 的分层原则与五项必备信息沉淀，只影响单个项目的规则写入该项目规则而不写入本技能。

## 5. 验收

- 文首元数据、必填章节（如“当前依据”集中列表）与内容职责满足对应主类型专册要求。
- 通过 [01.format-check.entrypoint.md](01.format-check.entrypoint.md) 的 `md_format.py --check` 与 `check_md.py` 零错误门禁。
- 仓库内相对链接与锚点有效，无本机盘符或 `file://` 路径泄露；人工审阅前未以格式化前草稿冒充最终交付版。
