## 1. 当前依据

- [技能入口](../SKILL.md)：工具命令入口。
- [执行流程](01.base-workflow.md)：落盘后格式化与复核闭环。

- [check_md.py](../scripts/check_md.py)、[md_format.py](../scripts/md_format.py)、[test_verdantflare_markdown.py](../scripts/test_verdantflare_markdown.py)：量化检查与回归测试实现。

## 2. 测量流程

交付审阅或最终提交前，按以下顺序对本次明确文件列表执行测量并记录输出：

1. **Prettier 格式化一致性检查**：运行 `python -X utf8 scripts/md_format.py --check <files...>`。退出码 `0` 表示格式化结果稳定；退出码 `1` 表示存在未格式化差异；退出码 `2` 表示未探测到可用 Prettier（须在交付报告中如实标记“Format 未完成”）。
2. **结构量化检查**：运行 `python -X utf8 scripts/check_md.py <files...>`，输出每条问题的行号、级别（`E` 错误 / `W` 警告）、规则代号与原因，汇总 `PASS` 或 `FAIL`。
3. **脚本同步区复核**：目标文档含生成脚本同步区域时，执行目标仓库对应的 `--sync-md-only --dry-run` 或预览检查，确认匹配标签未受损。
4. **技能自身回归（仅修改本技能时）**：运行 `test_verdantflare_markdown.py` 单测、`verdantflare-meta-skill` 的 `lint_skill.py lint --style numbered` 及 `install.py` 哈希比对。

## 3. 文字评分规则与数据判据

### 3.1 文字评分规则

- **结构与层次**：长内容由连续编号标题承载，不出现多层列表套列表再套代码块的深层缩进；独立代码块与表格顶格书写，归属关系清晰。
- **源码与预览可读性**：文字表格仅放简短索引或对照，详细说明放在表下；媒体表格满足两行等宽与点击直跳要求。
- **完整性与可移植性**：文首元数据与必填章节符合对应类型专册要求；仓库内相对链接与标题锚点有效，无本机盘符或 `file://` 路径泄露。

### 3.2 数据判据与门禁阈值

量化阈值唯一定义于 [check_md.py](../scripts/check_md.py)：

| 规则代号         | 级别 | 量化判据与阈值                                                      |
| :--------------- | :--- | :------------------------------------------------------------------ |
| `eol-crlf`       | `E`  | 跨平台统一使用 `LF (\n)` 换行符，文件中 `\r`（`CR/CRLF`）数量为 `0` |
| `list-depth`     | `E`  | 列表嵌套深度 `<= 2`（`MAX_LIST_DEPTH = 2`）                         |
| `table-columns`  | `E`  | 文字表格列数 `<= 4`（`MAX_TABLE_COLUMNS = 4`；媒体表格豁免）        |
| `table-width`    | `E`  | 文字表格格式化行宽 `<= 120` 显示列（全角计 2；媒体表格豁免）        |
| `table-br`       | `E`  | 表格单元格内 `<br>` 标签数为 `0`                                    |
| `heading-number` | `E`  | 一级标题不编号；启用编号的文档二级起按 `1.`、`1.1` 连续递增不跳级   |
| `broken-link`    | `E`  | 本地相对链接目标文件存在（断链数为 `0`）                            |
| `local-path`     | `E`  | 正文与链接目标中盘符路径或 `file://` 出现次数为 `0`                 |
| `block-in-list`  | `W`  | 列表项内嵌代码块或表格提示警告，仅强制模板或步骤内必要代码块可保留  |
| `anchor`         | `W`  | Markdown 标题锚点未命中提示警告，须核对目标标题或说明例外原因       |

此外，[评审文档](review.md)中交付预览的单文件视频体积严格 `< 18MB`（编辑器内置预览上限约 `20MB`）。任意 `E` 级错误 > 0 时 `check_md.py` 返回退出码 `1` 并判定 `FAIL`，必须清零后方可交付；`W` 级警告须逐条核实并在交付说明中写明保留理由。

## 4. 人工审阅与交付报告

静态检查与 Prettier 格式化通过只证明 Markdown 源码结构合规，不替代事实核验、编辑器 Markdown Preview 视觉效果确认或业务审批。

交付报告须如实区分并记录：本次交付文件清单、`md_format.py --check` 与 `check_md.py` 实测结果、保留的 `W` 级警告及例外依据、是否适用存量小改豁免，以及尚未完成人工预览或环境验证的事项。
