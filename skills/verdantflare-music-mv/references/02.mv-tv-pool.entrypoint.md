# verdantflare-music-mv：90 秒+ TV Version 素材池与 Omni 制作

## 1. 输入与输出

- **输入**：已批准 `90s+` 整曲 Master WAV（及可选分离人声干声 Vocals WAV）、角色主造型与换装清单、原作动漫/影视分镜致敬锚点、目标画幅（`9:16` 全屏 + 可选 `16:9` 漫画三联叠画）。
- **输出**：冻结人物五视图库（`CHAR-01`、`CHAR-02A`/`02B` 等）、共享纯场景空景母图库（`scenes/`）、含致敬锚点的 `storyboard.md`、逐镜专属审核目录（`shots/<GU_ID>/review.md`、`spec.json`、`output/`）、混合唇形同步特写镜与最终装配成片。
- **公共依据**：[公共规范](00.common.rules.md)、[公共验收与审核门](00.common.acceptance.md)、[Video Skill Google Flow 规范](../../verdantflare-video/references/google-flow.md)。

## 2. 分类

- **适用场景**：`90s+` 全长 TV Version 素材池模式（按 `2.5x–3x` 剪辑冗余比规划 `10s` 生成单元，分批过审再快切剪辑），或采用 **Google Omni Flash 1.2**（`route=google-flow`、`model=omni-1.2-flash`）的 30s/全长 MV 制作。
- **渠道降级分支**：仅当 `google-flow` 出现 502 / `channel_http_error` 等渠道故障且经用户明确授权临时切换时，沿用同一套输入切至 **Higgsfield Seedance 2.5 Draft**（`route=higgsfield`、`model=seedance_2_5_draft`、`mode=reference_to_video`、`resolution=480p`、`--price-ceiling 35`，账号并发上限 `1` 须串行提交，最多 4 图 + 1 视频，同样不传 `first_frame/last_frame`）。
- **混合唇形同步分支（Hybrid Lip-Sync）**：Omni 1.2 与 Seedance 2.5 不支持参考音频；2–3 个核心副歌正面唱词高光镜从批准 Master 截取精准人声干声（Vocals WAV）导入 Video MCP，走本地免费 `route=h3-fasth3`（`minimax-h3-ref2va`，传 `CHAR` 五视图 + 舞台空景 + `--audio-ref`，可选 `--regenerate-2k`）实现逐字精准对口型；其余舞台氛围/握麦特写/侧逆光/长元音爆发镜继续用 Omni 1.2 / Seedance 2.5 并在剪辑时卡拖音点短切。

## 3. 工作流

1. **五视图与纯景母图库冻结**：采用 `verdantflare-image-character` 统一五视图（上三格无头全身正/90°侧/背 + 下两格正脸/60°侧脸）冻结 `visualbible.md`；同角色换装（如校园日常 `CHAR-02A` / 球场短装 `CHAR-02B`）以已冻结主造型派生新五视图并单独审定。建立 `scenes/` 无人空景母图库，同空间不同时段/年代以首张母图经 `image.edit` 派生以锁死建筑几何。
2. **分镜与素材池规划**：在 `storyboard.md` 显式检索并规划 3–6 个原作 OP/ED 或漫画/剧集经典分镜致敬锚点；按 `2.5x–3x` 冗余比拆分 `10s` 生成单元；`9:16` 竖屏成片中，全屏单镜/舞台特写用原生 `9:16`，跨年代时空对照名场面用原生 `16:9` 制作三横屏竖排叠画（Triptych）。
3. **零遗漏 7 槽位输入核验与审核**：为每个单元建 `shots/<GU_ID>/review.md` 与 `spec.json`，按第 4 节 7 槽位逐项核对（总数 `<= 7 图 + <= 1 视频`），编写分秒景别节拍（`0–2.5s / 2.5–5.5s / 5.5–8s / 8–10s`），待输入侧过审后再渲染。
4. **渲染调用与下载落盘**：
   - 默认固定 `route=google-flow`、`model=omni-1.2-flash`、`upscale="1080p"`（0 积分免费超分，失败自动回退 720p），单段 `3–15s`，不传参考音频、`first_frame` 或 `last_frame`。
   - **CLI 实测约束**：图片须先经 `video_client.py import` 取得 Video 原生 `art_*` ID，再以 `--image-ref <video_art_id>=<purpose>` 绑定；`video_client.py generate` 在 MCP 模式下不接受 `--output`、`--watermark`、`--no-generate-audio`；异步返回 `video_task_id` 后先下载至 C 盘 `.tmp/` 再拷贝至 `.gdrive/`（防 Windows 跨盘 `os.replace` 报 `[WinError 1]`）。
5. **K09 分级、逐镜质检与成片封装**：完成[K09 分级](00.common.rules.md#5-生成后内容分级评估k09-强制步骤)与 1 秒 1 帧 `contact-sheet.png` 质检，过审入剪辑池。剪辑时静音内生音轨、从零时码挂载批准 Master WAV；若含“35mm 柯达胶片”等提示词，全屏单镜统一施加 `crop=iw*0.92:ih*0.92` 安全裁边防胶片打孔黑边（如 `KODAK 55`）再缩放至 `1080×1920`；预览与母版音轨优先用开源 **`libmp3lame`（MP3 `160k–256k`）**，避免 VS Code / Antigravity Electron 预览器报 `AAC codec can't be played`。

## 4. 规范

### 4.1 零遗漏 7 槽位参考传入矩阵

每个镜头在 `shots/<GU_ID>/review.md` 强制逐项核对（`reference_to_video` 最多 7 图，`video_editing` 最多 1 段 `>= 3s`、`<= 128 MiB` `.mp4` + 7 图）：

| 槽位                     | `purpose` 与职责说明                                                               |
| :----------------------- | :--------------------------------------------------------------------------------- |
| **Slot 1 主角五视图**    | `character`（必选）：有人物必传冻结五视图；换装须先派生并审定新五视图              |
| **Slot 2 次角五视图**    | `character`（按需）：仅 OTS/背影/前景虚化出现第二角色时传；严禁双正脸同框          |
| **Slot 3 纯场景空景**    | `scene`（强推荐）：取自 `scenes/` 无人空景母图库；跨时段由母图 `image.edit` 派生   |
| **Slot 4 关键道具**      | `prop`（按需）：跨镜固定物件（篮球、易拉罐、电车、复古立麦等）                     |
| **Slot 5 构图/光影锚点** | `style`（可选）：仅用于复杂机位或情绪光影定调，严禁悬空动态帧                      |
| **Slot 6 上镜尾帧衔接**  | `continuity`（按需）：同空间相邻镜头衔接时传入上一镜成片抽出末帧                   |
| **Slot 7 参考视频**      | `video`（可选，`video_editing`）：仅复刻运镜/动作节奏或精修原片时传 `>= 3s` `.mp4` |

### 4.2 核心禁忌与防误伤避词

- **严禁悬空/失衡动态静态关键帧**，且 `google-flow` 原生不接受 `first_frame` / `last_frame`。
- **严禁全程全身平拍**：10s 单元必须含局部特写与景别起伏。
- **开场/漫步氛围镜严禁无故转圈与突兀回头**：前奏或抒情漫步保持机位稳定（如脚步特写 + 纯背影前行），禁止塞入“环绕转一圈 + 突然回头看镜头”。
- **Google Flow 防安全过滤误伤避词**：涉及校园/运动短装人物时，Prompt 避免混用“18岁 / 少年 / 高中 / 猛力 / 汗珠飞溅”等易触发 `rejected before charging` 的字眼，改用“年轻青年 / 大学篮球馆 / 敏捷急停 / 眼神专注自信”等中性写实表述，外貌完全由冻结五视图锁定。

## 5. 验收

- **逐镜双门禁**：每个 `shots/<GU_ID>/review.md` 均具备完整 5 分区，先过“输入/提示词/参数审核”再渲染，再过 K09 分级与“输出视频审核”（预览 `< 18MB`、1 秒 1 帧接触表、记录抽帧数）后入剪辑池。
- **致敬与口型核验**：`storyboard.md` 含 3–6 个原作致敬锚点；核心副歌正面唱词高光镜通过 `h3-fasth3` 精准对口型，其余舞台镜无口型穿帮。
- **成片封装验收**：全片满屏无胶片打孔黑边、`libmp3lame` MP3 音轨可在内置预览器直接有声播放、Master WAV 零时码同步且过 Release Gate。
