# Music MV 人工审核门

审核状态为 `待审核`、`已批准`、`需修改` 或 `已否决`。工具成功、自动检查通过和 Agent 建议均不能代替用户批准。

## 人工审核载体

面向用户的审核 Markdown 是审核入口，必须在候选条目中直接呈现媒体，不能只列裸路径或要求用户自行寻找文件：

- 图片使用相对路径内嵌，并让预览图链接到原图；
- 视频优先使用当前 Markdown 渲染器支持的内嵌播放器，同时保留可点击文件链接作为回退；
- 每个媒体紧邻显示候选 ID、版本、对应时码、自动检查、审核重点和当前状态；
- 同一审核批次集中在一个 Markdown，机器状态继续以 Timeline、Artifact 和审核记录为事实源；
- 媒体尚未生成时明确显示“未开始”，不得用文字描述冒充可审核视觉结果。

## Director Gate

呈现 Treatment、Visual Bible、歌曲结构与主要资产版本。用户批准核心概念、人物与造型、场景、表演/叙事比例、摄影规则和禁用内容。

## Animatic Gate

提供挂载批准 Master 的全曲 Animatic、Shot Timeline 摘要和预计 H3 Generation Unit 清单。用户批准整片节奏、段落视觉职责、故事完整性、镜头覆盖和高成本生成范围。

## Shot Gate

先提交一个成本受控且能代表主要动态风险的 4 至 6 秒镜头。该镜头未通过时停止同类批量生成，不能用长镜头继续试错。

逐镜或按明确批次提供可播放候选、覆盖全时长的逐秒接触表、连续性上下文和自动媒体检查。每个候选必须以 1 倍速完整播放，并分别记录身份、表演、真实身体位移、动作周期、背景视差、相机轨迹、连续性、构图、节奏、技术和合规结论。首、中、尾三帧只用于定位问题，不能作为动态通过依据。用户选择候选、要求定向重做或否决镜头。

## Picture Lock Gate

提供所有 Shot 已解析到批准素材的全片预览。用户批准镜头顺序、入出点、转场、速度处理和画面锁定；此后只允许修正明确的技术交付问题，创作修改必须解除 Picture Lock 并记录原因。

## Release Gate

提供最终 Master 来源、主视频、字幕版、无字幕版、封面、媒体检查、权利清单和 provenance。完整播放确认无黑帧、错误重复、字幕越界、音频替换、编码错误或未批准素材后，用户才能批准发布包。

每次决定追加时间、审核门、版本、审核资产、自动检查、用户原始决定和批注，不改写历史。
