# 片场无人场景还原：分类与边界

## 1. 当前依据

- [技能入口](../SKILL.md)：范围、协作关系与按需读取路由。
- [规则约束](01.base-rules.md)：还原硬规则、固定建筑层与可变剧情层剥离、五向／链式共边锚定与案例参数边界。
- [验收标准](01.base-acceptance.md)：三层标注审计、九类失败案例拦截与候选排序准则。

## 2. 适用与不适用范围

### 2.1 适用任务

- **单镜剧照还原法（Single-View Clean Plate）**：给定影视剧某一固定机位、微动机位或大角度摇移镜头的连续视频帧，利用人物走动露出的相邻帧背景，剥离全部人物、可变剧情道具（含室外街道临时车马、平板车与扬尘）及常驻台标／水印，1:1 还原该机位的无人片场空景；当同一镜头内相机摇移超过 30% 画幅且首尾露出不同建筑节点时，按[大角度摇移镜头起落幅双锚点拆分规则](01.base-workflow.md#31-连续帧抽取长摇镜拆分与遮挡比对)分别还原起幅与落幅。
- **多视角空间扩展与闭合还原法（Multi-View Spatial Closure & Chain Extension）**：以已审定的实拍单镜无人母版为共边与材质锚点，按片场空间拓扑分为两类扩展子分支：
  - **拓扑 B1：围合空间正交五向闭合（Five-View Orthogonal Closure）**：针对四合院或单房间封闭片场，结合同片场不同时刻的广角帧、反打帧、过肩帧与高位俯拍帧，按四个水平正交方向＋俯视角逐向咬合共边闭合；其中俯视角按片场物理形态分为**室外／半室外院落含顶俯视（Outdoor Roofed Top-Down）**（保留四面屋顶瓦面、院心铺地与门外前场，如天龙聚贤庄）与**室内封闭房间无天花板剖面俯视（Indoor No-Ceiling Cutaway Top-Down）**（沿四壁顶沿水平剖去天花板与顶梁、仅留地面灯影光斑以展示四壁与器具闭合布局，如电锯惊魂密室浴室）。
  - **拓扑 B2：开放街区多节点链式共边扩展（Linear Street & Multi-Node Chain Extension）**：针对沿主街、广场或动线线性延展的开放街区片场（如三国安喜县街区），先对原片实拍的核心还原区（如两房一树、拴马桩、井亭、馆驿木门）逐镜完成单镜去人母版，再以核心区母版为共边与材质锚点，结合考据卡唯一解与三维白模底图，沿街区动线向两端或广场侧翼逐节点链式推进推断扩展区（如城门、市楼市肆、县署、开阔广场与全街漫游收口），核心还原区以外全部显式标“推断”。
- **原帧保真带演员关键帧（Frame-Locked Actor Keyframe）**：在已还原无人场景或指定原帧基础上，遵循“只换面孔，天空／顶棚、植物／管线、材质、服装、姿势、位置一律按原帧”的还原硬规则，将目标演员正面半身身份照与无头服装三视图合成为带演员静帧。

### 2.2 排除边界

- **不做三维几何重建**：本技能产出二维多视角静帧参考，不直接修改 Blender `.blend` 网格、相机矩阵或材质节点；三维白模拟合归 `verdantflare-blender`。
- **不做动态视频生成**：本技能不调用 H3、Seedance、Omni 等视频模型；视频任务须在静帧获人工审定后另走 `verdantflare-video`。
- **不代签人工审美与母版选型**：AI 助手只对候选做客观规则核对与分数倒序展示，母版拍板权归用户（或经总导演核验后呈用户审定）。

## 3. 前置取证探针与任务分类判据

收到片场还原请求后，先对输入片源、已有母版与三维参考运行三项前置取证探针，并落盘结构化取证记录：

1. **片源与有效画幅探针**：读取输入视频或序列帧的实际分辨率、帧率、宽高比及黑边／遮幅区间（例如 16:9 容器内嵌 `1440×1080` 4:3 画面或 `1920×958` 2:1 画面时，先实测上下／左右黑边像素并裁切有效画幅，严禁把黑边或烧录字幕遮罩黑条送入生图模型）。
2. **连续帧位移、大摇镜拆分与遮挡探针**：先判定该镜头属于固定／微动机位还是大角度横摇／跟移长镜头（若首尾视场重叠低于 70% 且露出不同建筑节点，必须先拆为起幅 `Start Plate` 与落幅 `End Plate` 两个独立机位锚点）；随后在各锚点主帧前后抽取同机位连续帧序列（按 0.5 秒或关键动作位移采样），比对前景人物／车马与背景建筑的相对运动，划分“主帧直接可见区 `V`”“相邻帧真实露出区 `R`”与“全时段遮挡／盲区 `M`”，并按[固定建筑层与可变剧情状态层剥离规则](01.base-rules.md#21-固定建筑层与可变剧情状态层剥离规则)登记待清除剧情物与待归位／考据补入保留物。
3. **跨向共边、拓扑判定与白模规制探针**：盘点当前片场属于“围合四合院／室内单房间（走拓扑 B1 正交五向）”还是“室外开放街区／广场动线（走拓扑 B2 多节点链式共边）”，确认是否已有获批的核心母版、考据唯一解（及平面修订版本，如路中桩迁至广场侧前 `P2` 并缩放井亭至人体尺度）或三维白模参考；若引入白模截图作俯视、鸟瞰或街区扩展底图，必须先执行**白模建筑规制、外墙残块与沙盘底板预检**：
   - 检查建筑规制与最新审定平面是否一致（如四合院南墙仅唯一正门、单房间四壁闭合、街区广场拴马桩不在主路中线上且井亭符合人体尺度）。
   - 检查白模**外墙面以外**是否残留未清理的独立建筑体块、滑门导轨外延横条或穿墙管头，以及室外轴测／鸟瞰白模建筑模块外围是否垫有**带边界的灰色工作台底板（Studio Ground Plane）**；外延残块须在送入模型前剔除，外围灰色工作台底板须在提示词中显式指令替换为向四边无缝延展的全尺寸连续夯土街面或地面，严禁渲染出微缩沙盘底座切边。

按取证结果确定唯一执行分支：

| 任务分支                                   | 绑定下游流程                                                 |
| :----------------------------------------- | :----------------------------------------------------------- |
| 分支 A：单镜剧照还原（含长摇镜起落拆分）   | [单镜剧照还原流程](01.base-workflow.md#3-单镜剧照还原法流程) |
| 分支 B：空间扩展（五向 B1 ／ 街区链式 B2） | [空间扩展还原流程](01.base-workflow.md#4-空间扩展还原法流程) |
| 分支 C：原帧保真带演员                     | [带演员保真静帧流程](01.base-workflow.md#51-带演员保真静帧)  |

各分支触发判据：

- **分支 A（单镜剧照还原）**：针对单一机位主帧（或大摇镜拆分后的起／落幅锚点）去人去车马，且有同机位相邻连续帧可供遮挡比对。
- **分支 B（空间扩展与闭合）**：需将单镜核心无人母版扩展为整座围合片场的正交五向闭合空景（**拓扑 B1**），或以核心还原区为共边锚点沿开放主街／广场链式推进推断扩展区节点（**拓扑 B2**）。
- **分支 C（原帧保真带演员）**：已有指定秒点动作原帧及已审定演员半身照＋无头服装三视图，需在锁定背景与姿势下换脸出静帧。

## 4. 三层遮挡与脑补分区定义（含白模扩展节点降级映射）

所有单镜与空间扩展还原任务必须把画面划分为以下三层，并在标注板中用固定色框与标签分开展示，严禁把模型推断或白模扩展区域混充原片直接可见实证：

- **第一层：主帧真实可见区（`V1..Vn`，青色框 `#00e5ff`）**：仅限**以影视原片实拍帧为 `source_image`** 时，主帧未被人物、车马、字幕或台标／水印遮挡的原始像素区；必须 100% 保持原帧材质、色彩、构件数量与几何位置。
- **第二层：相邻帧／核心母版共边真实补全区（`R1..Rn`，绿色框 `#00e676`，配半透明绿底）**：实拍主帧被遮挡但在同机位相邻连续帧（或跨镜同框微调帧，如拴马桩镜头微调露出的相邻井亭檐角）中真实露出的区域；或在扩展视角中与已审定核心实拍母版直接同框咬合的共享建筑锚点区；必须以真实露出画面或已审定核心母版为准还原，禁止模型自由发挥。
- **第三层：模型补全／考据拓扑推断区（`M1..Mn`，橙色框 `#ff9100`，配半透明橙底）**：全时段被站立人群、车马、前景虚焦肩部、躺卧尸体与血泊或常驻台标遮挡的区域，经考据修订批准补入原片未直拍内部细节的区域（如在原片仅露四柱的井亭下按考据补入汉代木辘轳与水桶），以及核心还原区以外的所有跨视角／街区推断扩展区域；由模型严格沿周边已见纹理或已批准考据唯一解与审定白模平面延伸生成，并在标注图中显式标为“推断区／模型补全区”。
- **白模底图推断扩展节点的 `V/R/M` 强制降级映射规则**：凡以推断扩展区三维白模渲染图为 `source_artifact_id` 的节点（如开放街区的城门单层楼、市楼市肆、县署浅院、开阔广场 `P2` 布局与全县漫游总览），**严禁在标注板出现青框 `V`**；画面中与核心还原区已审定实拍母版直接咬合的共享构件（如共边入画的核心两房一树、`P2` 拴马桩本体、井亭外壳）最高只标**绿框 `R`（核心母版共边实证区）**，其余所有由考据卡唯一解与白模几何生成的扩展建筑、广场地面及考据升级构件必须 100% 标为**橙框 `M`（考据约束推断扩展区）**，且审阅图右下角标统一写 `内部样片 · 推断扩展`。
