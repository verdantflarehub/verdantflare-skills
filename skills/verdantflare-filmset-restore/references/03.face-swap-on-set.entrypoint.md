# 原帧保真带演员“只换面孔”静帧（03.face-swap-on-set）

## 1. 输入与输出

- **输入**：指定时间戳的动作原帧、该机位已审定的无人场景底板（Clean Plate）、已审定演员角色设定页（左胸部以上正面半身身份照＋右无头正／侧／背服装三视图）、Studio `project_id`。
- **输出**：2–3 张锁定原帧背景、姿势、位置与服装的“只换面孔”带演员关键帧候选原图、左右对照审阅板、K09 内容分级回执与 `manifest.json`。

## 2. 分类

适用于已有指定秒点动作原帧及已审定演员角色设定页，需要在 100% 锁定片场背景、光线、人物姿态、站位与服装形制的前提下，仅将原帧演员面部替换为目标演员身份（Frame-Locked Actor Keyframe）。

- 若尚未获得已审定的演员设定页（左半身照＋右无头服装三视图），先协同 `verdantflare-crew-character` 完成设定页制作与审定，审定前不出场景关键帧。
- 若需从有人原帧还原无人空景底板，先执行[单镜剧照还原](01.clean-plate.entrypoint.md)。

## 3. 工作流

1. **输入核验与资产绑定**：确认目标秒点原帧、对应机位无人底板及已审定角色设定页的 SHA-256 与 Studio `artifact_id`；严禁跨镜头混传外场参考图（如在室内或内院镜头混入外场马车与马匹）。
2. **多图参考编辑**：通过 `verdantflare-image` 的 `image.edit`（默认 `engine="codex"`、`model="gpt-image-2.6-sunburst"`、`resolution="2k"`、`quality="high"`、`background="opaque"`、`budget_limit="1"`），仅传入该镜原帧（`source_artifact_id`）、该镜无人底板与已审定演员设定页（`reference_artifact_ids`）。
3. **提示词约束**：声明只替换面部身份（及按审定设定页无头三视图对位服装），显式锁定天空／顶棚、植物／管线、材质、服装款式长短、人物动作姿势与空间站位一律按指定时间戳原帧事实执行，严禁凭文字剧本臆造动作。
4. **轮询、分级与审阅板交付**：轮询 `image.status` 与 `image.result`，校验尺寸与 SHA-256，实际看图调用 `image.rate_content` 提交 K09 分级（`rubric v1.0`），合成左右对照审阅板并经 `gdrive.py` 入库审计。

## 4. 规范

- **只换面孔与原帧姿态硬规则**：遵循[公共规则第 3 节](00.common.rules.md#3-还原硬规则a63--s4--a54--a77-铁律)第 5 条，服装款式长短、动作姿势与空间站位一律按原帧事实，严禁凭剧本将“扶持／坐倒”改画为“出掌／抱行”。
- **设定页版式前置约束**：引用的演员设定页必须为“左胸部以上正面半身照＋右无头正／侧／背服装三视图”，禁止以全身带脸三视图作为服装参考。
- **场景纯净度约束**：室内或内院镜头严禁混入外场马车、马匹或无关道具；背景与光线须与该镜无人底板及原帧保持一致。

## 5. 验收

按[公共验收](00.common.acceptance.md)核验像素尺寸、SHA-256 与 K09 分级回执，重点排查[失败案例六](00.common.acceptance.md#36-失败案例六带演员静帧的人物服装姿势或空间道具失真)（服装款式／帽冠／袖口、动作姿势与原帧一致、无混入外场车马），生成两列等宽审阅板并按客观评分倒序呈报用户审定。
