# 单镜剧照去人片场空景还原（01.clean-plate）

## 1. 输入与输出

- **输入**：原始视频片源或高保真连续抽帧图像、目标时间码区间、Studio `project_id`。
- **输出**：每个机位（或大摇镜起／落幅锚点）产出 2–3 张 100% 无人空景候选原图、1 张连续帧遮挡比对图、每张候选配套的“原帧／无人场景左右对照板”与 `V`/`R`/`M` 三层遮挡标注板，以及含请求参数／任务 ID／Artifact ID／SHA-256／K09 分级回执的 `manifest.json`。

## 2. 分类

适用于给定影视剧某一固定机位、微动机位或大角度摇移镜头的连续视频帧，利用人物走动露出的相邻帧背景，剥离全部人物、可变剧情道具（含室外临时车马、平板车与扬尘）及常驻台标／水印，1:1 还原该机位无人片场空景（Single-View Clean Plate）。

- 若同一镜头内相机摇移超过 30% 画幅且首尾露出不同建筑节点，按本入口第 3.1 节拆为起幅 `Start Plate` 与落幅 `End Plate` 分别还原。
- 单镜核心母版审定后，如需构建整座围合片场五向闭合（拓扑 B1）或开放街区多节点链式扩展（拓扑 B2），转入[空间扩展与闭合](02.space-closure.entrypoint.md)；需制作带演员保真静帧转入[带演员只换面孔静帧](03.face-swap-on-set.entrypoint.md)。

## 3. 工作流

### 3.1 连续帧抽取、长摇镜拆分与遮挡比对

1. **有效画幅裁切**：先按[公共规则第 1 节](00.common.rules.md#1-排除边界与前置取证探针)实测片源黑边并裁切有效画面区（如聚贤庄从 `1920×1080` 裁切 `[240, 0, 1680, 1080]` 得 `1440×1080` 4:3 有效区；密室从 `1920×1080` 裁去上下黑边 `y=61..1019` 得 `1920×958` 2:1 有效区），计算并记录主帧与参考帧的 SHA-256。
2. **大角度摇移镜头起落幅双锚点拆分（Start/End Keyframe Split）**：当同一镜头内相机发生超过 30% 画幅的水平／垂直大幅横摇或跟移、且首尾画面视场重叠低于 70% 并露出不同建筑节点（如从馆驿内堂坐榻大幅右摇至出入木门，或从两房一树大幅右摇至开阔广场拴马桩）时，**严禁将无视场重叠的首尾帧混作同一固定机位的相邻补全帧**，必须拆分为**起幅锚点（Start Plate）**与**落幅锚点（End Plate）**两个独立单镜节点，分别在其起幅时间窗与落幅时间窗内抽取同段相邻连续帧独立还原。
3. **连续帧采样与比对**：在各机位锚点主帧前后区间抽取连续帧（如间隔 0.5 秒或沿微动／走位节点采样），逐帧比对人物与临时车马位移：
   - 找出主帧未被遮挡的基线区域，登记为 `V1..Vn`（青框 `#00e5ff`）。
   - 找出主帧被人物或车马遮挡、但在同机位相邻帧随人物移动或镜头微调而真实露出的建筑／工业构件（如花台立腿、矮石凳左腿、浴缸凹龛角、壁挂洗手盆、淋浴明管、石桩下段麻绳或微调同框露出的相邻井亭飞檐角），记录对应露出帧的时间戳与坐标框，登记为 `R1..Rn`（绿框 `#00e676`）。
   - 找出整个时间窗内始终被站立人群、临时车马、前景虚焦过肩人物、躺卧尸体／血泊或常驻台标遮挡的区域，以及按批准考据修订补入亭／龛内部的推断构件区，登记为 `M1..Mn`（橙框 `#ff9100`）。
4. **生成连续帧比对板**：将主帧与提供 `R` 区的相邻关键帧拼合为“连续帧遮挡比对图”，在图中框出 `V`、`R`、`M` 区域并配文字说明。

### 3.2 多图参考导入与 GPT Image 2.6 编辑

1. **受控导入或复用原生 Artifact**：通过 `verdantflare-image` 的 `image.import` 导入主帧与提供 `R` 区的 1–2 张关键相邻帧（若已是 Studio 原生图像 Artifact 则直接复用其 `artifact_id`，避免大体积 PNG 重复上传触发 `HTTP 413`）。
2. **构造 `image.edit` 请求**：
   - `source_artifact_id`：绑定主帧有效区 Artifact。
   - `reference_artifact_ids`：按顺序传入提供 `R` 区真实画面的相邻帧（及必要时对齐下墙规制的白模）Artifact。
   - 渠道与规格：默认 `engine="codex"`、`model="gpt-image-2.6-sunburst"`、`resolution="2k"`、`quality="high"`、`background="opaque"`、`budget_limit="1"`，画幅 `aspect_ratio` 选择与有效画幅最接近的标准枚举（`4:3` 或 `16:9`）。
   - 提示词：按片场类型选择[公共规则第 4 节](00.common.rules.md#4-还原硬规则提示词七段结构室外室内双分支)的室外或室内七段式模板，显式指明从第几张参考图恢复哪一处 `R` 区构件、按固定与可变层剥离规则清除人物与临时车马并保留固定收束麻绳／归位锁链或考据批准的汲水装置，并为 2–3 张候选附加聚焦点微调后缀。
3. **轮询、校验与内容分级**：按 `task_id` 轮询 `image.status` 与 `image.result`，下载产物并校验 SHA-256；实际查看每张生成图后调用 `image.rate_content` 提交 K09 分级（`general` 或 `nsfw`，`rubric_version="rubric v1.0"`）。

### 3.3 中断恢复与局部返修

- **任务超时恢复**：`image.edit` 超时或连接中断时，读取本地 `*-submit.json` 中的 `task_id` 调用 `image.status` 与 `image.result` 取回结果，严禁更换幂等键重复提单。
- **局部结构修正**：发现局部建筑规制或残块错误（如旧白模残留导致双门楼、外墙外延导轨短棍、过肩虚焦区双洗手槽增生）时，直接以该候选原生 `artifact_id` 为 `source_artifact_id`、以正确拓扑图或单器具母版为 `reference_artifact_ids` 局部修正，并用 `gdrive.py remove --apply` 清理无引用的被替代旧版。

## 4. 规范

严格执行[公共规则](00.common.rules.md)全部六条还原硬规则、固定建筑层与可变剧情状态层剥离规则及七段式双分支提示词规范；核心实拍还原图右下角标统一写“内部样片”，严禁把案例裁切框或帧号硬编码为默认值。

## 5. 验收

按[公共验收](00.common.acceptance.md)运行 `build_clean_plate_boards.py` 生成 1:1 对照板与 `V`/`R`/`M` 三层标注板，对照九类典型失败案例逐项核查并完成 100 分制客观排序，执行 `md_format.py`、`check_md.py` 与 `gdrive.py audit`，停在人工母版审定门禁。
