# 围合五向闭合（B1）与开放街区链式扩展（B2）（02.space-closure）

## 1. 输入与输出

- **输入**：已获人工审定的实拍单镜核心无人母版、同片场广角／反打／过肩／高位俯拍原帧、经预检的三维白模底图与考据唯一解（及最新审定平面）、Studio `project_id`。
- **输出**：按正交五向（拓扑 B1）或开放街区各节点（拓扑 B2）逐向／逐节点产出的 2–3 张无人空景候选原图、配套对照板与 `V`/`R`/`M` 三层标注板（白模扩展节点执行强制降级映射）、`manifest.json` 与客观量化排序表。

## 2. 分类

以已审定的实拍单镜无人母版为共边与材质锚点，按片场物理拓扑严格分为两类，严禁对开放街区强套四面围合墙命名：

- **拓扑 B1：围合空间正交五向闭合（Five-View Orthogonal Closure）**：适用于四合院或单房间封闭片场，按四个水平正交方向＋俯视角逐向咬合闭合；俯视角分**室外／半室外院落含顶俯视（Outdoor Roofed Top-Down）**（保留四面屋顶瓦面、院心铺地与门外前场，如聚贤庄）与**室内封闭房间无天花板剖面俯视（Indoor No-Ceiling Cutaway Top-Down）**（沿四壁顶沿水平剖去天花板与顶梁、仅留地面灯影光斑以展示四壁与器具闭合布局，如密室浴室）。
- **拓扑 B2：开放街区多节点链式共边扩展（Linear Street & Multi-Node Chain Extension）**：适用于沿主街、广场或动线线性延展的开放街区片场（如安喜县街区）；先完成原片实拍核心还原区单镜母版，再沿动线逐节点链式推进推断扩展区，核心还原区以外全部显式标“推断”。

## 3. 工作流

### 3.1 拓扑 B1：围合空间正交五向闭合流程

建立正交五向坐标系（如室外院落“东向西、南向北、西向东、北向南、俯视”，或室内单房间“浴缸端 N、门侧 S、东墙 E、西墙 W、无天花板俯视”），严格按有向无环链式顺序推进（上游母版未定、下向不开）：

1. **方向一（基准面，如东向西 `E→W` 或北端 `S→N`）**：选原片信息密度最高的主机位完成[单镜剧照还原](01.clean-plate.entrypoint.md)，经人工审定选出**方向一母版**作为全片场第一张共边锚点。
2. **方向二（相邻正交面或主反打面）**：选取同框拍到共享边界的原帧为主帧，辅以同向相邻连续帧与**方向一母版**作为 `reference_artifact_ids`，锁死共享墙角、管线或地面材质。若主帧属于前景虚焦过肩反打（OTS）且截断了长条器具（如洗手槽、长桌），必须在提示词中显式声明该器具为单一数量、被遮挡端之外仅为干净墙面，严禁横向重复增生。
3. **方向三（正交立面或 180° 反打面）**：结合该向实拍原帧（或局部近景帧）与前两向已锁定母版，将同一墙面的南北／左右两段（如密室东墙北段淋浴区与南段镜面长槽区，或聚贤庄东廊与前景双长石凳）无缝咬合在同一立面内。
4. **方向四（第四面围合墙面）**：以该墙实拍原帧或两侧相邻方向母版联合夹逼生成，按空场景剥离规则移除倚靠墙边或浴缸沿的人物与散落衣物，并将固定锁链等归位至自然落地空环状态。
5. **方向五（俯视角 `Top-Down`）**：先对三维白模俯视底图执行**建筑规制与外墙外延残块预检**（剔除旧工程多余门楼、外墙以外伸出的滑门导轨横条或穿墙残块），再按片场形态分两类闭合：
   - **分支 5A：室外院落俯视**：分三档闭合——① 原片高位斜俯帧 1:1 去人底板锁定真实地面石板纹理；② 经预检的正俯视平面图加前四向母版生成 90° 垂直正俯视全院全景；③ 高空斜俯鸟瞰全院全景，将四面屋顶、院心铺地与门外前场一次收口。
   - **分支 5B：室内封闭房间无天花板剖面俯视（No-Ceiling Cutaway Top-Down）**：以经预检的无顶棚正俯视白模（`layout-top`）为 `source_artifact_id`，同时传入前四向水平母版与原片室内俯拍帧（提取地砖灰缝与顶灯反光），显式指令 **`NO CEILING / top-down architectural cutaway`**（不加天花板盖板、不加遮挡视线的横梁实体，仅保留冷蓝荧光等顶灯在地面瓷砖上的反射光斑，四壁顶沿切口齐整闭合，外墙以外为纯暗背景且严禁伸出导轨或门外走廊），完整展示单房间四壁与四侧器具的平面闭合布局。

### 3.2 拓扑 B2：开放街区多节点链式共边扩展流程

1. **核心还原区（Core Restoration Zone）单镜去人锁定锚点**：先对原片有实拍镜头的全部核心节点（如 `C1` 两房一树、`C2` 拴马桩、`C3` 井亭、`C4` 馆驿出入木门）逐一完成单镜去人还原，锁死原片真实的屋瓦、夯土墙、木格栅、粗石桩形制（含桩身收束麻绳）、井亭与黄土街面材质色板，以及跨镜同框共边证据（如 `C2` 左前景露出的井亭飞檐角）。
2. **推断扩展区白模平面与沙盘底板预检**：对核心区以外沿主街延伸的推断扩展节点（如 `E1` 城门、`E2` 市楼市肆、`E3` 县署、`E4` 开阔广场与全县漫游收口），先核对三维白模是否已对齐最新审定平面与尺度（例如馆驿门前为黄土开阔广场、井亭在广场右前方并缩至人体尺度、拴马桩位于井亭左前方约 4 米的 `P2` 位且不在主路中线上）；同时检查轴测／俯视白模外围的灰色工作台底板，在提示词中强制要求将其替换为延伸至画框四边的全尺寸连续黄土广场与街面（消除微缩沙盘底座切边）。
3. **共边参考绑定与画外地标视锥隔离**：各扩展节点以经预检的白模底图（或同集外围镜头原帧）为 `source_artifact_id`，将相邻核心区母版（如 `C1` 两房一树、`C2` 拴马桩、`C3` 井亭）传入 `reference_artifact_ids` 锁定共享构件与材质；若当前机位已越过某核心地标（如相机越过两房之间的无叶树拍广场右前方的拴马桩与井亭，或大树仅位于上方两房之间而不在石桩旁），必须在提示词中显式声明**画外／异位地标负向排除**（如 `NO hallucinated tree beside the tethering post`），防止参考图中的大树被跟拍复制到石桩旁。
4. **`V/R/M` 降级标注与跨版本保留（核心区以外全部标推断）**：以推断扩展白模为底图的节点严格执行[公共规则第 2 节](00.common.rules.md#2-三层遮挡与脑补分区定义含白模扩展节点降级映射)的 `V/R/M` 强制降级映射（同框入画的核心区共享锚点标绿框 `R`，其余所有扩展建筑、开阔广场与考据构件 100% 标橙框 `M`，不标青框 `V`，右下角标统一写 `内部样片 · 推断扩展`）。当平面布局经新决议升级（如由旧 `P0` 路中桩升级为 `A77` 开阔广场＋`P2` 桩位＋人体尺度井亭）时，按新平面重做受影响扩展节点候选，变更文档中原候选标为“已被新决议取代”保留备查，不直接删除历史记录。

## 4. 规范

遵循[公共规则](00.common.rules.md)全部六条硬规则、室外／室内双分支七段式提示词与第 5 节防漂移规则，重点核查：

- 母版未定、下向不开；跨镜参考必须限定作用域并显式写入画外／异位地标负向排除。
- 室外白模底图必做灰色工作台底板消边指令；室内俯视白模必做外墙外延残块预检与无顶棚剖面指令。
- 推断扩展白模节点严禁在标注板出现青框 `V`，右下角标统一写 `内部样片 · 推断扩展`。

## 5. 验收

按[公共验收](00.common.acceptance.md)运行 `build_clean_plate_boards.py` 合成对照板与 `V`/`R`/`M` 标注板，重点排查失败案例三、四、五、七、八、九，完成 100 分制客观排序、K09 内容分级与 `.gdrive` 审计，每完成一个方向或节点须停在人工母版审定门禁后再开启下游。
