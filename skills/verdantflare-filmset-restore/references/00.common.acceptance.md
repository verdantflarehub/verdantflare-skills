# 片场无人场景还原：公共验收、失败排查与审阅板门禁

## 1. 测量流程与还原核对清单

提交候选给总导演核验或用户审定前，执行者必须先运行以下实测与看图核对并将结果记入变更或设计文档：

1. **字节、尺寸与分级探针**：核验下载图像实际像素尺寸、SHA-256 与服务端回执一致；确认全部候选已完成 `image.rate_content` 分级且状态为 `ok`。
2. **并排对照与三层标注合成**：运行 [build_clean_plate_boards.py](../scripts/build_clean_plate_boards.py)（启用上下／左右纯黑填充条自动检测裁切对齐及标签防溢出碰撞避让）生成 1:1 左右并排对照板与 `V`/`R`/`M` 三层遮挡标注板，实际打开图像逐区检查；白模底图推断扩展节点必须确认标注板**未标青框 `V`**（仅绿框 `R` 与橙框 `M`）。
3. **五项还原硬规则逐项实看核对**：
   - **天空／顶棚、光线与沙盘底板消边**：室外墙顶外及月洞门内上方纯净天空（无多余树叶远山、紧裁瓦檐未拉远补天空），室外白模灰底板已替换为连续夯土广场／街面（无沙盘切边）；室内保持原帧顶棚梁板与荧光灯管位置色温（无外窗天窗，室内俯视图彻底剖去天花板与横梁）。
   - **建筑立面、门牌、镜面与瓦顶／瓷砖**：室外瓦当、实心墙与毛石台基、浮雕圆饰（未穿洞）、门洞、柱联、素木牌（如“安喜”“市”）与无字本色布幌，或室内方格白砖、缺砖水泥块、暗反光镜面（未变外窗）、锈铁大门位置与原帧及考据唯一解一致。
   - **植物／管线、画外地标排除与固定陈设**：室外攀藤、盆栽品种、花台立腿、两房间唯一无叶乔木（已越过大树机位确认拴马桩旁无跟拍幻觉树），或室内角部粗立管、横管弯头、法兰、水箱心形涂记 `♡`、淋浴阀件（对照 `R` 区）完整还原，前景过肩遮挡区无单长槽复制成双联槽。
   - **家具／卫浴／桩亭器具、可变层剥离与地面铺装**：浅灰长石凳保持石材与双凳接缝（未变木凳），临时车驾、马匹、木轮车与扬尘 100% 清除，拴马桩下柱两圈松绳侧结与人体尺度井亭下石井台、木井栏、横轴木辘轳、木水桶按考据唯一解还原；室内尸体、血泊、手枪、散落衣物 100% 清除且固定锁链归位为自然落地空脚镣环（无铁球代理）；条石、方格地砖或开阔黄土广场连续贯通。
   - **建筑规制、平面位置与跨镜咬合**：五向或街区链式共边构件高度、颜色、数量一致，四合院南墙仅唯一正门、室内单房间四壁闭合且无外墙外延导轨残块、街区馆驿门前为开阔黄土广场（主路中线无桩，拴马桩在井亭左前方约 4 米的 `P2` 位，井亭符合人体尺度）。
4. **文档与 `.gdrive` 引用审计**：运行 `verdantflare-write-markdown` 的 `md_format.py`、`check_md.py`（0 errors、0 warnings）及 `verdantflare-meta-googledrive` 的 `gdrive.py audit`（`missing: 0, unmanaged: 0`），被替换且无引用的旧图已清理（或按要求在变更中标明“已被新决议取代”保留历史记录）。

## 2. 审阅板合成与 `.gdrive` 入库命令

每方向出图并完成看图自检后，调用 [build_clean_plate_boards.py](../scripts/build_clean_plate_boards.py) 生成左右对照板与三层遮挡标注板，再经 `gdrive.py` 入库并审计：

```text
python -X utf8 scripts/build_clean_plate_boards.py .tmp/work/v2-cand-01-board.json
python -X utf8 -m unittest discover -s scripts -p "test_*.py"
python -X utf8 ~/.agents/skills/verdantflare-meta-googledrive/scripts/gdrive.py --project . put /path/to/file.png --bucket pending --name <logical-path> --reason markdown-reference
python -X utf8 ~/.agents/skills/verdantflare-meta-googledrive/scripts/gdrive.py --project . audit --doc docs/path/to/doc.md
```

`board-spec.json` 包含 `canvas_size`、可选 `auto_trim_black_bars`（默认 `true`，自动检测并裁去模型在 `16:9` 容器下为 `2:1` 画面补出的上下窄黑边）、`source_image`、`clean_image`、`comparison_title`、`comparison_subtitle`、`comparison_output`、`annotation_title`、`annotation_subtitle`、`annotation_output`、`footer_lines` 及 `regions`（每项含 `tier: "V"|"R"|"M"`、`box: [x1,y1,x2,y2]`、`label`、可选 `tag_xy`）。

## 3. 九类已验证典型失败案例与预防检查表

以下九类失败案例来自天龙八部聚贤庄（一至六）、电锯惊魂密室浴室（五扩展与七）与三国演义安喜县街区（八与九）实战验证，出图后必须逐条对照排查：

### 3.1 失败案例一：天空被换成树林（或室内暗镜面被画成外窗）

- **现象与根因**：室外院墙上方或月洞门拱顶内侧纯净天空出现绿树林／树冠（如聚贤庄 S4 候选 01），或室内暗反光镜面被画成透光外窗；源于模型“墙外有园林”与“矩形框即窗户”先验。
- **预防检查**：室外显式写 `Do NOT add any trees, foliage, or mountains above the wall or inside the moon gate upper opening`；室内镜框写 `keep as an opaque dark tarnished mirror, NEVER an exterior window or skylight`。放大查天际线与镜面。

### 3.2 失败案例二：植物被换成绣球或擅自增删盆栽假山

- **现象与根因**：高石花台绿叶松柏盆景被换成白色绣球花，或空白墙裙／竹丛下多出花盆与假山石（如聚贤庄方向三候选 03）。
- **预防检查**：结合相邻帧 `R` 区锁定原盆景，点名写 `Do NOT replace green bonsai with white flowers or hydrangeas; do NOT add extra pots or rocks`。

### 3.3 失败案例三：浅灰石凳被换成木凳或反打丢失双凳

- **现象与根因**：前景两张浅灰石材长凳被画成褐色木凳，或 180° 反打只露单凳一角（如聚贤庄方向三候选 01、03）。
- **预防检查**：大写锁定 `TWO adjacent smooth pale-grey STONE benches placed end-to-end (NOT wood)`，反打必传方向一母版，将“双凳接缝完整可见”列为首选判据。

### 3.4 失败案例四：跨镜参考导致西墙南段石花台被搬到北段

- **现象与根因**：聚贤庄方向二（南向北）候选 02、03 将方向一母版左半场的石花台与矮石凳错搬到西墙北段圆饰与芭蕉之间。
- **预防检查**：跨向传参写明“参考图仅提取共边材质与端头构件；非重叠区保持原帧空白墙裙，严禁跨区搬移异侧道具”。

### 3.5 失败案例五：旧白模残留独立体块或外墙导轨外延导致双庄门／墙外短棍

- **现象与根因**：聚贤庄方向五鸟瞰首版南墙出现双庄门；密室方向五无顶俯视左下角外墙外伸出金属短棍；源于 Blender 白模未清理旧门楼体块或滑门导轨外延横条。
- **预防检查**：白模送入前必做建筑规制与外墙外延残块预检，提前裁除或在提示词显式指令移除外墙外侧突出物。

### 3.6 失败案例六：带演员静帧的人物服装、姿势或空间道具失真

- **现象与根因**：用全身带脸三视图代替“半身照＋无头三视图”，或服装长度、帽冠与原片不符；关键帧将“扶持／坐倒”画成“出掌／抱行”，或内院混入外场马车马匹。
- **预防检查**：设定页固定左半身照＋右无头三视图并附原片多秒点裁图；关键帧只传本镜相邻原帧与本镜无人底板，严禁混传外场参考。

### 3.7 失败案例七：前景虚焦过肩遮挡（OTS）导致长条器具横向重复增生

- **现象与根因**：密室方向二（`E4 / O6R3 n185`）左前景虚焦头肩截断白瓷长槽洗手盆 `C19` 左端，候选 01、03 周期延展出双联洗手盆，仅候选 02 保持单长槽与左侧空白白砖墙。
- **预防检查**：第 6 段大写声明 `ONE single white porcelain utility trough sink ONLY; to the left of this single trough sink where the blurred foreground shoulder was removed, show ONLY flat square white wall tiles, do NOT duplicate or add a second sink basin`；双盆增生直接扣 10–15 分降序。

### 3.8 失败案例八：相机越过核心地标后，参考图中的画外地标被跟拍幻觉重现

- **现象与根因**：安喜县机位越过 `C1`（两房一树）向前拍广场拴马桩与井亭时，传入 `C1` 母版诱发拴马桩旁凭空多出一棵幻觉树（早期 `N2-c1/c2` 退回）。
- **预防检查**：显式写相机视锥画外／异位地标负向排除（`CRITICAL: NO hallucinated tree beside the tethering post; the single bare tree exists ONLY in the 0.6m gap between the two houses / is behind the camera outside the field of view`）；焦点旁多出幻觉树扣 15 分降序。

### 3.9 失败案例九：室外轴测／鸟瞰白模外围“灰色工作台底板”诱发微缩沙盘切边

- **现象与根因**：安喜县鸟瞰／斜俯白模外围平坦灰底板被渲染为展厅微缩建筑沙盘底座（早期 `N2-clean`）。
- **预防检查**：第 4 段显式写 `Replace all flat grey studio ground plane outside the buildings with continuous full-scale compacted earth plaza/road and low walls extending seamlessly to all four frame edges; NO miniature maquette border, NO tabletop model base`。

## 4. 候选评分准则与审阅板交付门禁

每方向、每镜或每街区节点的 2–3 张候选按以下五项维度做 100 分制客观量化评分，按分数倒序排列呈报（不代用户拍板）：

| 评分维度与满分               | 核心通过指标与一票否决阈值                                                     |
| :--------------------------- | :----------------------------------------------------------------------------- |
| 人物／可变层与台标清除（20） | 人物、尸体、临时车马、血泊、散落衣物、水印清除率 100%；残留人体或台标一票否决  |
| `V`/`R` 区保真（25分）       | 天空无树、镜面不变窗、石凳不变木、长槽不重复、锁链／桩绳归位、桩旁无跟拍幻觉树 |
| `M` 区几何与降级标注（20分） | 墙裙、砖缝、条石与开阔黄土广场贯通，白模扩展节点禁用青框 `V`、100% 标推断 `M`  |
| 建筑规制、平面与共边（20分） | 单正门／四壁闭合／广场 `P2` 桩位与人体尺度井亭、无外墙残块、无微缩沙盘底座切边 |
| 影视质感与规格（15分）       | 尺寸与哈希校验一致、无多余黑边、光影贴合原片、标“内部样片”与 K09 `general`     |

扣分梯度细则：

- **`V`/`R` 区保真与可变层扣分**：石材变木质、双石凳漏为单凳、前景虚焦区将单长槽洗手盆重复增生为双联槽、跨区将石花台错搬或将画外大树幻觉搬到拴马桩旁，每项扣 10–15 分；残留室外临时木轮车或车马扣 6–10 分；门洞内上方出现小簇绿叶、竹下多出碎石或外墙外侧保留导轨短棍残块扣 4–5 分。
- **`M` 区几何、考据构件与沙盘切边扣分**：未按最新审定平面与考据唯一解还原（如拴马桩仍留路中 `P0` 未迁至广场 `P2`、井亭未缩至人体尺度或漏配横轴木辘轳与水桶）、白模外围出现微缩沙盘底座切边、地面网格明显扭曲或白模扩展节点违规标青框 `V`，每项扣 6–15 分。

审阅板交付版式契约：

- **两列等宽预览表**：在设计、评审或变更文档中展示对照板与标注板时，严格采用两列两行等宽表格——第一行放可点击图片 `[![编号](相对路径)](相对路径)`，第二行只放简短纯文本编号（如 `V2-C02-COMP`、`V2-C02-ANN`），详细分析与独立原图链接列在表格下方。
- **母版锁定与接力门禁**：报告客观排序与各候选差异后停在审阅门禁，待用户（或总导演核验后呈用户）选定某张候选为该方向母版后，再登记母版并启动下一方向或下游阶段。
