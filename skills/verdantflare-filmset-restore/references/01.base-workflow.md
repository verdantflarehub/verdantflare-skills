# 片场无人场景还原：执行流程

## 1. 当前依据

- [技能入口](../SKILL.md)：范围与审阅板合成工具入口。
- [分类与边界](01.base-category.md)：前置取证探针、三分支划分、五向围合（B1）／街区链式（B2）拓扑与 `V`/`R`/`M` 三层遮挡（含白模降级映射）定义。
- [规则约束](01.base-rules.md)：还原硬规则、固定与可变层剥离、提示词室外／室内双模板与链式防漂移要求。
- [验收标准](01.base-acceptance.md)：九类失败案例排查、候选评分排序与审阅板交付。

## 2. 前置条件与输入输出

- **前置输入**：原始视频片源或高保真抽帧图像、目标时间码区间、Studio `project_id`、当前已审定的相邻方向或核心还原区无人母版（空间扩展阶段）或角色设定页（带演员静帧阶段）。
- **标准输出**：每批次、每方向或每节点产出 2–3 张无人空景（或带演员）候选原图、1 张连续帧／跨镜咬合取证比对图、每张候选配套的“原帧（或白模底图）／无人场景左右对照板”与“三层遮挡标注板”、包含请求参数／任务 ID／Artifact ID／SHA-256／K09 分级回执的 `manifest.json`。

## 3. 单镜剧照还原法流程

### 3.1 连续帧抽取、长摇镜拆分与遮挡比对

1. **有效画幅裁切**：实测片源黑边并裁切有效画面区（如聚贤庄从 `1920×1080` 裁切 `[240, 0, 1680, 1080]` 得 `1440×1080` 4:3 有效区；密室从 `1920×1080` 裁去上下黑边 `y=61..1019` 得 `1920×958` 2:1 有效区），计算并记录主帧与参考帧的 SHA-256。
2. **大角度摇移镜头起落幅双锚点拆分（Start/End Keyframe Split）**：当同一镜头内相机发生超过 30% 画幅的水平／垂直大幅横摇或跟移、且首尾画面视场重叠低于 70% 并露出不同建筑节点（如从馆驿内堂坐榻大幅右摇至出入木门，或从两房一树大幅右摇至开阔广场拴马桩）时，**严禁将无视场重叠的首尾帧混作同一固定机位的相邻补全帧**，必须拆分为**起幅锚点（Start Plate）**与**落幅锚点（End Plate）**两个独立单镜节点，分别在其起幅时间窗与落幅时间窗内抽取同段相邻连续帧独立还原。
3. **连续帧采样与比对**：在各机位锚点主帧前后区间抽取连续帧（如间隔 0.5 秒或沿微动／走位节点采样），逐帧比对人物与临时车马位移：
   - 找出主帧未被遮挡的基线区域，登记为 `V1..Vn`（青框）。
   - 找出主帧被人物或车马遮挡、但在同机位相邻帧随人物移动或镜头微调而真实露出的建筑／工业构件（如花台立腿、矮石凳左腿、浴缸凹龛角、壁挂洗手盆、淋浴明管、石桩下段麻绳或微调同框露出的相邻井亭飞檐角），记录对应露出帧的时间戳与坐标框，登记为 `R1..Rn`（绿框）。
   - 找出整个时间窗内始终被站立人群、临时车马、前景虚焦过肩人物、躺卧尸体／血泊或常驻台标遮挡的区域，以及按批准考据修订补入亭／龛内部的推断构件区，登记为 `M1..Mn`（橙框）。
4. **生成连续帧比对板**：将主帧与提供 `R` 区的相邻关键帧拼合为“连续帧遮挡比对图”，在图中框出 `V`、`R`、`M` 区域并配文字说明。

### 3.2 多图参考导入与 GPT Image 2.6 编辑

1. **受控导入或复用原生 Artifact**：通过 `verdantflare-image` 的 `image.import` 导入主帧与提供 `R` 区的 1–2 张关键相邻帧（若已是 Studio 原生图像 Artifact 则直接复用其 `artifact_id`，避免大体积 PNG 重复上传触发 `HTTP 413`）。
2. **构造 `image.edit` 请求**：
   - `source_artifact_id`：绑定主帧有效区 Artifact。
   - `reference_artifact_ids`：按顺序传入提供 `R` 区真实画面的相邻帧（及必要时对齐下墙规制的白模）Artifact。
   - 渠道与规格：默认 `engine="codex"`、`model="gpt-image-2.6-sunburst"`、`resolution="2k"`、`quality="high"`、`background="opaque"`、`budget_limit="1"`，画幅 `aspect_ratio` 选择与有效画幅最接近的标准枚举（`4:3` 或 `16:9`）。
   - 提示词：按片场类型选择[室外庭院／街区或室内全封闭片场七段式提示词模板](01.base-rules.md#3-还原硬规则提示词七段结构室外室内双分支)编写，显式指明从第几张参考图恢复哪一处 `R` 区构件、按[固定与可变层剥离规则](01.base-rules.md#21-固定建筑层与可变剧情状态层剥离规则)清除人物与临时车马并保留固定收束麻绳／归位锁链或考据批准的汲水装置，并为 2–3 张候选附加聚焦点微调后缀。
3. **轮询、校验与内容分级**：按 `task_id` 轮询 `image.status` 与 `image.result`，下载产物并校验 SHA-256；实际查看每张生成图后调用 `image.rate_content` 提交 K09 分级（`general` 或 `nsfw`，`rubric_version="rubric v1.0"`）。

## 4. 空间扩展还原法流程

### 4.1 拓扑 B1：围合空间正交五向闭合流程

当需要把单镜无人场景扩展为四合院或单房间封闭片场的立体围合空间时，建立正交五向坐标系（如室外院落“东向西、南向北、西向东、北向南、俯视”，或室内单房间“浴缸端 N、门侧 S、东墙 E、西墙 W、无天花板俯视”），严格按以下链式顺序逐向推进：

1. **方向一（基准面，如东向西 `E→W` 或北端 `S→N`）**：选原片信息密度最高的主机位完成单镜剧照还原，经人工审定选出**方向一母版**作为全片场第一张共边锚点。
2. **方向二（相邻正交面或主反打面）**：选取同框拍到共享边界的原帧为主帧，辅以同向相邻连续帧与**方向一母版**作为 `reference_artifact_ids`，锁死共享墙角、管线或地面材质。若主帧属于前景虚焦过肩反打（OTS）且截断了长条器具（如洗手槽、长桌），必须在提示词中显式声明该器具为单一数量、被遮挡端之外仅为干净墙面，严禁横向重复增生。
3. **方向三（正交立面或 180° 反打面）**：结合该向实拍原帧（或局部近景帧）与前两向已锁定母版，将同一墙面的南北／左右两段（如密室东墙北段淋浴区与南段镜面长槽区，或聚贤庄东廊与前景双长石凳）无缝咬合在同一立面内。
4. **方向四（第四面围合墙面）**：以该墙实拍原帧或两侧相邻方向母版联合夹逼生成，按空场景剥离规则移除倚靠墙边或浴缸沿的人物与散落衣物，并将固定锁链等归位至自然落地空环状态。
5. **方向五（俯视角 `Top-Down`）**：先对三维白模俯视底图执行**建筑规制与外墙外延残块预检**（剔除旧工程多余门楼、外墙以外伸出的滑门导轨横条或穿墙残块），再按片场形态分两类闭合：
   - **分支 5A：室外院落俯视**：分三档闭合——① 原片高位斜俯帧 1:1 去人底板锁定真实地面石板纹理；② 经预检的正俯视平面图加前四向母版生成 90° 垂直正俯视全院全景；③ 高空斜俯鸟瞰全院全景，将四面屋顶、院心铺地与门外前场一次收口。
   - **分支 5B：室内封闭房间无天花板剖面俯视（No-Ceiling Cutaway Top-Down）**：以经预检的无顶棚正俯视白模（`layout-top`）为 `source_artifact_id`，同时传入前四向水平母版与原片室内俯拍帧（提取地砖灰缝与顶灯反光），显式指令 **`NO CEILING / top-down architectural cutaway`**（不加天花板盖板、不加遮挡视线的横梁实体，仅保留冷蓝荧光等顶灯在地面瓷砖上的反射光斑，四壁顶沿切口齐整闭合，外墙以外为纯暗背景且严禁伸出导轨或门外走廊），完整展示单房间四壁与四侧器具的平面闭合布局。

### 4.2 拓扑 B2：开放街区多节点链式共边扩展流程

当目标片场是沿主街、开阔广场或漫游动线线性展开的开放街区（如安喜县主街：核心实拍区＋推断扩展区）时，严禁强套四面围合墙命名，按以下四步链式推进：

1. **核心还原区（Core Restoration Zone）单镜去人锁定锚点**：先对原片有实拍镜头的全部核心节点（如 `C1` 两房一树、`C2` 拴马桩、`C3` 井亭、`C4` 馆驿出入木门）逐一完成单镜去人还原，锁死原片真实的屋瓦、夯土墙、木格栅、粗石桩形制（含桩身收束麻绳）、井亭与黄土街面材质色板，以及跨镜同框共边证据（如 `C2` 左前景露出的井亭飞檐角）。
2. **推断扩展区白模平面与沙盘底板预检**：对核心区以外沿主街延伸的推断扩展节点（如 `E1` 城门、`E2` 市楼市肆、`E3` 县署、`E4` 开阔广场与全县漫游收口），先核对三维白模是否已对齐最新审定平面与尺度（例如馆驿门前为黄土开阔广场、井亭在广场右前方并缩至人体尺度、拴马桩位于井亭左前方约 4 米的 `P2` 位且不在主路中线上）；同时检查轴测／俯视白模外围的灰色工作台底板，在提示词中强制要求将其替换为延伸至画框四边的全尺寸连续黄土广场与街面（消除微缩沙盘底座切边）。
3. **共边参考绑定与画外地标视锥隔离**：各扩展节点以经预检的白模底图（或同集外围镜头原帧）为 `source_artifact_id`，将相邻核心区母版（如 `C1` 两房一树、`C2` 拴马桩、`C3` 井亭）传入 `reference_artifact_ids` 锁定共享构件与材质；若当前机位已越过某核心地标（如相机越过两房之间的无叶树拍广场右前方的拴马桩与井亭，或大树仅位于上方两房之间而不在石桩旁），必须在提示词中显式声明**画外／异位地标负向排除**（如 `NO hallucinated tree beside the tethering post`），防止参考图中的大树被跟拍复制到石桩旁。
4. **`V/R/M` 降级标注与跨版本保留（核心区以外全部标推断）**：以推断扩展白模为底图的节点严格执行[白模扩展节点 `V/R/M` 强制降级映射规则](01.base-category.md#4-三层遮挡与脑补分区定义含白模扩展节点降级映射)（同框入画的核心区共享锚点标绿框 `R`，其余所有扩展建筑、开阔广场与考据构件 100% 标橙框 `M`，不标青框 `V`，右下角标统一写 `内部样片 · 推断扩展`）。当平面布局经新决议升级（如由旧 `P0` 路中桩升级为 `A77` 开阔广场＋`P2` 桩位＋人体尺度井亭）时，按新平面重做受影响扩展节点候选，变更文档中原候选标为“已被新决议取代”保留备查，不直接删除历史记录。

## 5. 带演员保真静帧与失败恢复

### 5.1 带演员保真静帧

在已审定的无人场景底图或指定动作原帧基础上，只传入该镜原帧、该镜无人底板及已审定演员设定页（左胸部以上正面半身照＋右无头正／侧／背服装三视图），严格保持原帧人物姿态、位置、服装与背景，仅替换面部身份。

### 5.2 审阅板合成与 `.gdrive` 入库命令

每方向出图并完成看图自检后，调用 [build_clean_plate_boards.py](../scripts/build_clean_plate_boards.py) 生成左右对照板与三层遮挡标注板（脚本内置上下／左右纯黑填充边自动检测裁切对齐、文字标签右边界钳制与垂直碰撞自动下移），再通过 `verdantflare-meta-googledrive` 的 `gdrive.py` 入库并审计：

```text
python -X utf8 scripts/build_clean_plate_boards.py .tmp/work/v2-cand-01-board.json
python -X utf8 -m unittest discover -s scripts -p "test_*.py"
python -X utf8 ~/.agents/skills/verdantflare-meta-googledrive/scripts/gdrive.py --project . put /path/to/file.png --bucket pending --name <logical-path> --reason markdown-reference
python -X utf8 ~/.agents/skills/verdantflare-meta-googledrive/scripts/gdrive.py --project . audit --doc docs/path/to/doc.md
```

`board-spec.json` 包含 `canvas_size`、可选 `auto_trim_black_bars`（默认 `true`，自动检测并裁去模型在 `16:9` 容器下为 `2:1` 画面补出的上下窄黑边）、`source_image`、`clean_image`、`comparison_title`、`comparison_subtitle`、`comparison_output`、`annotation_title`、`annotation_subtitle`、`annotation_output`、`footer_lines` 及 `regions`（每项含 `tier: "V"|"R"|"M"`、`box: [x1,y1,x2,y2]`、`label`、可选 `tag_xy`）。

### 5.3 中断恢复与局部返修

- **任务超时恢复**：`image.edit` 超时或连接中断时，读取本地 `*-submit.json` 中的 `task_id` 调用 `image.status` 与 `image.result` 取回结果，严禁更换幂等键重复提单。
- **局部结构修正**：发现局部建筑规制或残块错误（如旧白模残留导致双门楼、外墙外延导轨短棍、过肩虚焦区双洗手槽增生）时，直接以该候选原生 `artifact_id` 为 `source_artifact_id`、以正确拓扑图或单器具母版为 `reference_artifact_ids` 局部修正，并用 `gdrive.py remove --apply` 清理无引用的被替代旧版。
