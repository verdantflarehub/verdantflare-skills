# 全局安装与技能回归测试（03.install）

## 1. 输入与输出

- **输入**：本技能唯一维护源码目录、可选的 `--skills-root` 目标安装根（默认 `~/.agents/skills`）及覆盖确认开关 `--replace`。
- **输出**：同步至 `~/.agents/skills/verdantflare-write-markdown` 且逐文件 SHA-256 校验一致的全局安装副本，以及单元测试与技能静态检查全部通过的回归报告。
- **公共约束**：遵循 [00.common.rules.md](00.common.rules.md) 与 `verdantflare-meta-skill` 全局安装边界；仅维护本技能源码时执行，普通文档任务不顺带改造本技能。

## 2. 分类

| 运维场景         | 适用条件与行为                                                                     |
| :--------------- | :--------------------------------------------------------------------------------- |
| 首次全局安装     | 目标安装根下尚无本技能副本；直接复制并校验逐文件哈希                               |
| 同源覆盖更新     | 源码更新后同步至全局副本；副本与源码不同时先确认无仅存于副本的修改再加 `--replace` |
| 技能自身回归验证 | 修改本技能脚本、规则或专册后，执行单测、静态检查与安装一致性核验                   |

## 3. 工作流

在本技能源码目录运行依赖安装、回归测试与全局同步：

```text
python -m pip install -r scripts/requirements.txt
python -X utf8 -m unittest discover -s scripts -p "test_*.py"
python -X utf8 scripts/install.py [--skills-root ~/.agents/skills] [--replace]
```

1. **运行单元测试**：执行 [test_verdantflare_markdown.py](../scripts/test_verdantflare_markdown.py)，覆盖 `md_format.py` Prettier 探测/参数/豁免、`check_md.py` 全部量化规则与 `install.py` 安装校验。
2. **执行技能静态检查**：对本技能源码目录执行 `verdantflare-meta-skill` 的 `lint_skill.py lint <skill_dir> --style numbered`，并在不含兄弟技能的隔离副本中复验 `0 errors`。
3. **同步全局副本**：运行 [install.py](../scripts/install.py) 复制至 `~/.agents/skills/verdantflare-write-markdown` 并逐文件校验哈希；若副本存在差异，先确认无仅存于副本的修改再加 `--replace` 覆盖。

## 4. 规范

- 本技能源码只在仓库唯一维护源修改，安装副本不直接修改。
- 修改既有规则或阈值时必须同步检查 [check_md.py](../scripts/check_md.py)、[md_format.py](../scripts/md_format.py) 与 [test_verdantflare_markdown.py](../scripts/test_verdantflare_markdown.py)，保持入口、专册、范例与测试一致。
- 仅执行普通业务文档编写或格式化任务时，不顺带修改或重装本技能。

## 5. 验收

- `python -X utf8 -m unittest discover -s scripts -p "test_*.py"` 全部通过。
- `lint_skill.py lint <skill_dir> --style numbered` 在源码目录、隔离目录及安装目录均返回 `0 errors`。
- 安装副本与维护源码逐文件 SHA-256 完全一致（排除 `__pycache__` 与 `*.pyc`）。
