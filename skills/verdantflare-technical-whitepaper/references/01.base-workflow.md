# 技术白皮书与配图流程

## 1. 当前依据

- [分类与边界](01.base-category.md)：图的职责。
- [规则约束](01.base-rules.md)：图内文字与外置图例。
- [验收标准](01.base-acceptance.md)：交付检查。

## 2. 准备

读取当前需求与有效设计，恢复已有图源及人工反馈，区分有效决定与历史草稿。列出主体、功能、关系及证据，再决定图的类型。用户明确暂停绘图时停止该制作任务；整理技能不自动恢复原图制作。

## 3. 绘制与编排

先确定节点与连线结构，再定义业务色系、建设状态和阶段样式。已有结构足以表达架构时先出可审阅图，不为不影响结构的字段细节反复拖延出图。

将架构图、图名简介、状态说明与图例分别制作。图例每项使用实际样式的图块配解释，和正文一起编排。导出可查看的图片并保留可编辑源；图的修订同步文档引用和图例，不覆盖需保留的批准原件。

## 4. 检查与交付

实际查看最终导出文件，逐项检查架构语义与文字边界；再检查文档中的图题、简介、图例和状态是否与图一致。修改后只重验受影响内容。按项目规则保存素材，交付图片与包含说明的文档入口，明确未完成项。

视觉不合格时修改原图源再导出，不以新增另一张临时图充当原审阅入口。缺少用户决定时保留问题，继续独立工作；不重复索取已有批准，不把等待答复写成方案通过。
