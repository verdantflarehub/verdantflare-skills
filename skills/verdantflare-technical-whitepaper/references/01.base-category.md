# 技术白皮书与配图分类

## 1. 当前依据

- [技能入口](../SKILL.md)：能力与路由。
- [规则约束](01.base-rules.md)：图文分离与图例约定。

## 2. 总体架构图

回答谁使用系统、各业务主体负责什么、有哪些功能与协议、输入输出流向哪里。功能层次按实际设计表达，不以同机部署推导业务隶属关系。区分系统负责运营的外部对象、成果接收端和支撑依赖；具体摆放依用户指定或关系可读性决定。

## 3. 部署架构图

回答服务部署在哪里、服务器或集群边界是什么、容器和存储如何连接。业务独立与物理共址可以同时成立。保持与总体图的主体对应，不把业务依赖自动画成同一服务器内的组件。

## 4. 技术白皮书

将问题、方案、技术选型、接口、数据、部署、验证与待决事项组织成可审阅文档。按任务需要选择图，不机械扩充页数。图名、简介、图例和审核状态属于文档内容；具体技术栈、FAQ 与证据依据当前项目，不能从上一项目照搬。
