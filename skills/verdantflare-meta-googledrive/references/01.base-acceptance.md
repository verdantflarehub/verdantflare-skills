## 2. 测量流程与回归测试

每次完成素材入库、链接改写、旧版移除或技能脚本维护后，必须运行对应探针采集结构化 JSON 输出，不得凭印象判定通过：

1. **文档引用审计**：运行 `python scripts/gdrive.py --project '<project-abs-path>' audit --doc <target.md>`（全仓验收时运行不带 `--doc` 的 `audit`），采集 `missing`、`unmanaged`、`git_exempt`、`human_owned` 与 `references` 列表。
2. **内容摘要核验**：运行 `python scripts/gdrive.py --project '<project-abs-path>' verify`（大型流式目录传 `--key` 抽检本次变更项），采集 `verified`、`invalid` 与 `needs_review`。
3. **技能行为回归测试**：修改技能脚本或重装前，在技能目录运行单元测试：

```powershell
python -m unittest discover -s scripts -p test_gdrive.py -v
```

[test_gdrive.py](../scripts/test_gdrive.py) 覆盖软连接初始化与重复执行、旧目录接入与冲突拒绝、Windows `junction` 联接回退、直写入库与回执累积、Markdown 与 HTML 引用解析、Git 跟踪豁免、审计范围隔离、摘要核验、移除拒绝条件、人工目录保护、挂载缺失保护及全局安装备份保留。

## 3. 验收判据（文字规则与数据准则）

本技能按实际数据做通过/拒绝判定，不对素材画面美观程度评分：

### 3.1 引用完整性

- **文字规则**：处理范围内每条实际引用均指向存在的目标，且归属为助手受管目录（`assistant`）、人工素材目录（`human`）或 Git 跟踪文件（`git`）；扫描范围与不支持的语法须在交付报告中单独说明。
- **数据准则**：`audit` 报告中 `missing == 0` 且 `unmanaged == 0`（退出码为 `0`）。

### 3.2 内容完整性

- **文字规则**：素材入库复制前后字节内容完全一致，受管目录中无原地篡改文件、无中断半文件或未处理的云端冲突副本；发生冲突时保留原目标并报错终止。
- **数据准则**：`put` 复制前后 SHA-256 摘要一致；`verify` 报告中 `invalid == []` 且 `needs_review == []`（任一非空即以退出码 `1` 拦截）。

### 3.3 存储边界

- **文字规则**：本地 `.gdrive` 必须是指向远端项目目录的软连接，`managed/` 内不含任何无需同步的历史或临时杂项，移除旧版时不破坏任何现存文档引用。
- **数据准则**：`status` 返回 `mount_available == true` 且 `.gdrive` 解析为远端 `drive_target`；`.gdrive/managed/history` 不存在；`remove` 执行前目标 `key` 的全仓 Markdown 引用计数为 `0`。

### 3.4 云同步与多机验收报告口径

- **文字规则**：写入本机映射盘只证明本机可读，不能证明云端上传完成或第二台电脑下载完成；远端删除同样可能延迟同步，不能把本机删除成功当作所有设备已删除。
- **数据准则与报告区分**：仅在本机完成 `put/audit/verify` 时，只报告**“映射盘读写验证通过”**；只有等待客户端显示同步完成、在第二台电脑执行 `init` 后运行 `audit` 与 `verify` 并核对抽样 SHA-256 摘要一致，方可报告**“多机同步验收通过”**。

## 4. VS Code 预览验证

自动化回归使用 Node 18+ 与开发依赖 markdown-it 14.1.0；从 `resources/vscode-preview/` 执行 `npm install --ignore-scripts` 后运行 `npm test`，依赖及缓存不提交。目标仓库要求集中临时目录时用 `npm install --prefix <temporary-dir> markdown-it@14.1.0 --ignore-scripts` 并通过 `NODE_PATH` 指向其 `node_modules`。

- Node：真实回环 HTTP 覆盖令牌、Host、GET/HEAD、ETag、单段 Range、416、中文空格、目录联接与链接逃逸；真实 Markdown 解析覆盖可点击图片、HTML 媒体、实体和代码块保护。
- Python：执行原 `test_gdrive.py`，另覆盖确定性 VSIX 内容、XML、只读检查、互斥参数、CLI 失败传播和版本不符拒绝。
- 安装：`install.py --vscode` 成功后 `--check-vscode` 回读匹配版本；重新加载扩展宿主再验证桌面，不以安装完成推断当前运行版本。
- 桌面：单文件夹资源管理器无额外根目录；managed/output 图片与嵌套点击正常，HTML 音视频加载、播放和拖动正常；未放行 HTTP 时提示安全设置，用户选择后复验。控制链路不可用时明确标记未验证，不将自动化结果当作人工 CP 确认。
