# VerdantFlare 剧本审核

按用户指定范围审核剧本；已有项目先读取当前剧本版本、人物小传、来源与受影响的既有素材记录。原著事实、改编设定、已批准资产和审核建议分别标明，不能把建议写成已获批准的剧情。

审核完整剧本包时，同时核对[六类文档规范](../writing/script-package-standard.md)、包索引、实际版本和跨文档状态链；缺失必要设定按影响记录 P1。仅请求单稿审核时限定范围，不自动重写整个包。用户要求创作或返修时，用[完整剧本 Skill](../writing/guide.md)落实正文和关联设定的同步修改，复审可自行修复的发现后再交付。

审核时读取[剧本审核标准与记录模板](script-review-standard.md)。先确定用户交付的是分集大纲、逐镜提纲还是可供表演的完整剧本；完整剧本逐场检查内外景、地点、时间、站位、动作、独立说话者与台词/有意沉默、环境声和音乐 Cue 的进出。再核对镜号、时长、角色/道具/地点和版本等可验证事实，逐集检查观众可见的目标、阻碍、转折、集尾兑现以及跨集因果。AI 制作可行性只检查剧本阶段能判断的身份、造型、动作、可读文字、声音和素材依赖；实际表演与留存效果须由后续粗剪验证。

输出按严重度排列、带集/镜/行或版本引用的发现，说明影响、可执行返修方向及受影响下游。给出“可进入下一阶段 / 有条件进入不依赖部分 / 返修后复审”的建议结论；只有真实审核者记录的决定才可标为批准。用户只要求审核时保留输入剧本；用户要求改稿时另存新版本，复审新旧差异并更新引用。

本 Skill 不调用 Image、Video 或其他收费生成能力。审核通过后的导演计划交由 [Director Skill](../directing/guide.md)，影视资产与镜头制作交由 [Film Production Skill](../production/guide.md)。
