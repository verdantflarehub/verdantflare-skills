# 视频证据与时间定位

## 1. 不同分段含义

原片剪辑镜头、生成分段和镜内节拍分别记录。外部表格把一段称为 Shot，不代表原片在那里发生切镜；先读表格说明，保留其原义和来源行。生成分段可能只改变字卡、讲述重点或制作输入。镜内的主体动作、相机运动、图形运动同样分别判断。

验证切镜需查看边界前后真实画面；只有分段中间的一张图时，保留“剪辑边界未核验”。按实际证据建立对应，可以多对多，不能把每个表格编号强制映射成独立切镜。

## 2. 实际时间和覆盖

记录请求时间与解码实际时间。解码器返回邻近帧、视频起始时间和时间基准差异，可能导致请求秒数不等于读到的帧；两版对应以实际时间和可见事件共同确认。若需要精确到帧，使用已确认时基和帧索引，不能把四舍五入的秒数直接当精确边界。

中间采样可核对段落主题，不能证明连续运镜、完整对白或没有短切镜。对动态数值、过渡动画和快速字幕，观察单帧差异后先查看邻域；动画中的中间数字不自动等于目标值错误。图像序列覆盖全时段分布与完整视频内容已分析，是两种不同声明。

## 3. 分开原片、外部分析与重制

原片可能自带标题、箭头、气流、图形及引用；不能都判为拆解作者叠层。将标注版额外的时码、层级号、多轨时间线和重配音与原画分开。未听取音轨时，字幕只作为画面文本，不称为已核验逐字对白。

原表的精确角度、光流、音效和时间声明，按其说明区分测量、推断与制作设计。本轮未重新测量就保持“外部分析提供”。重制提示的时间与分析节拍不一致时保留两个版本及差异，不能从提示词反推原片事实。

## 4. 进入再创作与成果

按用户目标抽取结构和约束，替换主体、环境、人物关系、物件与节奏，再检查因果和连续性。产品机制讲解的分层方法不能自动套到剧情叙事；剧情中重复物件、反应与信息揭示需按实际事件组织。

交付正文、结构化分段及来源关系。未取得参考别名对应文件时写明依赖缺失；模型目录存在、参数匹配、实际生成和效果审核分别记录。二维图示、数值相机描述和空工作流文件不能作为真实 Blender 或 ComfyUI 工程。
