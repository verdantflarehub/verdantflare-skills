# 媒体参考完整拆解与方法学习（01.media-breakdown）

## 1. 输入与输出

- **输入**：原作品（视频、歌曲、剧本或风格素材，或已收录于 World `collection` 固定修订中的 `draft_id` / `revision_id` / `file_id`）、已有拆解文档或标注演示视频、用户分析目标及预算授权（使用 `world.analyze` 服务时）。
- **输出**：可编辑的结构化拆解成果（镜头／节拍表、声画关系、角色与剧情结构、曲式／配器、风格规则、工程重建提案与提示词草稿）、覆盖状态记录（`pending/complete/failed/unsupported/not_applicable`）、方法候选或 `world.analyze` 固定学习修订（`learning.revision`）。

## 2. 分类

按交付意图与作品类型进入对应路径：

- **本地／宿主直接拆解**：涵盖视频／宣传片／电影片段、剧本与短剧、歌曲／配乐／MV、风格／人物／场景四类作品，默认覆盖提交作品的完整范围与全部适用维度；内部步骤自动衔接，不要求用户逐项“继续分析”。
- **学习已有拆解**：按原片、表格、标注视频各自角色对照提炼可迁移方法；已有分析不是原片事实或自动拆解成功证据。
- **服务端完整拆解（`world.analyze`）**：实际发现 Studio `world.analyze` 且 `capabilities.enabled == true` 时，走一次提交、查询与受控重试恢复路径。

## 3. 工作流

### 3.1 完整分析与按作品类型组织成果

先识别原作品、已有拆解文档、标注演示与新创作成果的角色，固定文件摘要、时长／全文范围、时间基准、版本与来源。每个适用维度记录已分析范围、证据和状态；不适用需说明理由，未知结论保留为未知。

- **视频、宣传片与电影片段**：先建立叙事／沟通目的与段落，再划分剪辑镜头；镜内新信息、动作变化与注意力转移记为节拍，用稳定局部 Key 和时间范围关联，不把每帧自动变成独立资产。逐镜描述主体、动作起落、构图、场景／道具、相机观感、光色与信息目的；相机运动、主体运动、剪辑切换、二维图形运动分别判断；仅凭成片不能确定焦距、空间尺寸和相机轨迹时标推断。旁白、对白、字幕、音效、音乐、图形分别定位后建立声画同步，测量明确单位、帧率、偏移正负与来源，未听取音轨不能凭画面补写为事实。模型观察用于已有作品返修前须对照批准台词、原录音与实际剪辑窗口；错听、漏词、合句或混淆角色时保留原生结果并标差异，不据此改词、换声线或撤销批准；宽带电平不能代替听感，快速接触与口型按原生采样率标明局限。用户要求工程时形成明确重建任务（白模尺度假设、场景对象、连续相机起落与关键帧、ComfyUI 输入与预期控制输出），工程由实际生产能力生成并重开／执行验证。
- **剧本与短剧**：按幕／场／事件定位原文或视听证据，提取角色目标、阻力、知情顺序、关系变化、冲突升级、反转和悬念；逐字对白有来源，概括标概括。再创作将替换映射到因果与场次，交付具体改写内容或可执行改写提示词，不能仅改人名就声称完成新剧结构。
- **歌曲、配乐与 MV**：歌曲按曲式、动机、节奏、配器、人声、情绪推进和听感拆解；歌词／文本、听感推断与测量分别举证，未分轨不交假 Stem，未识谱不称已获 MIDI 或准确和弦。MV 另建镜头与乐句、重拍、段落变化对应，区分剧情、表演与视觉段落；完整视频分析不能代替音乐分析。
- **风格、人物与场景**：风格拆成叙事、表演、构图、光色、运动、剪辑与声音规则，给适用条件、例外与模块配合；单一片段不宣称总结导演全部风格，不靠作者姓名代替可执行描述。人物区分演员身份与剧中角色；场景区分空间、物件、材质、光线与调度，二维可见信息不等于完整三维模型。

### 3.2 学习一份已有拆解

先读表格结构与图例，区分真实记录、汇总与说明行；对照原片同一定位分别保存作者声明与本次独立核验。只有拆解文件时可学组织方法，但不声称核实原作事实。Roadster 案例可迁移方法包括：镜头与镜内节拍分层、多声画轨单独定位后建同步、“看到什么／为何有效／新作品如何使用”分开、提示词由结构／动作／节奏／约束导出；但该案例车辆外观、镜头数、帧率、颜色与时码均非通用默认。已有答案重放不证明自动分析泛化。

### 3.3 服务任务提交、查询与受控重试（`world.analyze`）

1. **能力与原件确认**：发现 `world.analyze` 及其 `inputSchema`，调用 `{"mode":"capabilities"}` 检查 `enabled`、`models`、`input_mime_types`、`max_media_bytes`。原片须在 World `collection` 固定修订中，经 `world.draft` 取真实 `draft_id`、`revision_id` 与 `file_id`；不接收任意 URL，不把输入媒体或私有正文写入技能包。
2. **一次提交（`mode=submit`）**：提交前保存新生成的 UUID v7 `task_id` 与原请求；传入固定 `source`、`model_id`（须在 `capabilities.models`）、大于零的十进制字符串 `budget_limit` / `budget_per_call`（总额不小于单次，未获预算授权前不自行填入付费上限）、`prompt_targets`（唯一 `key`、`requested_label`、`task_type`、`input_mode`、`adaptation_guidance` 及确知时才填的可选 `model_id`）。不传组织、用户、项目或原文工具命令。返回 `request_state` 仅表示已接单，后台自动完成媒体准备、画面声音观察、跨段关联、分类成果、提示词适配与固定学习保存。
3. **查询与中断恢复**：用 `mode=get,task_id` 查询，忘记编号用 `mode=list`（按 `next_before_task_id` 翻页）。提交超时或响应丢失先查原 `task_id`，恢复仅重放原参数和原编号，不生成新号补交。预算耗尽停止新调用、继续查回已发调用，`reserved` 为保守占用非实际扣款。
4. **受控重试（`mode=retry`）**：Schema 支持且任务因确定语义错误停止时，在既有授权次数与原预算内保存新 UUID v7 `retry_id` 调用 `world.analyze(mode=retry, task_id, retry_id)`。观察片段、跨段关联、类型化成果或提示词批次常规最多追加两次（成功部分复用，原失败回执与预算保留）；仅当关联第 2 次使用短编号且仅实体成员遗漏，或成果／提示词批次经服务固定原生失败回执证实命中限定诊断条件（风格色值附注或证据汇总表达、方法步骤输入／输出依赖缺失、提示词空可选负面字段或本范围必需证据唯一遗漏）时，服务可接纳第 3 次最终纠正，任何批次禁止第 4 次生成。`MAX_TOKENS` 截断可在同一上限内受控 retry，不得手工补齐截断 JSON。校验器修复漏识后 `retry` 可能先执行无生成复验（不占模型重试），但 `retry` 非只读检查，复验未通过或下游恢复仍可能调用模型，授权用尽时禁止调用。
5. **取用完整成果**：`learning.state=saved` 时从 `learning.revision` 定位 `manifest.domain_documents` 的 `reference-learning`，经 `artifact.read` 读取完整正文（最多 4 MiB，不静默截断），并按[成果读取与保存](02.world-asset.entrypoint.md)区分 v1／v2；`learning_saved_need_evidence` 不能改称全量完成。

## 4. 规范

### 4.1 视频证据与时间定位

- **分段含义**：原片剪辑镜头、生成分段与镜内节拍分别记录；验证切镜须看边界前后真实画面，仅分段中图须保留“剪辑边界未核验”。跨段关联的镜头组仅指同一连续镜头的计算分段，全部镜头恰好出现一次且顺序与原时码不变，同一人物／道具／地点不足以合并切镜；人物与声音关联仍为有证据的推断。
- **实际时间与覆盖**：记录请求时间与解码实际时间，精确定帧须用已确认时基与帧索引。中间采样不证明连续运镜或无短切镜；字幕可跨切镜按时间交集核对，片尾不得声明画面延续至原片外；声音区间类型须与对白、音乐、音效一致。
- **分开原片、外部分析与重制**：原片自带标题、箭头与图形不判为拆解叠层，标注版时码、多轨时间线与重配音须与原画分开，未听音轨时字幕仅作画面文本。本轮未重测的外部分析角度／光流／时间保持“外部分析提供”，不能从重制提示反推原片事实。产品机制讲解分层不自动套到剧情叙事。

### 4.2 跨能力公共约束

遵循[公共规则](00.common.rules.md)：提示词按[模型提示词适配](03.prompt-adapt.entrypoint.md)独立交付，不以长报告替代可复制正文；二维图示、数值相机描述和空工作流文件不能作为真实 Blender 或 ComfyUI 工程；模型输出键引用、时间覆盖或音频层矛盾须由重新分析修正，不能删除证据、补写模板或强制通过。

## 5. 验收

按[公共规则第 4 节](00.common.rules.md#4-通用验收与核对条件)逐项核对：

- 全部适用维度实际完成才声明完整拆解；逐项区分已观察、未覆盖与未知结论，局部采样不标为完整作品。
- `world.analyze` 成果须从 `learning.revision` 固定回读并核对 ContentRef、摘要与大小，保持任务冻结的组装版本与处理快照，不把自动组装的 `unassessed` 显示为推荐。
- 方法候选无新输入试用证据时保持“候选”标记，不自动改写已安装技能。
