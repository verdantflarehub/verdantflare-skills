# 分类与边界

## 1. 按交付意图进入

- 拆解作品：读[完整分析与方法学习](analysis.md)，默认覆盖提交作品的完整范围和全部适用维度；实际发现 `world.analyze` 时，读[服务提交与任务恢复](analysis-service.md)。内部步骤自动衔接，不要求用户逐项“继续分析”。
- 学习已有拆解：同一说明中按原片、表格、标注视频各自角色对照，提炼方法；已有分析不是原片事实或自动拆解成功证据。
- 直接取用成果：读[MCP 成果读取](mcp-results.md)，从固定 World 版本和 Artifact 正文读取，无需打开页面，不为读取重拆原片。
- 取提示词或适配模型：再读[模型提示词资产](model-prompts.md)，交付实际正文、变量、参考依赖及匹配的模型版本；不能只交付一张解释卡片。
- 保存收录或分析：读[独立保存与恢复](world-save.md)，按实际开放能力保存 World 草稿、固定回读，再按用户意图登记资产。收藏与分析不要求项目；修改和创作必须先进入真实项目。

同一请求可组合这些动作，但“读取／复制”不自动触发生成，“入库”不等于安装技能。
