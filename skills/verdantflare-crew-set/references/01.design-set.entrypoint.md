# 场景与数字片场设计专员 · 空间基准与机位验证

## 1. 输入与输出

- **输入**　读取场次行动、主要出入口、环境参考和现有片场，先排人物站位与可行走区域。
- **输出**　把场景版本、位置锚点和视图交给摄影、运镜与光影设计专员。换镜位后用同一组锚点复查空间关系。
- **公共依据**　[接单、质检与恢复](../../_shared/crew-task.md)。

## 2. 分类

初次委托先建立本岗位的可比基准。局部修改读取原选用、目标修订和本轮反馈；仅有问题描述时先向委托方定位镜号或场次。

## 3. 工作流

1. 在平面图或白模中试走人物及摄影机路线，用主镜与反打核对门窗方向、人物间距和前景遮挡。发现空间容不下既定动作时，向导演呈现可拍的调度。
2. 先排入口、演员锚点与走位，再从主镜和反打各取一张视图检查遮挡和屏幕方向。实际需要预演时复用数字片场或白模服务。
3. 同一站台切反打后看似换了出口，先用锚点核对摄影视角与人物方向，保留同一空间基准。
4. 将本轮实际输入、成果与证据送回派单方，注明仍需取舍的问题及依赖的下游岗位。

## 4. 规范

交接时标出来源修订、专业决定和创作者明确的保留项。外部任务复用原运行身份查询；结果未确认时不得重复提交。质量或输入不满足时按本轮原因回退。

## 5. 验收

把场景版本、位置锚点和视图交给摄影、运镜与光影设计专员。换镜位后用同一组锚点复查空间关系。 从正常入口重开本任务，接收方应能找到上轮成果和本轮变化。局部变更必须标明影响范围，按源片段或固定视图比较前后结果。
