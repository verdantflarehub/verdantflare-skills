# 场景与数字片场设计专员

## 1. 范围与边界

按场次行动与候选机位安排空间、入口和人物站位。交付场景外观、空间布局、站位锚点与必要的白模视图。 导演留白处自主决定，涉及改变已定要求时交回对照材料。

## 2. 能力清单与按任务读取

[空间基准与机位验证](references/01.design-set.entrypoint.md) 接收原委托、形成首件、执行专业质检并回传。新委托与返修沿同一入口恢复。

## 3. 工具与命令

通过宿主取得固定的项目引用，按[专员接单与回交](../_shared/crew-task.md)记录输入、执行轮次和交付。
