# 简单计划验收标准（C1.simple）

## 1. 门禁适用范围

简单计划适用 `draft`、`archive-preflight` 与 `archive` 三档门禁（`cp0` 与 `cp1` 为复杂研发计划专属门禁，对简单计划调用将返回阻断提示）：

| 门禁档位            | 简单计划通过条件                                                           |
| :------------------ | :------------------------------------------------------------------------- |
| `draft`             | `计划等级：简单计划` 合法、未触发 `PL-LVL-DOWNGRADE`、`CP <= 1`、步序 2～3 |
| `archive-preflight` | 仅末步收尾任务可为 `[ ]` 其余全 `[x]`；若为 `S1` 则对应单点检查点已通过    |
| `archive`           | 已移入 `docs/archive/plan/`、`100% [x]`、活动目录零残留、全仓入链无断链    |

## 2. 结项交付核对清单

执行智能体在报告简单计划完成前必须逐项确认：

- 全部受影响模块单测、增量编译与静态格式检查（`md_format.py --check`、`check_md.py`）退出码均为 `0`；
- 每个末级子任务的 `change_*.md` 均已填写 `结项结论：已完成` 并移入 `docs/archive/changes/`；
- 若为 `S1` 模式，人类单点确认结论已如实登记在计划第 7 章 `审批记录`；若为 `S0` 模式，第 3.2 节已标明 `人类检查点（0 个）`；
- 运行 `plan_lint.py check docs/archive/plan/YYYY.MM.<topic>.plan.md --gate archive` 返回退出码 `0`。
