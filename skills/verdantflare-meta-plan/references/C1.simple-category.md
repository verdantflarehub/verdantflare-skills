# 简单计划分类与模式选型（C1.simple）

## 1. 适用特征

当研发任务不触碰复杂判据（见 [共享分类](01.base-category.md)）且同时具备以下三项特征时，定级为 `简单计划`：

- **改动单域收敛**：修改范围限定在单一仓库、单一子服务或单一技能包内部，例如契约内缺陷修复、局部重构、样式微调、辅助脚本优化或文档规范整理。
- **外部契约稳定**：不改变既有跨服务公共 API、数据库表结构、安全鉴权边界或集群拓扑。
- **验证自闭环**：存在确定性单测、静态检查或离线复现实验命令，可由执行智能体独立完成闭环验证。

## 2. 人类参与模式（S0 与 S1）

简单计划文首在 `计划等级：简单计划` 下可紧随声明可选字段 `管控模式`，按是否需要人类单点介入分为两档：

| 管控模式 | 人类检查点数与适用场景                                                 |
| :------- | :--------------------------------------------------------------------- |
| `S0`     | `0 CP`（人类零参与）：目标与授权已在立项明确，智能体全自动验收归档推送 |
| `S1-CP0` | `1 CP`（前置确认）：编码前需人类确认外部凭据、口令或单一界面交互小取舍 |
| `S1-CP1` | `1 CP`（结项体验）：智能体验证通过后需人类做一次轻量桌面或页面视觉确认 |

## 3. 升级触发边界

简单计划执行过程中一旦出现以下任一情形，必须立即按 [共享分类](01.base-category.md) 升级为 `复杂研发计划`：

- 排查发现根因跨越多个仓库、需同步变更公共契约或数据库结构；
- 需要同时设置前置方案审核（`CP0`）与结项验收审批（`CP1`）两个人类检查点。
