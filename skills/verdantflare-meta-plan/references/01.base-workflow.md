# 研发计划共享执行流程

## 1. 标准五步管控主干

研发计划从立项到归档统一遵循“分级定界 -> 脚手架初始化 -> 门禁校验 -> 取证与核验 -> 同构归档”主流程；具体分支差异分别见 [简单计划流程](C1.simple-workflow.md) 与 [复杂计划流程](C2.complex-workflow.md)。

### 1.1 立项分级探测

收到研发任务后，先运行 `classify` 对需求文本或初稿做确定性扫描（识别否定语境，避免“不涉及数据库迁移”误加复杂分）：

```text
python -X utf8 scripts/plan_lint.py classify --text "<需求描述>" --json
python -X utf8 scripts/plan_lint.py classify --plan docs/plan/YYYY.MM.<topic>.plan.md --json
```

### 1.2 脚手架原子初始化

确定等级后使用 `init` 基于内置模板生成受控文档骨架。`init` 先校验输出路径不逃逸 `--root` 且默认拒绝覆盖已有文件：

```text
python -X utf8 scripts/plan_lint.py init --level simple --slug demo-fix --title "修复示例缺陷" --owner Mengsk --cp-mode s0
python -X utf8 scripts/plan_lint.py init --level complex --slug core-arch --title "核心架构升级" --owner Mengsk --with-core-docs
```

### 1.3 确定性哈希计算

复杂计划在呈报 `CP0` 前及签署阶段评审报告时，分别使用 `lock-hash` 与 `review-hash` 计算跨平台一致的 `sha256:<64hex>` 摘要：

```text
python -X utf8 scripts/plan_lint.py lock-hash docs/acceptance/accept_YYYYMMDD_<topic>.md --json
python -X utf8 scripts/plan_lint.py review-hash --stage t2 --design docs/design/spec.md --accept docs/acceptance/accept.md
python -X utf8 scripts/plan_lint.py review-hash --stage t4 --accept docs/acceptance/accept.md
```

### 1.4 五档门禁递进检查

在计划起草、`CP0` 报审、`CP1` 报审、归档移入前预检及归档移入后终检五个节点，依次运行对应门禁档位：

```text
python -X utf8 scripts/plan_lint.py check docs/plan/YYYY.MM.<topic>.plan.md --gate draft --repo-id <org/repo>
python -X utf8 scripts/plan_lint.py check docs/plan/YYYY.MM.<topic>.plan.md --gate cp0
python -X utf8 scripts/plan_lint.py check docs/plan/YYYY.MM.<topic>.plan.md --gate cp1
python -X utf8 scripts/plan_lint.py check docs/plan/YYYY.MM.<topic>.plan.md --gate archive-preflight
python -X utf8 scripts/plan_lint.py check docs/archive/plan/YYYY.MM.<topic>.plan.md --gate archive
```

## 2. 跨智能体异步等待与重试规程

复杂计划在 `T1`、`T2` 与 `T4` 发起跨智能体审核时，必须遵守低轮询守护规程：

- **阻塞等待优先**：优先使用宿主调度器的阻塞等待能力（如 `launch.py --wait` 或受控任务结果回调）一次性回收终态结果，禁止在循环中高频轮询状态接口。
- **退避查询与收据落盘**：若宿主连接中断需恢复查询，先核对原 `task_id` 与 `session_id / thread_id`，严禁重复派发同一评审轮次；拿到结论后立即将原生会话 ID、任务 ID 与轮次 ID 写入 `docs/reviews/` 或 `docs/acceptance/` 对应章节。

## 3. 存量冻结与单向迁出操作

新接入本技能的历史仓库仅允许在首次接入时运行一次 `freeze`；历史计划补齐 `计划等级` 后运行 `migrate-legacy` 完成单向迁出：

```text
python -X utf8 scripts/plan_lint.py freeze --root . --repo-id <org/repo>
python -X utf8 scripts/plan_lint.py migrate-legacy docs/plan/2026.10.legacy-demo.plan.md
```
