# 研发计划共享验收标准与规则码字典

## 1. CLI 退出码契约

`scripts/plan_lint.py` 所有子命令遵守统一三值退出码契约，便于 CI 与宿主智能体无歧义判定：

| 退出码 | 语义定义与典型触发条件                                                      |
| :----- | :-------------------------------------------------------------------------- |
| `0`    | 门禁检查全绿放行，或 `classify / init / lock-hash / review-hash` 成功完成   |
| `1`    | 命中至少一条 `PL-*` 业务门禁阻断规则（输出违规代码、文件定位与修复指引）    |
| `2`    | 参数互斥错误、目标文件缺失、符号链接越界、重复 `freeze` 或 `.gdrive` 未挂载 |

## 2. 全量门禁规则码字典

| 规则码                | 拦截档位与判定标准                                                                    |
| :-------------------- | :------------------------------------------------------------------------------------ |
| `PL-LVL-REQ`          | `draft+`：缺失必填 `计划等级`，或双棘轮检测到已迁出/历史分级计划回退删字段            |
| `PL-LVL-DOWNGRADE`    | `draft+`：命中复杂判据或设 `>= 2` 个 `CP` 却未获特批擅自标记为 `简单计划`             |
| `PL-DRAFT-STRUCT`     | `draft+`：文首重复键、阶段结构不合法（如复杂计划缺改 `T1–T5`）或计数失配              |
| `PL-CP0-TXT`          | `cp0+`：关联专题设计缺失，或正文缺少非空 `text` 架构/流程/原理代码块                  |
| `PL-CP0-IMG`          | `cp0+`：设计未嵌入合规 `.gdrive/managed/` 配图、缺 `receipts/` 回执或哈希失配         |
| `PL-GDRIVE-UNMOUNTED` | `cp0+`（退出码 `2`）：设计引用受管图片但当前工作区 `.gdrive` 映射盘未就绪             |
| `PL-CP0-REV`          | `cp0+`：缺失反向关联本计划的 `t1` 或 `t2` 有效通过报告，或未闭环问题 `> 0`            |
| `PL-REV-STALE`        | `cp0 / cp1 / archive*`：当前最新阶段报告 `评审对象哈希` 与冻结切片实时值失配          |
| `PL-REV-INDEP`        | `cp0 / cp1`：违反作者与核验方互斥、越权传 `d4b`、双棒兼任或拉 Claude 替补细节审       |
| `PL-CP0-ACC`          | `cp0+`：缺失反向关联本计划的 `accept_*.md`，或第 2 章未定义 `S1..Sn` 场景             |
| `PL-CP0-PROC`         | `cp0`：考卷第 2 章缺验收流程三方审定记录，或某场景缺取证流程/证据内容/充分性判据/判定 |
| `PL-CP1-TASKS`        | `cp1`：`T1–T4` 存在未勾选 `[ ]` 的末级实施或验收子任务                                |
| `PL-CP1-LOCK`         | `cp1+`：考卷第 2 章实时 `lock-hash` 与第 7 章 `CP0` 锁卷哈希不一致或减场景            |
| `PL-CP1-ACC`          | `cp1+`：验收状态未达标、第 3 章残留待回填占位或第 `4.1–4.5` 节缺 64 位哈希            |
| `PL-CP1-REV`          | `cp1+`：缺失 `t4` 有效通过报告、缺 Codex 核验或 Claude 抽查收据、问题未清零           |
| `PL-ARC-SYM`          | `archive*`：审批或状态未闭合、活动目录残留文件，或全仓入链存在断链不可达              |
