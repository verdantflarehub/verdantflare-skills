# 全局安装与本机智能体接入（05.install）

## 1. 输入与输出

- **输入**：维护源技能目录路径、目标统一安装根（默认 `~/.agents/skills/<name>/`）及需接入的本机智能体列表。
- **输出**：与维护源逐文件哈希一致的全局安装副本，以及各智能体指向统一安装根的接入配置。
- **公共依据**：[公共规范](./00.common.rules.md)、[评审与验收](./04.review.entrypoint.md)。

## 2. 分类

- **安装与更新技能**：每次技能更新均执行，将维护源完整复制到 `~/.agents/skills/<name>/`，只写此单一位置，不为各智能体分别复制。
- **本机智能体接入**：每台机器、每个智能体只做一次环境配置，使其发现 `~/.agents/skills`；接入属环境变更，首次执行或改动前须获用户授权。

## 3. 工作流

### 3.1 安装与更新步骤

1. 在维护源运行静态检查与回归测试，并复制到不含兄弟技能的隔离临时目录运行 `lint_skill.py`，确认无跨技能或仓库资产断链。
2. 若 `~/.agents/skills/<name>/` 已存在，先比对它与维护源的差异，确认无仅存在于安装副本的有效修改，再按确切名称删除旧目录。
3. 复制整个技能目录到 `~/.agents/skills/<name>/`，排除 `__pycache__`、`*.pyc` 等缓存。
4. 在安装位置运行静态检查，并与维护源逐文件比对哈希一致。

### 3.2 各智能体接入方式

| 智能体      | 接入方式                                                  |
| :---------- | :-------------------------------------------------------- |
| Codex       | 原生读取 `~/.agents/skills`，无需配置                     |
| Grok        | 原生读取各层 `.agents/skills`，无需配置                   |
| Antigravity | 全局 `~/.gemini/config/skills.json` 指向统一安装根        |
| Claude Code | `~/.claude/skills` 建为指向统一安装根的目录联接或符号链接 |

- **Antigravity**：在 `~/.gemini/config/skills.json` 创建或合并条目 `{"entries": [{"path": "~/.agents/skills"}]}`（不覆盖其他配置），新开会话生效。
- **Claude Code**：确认原目录技能均已在统一安装根存在一致副本后，删除原目录并建立联接（Windows：`cmd /c mklink /J "%USERPROFILE%\.claude\skills" "%USERPROFILE%\.agents\skills"`；macOS/Linux：`ln -s ~/.agents/skills ~/.claude/skills`）。

## 4. 规范

- 技能源码只在一处维护，严禁直接修改 `~/.agents/skills/` 中的安装副本；若发现副本被改过，先将有效修改合回维护源再重新安装。
- 全局技能严禁链接源码仓库的业务资产或兄弟技能目录；目录内指向外部的符号链接同样视为外部依赖。

## 5. 验收

- 安装位置通过 `lint_skill.py lint ~/.agents/skills/<name> --style numbered`（0 errors）且与维护源逐文件哈希一致。
- 接入验证须逐个确认配置或联接指向正确，并在各智能体新开会话核对技能列表；未实际开会话核对的智能体记为「已配置、未验证」，不报告为可用。
