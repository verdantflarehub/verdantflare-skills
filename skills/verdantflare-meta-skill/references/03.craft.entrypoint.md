# 电影工业工艺技能设计与治理（03.craft）

## 1. 输入与输出

- **输入**：电影工业单一专业技法领域的知识、方法论与审片标准（如运镜设计 `*-craft-camera`、布光色彩 `*-craft-lighting`、表演调度 `*-craft-acting`、剪辑节奏 `*-craft-editing`）。
- **输出**：纯领域决策与创作技法型 `*-craft-*` 技能目录（只产出结构化方案、镜头语言、专业指令或审片意见，不耦合底层生图/生视频管线），通过 `lint_skill.py --profile craft --style numbered` 校验。
- **公共依据**：[公共规范](./00.common.rules.md)、[公共流程](./00.common.workflow.md)、[公共验收](./00.common.acceptance.md)。

## 2. 分类

工艺技能（`--profile craft`，目录名含 `-craft-` 时自动识别）是电影工业管线中的**专业技法与审美评价知识库**：电影工业的专业设计表达与专业评价门槛极高，无法指望生成模型天生自带，必须长期从影视工业方法论与实战案例中持续收集、沉淀为跨模型永恒有效的结构化资产，供 `crew` 与 `director` 复用：

| 典型工艺域 | 典型产出物（跨模型、跨项目复用）         |
| :--------- | :--------------------------------------- |
| 运镜设计   | 机位轴线表、推拉摇移节奏与景别切换指令   |
| 布光与色彩 | 主辅轮廓光布光图、色温反差与影调控制规范 |
| 剪辑与节奏 | 节拍切点表、声画对位与转场逻辑           |
| 审美与构图 | 三分法/负空间/景深构图法则与审片纠偏清单 |

## 3. 工作流

1. **界定专业决策契约**：明确每个 `NN.<cap>.entrypoint.md` 的输入（剧情节拍、情绪目标、空间约束或待审粗片）与输出（标准化技法方案、镜头/灯光指令或可操作审片单），确保输出可直接被 `crew` 专员或 `director` 导演消费。
2. **沉淀方法论与正反样例**：在「分类」中按场景/情绪/空间类型建立技法选型矩阵；在「规范」中沉淀电影工业硬法则（如 180 度轴线原则、视觉引导线、情绪与焦段对应关系）及有依据的破格例外；在「验收」中建立文字审美准则与可复核检查项。
3. **运行工艺分型校验**：执行 `python -X utf8 scripts/lint_skill.py lint /path/to/mk-craft-camera --profile craft --style numbered`（目录名含 `-craft-` 时 `--profile auto` 自动启用）。

## 4. 规范

- **零底层实现渗透红线**：`*-craft-*` 技能表达的是**跨模型永恒有效的电影工业技法**，严禁硬编码底层模型权重（`.safetensors`/`.ckpt`/`.gguf`）、LoRA 数值权重配比、ComfyUI 节点编号、采样器/Sigmas 参数或特定生图 API 参数；违者由 `lint_skill.py --profile craft` 告警拦截。
- **决策与执行分离**：`craft` 技能只负责出专业方案、改写创作指令与做专业审片，不直接持有 GPU 租约、不直接发起生图/生视频调用，也不替代人类做最终审美拍板。
- **可复用粒度**：优先按“设计方案 / 审片纠偏”等真正可独立交付的智力产出建 `NN.<cap>.entrypoint.md`，不把单个镜头术语拆成碎片文件。

## 5. 验收

- `lint_skill.py lint <target> --profile craft --style numbered` 返回 `PASS`（0 errors, 0 warnings），无任何底层实现泄露告警。
- 用真实剧情或粗片样例验证：产出的技法方案不依赖特定生成模型即可清晰指导 `crew` 专员落地，且能有效指出反例中的专业缺陷（如越轴、跳切、光比失衡）。
