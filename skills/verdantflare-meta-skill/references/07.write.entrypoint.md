# 文档编写技能设计与治理（07.write）

## 1. 输入与输出

- **输入**：服务负责人个人工作流、与产品项目业务无关的文档编写技能诉求，如 Markdown 排版、计划编制、白皮书与架构配图（命名约定为 `*-write-*`）。
- **输出**：独立于电影工业四层调用链、可跨仓库全局安装的 `*-write-*` 技能目录，通过 `lint_skill.py --profile write --style numbered` 校验。
- **公共依据**：[公共规范](./00.common.rules.md)、[公共流程](./00.common.workflow.md)、[公共验收](./00.common.acceptance.md)。

## 2. 分类

文档编写技能（`--profile write`，目录名第二段为 `write` 时自动识别）不属于四层，与 [元治理技能](./06.meta.entrypoint.md)、[助手调度技能](./08.agent.entrypoint.md) 同为个人工具技能：

| 子类     | 典型技能                        |
| :------- | :------------------------------ |
| 通用排版 | `verdantflare-write-markdown`   |
| 计划管控 | `verdantflare-write-plan`       |
| 图文文档 | `verdantflare-write-whitepaper` |

## 3. 工作流

1. **判定归类**：规定某类文档如何编写、排版、检查与交付的技能归入本分型；管理工作机制的归 `meta`。
2. **按三段式命名**：`<前缀>-write-<对象>`，对象为文档类型且合并为一个词。
3. **明确规则优先级**：声明用户当前要求、目标仓库规则高于本技能默认规范，第三方原文、历史归档与机器生成区域保留原格式。
4. **配齐确定性检查**：格式化与结构检查用脚本实现并附回归测试，执行 `python -X utf8 scripts/lint_skill.py lint /path/to/verdantflare-write-demo --profile write --style numbered`。

## 4. 规范

- **三段式命名强制**：名称须恰为三段且第二段为 `write`，否则由 `lint_skill.py` 报 `ERROR`。
- **只管写法不管业务**：规定文档结构、格式与检查门禁，不替代具体业务方案设计与人工终审；不把四层业务技能作为自身运行前提。
- **不做底层渗透检查**：不启用 `craft / crew / director` 的底层渗透告警。
- **全局安装独立性**：须能在无项目兄弟技能的隔离目录安装与复验，安装与发布按 [安装技能](./01.install.entrypoint.md) 执行。

## 5. 验收

- `lint_skill.py lint <target> --profile write --style numbered` 返回 `PASS`（0 errors），无三段式命名错误。
- 自带格式与结构检查脚本的回归测试通过，规则优先级与豁免边界在入口中明确声明。
