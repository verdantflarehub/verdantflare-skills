# 原子技能设计与治理（02.atomic）

## 1. 输入与输出

- **输入**：底层模型、工具链或无状态技术算子的需求（如 `vf-video`、`mk-image-nsfw`、`vf-comfyui`），或待整改/待评审的存量原子技能目录。
- **输出**：按扁平前缀原子能力入口组织的 `atomic` 技能目录，通过 `lint_skill.py --profile atomic --style numbered` 及业务样例验证。
- **公共依据**：[公共规范](./00.common.rules.md)、[公共流程](./00.common.workflow.md)、[公共验收](./00.common.acceptance.md)。

## 2. 分类

原子技能（`--profile atomic`，默认分型）是整套电影工业技能体系的底层执行算子，按能力复杂度分为两类：

- **单能力算子**：仅需 `SKILL.md` + `references/01.<cap>.entrypoint.md`，不建 `00.common.*` 空壳。
- **多能力引擎**（如 `vf-video` 的 `01.t2v / 02.i2v / 03.fl2v / 04.ref2v`）：按“一次明确输入 → 一次可独立交付的技术产物”分配唯一两位编号（`01~99`），仅在 2 个及以上能力共用规则/门禁时按需抽入 `00.common.<维度>.md`。

## 3. 工作流

1. **规划目录与能力粒度**：按独立技术交付物切分 `NN.<cap>.entrypoint.md`（严禁把“参数检查”“打印日志”等内部步骤拆成独立入口），每个入口按固定五段式（输入与输出 → 分类 → 工作流 → 规范 → 验收）编写。
2. **初始化或整改**：新建按[公共流程](./00.common.workflow.md#2-通用脚手架命令)运行 `init`；存量按[整改四步法](./00.common.workflow.md#3-存量技能整改四步法)搬移重组；新经验按[先验证再沉淀](./00.common.workflow.md#4-经验沉淀四步闭环先验证再沉淀)入库。
3. **设计数据驱动分类**（仅输入来源不确定且分错会导致下游失败时）：在能力的「分类」节定义前置取证探针、可复现的数值/布尔判据及与下游工作流/参数预设的确定性绑定。
4. **运行检查与样例验证**：执行 `lint_skill.py lint <skill_dir> --profile atomic --style numbered`、自带脚本单测及真实样例实跑。

## 4. 规范

统一扁平前缀目录结构如下（根目录仅允许 `SKILL.md`）：

```text
<skill-name>/
├── SKILL.md                           入口：范围与边界、能力清单与按任务读取、工具与命令
├── references/
│   ├── 00.common.<维度>.md            可选：跨能力共享（category/workflow/rules/acceptance 按需建）
│   ├── 01.<cap>.entrypoint.md         必备：原子能力 01 入口（输入/输出 + 分类/工作流/规范/验收）
│   ├── 01.<cap>.<维度>.md             可选：单文件超 10000 字符时按需拆出的同前缀子专册
│   ├── 02.<cap>.entrypoint.md         可选：原子能力 02 入口（编号 01~99 只增不重排）
│   └── <主题>.md                      可选：接口、数据字典等纯参考附录
├── scripts/                           可选：脚本与测试
└── resources/ 或 assets/              可选：模板、样例与静态资源
```

- **底层实现自包含**：底模权重、LoRA 矩阵、采样器、ComfyUI 节点编号、显存账本与 API 错误码契约全部收敛在 `atomic` 技能内部，对外暴露稳定输入/输出与可观测门禁，严禁耦合上层业务剧情或剧组工种流程。
- **四维归属**：适用输入归**分类**，步骤与失败恢复归**工作流**，硬约束与默认值归**规范**，测量与门禁归**验收**。

## 5. 验收

- `lint_skill.py lint <target> --profile atomic --style numbered` 返回 `PASS`（0 errors, 0 warnings），无超长能力名告警，无 `00.common.*` 冒充原子能力行。
- 自带脚本单测通过，真实或隔离样例走通触发、参数路由、执行与失败恢复；含自动门禁时满足[评分门禁三件套](./00.common.acceptance.md#3-行为验证与评分门禁设计)。
