# 静态检查、质量评审与门禁验收（04.review）

## 1. 输入与输出

- **输入**：待检查或待评审的技能目录路径，以及可选风格参数（`--style numbered`、`--allow-placeholders`）。
- **输出**：静态检查报告（errors / warnings）、按严重程度排序的评审发现，以及分离记录的静态/行为/人工验收结论。
- **公共依据**：[公共规范](./00.common.rules.md)、[检查器](../scripts/lint_skill.py)、[回归测试](../scripts/test_lint_skill.py)。

## 2. 分类

- **能力入口架构校验（默认）**：当 `references/` 下存在 `NN.<cap>.entrypoint.md`（或空目录）时启用，校验能力入口链接、编号唯一性、入口五段式（输入/输出、分类、工作流、规范、验收）、子维度专册归属及 `00.common.<维度>.md` 合法命名。
- **存量兼容架构校验（Legacy）**：当 `references/` 下不存在 `*.entrypoint.md` 但存在 `01.base-*.md` 时自动兼容，校验四份底座、`Cx.<slug>-<dim>.md` 分支矩阵及 4 行泛化路由表告警。

## 3. 工作流

1. **运行静态检查**：执行 `python -X utf8 scripts/lint_skill.py lint /path/to/target-skill --style numbered`。
2. **执行回归测试**（修改初始化器或检查器时）：执行 `python -X utf8 -m unittest discover -s scripts -p test_lint_skill.py`。
3. **语义与行为评审**：核对 `description` 触发准确性、能力粒度是否正交、输入/输出契约是否清晰、约束是否有来源与边界、是否越权；用真实或隔离样例验证触发、命令与失败处理。
4. **输出分级报告**：评审请求直接给出按严重程度排序的发现、位置、影响与建议，不擅自改写被审对象；分别报告静态检查、行为验证与实际人工确认结果。

## 4. 规范

- **强制静态不变量**：入口三节标题与顺序、正文 ≤4000 字符、代码块 ≤20 行、H3 ≤3 且禁用 H4+、根目录仅 `SKILL.md`、合法 YAML 且无重复键、`name` ≤64 且与目录一致、`description` 非空 ≤1024 且无 XML 标签、递归检查本地链接与 GitHub 风格标题锚点、未完成占位符拦截（忽略代码区）。
- **链接边界**：本地链接允许指向本技能、兄弟技能（同父目录且含 `SKILL.md`）及同一 Git 仓库内资产，逃出仓库根目录报错；全局安装技能交付前须在无兄弟技能的隔离目录复验零断链。
- **专册告警**：单份专册超过 10000 字符给出警告，提示按维度拆出 `NN.<cap>.<dim>.md` 或精简历史叙述；模板、`assets`、`scripts` 内文档不递归 lint，但被链接时校验目标存在。
- **评分与门禁设计**（目标技能含自动门禁或候选排序时）：验收章节须同时具备**测量流程**（必跑探针与审计记录）、**文字评分规则**（业务语义与合理性）与**数据评分准则**（测量变量、通过区间与否决阈值）；阈值只在一处定义并注明来源与适用条件。

## 5. 验收

- 静态检查通过不代表业务正确或用户批准；未运行的环境测试记为未验证，未经用户确认不得标记人工批准。
- 对检查器或初始化器的任何改动，回归测试须覆盖：能力入口默认/多能力/拆分骨架、`00.common.*` 可选生成、缺入口/缺五段/编号冲突/孤立子专册/未链接拦截、存量 `01.base-*` 兼容、YAML 边界、断链与锚点、隔离路径与跨目录 CLI 执行。
