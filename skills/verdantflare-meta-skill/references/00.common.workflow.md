# 技能通用新建、整改与经验沉淀流程

## 1. 当前依据

- [技能入口](../SKILL.md)：范围、能力清单与最短命令。
- [公共规范](./00.common.rules.md)：入口硬约束、减字迭代与目录命名契约。
- [公共验收](./00.common.acceptance.md)：静态不变量、回归测试与门禁设计。

## 2. 通用脚手架命令

命令在本技能安装目录运行，目标目录可以是任意项目；从其他目录调用时使用实际脚本路径：

```text
python -m pip install -r scripts/requirements.txt
python -X utf8 scripts/lint_skill.py init /path/to/vf-video --capabilities 01.t2v,02.i2v,03.fl2v,04.ref2v --common rules
python -X utf8 scripts/lint_skill.py init /path/to/mk-craft-camera --capabilities 01.camera-plan --split
python -X utf8 scripts/lint_skill.py lint /path/to/target-skill --style numbered --allow-placeholders
```

- `init` 采用非覆盖模式：已存在文件一律保留；向已有技能追加新能力后，手工将新能力行合入 `SKILL.md` 路由表。
- `--capabilities` 支持 `01.t2v,02.i2v` 或简写 `t2v,i2v`（自动编号）；`--common` 按需生成 `00.common.<维度>.md`；`--split` 为长能力拆出同前缀四维子专册。
- 模板清单：[SKILL.template.md](../resources/templates/SKILL.template.md)、[NN.cap.entrypoint.template.md](../resources/templates/NN.cap.entrypoint.template.md)、[NN.cap.entrypoint-split.template.md](../resources/templates/NN.cap.entrypoint-split.template.md)、[NN.cap.dim.template.md](../resources/templates/NN.cap.dim.template.md)、[00.common.dim.template.md](../resources/templates/00.common.dim.template.md)。

## 3. 存量技能整改四步法

存量结构整改只做搬移、重组与精简，不顺手改变业务执行行为；发现规则冲突或过时内容登记为待确认项。

1. **盘点**：运行 `lint_skill.py lint <target>` 记录错误与警告；列出入口与 `references/` 全部文件，按对外独立交付能力归组，标出跨能力公共约束及待删除试错叙述。
2. **拆分与搬移**：为每个原子能力建 `NN.<cap>.entrypoint.md`（单文件超 10000 字符时拆出 `NN.<cap>.<dim>.md`），跨能力共享内容归入 `00.common.<dim>.md`；`FAQ.md`、`lessons.md` 拆进工作流失败恢复与规范例外。
3. **重写入口**：按三节格式重写 `SKILL.md`，第二章路由表只列真正原子能力并经减字迭代控制在 2～8 字。
4. **修引用与复验**：同步更新仓库活动文档中指向旧文件名或锚点的链接；运行 `lint_skill.py --style numbered`、`check_md.py` 与自带单测，核对关键约束、命令与阈值无遗漏。

## 4. 经验沉淀四步闭环（先验证、再沉淀）

凡新增或改变分类判据、工作流步骤、阈值或硬约束，按以下闭环执行；纠错字、修链接、调格式等不改变行为的微调直接处理：

1. **界定取证与分类**：分析问题在旧流程中为何漏检或做错，提炼可前置识别的探针与判据。
2. **设计流程与配套改动**：设计端到端处理步骤，脚本与配置改动一并纳入版本管理。
3. **真实案例验证**：在典型真实案例走通取证、执行、测量与评审，在项目变更或缺陷文档留下可追溯证据；需人工确认的环节取得真实结论。
4. **验证后再沉淀**：只把通过验证的判据、步骤、规范与门禁写入对应能力或 `00.common.*`；试错过程留在项目文档。每条拟沉淀规则须能回答来源与证据、适用范围、约束性质（硬约束/默认值/偏好）、例外及更新条件。
