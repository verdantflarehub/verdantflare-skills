# 作品统筹导演技能设计与治理（05.director）

## 1. 输入与输出

- **输入**：整部作品（短剧、宣传片、音乐 MV 或多镜叙事片）的创意策划、世界观设定与跨工种统筹交付诉求（命名约定为 `*-director-*`）。
- **输出**：负责全局节奏、一致性总控与多专员调度交片的 `*-director-*` 技能目录，通过 `lint_skill.py --profile director --style numbered` 校验。
- **公共依据**：[公共规范](./00.common.rules.md)、[公共流程](./00.common.workflow.md)、[公共验收](./00.common.acceptance.md)。

## 2. 分类

导演技能（`--profile director`，目录名含 `-director-` 时自动识别）位于电影工业技能体系顶层，按作品形态分流：

| 作品形态 | 导演统筹核心职责                                            |
| :------- | :---------------------------------------------------------- |
| 叙事短剧 | 剧本节拍、角色/空间联合一致性锁定、分镜总表与多工种并行交片 |
| 音乐 MV  | 曲目节拍对位、视觉母题统筹、素材池编排与成片混剪总控        |
| 品牌宣传 | 叙事钩子、信息密度节奏、多场景风格统一与终审成片交付        |

## 3. 工作流

1. **锁定全局一致性基线**：在开工前冻结作品级不可变约束（角色固定身份与定妆母版、空间拓扑与轴线、统一影调/画幅与已否定历史候选清单），作为所有下游工种的唯一上游事实源。
2. **编排工艺与专员协同**：按作品节拍拆解工种任务单——向 `craft` 工艺技能咨询运镜、布光与剪辑节奏方案，向多个 `crew` 专员技能派发具体镜头/资产交付任务，并维护全局依赖与返修回环。
3. **组织作品级检查点与终审交片**：收敛各工种产物，组织首轮母版审定、粗剪看片与终版交付检查点，按作品级验收单呈报人类终审。
4. **运行导演分型校验**：执行 `python -X utf8 scripts/lint_skill.py lint /path/to/mk-director-drama --profile director --style numbered`（目录名含 `-director-` 时 `--profile auto` 自动启用）。

## 4. 规范

- **零底层渗透与跨层越权红线**：`*-director-*` 只管作品级世界观、节拍、联合一致性与工种编排，严禁硬编码任何底层模型权重（`.safetensors/.ckpt/.gguf`）、LoRA 权重配比、ComfyUI 节点编号或采样器参数（由 `lint_skill.py --profile director` 静态拦截），也不得绕过 `crew` 专员直接堆砌底层推理命令。
- **全维度约束不可局部解除**：局部镜头返修时必须保留全部既有身份、空间与光影约束，禁止因单镜微调放松全局一致性基线。
- **人类审美终审权**：首轮视觉母版与最终成片决策权归人类负责人，导演技能只做方案编排、量化筛查与证据呈报，不代拍板。

## 5. 验收

- `lint_skill.py lint <target> --profile director --style numbered` 返回 `PASS`（0 errors, 0 warnings），无任何底层实现泄露告警。
- 核对技能入口确认清晰界定了全局一致性锁定、多工种调度接口与人类终审检查点，未把底层工具参数或单一工种细碎步骤塞入导演层。
