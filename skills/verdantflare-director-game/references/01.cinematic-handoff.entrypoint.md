# 游戏过场总导演的过场衔接工作流

## 1. 输入与输出

接收触发事件、入场角色位置与朝向、持物和场景状态、须揭示的信息、允许时长、回控状态与真实进出画面。

向创作者及游戏制作方交付可播放过场、事件与分支引用、起止状态、交还控制的位置和画格，保留实际边界画面的比对记录。

## 2. 分类

线性触发复核一条完整进出路径；若玩法输入有不同角色、道具或事件分支，为会改变画面的每个条件绑定可用版本。 首次接单登记委托范围、期限、首件与下次检查时间。续接只读取本项目本单最新有效的委托、决定、保留项、上次交付及其引用。

## 3. 工作流

1. 与游戏制作方对照触发帧和回控帧，注明角色朝向、所在位置、控制对象与道具实例。把需要观众读懂的行动变化交给场景、道具和剧情执行导演。
2. 以角色在过场中捡起钥匙为例，给出入场空手、拾取、持物离场三段可见依据。回收候选后，将实际玩法入口、过场和回控连续播放并截取两个交界处。
3. 若过场末镜持钥匙而玩法回控仍空手，先核对触发的事件分支和交付的剪辑版本。错用出口可换正确版本，镜头缺交代则退回剧情执行导演；事件本身须改时请制作方确认再改拍。
4. 向创作者及游戏制作方交付可播放过场、事件与分支引用、起止状态、交还控制的位置和画格，保留实际边界画面的比对记录。 在当前项目轮次登记对应文件、媒体源入出点、责任岗位、接收回执与需要下一步决定的具体事项。

## 4. 规范

领域争议按候选和具体位置向工艺专家咨询；委托方记录采纳依据与适用范围。专员自行决定导演留白的实现。涉及改变创作者明确要求时，将原案、改案和可观察的差异并列呈报。首件、质检结果、预计超期和需人取舍时向委托方汇报。遭遇输入冲突、权限或预算不足，保存局部成果、已发任务号与恢复条件，停止受影响步骤。等待人工时暂停制作计时。

复用服务端任务号与固定输入版本核实迟到回执。退回修改时开同一委托的新轮次，保留来源、未变约束和旧选片。改派后的回执只归入原尝试；由拥有当前代次与写权限的服务登记正式选择。宿主能力不足时据实记录，供接收方识别待验部分。

## 5. 验收

真实三个区间可连播，入口的角色与出口的控制对象、朝向、位置和持有状态均可核对。保留退回版本及修订后出口的并列证据。 将正常版及返修版的输入、候选、质检、选用和交付引用写回项目。接收方能从成果打开实际画面或领域文件，追到对应轮次和保留的原始版本。人类审美决定须能定位原始消息及候选。未获决定时标明待审和负责人。
