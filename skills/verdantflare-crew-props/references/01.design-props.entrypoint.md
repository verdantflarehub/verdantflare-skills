# 道具设计专员 · 道具实例与交接

## 1. 输入与输出

- **输入**　按故事时间登记关键道具的实例、数量、外观、持有人与转手顺序。
- **输出**　把细节参考和各场进出状态交给表演、关键帧与连续性岗位。补拍特写时对照主镜所用的同一件道具。
- **公共依据**　[接单、质检与恢复](../../_shared/crew-task.md)。

## 2. 分类

初次委托先建立本岗位的可比基准。局部修改读取原选用、目标修订和本轮反馈；仅有问题描述时先向委托方定位镜号或场次。

## 3. 工作流

1. 为关键动作试摆实际握法和朝向。例如同一封信从甲右手进入乙左手，分别记录交接前、中、后信封的封口与可见面。
2. 按故事时间建立道具实例表，包括数量、可见面、持有手、损耗、场次入口与出口状态。标明需要特写的细节。
3. 同一封信交手后信封开口不能自动复原；若是回忆镜，用故事时间绑定拆封前版本。
4. 将本轮实际输入、成果与证据送回派单方，注明仍需取舍的问题及依赖的下游岗位。

## 4. 规范

交接时标出来源修订、专业决定和创作者明确的保留项。外部任务复用原运行身份查询；结果未确认时不得重复提交。质量或输入不满足时按本轮原因回退。

## 5. 验收

把细节参考和各场进出状态交给表演、关键帧与连续性岗位。补拍特写时对照主镜所用的同一件道具。 从正常入口重开本任务，接收方应能找到上轮成果和本轮变化。局部变更必须标明影响范围，按源片段或固定视图比较前后结果。
