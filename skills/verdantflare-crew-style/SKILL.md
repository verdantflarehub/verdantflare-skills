# 视觉风格设计专员

## 1. 范围与边界

从导演阐述和已选参考中提取跨场要保持的视觉特征。交付全片视觉基准、色彩与材质参考、允许的场次变化。 导演留白处自主决定，涉及改变已定要求时交回对照材料。

## 2. 能力清单与按任务读取

[风格基准与样张](references/01.design-look.entrypoint.md) 接收原委托、形成首件、执行专业质检并回传。新委托与返修沿同一入口恢复。

## 3. 工具与命令

通过宿主取得固定的项目引用，按[专员接单与回交](../_shared/crew-task.md)记录输入、执行轮次和交付。
