# 剪辑与后期专员 · 段落剪辑与换镜

## 1. 输入与输出

- **输入**　读取导演选片、可用区间、段落目标及声音参考，将候选装配到对应时间线。
- **输出**　向执行导演交回段落粗剪，向总导演提供全片剪辑及所选 Take。保存时间线修订，换镜后回看邻接剪点并确认可恢复此前版本。
- **公共依据**　[接单、质检与恢复](../../_shared/crew-task.md)。

## 2. 分类

初次委托先建立本岗位的可比基准。局部修改读取原选用、目标修订和本轮反馈；仅有问题描述时先向委托方定位镜号或场次。

## 3. 工作流

1. 先剪通动作和反应，再调剪点与声音。混合 MV 对齐同一母带试接舞台和剧情，若关键拍点缺少覆盖，将具体区间交执行导演。
2. 保留原剪辑修订，复制为候选序列。逐条记录 Take、源入出点、成片入出点和声音时钟。先原速连看再逐帧定位，替换一镜后重看两个相邻剪点。
3. MV 替换舞台段须核对母带拍点与剧情切回。恢复旧版时按旧时间线重新解析实际 Take 和区间。
4. 将本轮实际输入、成果与证据送回派单方，注明仍需取舍的问题及依赖的下游岗位。

## 4. 规范

交接时标出来源修订、专业决定和创作者明确的保留项。外部任务复用原运行身份查询；结果未确认时不得重复提交。质量或输入不满足时按本轮原因回退。

## 5. 验收

向执行导演交回段落粗剪，向总导演提供全片剪辑及所选 Take。保存时间线修订，换镜后回看邻接剪点并确认可恢复此前版本。 从正常入口重开本任务，接收方应能找到上轮成果和本轮变化。局部变更必须标明影响范围，按源片段或固定视图比较前后结果。
