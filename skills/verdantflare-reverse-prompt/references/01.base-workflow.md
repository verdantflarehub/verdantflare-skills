# 单图场景反推提示词执行流程

## 1. 当前依据

- [分类与边界](01.base-category.md)：六项前置视觉盘点、三类场景判定与输出变体分流。
- [规则约束](01.base-rules.md)：可见事实与补全分离、去污染脱敏与防漏配对硬规则。
- [验收标准](01.base-acceptance.md)：静态校验门禁、八维复现对照评分与交付格式。
- [分块模板库](templates.md)：`c1` / `c2` / `c3` 分块结构、`template` 变量规范与 `en` 写法。

## 2. 端到端反推步骤

1. **输入核验**：确认输入为单张可读静态图片（非视频、非批量组图）；若用户同时指定了目标输出变体（`default` / `template` / `en`）或额外要求（如“把半身原图补全为全身穿搭提示词”），先记录为显式覆盖项。
2. **执行六项视觉盘点**：读取图片像素比例与视觉细节，按[分类与边界](01.base-category.md#3-前置视觉盘点分类取证)确定类别（`c1`、`c2` 或 `c3`）、画幅比例、景别、时代风格、可见要素及需清洗的污染项（水印、字幕、黑边）。
3. **逐块撰写结构化正文**：参照[分块模板库](templates.md)中对应类别的分块顺序逐段填充：
   - 先写主体与核心视觉特征，再写环境层次、姿态/空间关系、摄影构图与画面质感，最后生成与本场景配对的 `【严格要求】`。
   - 严格遵守[规则约束](01.base-rules.md)：物理可描述性优先、显式成年年龄段、禁明星真名与水印词；凡属画外推断的补全项不在正文伪装成实景，统一记入正文下方的“补全说明”。
4. **运行确定性静态校验**：将反推正文写入临时文本（如 `.tmp/reverse-prompt/draft.txt`）并运行 `scripts/prompt_lint.py` 校验，未通过则逐项修复直至退出码为 `0`。
5. **按需输出变体**：默认直接交付中文分块正文；若用户请求 `template` 或 `en`，在校验通过的中文事实基线上转换并对应执行 `--variant template` 或 `--variant en` 校验。
6. **可选纯文生图闭环复现**：仅在用户明确要求“验证复现效果”或处于技能验证阶段时执行，不在常规反推时擅自触发付费生图：
   - 调用 `verdantflare-image`（默认 `engine="codex"`，`model="gpt-image-2.6-sunburst"`），**仅传反推提示词正文**（不传原图作参考图），按原图画幅生成 1 张复现图。
   - 按 K09 完成 `image.rate_content` 内容分级评估；`nsfw` 产物立即隐藏不展示。
   - 对原图与复现图按[验收标准](01.base-acceptance.md#3-八维复现对照评分标准可选闭环验证用)打分，记录偏差项；如关键维度失真（例如全身被裁成半身、主色跑偏），先修正提示词并记录修订原因，最多重跑 1 轮，不无止境循环烧预算。

## 3. 工具命令参考

脚本位于本技能 `scripts/` 目录，支持从任意工作目录通过绝对或相对路径调用：

```text
python -X utf8 scripts/prompt_lint.py lint .tmp/reverse-prompt/draft.txt --category c1
python -X utf8 scripts/prompt_lint.py lint .tmp/reverse-prompt/draft.txt --category c2 --json
python -X utf8 scripts/prompt_lint.py lint .tmp/reverse-prompt/tpl.txt --category c1 --variant template
python -X utf8 scripts/prompt_lint.py lint .tmp/reverse-prompt/en.txt --category c1 --variant en
python -X utf8 scripts/prompt_lint.py parse .tmp/reverse-prompt/draft.txt --category c1 --json
python -X utf8 -m unittest discover -s scripts -p "test_*.py"
```

- `--category`：`c1`（单人完整场景）、`c2`（无人纯场景）、`c3`（多人互动剧照）。
- `--variant`：`default`（默认中文直出）、`template`（允许 `{{变量}}` 并输出变量清单）、`en`（校验英文自然语言段落与负向约束）。
- `--json`：输出机器可读结构化结果（含 `status`、`errors`、`warnings`、`sections`、`aspect_ratio`、`variables`）。

## 4. 失败恢复与异常处理

- **图片模糊或严重遮挡**：对无法辨认的微观纹样或鞋履，按“可见粗粒度特征＋保守合理补全”处理，并在“补全说明”如实列出不确定项，不编造高精刺绣或品牌细节。
- **`prompt_lint.py` 报错（退出码 `2`）**：优先补齐缺失分块、画幅比例与配对负向约束，清除残留占位符或水印词后复跑，不得跳过校验直接交付。
- **可选闭环生图超时或返回 `queued`**：遵循 `verdantflare-image` 恢复规程，保留原任务 ID 查询结果，严禁重复提交造成重复计费。
