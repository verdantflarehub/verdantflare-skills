# 分块模板库与输出变体规范

## 1. 当前依据

- [技能入口](../SKILL.md)：三类场景原子能力路由与边界。
- [公共规范](./00.common.rules.md)：前置视觉盘点、四大核心硬规则、配对负向清单与变体分流。
- [公共验收标准](./00.common.acceptance.md)：静态校验门禁与八维复现对照评分。

## 2. C1 单人完整场景（默认标杆八段式）

严格按以下八个分块标题顺序输出，每块以自然、紧凑、可直接渲染的中文段落写成：

```text
【人物形象】
<明确成年年龄段、性别与地域气质、身形比例、五官骨相与眼神神态。>
<皮肤色泽与真实纹理、自然毛孔与细腻光泽，不要假面感。>

【发型与妆容】
<发色、发长、发型结构、碎发细节与发饰材质点缀。>
<妆容时代风格、眉形、眼妆与唇色。>

【完整服装搭配】
<主服装色系、面料、版型、领口剪裁与纹样分布。>
<外搭层次、领口袖口滚边或结构细节。>
<腰饰、耳饰、手饰等配饰。>
<下装、袜履与鞋面装饰细节。>
<手持道具材质、颜色与图案细节（无道具则省略本句）。>

【场景环境】
<地点时代与核心地面/建筑特征，前中远景空间层次、天气氛围与植被点缀。>

【人物姿态】
<站位/坐姿与环境锚点关系、双手与道具交互、身体朝向与神态、服装下摆垂坠状态。>

【摄影构图】
<画幅比例（如 9:16 竖版）、景别（如全身摄影）、主体构图位置、镜头距离与头脚留白、机位高度。>

【画面质感】
<摄影风格、等效焦段（如 85mm 镜头）、光线方向与性质、环境色与服装色协调关系、微观面料与皮肤质感、清晰度。>

【严格要求】
<构图防裁切硬约束＋突出重点＋配对负向排除项：不要半身照（全身时）、不要过度浓妆、不要现代元素（年代题材时）、不要塑料皮肤、不要拼图、不要文字、不要额外水印。>
```

## 3. C2 无人纯场景 / 建筑空景（七段式）

适用于无主体人物的室内外片场、建筑空间、自然风光或 Clean Plate：

```text
【空间定位】
<时代背景、地域建筑规制、室内/室外属性与整体情绪基调。>

【主体建筑】
<核心建筑体量、结构构件（屋檐、柱廊、门窗、墙面材质）、比例与年代旧化痕迹。>

【陈设与材质】
<可见固定家具、灯具、器物或植被分布，地面铺装与砖石木料金属等微观质感。>

【空间层次】
<前景、中景、远景纵深关系、视觉引导线、主次焦点与留白区域。>

【光影氛围】
<光源方向与类型、明暗对比、色温层次、天气雾气或空气微尘细节。>

【摄影构图】
<画幅比例（如 16:9 横版）、景别、机位高度与水平/垂直透视校正、等效焦段与景深。>

【严格要求】
<严格无人空景，不要出现人物、行人、剪影或手部入镜；不要现代穿帮元素（年代场景时）；不要拼图，不要文字，不要额外水印。>
```

## 4. C3 多人互动 / 影视剧照（分角色八段式）

保留八段外框，人物与服装按画面主次分层描述，避免多人特征串色或站位互换：

- `【人物形象】`：分行列出“主体人物 A（画面左侧/前景）”“主体人物 B（画面右侧/中景）”各自的成年年龄段、气质、五官与真实皮肤质感。
- `【发型与妆容】`：按人物 A、人物 B 分别说明发型、发饰与妆面。
- `【完整服装搭配】`：按人物 A、人物 B 分别说明主服装色系、面料、配饰、鞋履与手持道具，显式区分主色调防串色。
- `【场景环境】`：同 C1，明确多人所处的具体空间锚点。
- `【人物关系与姿态】`：明确相对站位、前后遮挡关系、视线交汇方向、肢体/道具交互与情绪张力。
- `【摄影构图】`、`【画面质感】`、`【严格要求】`：同 C1，并在 `【严格要求】` 中追加“人物数量严格锁定为 N 人，不增减人物，服装与面部特征不互相混淆”。

## 5. 参数化模板模式（`--variant template`）

当用户需要把反推结果沉淀为可批量换人、换装或换景的复用模板时：

1. 保持 `c1` / `c2` / `c3` 的全部 `【...】` 分块标题、`【摄影构图】`、`【画面质感】` 与 `【严格要求】` 骨架不变。
2. 仅将用户指定的或天然可变的要素替换为双大括号占位符，如 `{{人物年龄与气质}}`、`{{主服装配色与材质}}`、`{{场景环境}}`、`{{手持道具}}`。
3. 在提示词正文下方附两列“变量名 / 原图默认取值”对照表，确保随时可一键还原原图版本。

## 6. 英文自然语言模式（`--variant en`）

当目标模型更偏好英文自然语言输入时：

1. 将对应中文分块的全部视觉事实翻译并润色为 `2～4` 段连贯的英文摄影描述（Subject & Styling → Setting & Pose → Composition, Lighting & Texture），禁止拆成零散逗号标签堆砌。
2. 保留明确画幅声明（如 `9:16 vertical full-body photograph`）、成年年龄描述（如 `a 23-year-old adult East Asian woman`）与真实皮肤/面料纹理词（如 `natural skin texture, visible pores, no plastic skin`）。
3. 末尾以 `Strict requirements:` 独立段落列出全部配对负向约束（如 `Full body from head to shoes strictly in frame, no cropping, no half-body shot, no modern elements, no collage, no text, no watermark.`）。
