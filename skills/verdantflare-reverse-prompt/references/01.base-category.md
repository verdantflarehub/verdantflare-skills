# 单图场景反推提示词分类与边界

## 1. 当前依据

- [入口](../SKILL.md)：技能范围、协作边界与按需读取路由。
- [规则约束](01.base-rules.md)：可见事实与补全分离、脱敏合规与防漏硬规则。
- [分块模板库](templates.md)：三类场景完整分块字段与变体规范。

## 2. 适用与不适用范围

- **适用输入（v1 仅单图）**：单张本地静态图片（`.png` / `.jpg` / `.jpeg` / `.webp`）或已解析为单张图像的受控 Artifact，包括实拍影视剧照、角色定妆照、完整穿搭图、室内外空景片场图、概念氛围图及 `verdantflare-filmset-restore` 产出的 Clean Plate。
- **不适用输入（v1 明确排除）**：多角度组图联合反推、视频文件自动抽关键帧反推、整片/整曲分镜资产沉淀（交 `verdantflare-reference-learning`）、需要像素级去人物或共边补图（交 `verdantflare-filmset-restore`）、纯文字创意扩写（无参考原图）。
- **越界处理**：用户一次传入多张图片或视频并要求综合反推时，明确告知 v1 仅支持单图，请用户指定其中 1 张主图执行，或拆分为逐张独立反推。

## 3. 前置视觉盘点（分类取证）

在动笔写提示词前，必须先对单图执行六项客观盘点，不得跳过直接套模板：

1. **主体人物数量**：`0` 人、`1` 位主体人物（含远处虚化背景路人不超过视觉主导地位）、或 `2` 位及以上主体人物。
2. **画幅与方向**：读取或估算图像宽高比（如 `9:16` 竖版、`16:9` 横版、`3:4`、`4:3`、`1:1`）。
3. **景别与裁切边界**：全身（头顶至鞋底完整入镜）、七分/膝上、半身、近景/特写、或大远景/建筑全景。
4. **时代与风格基调**：写实摄影（现代/民国/古装/工业/复古胶片）、影视剧照、或非写实绘画/二次元/3D 渲染。
5. **可见关键要素清单**：列出主服装层数、可见配饰与手持道具、前景/中景/远景关键构件、光源方向与色温。
6. **污染与缺损项**：识别画面中的台标、字幕、水印、黑边、现代穿帮杂物，以及被裁切或被遮挡的局部。

## 4. 场景分型矩阵

根据前置视觉盘点中的主体人物数量与画面焦点，确定性映射到三类分块模板之一：

| 类别编码 | 判定条件与对应分块骨架 |
| :--- | :--- |
| `c1`（单人完整场景） | 画面有 `1` 位明确视觉主体人物（穿搭、定妆、人像场景或单人剧照），采用标准八段式（默认标杆） |
| `c2`（无人纯场景） | 画面无主体人物（`0` 人，如建筑外观、室内片场、庭院街区、自然空景或 Clean Plate），采用七段式 |
| `c3`（多人互动剧照） | 画面有 `2` 位及以上视觉主体人物存在空间站位或动作/视线交互，采用分角色八段式 |

- **兜底判定**：若画面包含极小比例远景人物（仅作建筑比例尺、五官与穿搭不可辨），按 `c2` 处理，并在 `【严格要求】` 中根据用户诉求决定是否移除远景路人。
- **景别冲突处理**：若原图为半身照但用户显式要求反推“完整全身穿搭”提示词，仍归 `c1`，可见部分按实景写，画外下装/鞋履按原图风格补全并在提示词正文下方单列“补全说明”。

## 5. 输出变体分流

| 变体模式 | 适用意图与输出特征 |
| :--- | :--- |
| `default`（默认） | 直接输出中文结构化 `【...】` 分块正文，可直接复制生图，不掺杂额外寒暄 |
| `template` | 保留构图、光影、质感与严格要求骨架，将可变主体/服装/场景替换为 `{{变量名}}` 并附变量表 |
| `en` | 按同等视觉信息密度转为自然流畅的英文摄影描述段落与负向约束句，不堆砌碎片标签 |
