# 无人纯场景七段式反推（02.empty-scene）

## 1. 输入与输出

- **输入**：单张无主体人物的静态场景图（建筑外观、室内片场、庭院街区、自然风光、概念氛围图或 `verdantflare-filmset-restore` 产出的 Clean Plate），以及可选输出变体（`default` / `template` / `en`）与画幅覆盖要求。
- **输出**：通过 `prompt_lint.py --category c2` 校验的标准七段式结构化提示词正文（或对应变体）、可选“补全说明”与校验结论。
- **公共依据**：[公共规范](./00.common.rules.md)、[公共验收标准](./00.common.acceptance.md)、[分块模板库](./templates.md)。

## 2. 分类

- **命中条件（`c2`）**：经[前置六项视觉盘点](./00.common.rules.md#22-前置六项视觉盘点分类取证)确认，画面主体人物数量为 `0` 人。
- **兜底判定**：若画面包含极小比例远景人物（仅作建筑比例尺、五官与穿搭不可辨），按 `c2` 处理，并在 `【严格要求】` 中根据用户诉求决定是否移除远景路人。
- **边界分流**：含 1 位明确主体人物转 [01.single-portrait.entrypoint.md](./01.single-portrait.entrypoint.md)；含 2 位及以上主体人物转 [03.multi-character.entrypoint.md](./03.multi-character.entrypoint.md)。若原图有前景人物需要像素级去人还原，应交 `verdantflare-filmset-restore`，不归本能力。

## 3. 工作流

1. **输入核验与六项视觉盘点**：确认单张静态空景图可读；盘点画幅比例、景别（大远景/中景室内/建筑全景）、时代与建筑规制、可见固定构件/灯具/家具/材质清单、光源方向与主导色偏，以及台标/字幕/现代穿帮污染项。
2. **按 C2 七段式逐块撰写**：严格按 [分块模板库](./templates.md#3-c2-无人纯场景--建筑空景七段式) 顺序填充 `【空间定位】`、`【主体建筑】`、`【陈设与材质】`、`【空间层次】`、`【光影氛围】`、`【摄影构图】`、`【严格要求】`。
   - 写清多灯具或重复构件（悬吊灯管、廊柱、门窗）的真实空间排布（居中纵深或左右错落），避免模型自动居中对称。
   - 强电影调色或高偏色场景在 `【光影氛围】` 显式声明主导色偏方向与强度，避免中性白平衡校正。
3. **确定性静态校验**：将正文写入临时文本，运行 `python -X utf8 scripts/prompt_lint.py lint .tmp/reverse-prompt/draft.txt --category c2`，退出码非 `0` 时修复直至返回 `0`。
4. **按需变体转换与校验**：需要 `template` 或 `en` 时在通过校验的中文事实基线上转换并执行对应 `--variant` 校验。
5. **可选纯文生图闭环复现**：仅用户显式要求时协同 `verdantflare-image` 仅传文本生图、按 K09 分级并按八维标准对照评分（最多重跑 1 轮）；超时或 `queued` 时保留原任务 ID 查询，不重复提交。

## 4. 规范

遵循 [公共规范](./00.common.rules.md) 全部四大硬规则，并重点落实 `c2` 专项约束：

- **严格无人配对**：`【严格要求】` 必须包含 `严格无人空景，不要出现人物、行人、剪影或手部入镜`，防止生图模型自动塞入路人或游客。
- **构件排布与色偏显式化**：重复构件必须写明具体位置关系，强偏色必须写明色偏强度与方向；禁止使用空洞形容词替代建筑材质、旧化痕迹与光学参数。
- **年代题材防穿帮**：古装、民国或历史空景必须写清地面铺装与建筑材质，并在 `【严格要求】` 配对 `不要现代元素`。
- **通用必配**：`【严格要求】` 必含 `不要拼图，不要文字，不要额外水印`。

## 5. 验收

- 运行 `python -X utf8 scripts/prompt_lint.py lint <draft> --category c2`（及对应 `--variant`）退出码为 `0`，七段标题齐全、画幅有效、含无人空景配对负向约束且无污染词。
- 若启用可选闭环复现，满足[公共验收标准](./00.common.acceptance.md)的总分 `>= 80` 且第 6、8 维均 `>= 10` 分，复现图中无误入路人、灯具排布与主导色偏未跑偏。
- 交付正文、可选“补全说明”与校验结论行，闭环结果与人工终审分列说明。
