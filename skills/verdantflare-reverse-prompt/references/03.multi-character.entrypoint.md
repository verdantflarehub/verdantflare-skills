# 多人互动剧照分角色八段式反推（03.multi-character）

## 1. 输入与输出

- **输入**：单张含 2 位及以上视觉主体人物的静态互动场景图或影视剧照，以及可选输出变体（`default` / `template` / `en`）与覆盖要求。
- **输出**：通过 `prompt_lint.py --category c3` 校验的分角色八段式结构化提示词正文（或对应变体）、可选“补全说明”与校验结论。
- **公共依据**：[公共规范](./00.common.rules.md)、[公共验收标准](./00.common.acceptance.md)、[分块模板库](./templates.md)。

## 2. 分类

- **命中条件（`c3`）**：经[前置六项视觉盘点](./00.common.rules.md#22-前置六项视觉盘点分类取证)确认，画面存在 `2` 位及以上视觉主体人物，且人物之间存在明确空间站位、前后遮挡或动作/视线交互。
- **边界分流**：仅 1 位主体人物转 [01.single-portrait.entrypoint.md](./01.single-portrait.entrypoint.md)；无主体人物转 [02.empty-scene.entrypoint.md](./02.empty-scene.entrypoint.md)。若需对多张不同机位剧照做整片参考资产沉淀，交 `verdantflare-reference-learning`。

## 3. 工作流

1. **输入核验与六项视觉盘点**：确认单张静态图可读；统计精确主体人数 `N`，按画面主次与左右/前后位置建立人物编号（主体人物 A、主体人物 B……），盘点各角色服装色系与交互道具、画幅景别、光源色调与画面污染项。
2. **按 C3 分角色八段式逐块撰写**：严格按 [分块模板库](./templates.md#4-c3-多人互动--影视剧照分角色八段式) 顺序填充 `【人物形象】`、`【发型与妆容】`、`【完整服装搭配】`、`【场景环境】`、`【人物关系与姿态】`、`【摄影构图】`、`【画面质感】`、`【严格要求】`。
   - 前三块按人物 A、人物 B……分行独立描述并显式区分主色调与站位锚点，防止多角色串色或站位互换。
   - `【人物关系与姿态】` 写清相对站位、前后遮挡关系、视线交汇方向、肢体/道具交互与情绪张力。
3. **确定性静态校验**：将正文写入临时文本，运行 `python -X utf8 scripts/prompt_lint.py lint .tmp/reverse-prompt/draft.txt --category c3`，退出码非 `0` 时修复直至返回 `0`。
4. **按需变体转换与校验**：需要 `template` 或 `en` 时在通过校验的中文事实基线上转换并执行对应 `--variant` 校验。
5. **可选纯文生图闭环复现**：仅用户显式要求时协同 `verdantflare-image` 仅传文本生图、按 K09 分级并按八维标准对照评分（最多重跑 1 轮）；超时或 `queued` 时保留原任务 ID 查询，不重复提交。

## 4. 规范

遵循 [公共规范](./00.common.rules.md) 全部四大硬规则，并重点落实 `c3` 专项约束：

- **分角色隔离与成年必写**：每位主体人物必须在 `【人物形象】` 分别写明成年年龄段、骨相气质与画面方位（如“画面左侧/前景”），在 `【完整服装搭配】` 分别写明主色调与材质，严禁跨角色混写或出现真实明星姓名。
- **人数与防混淆锁定**：`【严格要求】` 必须追加 `人物数量严格锁定为 N 人，不增减人物，服装与面部特征不互相混淆`（`N` 替换为实际主体人数）。
- **构图与质感配对**：含全身构图时配对防裁切约束；写实剧照配对真实皮肤纹理与去塑料感约束；年代剧照配对 `不要现代元素`；必含 `不要拼图，不要文字，不要额外水印`。

## 5. 验收

- 运行 `python -X utf8 scripts/prompt_lint.py lint <draft> --category c3`（及对应 `--variant`）退出码为 `0`，八段标题齐全（含 `【人物关系与姿态】`）、人数锁定与配对负向约束完整、无占位符或水印词残留。
- 若启用可选闭环复现，满足[公共验收标准](./00.common.acceptance.md)的总分 `>= 80` 且第 6、8 维均 `>= 10` 分，复现图中人数准确、无串色或站位互换。
- 交付正文、可选“补全说明”与校验结论行，闭环结果与人工终审分列说明。
