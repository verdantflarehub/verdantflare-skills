# 单图场景反推提示词公共验收标准

## 1. 当前依据

- [技能入口](../SKILL.md)：技能范围与能力清单。
- [公共规范](./00.common.rules.md)：四大核心硬规则与配对负向清单。
- [校验脚本](../scripts/prompt_lint.py)：确定性静态校验实现。

## 2. 静态质量门禁（必过）

每次交付前必须运行 `scripts/prompt_lint.py lint` 且退出码为 `0`：

- **退出码 `0`**：全部必选分块齐全、顺序正确、各块达到最低信息密度、画幅声明有效、对应场景配对负向约束完整、无残留占位符与水印污染词。
- **退出码 `2`**：存在阻断级错误（缺块、空块、缺画幅、漏配对负向约束、非 `template` 模式残留 `{{...}}` 或 `TODO`、包含禁用平台水印词），必须修复后复跑，禁止带错交付。

常用校验与解析命令：

```text
python -X utf8 scripts/prompt_lint.py lint .tmp/reverse-prompt/draft.txt --category c1
python -X utf8 scripts/prompt_lint.py lint .tmp/reverse-prompt/draft.txt --category c2 --json
python -X utf8 scripts/prompt_lint.py lint .tmp/reverse-prompt/tpl.txt --category c1 --variant template
python -X utf8 scripts/prompt_lint.py lint .tmp/reverse-prompt/en.txt --category c1 --variant en
python -X utf8 scripts/prompt_lint.py parse .tmp/reverse-prompt/draft.txt --category c1 --json
python -X utf8 -m unittest discover -s scripts -p "test_*.py"
```

- `--category`：`c1`（单人完整场景）、`c2`（无人纯场景）、`c3`（多人互动剧照）。
- `--variant`：`default`（默认中文直出）、`template`（允许 `{{变量}}` 并输出变量清单）、`en`（校验英文自然语言段落与负向约束）。
- `--json`：输出机器可读结构化结果（含 `status`、`errors`、`warnings`、`sections`、`aspect_ratio`、`variables`）。

## 3. 八维复现对照评分标准（可选闭环验证用）

当执行“原图 → 反推提示词 → 纯文生图复现”闭环验证时，对原图与复现图按以下八个维度逐项客观打分（每维 `0～12.5` 分，满分 `100` 分），用于量化提示词还原力与定位漏项，不替代人类审美终审：

| 评分维度               | 满分与核查要点                                                         |
| :--------------------- | :--------------------------------------------------------------------- |
| 1. 主体身份 / 空间定位 | `12.5` 分：人物年龄气质骨相或建筑时代规制是否准确还原                  |
| 2. 发型妆容 / 核心构件 | `12.5` 分：发型发饰妆面清透度，或门窗屋檐柱廊等结构是否一致            |
| 3. 服装配饰 / 陈设材质 | `12.5` 分：主服装色系面料纹样、配饰袜履道具，或室内外材质肌理是否完整  |
| 4. 场景环境 / 空间层次 | `12.5` 分：前中远景布局、背景建筑植被与天气氛围是否吻合                |
| 5. 人物姿态 / 动线关系 | `12.5` 分：站位朝向、手势与道具交互、多人关系或空间引导线是否一致      |
| 6. 摄影构图与画幅      | `12.5` 分：画幅比例、景别、机位高度、主体占比与头脚留白是否匹配        |
| 7. 光影质感与色彩      | `12.5` 分：光源方向性质、焦段景深、整体色调与真实皮肤/面料质感是否还原 |
| 8. 严格要求达标度      | `12.5` 分：是否出现裁切头脚、塑料皮肤、现代穿帮、拼图、文字或水印翻车  |

- **闭环参考阈值**：总分 `>= 80` 且第 6、8 维均 `>= 10` 分视为纯文生图高保真达标；任一维度 `< 8` 分时必须定位提示词漏项或歧义词并记录修订。

## 4. 典型失败案例排查

1. **全身照反推后重生变成半身照**：原因为仅写了“全身照”而未明确镜头距离与头脚留白。预防：在 `【摄影构图】` 写明“人物从头顶到鞋底完整呈现，镜头保持足够距离”，并在 `【严格要求】` 配对“完整全身入镜，头部、双腿、鞋子全部保留，不得裁切，不要半身照”。
2. **写实人像重生出现过度磨皮塑料脸**：原因为只写“皮肤白皙”未强调真实微纹理。预防：在 `【人物形象】` 写“保留真实皮肤纹理、自然毛孔与细腻光泽，不要假面感”，并在 `【严格要求】` 配对“不要塑料皮肤”。
3. **古风/民国场景混入现代路灯、玻璃幕墙或现代鞋款**：原因为背景与鞋履描述过简且缺时代排除约束。预防：写清地面铺装、建筑材质与具体鞋履形制，并在 `【严格要求】` 显式加“不要现代元素”。
4. **无人空景重生自动冒出路人或游客**：原因为未在 `【严格要求】` 声明严格无人。预防：`c2` 必配“严格无人空景，不要出现人物、行人、剪影或手部入镜”。
5. **反推文本抄入原图字幕或平台水印**：原因为未做前置污染剔除。预防：盘点阶段剔除文字与台标，并通过 `prompt_lint.py` 拦截水印词。
6. **多灯具或强偏色空景被模型自动居中对称与中性白平衡**：真图闭环实测中，未指明灯具错落位置与色偏强度时，模型倾向把顶灯排成居中直线并弱化冷青蓝电影偏色。预防：在 `【空间层次】` 写明构件左右错落位置，在 `【光影氛围】` 显式声明主导色偏强度。

## 5. 交付报告要求

- **常规单图反推交付**：直接给出通过校验的提示词正文；若存在画外推断补全项，在正文下方单列简短“补全说明”；附带一行校验结论（类别、变体、`prompt_lint.py` 通过）。
- **含闭环复现验证交付**：额外区分“静态校验结果”“纯文生图复现与 K09 分级结果”“八维对照评分与偏差修订”，不把静态通过等同于复现效果已获人工终审。
