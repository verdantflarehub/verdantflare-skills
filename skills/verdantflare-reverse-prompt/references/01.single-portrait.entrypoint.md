# 单人完整场景八段式反推（01.single-portrait）

## 1. 输入与输出

- **输入**：单张含 1 位视觉主体人物的静态场景图（穿搭图、定妆参考图、人像场景图或单人影视剧照），以及可选的输出变体（`default` / `template` / `en`）与显式景别/画幅覆盖要求。
- **输出**：通过 `prompt_lint.py --category c1` 校验的标准八段式结构化提示词正文（或对应变体）、可选“补全说明”与校验结论。
- **公共依据**：[公共规范](./00.common.rules.md)、[公共验收标准](./00.common.acceptance.md)、[分块模板库](./templates.md)。

## 2. 分类

- **命中条件（`c1`）**：经[前置六项视觉盘点](./00.common.rules.md#22-前置六项视觉盘点分类取证)确认，画面存在 `1` 位明确视觉主体人物（允许远处虚化背景路人不占视觉主导地位）。
- **景别冲突处理**：若原图为半身照但用户显式要求反推“完整全身穿搭”提示词，仍归 `c1`，可见部分按实景写，画外下装/鞋履按原图时代、色系与材质逻辑补全，并在提示词正文下方单列“补全说明”。未获用户要求时严格按原图实际景别反推。
- **边界分流**：无主体人物（含极小比例远景比例尺路人）转 [02.empty-scene.entrypoint.md](./02.empty-scene.entrypoint.md)；2 位及以上主体人物互动转 [03.multi-character.entrypoint.md](./03.multi-character.entrypoint.md)。

## 3. 工作流

1. **输入核验与六项视觉盘点**：确认单张静态图可读并记录用户指定的变体或景别/画幅覆盖项；完成主体人物数量、画幅比例、景别裁切边界、时代风格、可见服装/配饰/环境/光源清单与污染项盘点。
2. **按 C1 八段式逐块撰写**：严格按 [分块模板库](./templates.md#2-c1-单人完整场景默认标杆八段式) 顺序填充 `【人物形象】`、`【发型与妆容】`、`【完整服装搭配】`、`【场景环境】`、`【人物姿态】`、`【摄影构图】`、`【画面质感】`、`【严格要求】`。
   - 先写主体与核心视觉特征，再写环境层次、姿态/锚点关系、摄影构图与画面质感，最后生成与本场景配对的 `【严格要求】`。
   - 画外推断项统一记入正文下方“补全说明”，不在正文伪装成实景。
3. **确定性静态校验**：将正文写入临时文本（如 `.tmp/reverse-prompt/draft.txt`），运行 `python -X utf8 scripts/prompt_lint.py lint .tmp/reverse-prompt/draft.txt --category c1`，退出码非 `0` 时逐项修复直至通过。
4. **按需变体转换与校验**：若用户要求 `template` 或 `en`，在通过校验的中文事实基线上转换并分别执行 `--variant template` 或 `--variant en` 校验（变量表与英文写法见 [分块模板库](./templates.md)）。
5. **可选纯文生图闭环复现**：仅在用户明确要求“验证复现效果”或技能验证阶段执行——调用 `verdantflare-image`（默认 `engine="codex"`，`model="gpt-image-2.6-sunburst"`），仅传反推提示词正文按原图画幅生图，按 K09 完成 `image.rate_content` 内容分级（`nsfw` 立即隐藏），按[八维复现对照评分](./00.common.acceptance.md#3-八维复现对照评分标准可选闭环验证用)打分，关键维度失真时最多修订重跑 1 轮。
6. **失败恢复**：图片模糊或遮挡时按“可见粗粒度特征＋保守合理补全”处理并在“补全说明”如实列出不确定项；生图超时或返回 `queued` 时保留原任务 ID 查询，严禁重复提交。

## 4. 规范

遵循 [公共规范](./00.common.rules.md) 全部四大硬规则，并重点落实 `c1` 专项约束：

- **成年年龄段必写**：`【人物形象】` 必须显式写出成年年龄段（如“23岁的成年东方女性”），严禁使用明星或真人姓名。
- **全身防裁切配对**：凡构图含“全身”，`【摄影构图】` 必须写明镜头距离与头脚留白，`【严格要求】` 必须配对 `完整全身入镜，头部、双腿、鞋子全部保留，不得裁切，不要半身照`。
- **写实人像质感配对**：写实人像在 `【人物形象】` 强调真实皮肤纹理与自然毛孔，在 `【严格要求】` 配对 `保留真实皮肤纹理与自然毛孔，不要塑料皮肤，不要假面感`。
- **年代题材防穿帮**：民国、古装、年代剧等题材必须在 `【严格要求】` 配对 `不要现代元素`，并写清地面铺装、建筑材质与具体鞋履形制。
- **通用必配**：`【严格要求】` 必含 `不要拼图，不要文字，不要额外水印`。

## 5. 验收

- 运行 `python -X utf8 scripts/prompt_lint.py lint <draft> --category c1`（及对应 `--variant`）退出码为 `0`，八段标题齐全、画幅有效、配对负向完整且无占位符或水印词残留。
- 若启用可选闭环复现，满足[公共验收标准](./00.common.acceptance.md)的总分 `>= 80` 且第 6、8 维均 `>= 10` 分，并经 K09 内容分级。
- 交付正文、可选“补全说明”与校验结论行，闭环验证时分列静态校验、复现分级与八维评分，不替代人工审美终审。
