# 单图场景反推提示词公共规范

## 1. 当前依据

- [技能入口](../SKILL.md)：技能范围、三类原子能力清单与协作边界。
- [公共验收标准](./00.common.acceptance.md)：静态门禁、八维复现对照评分与失败案例排查。
- [分块模板库](./templates.md)：`c1` / `c2` / `c3` 完整分块 Schema、`template` 变量规范与 `en` 写法。
- [校验脚本](../scripts/prompt_lint.py)：可自动检查规则的确定性实现。

## 2. 适用输入与前置六项视觉盘点

### 2.1 适用与越界输入（v1 仅单图）

- **适用输入**：单张本地静态图片（`.png` / `.jpg` / `.jpeg` / `.webp`）或已解析为单张图像的受控 Artifact，包括实拍影视剧照、角色定妆照、完整穿搭图、室内外空景片场图、概念氛围图及 `verdantflare-filmset-restore` 产出的 Clean Plate。
- **不适用输入**：多角度组图联合反推、视频文件自动抽关键帧反推、整片/整曲分镜资产沉淀（交 `verdantflare-reference-learning`）、需要像素级去人物或共边补图（交 `verdantflare-filmset-restore`）、纯文字创意扩写（无参考原图）。
- **越界处理**：用户一次传入多张图片或视频并要求综合反推时，明确告知 v1 仅支持单图，请用户指定其中 1 张主图执行，或拆分为逐张独立反推。

### 2.2 前置六项视觉盘点（分类取证）

在动笔写提示词前，必须先对单图执行六项客观盘点，不得跳过直接套模板：

1. **主体人物数量**：`0` 人、`1` 位主体人物（含远处虚化背景路人不超过视觉主导地位）、或 `2` 位及以上主体人物。
2. **画幅与方向**：读取或估算图像宽高比（如 `9:16` 竖版、`16:9` 横版、`3:4`、`4:3`、`1:1`）。
3. **景别与裁切边界**：全身（头顶至鞋底完整入镜）、七分/膝上、半身、近景/特写、或大远景/建筑全景。
4. **时代与风格基调**：写实摄影（现代/民国/古装/工业/复古胶片）、影视剧照、或非写实绘画/二次元/3D 渲染。
5. **可见关键要素清单**：列出主服装层数、可见配饰与手持道具、前景/中景/远景关键构件、光源方向与色温。
6. **污染与缺损项**：识别画面中的台标、字幕、水印、黑边、现代穿帮杂物，以及被裁切或被遮挡的局部。

## 3. 四大核心硬规则

### 3.1 可见事实与合理补全分离

- 正文优先还原原图真实可见的构图、光影、配色、服装层数、道具与环境构件。
- 若原图存在画面裁切（如半身照）或局部遮挡，而用户要求输出完整全身提示词，允许按原图时代、色系与材质逻辑做风格一致补全，但必须在提示词正文之外单列“补全说明”逐项标明哪些部位属于推断补全。
- 未获用户要求“补全全身”时，严格按原图实际景别反推，不擅自把近景或半身改写为全身。

### 3.2 去污染、脱敏与成年合规清洗

- **画面污染剔除**：自动忽略原图中的字幕条、平台水印、台标、上下黑边、播放器 UI 边框以及明显不属于该时代设定的现代穿帮杂物（如拍摄灯架、路牌二维码），严禁把这些元素写入正向描述。
- **去真实姓名**：人物外貌必须转化为可泛化的年龄段、地域气质、脸型骨相、五官比例与神态描述；严禁出现真实明星、网红或素人的姓名。
- **成年与内容分级红线**：凡涉及人物（`c1` / `c3`），必须在 `【人物形象】` 中明确写出成年年龄段（如“23岁的成年东方女性”“30岁左右的成年男性”）；如触发可选生图复现，必须经 `verdantflare-image` 执行 K09 `image.rate_content` 内容分级。

### 3.3 防漏项与负向约束自配对

`【严格要求】` 必须包含基础通用约束，并按场景特征自动配对专项约束：

- **通用必配（全部类别）**：`不要拼图，不要文字，不要额外水印`。
- **全身构图配对（含“全身”时必配）**：`完整全身入镜，头部、双腿、鞋子全部保留，不得裁切，不要半身照`。
- **写实人像配对（`c1` / `c3` 写实风格必配）**：`保留真实皮肤纹理与自然毛孔，不要塑料皮肤，不要假面感`。
- **时代/历史题材配对（民国、古装、年代剧等必配）**：`不要现代元素`。
- **无人纯场景配对（`c2` 必配）**：`严格无人空景，不要出现人物、行人、剪影或手部入镜`。

### 3.4 物理可描述性优先

- 所有描述必须落到生图模型可执行的具体视觉属性：色名与明度（如“月白色”“淡青瓷绿色”）、材质与工艺（如“真丝面料”“白色兰花与竹叶刺绣”“青石板”）、光源与方向（如“柔和阴天漫射光”“左侧窗斜射暖光”）、焦段与机位（如“85mm镜头”“平视机位”）。
- 多灯具或重复构件（如悬吊灯管、廊柱、窗户）必须写明空间排布方式（“居中纵深排布”还是“左右错落分布”），避免模型默认对称居中。
- 强电影调色或高偏色场景必须显式声明色偏方向与强度（如“强烈冷青蓝色调主导”），避免模型自动做中性白平衡校正。
- 禁止用“非常好看、绝美、高级感拉满、氛围感十足、大师级杰作”等空洞抽象形容词替代具体画面特征。

## 4. 输出变体分流与默认值

| 变体模式          | 适用意图与输出特征                                                                     |
| :---------------- | :------------------------------------------------------------------------------------- |
| `default`（默认） | 直接输出中文结构化 `【...】` 分块正文，可直接复制生图，不掺杂额外寒暄                  |
| `template`        | 保留构图、光影、质感与严格要求骨架，将可变主体/服装/场景替换为 `{{变量名}}` 并附变量表 |
| `en`              | 按同等视觉信息密度转为自然流畅的英文摄影描述段落与负向约束句，不堆砌碎片标签           |

- **默认输出语言与格式**：中文结构化 `【...】` 分块直出；仅在用户明确要求时切换 `template` 或 `en`。
- **默认画幅**：严格继承原图实际宽高比；用户显式指定改画幅（如将 `3:4` 改为 `9:16`）时按用户指定写入，并在“补全说明”中注明因画幅变化增加的上下或左右延展空间。
- **默认不生图**：单次反推请求只交付文本提示词与校验结果；只有用户明确要求“跑图验证”或“直接按反推提示词重画”时才协同 `verdantflare-image`。
- **更新条件**：后续若在真图闭环复现中发现新的高频跑偏项（如特定面料失真或多人手部错乱），经真实案例验证有效后再补充进第 3.3 节配对清单与校验脚本。
