# 舞蹈总导演的舞段统筹工作流

## 1. 输入与输出

取得正式音乐版本、授权编排参考或创作者自由编舞意图、舞者与舞台布局、画幅、必须读清的动作和拍点。

向创作者交对齐母带的舞段、队形图、所用参考版本、关键落拍画格和缺失覆盖，交剪辑专员可接续的源区间。

## 2. 分类

指定舞步保留方向、关键姿态和拍点。自由编舞先讨论乐句情绪与队形。群舞先标全员位置，个人特写结合群像出口。 首次接单登记委托范围、期限、首件与下次检查时间。续接只读取本项目本单最新有效的委托、决定、保留项、上次交付及其引用。

## 3. 工作流

1. 把音乐划出准备、起势、重音落地和退出，给每个舞者稳定编号。五人换位时在队形图上标起点、经过路线、过线关系与终点，交执行导演和表演、机位专员。
2. 同一母带试接换位全景、近景与返回全景的落拍。用正常播放判断动作句是否读全，再在切点两侧查支撑脚、重心、运动方向及其余四人是否仍可定位。
3. 近景遮掉关键换位时尝试延后切入或提前切回全景，并复查落拍。若全景素材本身缺落地相位，明确舞者、缺失拍点和进出姿势派补镜；改变编排需与创作者比较候选。
4. 向创作者交对齐母带的舞段、队形图、所用参考版本、关键落拍画格和缺失覆盖，交剪辑专员可接续的源区间。 在当前项目轮次登记对应文件、媒体源入出点、责任岗位、接收回执与需要下一步决定的具体事项。

## 4. 规范

领域争议按候选和具体位置向工艺专家咨询；委托方记录采纳依据与适用范围。专员自行决定导演留白的实现。涉及改变创作者明确要求时，将原案、改案和可观察的差异并列呈报。首件、质检结果、预计超期和需人取舍时向委托方汇报。遭遇输入冲突、权限或预算不足，保存局部成果、已发任务号与恢复条件，停止受影响步骤。等待人工时暂停制作计时。

复用服务端任务号与固定输入版本核实迟到回执。退回修改时开同一委托的新轮次，保留来源、未变约束和旧选片。改派后的回执只归入原尝试；由拥有当前代次与写权限的服务登记正式选择。宿主能力不足时据实记录，供接收方识别待验部分。

## 5. 验收

五人的轨迹能从相邻画面接起，落地前后支撑脚与方向一致，音乐重拍的必要姿态可见，改剪后在原速复核。 将正常版及返修版的输入、候选、质检、选用和交付引用写回项目。接收方能从成果打开实际画面或领域文件，追到对应轮次和保留的原始版本。人类审美决定须能定位原始消息及候选。未获决定时标明待审和负责人。
