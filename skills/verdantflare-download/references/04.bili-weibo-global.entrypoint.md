# B站、微博、X、YouTube 与全网通用下载（04.bili-weibo-global）

## 1. 输入与输出

- **输入**：哔哩哔哩（`bilibili.com/video/BV...`、`b23.tv/...`）、新浪微博（`weibo.com/tv/show/...`、`video.weibo.com/show?fid=...`）、X / Twitter（`x.com/.../status/...`、`twitter.com/.../status/...`、`t.co/...`）、YouTube（`youtube.com/watch?v=...`、`youtu.be/...`、`youtube.com/shorts/...`）以及 Reddit、Instagram、TikTok 等全网公开媒体链接。
- **输出**：最高码率标准 `.mp4` 视频（含 B 站/YouTube DASH 音画无损混流）、X/微博无损原图画廊（`_gallery/*.jpg`，图文混合推文双路落盘）、`*_metadata.json` 与 `C3` 门禁评测报告。
- **公共依据**：[公共规范](./00.common.rules.md)、[公共验收标准](./00.common.acceptance.md)、[通用下载与路由入口](./01.generic-http.entrypoint.md)。

## 2. 分类

由 [mk_video_download.py](../scripts/mk_video_download.py) 中的 `classify_platform_and_category()` 判定为 `C3` 类：

| 特征指标名         | 命中阈值区间                                                 |
| :----------------- | :----------------------------------------------------------- |
| `host_domain`      | 未命中 `C1` 与 `C2` 域名集合的所有合法 `http/https` 域名     |
| `sub_parser_route` | `bilibili`、`weibo`、`twitter`、`youtube` 及 `ytdlp_generic` |

- **媒体资产形态**：涵盖 B 站单 P/多 P 投稿视频、微博高清视频与九宫格原图、X/Twitter 最高码率 MP4 推文视频、纯多图推文画廊（`?format=jpg&name=orig` 原图）与图文视频混合推文（`media_type == "mixed"`）、YouTube `1080p/2K/4K` 音视频分离 DASH 混流视频及全网通用流媒体。
- **与 `C1 / C2` 边界**：凡属于抖音、西瓜、小红书、快手的链接严禁流入 `C3` 的 `ytdlp_generic` 分支（无 Cookie 会报 `403 Forbidden`）。
- **典型正反例**：正例 `BV1xx411c7mD`（B 站视频）、`x.com/user/status/1234567890`（X 推文视频）；反例为受 DRM 加密流媒体或需付费会员解锁的番剧（触发 `Gate G1` 阻断）。

## 3. 工作流

| 步骤编号 | 步骤名称与输出产物                                                               |
| :------- | :------------------------------------------------------------------------------- |
| `Step 1` | 识别子平台标识并解包短链                                                         |
| `Step 2` | 调用免登 API 或 `yt-dlp --js-runtimes node` 获取最高码率流与原图集               |
| `Step 3` | 流式下载、并发分片 DASH 混流或双路落盘，输出 `.mp4`、`.jpg` 与 `*_metadata.json` |

1. **Step 1（短链解包与标识提取）**：
   - B 站：跟随 `b23.tv` 提取 `BV` 号，请求 `api.bilibili.com/x/web-interface/view?bvid=<bvid>` 获取首 P 的 `cid` 与分辨率元数据。
   - X / Twitter：跟随 `t.co` 重定向提取数字 `tweet_id`。
   - YouTube：从 `watch?v=`、`youtu.be/` 或 `shorts/` 提取 11 位 `video_id`，自动探测本机 Node.js 运行时（`--js-runtimes node`）以解锁 EJS 签名挑战。
2. **Step 2（免登直链提取与最高码率排序）**：
   - **B 站免登 1080p DASH 与 16 线程多镜像并发混流**：优先请求 `api.bilibili.com/x/player/playurl?otype=json&fnver=0&fnval=16&qn=80&bvid=<bvid>&cid=<cid>&platform=pc&high_quality=1&try_look=1` 获取免登 `1080P`（`id=80, avc1`）DASH 视频流与 `192kbps`（`id=30280, mp4a`）DASH 音频流（含 `backupUrl` 多 CDN 镜像）；下载阶段通过 16 线程 HTTP `Range` 分片并发轮询多 CDN 镜像突破单连接限速，再调用 `ffmpeg -c copy -movflags +faststart` 无损混流为标准 `.mp4`（无 DASH 流时回退 `platform=html5&fnval=0` 的 `durl[0].url`）。
   - **X / Twitter Syndication $\pi$-Token 全模态算子**：计算令牌 $\text{token} = \text{replace}(\text{str}((\text{tweet\_id} / 10^{15}) \times \pi), \{0, .\})$ 请求 `cdn.syndication.twimg.com/tweet-result`；遍历 `mediaDetails` 全数组，对 `video` / `animated_gif` 筛选 `content_type == "video/mp4"` 且 `bitrate` 最大的直链；对 `photo` 升级为 `?format=jpg&name=orig` 无损原图；图文视频同帖自动标记 `media_type = "mixed"` 双路全量落盘。
   - **YouTube DASH 优选与 8 线程并发混流**：调用 `yt-dlp --js-runtimes node` 提取全量 `formats`，按目标画质（`4K/2K/1080p/720p`）优先锁定 H.264（`vcodec^=avc1`）最高码率视频轨与 `m4a` 音轨，通过 `--concurrent-fragments 8 --merge-output-format mp4` 拉流并无损封装。
   - **全网通用兜底**：未命中上述四者的 URL 直接调用 `yt-dlp` 下载并自动调用 `ffmpeg` 混流封装。
3. **Step 3（执行下载与门禁验收）**：

```powershell
$env:PYTHONUTF8="1"; python scripts/mk_video_download.py --input "<bili_weibo_x_or_global_url>" --output-dir "./.gdrive/downloads" --evaluate
```

4. **异常自愈与熔断回退**：
   - **原生 API 失败降级 `yt-dlp`**：B 站、微博或 X 轻量 API 因风控临时返回非 `200` 状态码时，无缝回退至 `parse_via_ytdlp()` 完成下载。
   - **硬门禁熔断**：目标视频需登录大会员或含 DRM 加密导致流不可读时，直接输出 `FAIL` 并阻断落盘。

## 4. 规范

### 4.1 专属操作禁令

1. **严禁 B 站 CDN 下载漏传 `Referer`**：B 站音视频 CDN 强制校验防盗链头，下载时必须携带 `Referer: https://www.bilibili.com/` 与桌面端 `User-Agent`，否则直接触发 `403 Forbidden`。
2. **严禁 X/Twitter 混入 `.m3u8`、最低码率流或漏采图文混合推文**：视频节点必须先过滤 `content_type == "video/mp4"` 再按 `bitrate` 降序取首项；图片节点升级为 `?format=jpg&name=orig`；`media_type == "mixed"` 必须双路全量落盘，严禁只下视频丢弃配图或因正文含外链导致 `yt-dlp` 报错中断。
3. **严禁 YouTube 1080p+ 仅下载单轨或缺失 JS 运行时**：YouTube `1080p` 及以上画质均为 DASH 音视频分离流，必须显式传入 `--js-runtimes node` 挂载本机 Node.js 并调用 `ffmpeg` 混流为含 AAC 音轨的标准 MP4。

### 4.2 专属算子参数与评分细则

| 算子或接口参数           | 固定取值与约束简述                                      |
| :----------------------- | :------------------------------------------------------ |
| B 站免登 1080p DASH 参数 | `qn=80&fnval=16&platform=pc&high_quality=1&try_look=1`  |
| Twitter Syndication 令牌 | 基于 `tweet_id / 10^15 * pi` 去零与小数点（公式见下）   |
| Twitter 原图画质升级参数 | `?format=jpg&name=orig`                                 |
| YouTube DASH 优选格式    | 优先锁定 `height<=1080` 的 `avc1` 视频流加 `m4a` 音频流 |

- **B 站免登 1080p DASH 参数**：`qn=80&fnval=16&platform=pc&high_quality=1&try_look=1`（含 `backupUrl` 16 线程 Range 并发 + `ffmpeg -c copy` 混流）。
- **Twitter Syndication 令牌公式**：$\text{token} = \text{str}((\text{float}(\text{tweet\_id}) / 10^{15}) \times \pi)\text{.replace}("0", "")\text{.replace}(".", "")$。
- **YouTube DASH 优选格式表达式**：`bestvideo[height<=1080][vcodec^=avc1]+bestaudio[ext=m4a]/bestvideo[height<=1080][ext=mp4]+bestaudio[ext=m4a]`。
- **评分细则**：X/Twitter 或微博成功选取最高码率项且音画双轨完整时，$S_3 = 20.0$；B 站或 YouTube DASH 未合并导致有画无声（非原片静音）时触发 `Gate G3` 扣分告警。

## 5. 验收

调用 [video_download_evaluator.py](../scripts/video_download_evaluator.py) 指定 `--category C3` 完成测量，必须同时通过 `Gate G1 ~ G3` 与以下 `Gate G4 · C3` 维度：

| 验收维度                     | 关键考核要求与阈值简述                                        |
| :--------------------------- | :------------------------------------------------------------ |
| 最高码率变体与原图升级合规性 | 视频取最大 `bitrate`，图片取 `orig`，混合推文双路保存         |
| 容器封装与双轨完备性         | 标准 `.mp4` 容器，`ffprobe` 检出有效视频流与音频轨            |
| 字节完整度                   | 误差 $\Delta_{\text{size}} \le 1\%$（或 `yt-dlp` 退出码 `0`） |
| 综合质量总分门禁             | 100 分制总分 $\text{Score} \ge 80.0$ 分                       |

- **最高码率变体与原图升级合规性**：X/Twitter 视频满足 `content_type == "video/mp4"` 且取最大 `bitrate`，图片带 `?format=jpg&name=orig`，`media_type == "mixed"` 时视频与 `_gallery/*.jpg` 同时存在；YouTube 1080p+ 完成 DASH 音画合并。
- **容器封装与双轨完备性**：标准 `.mp4` 容器，`ffprobe` 检出有效视频流（$W > 0, H > 0, \text{duration} > 0$）及有效音频轨（原片无声除外）。
- **字节完整度**：实际文件大小与 `expected_size` 相对误差 $\Delta_{\text{size}} \le 1\%$（或 `yt-dlp` 退出码 `0` 且体积 $\ge 10\text{ KB}$）。
- **综合质量总分门禁**：$\text{Score} \ge 80.0$ 分。
- **人工终审核对清单**：核对视频为该平台公开可获取最高清晰度、播放有声且音画同步、文件命名包含平台、作品 ID、作者昵称与净化标题。
