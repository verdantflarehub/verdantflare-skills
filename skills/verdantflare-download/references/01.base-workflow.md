# 全网无水印视频与图集下载技能（verdantflare-download）全局主干工作流（01.base-workflow）

## 1. 当前依据

- [../SKILL.md](../SKILL.md)：技能顶层入口与全局路由索引。
- [01.base-category.md](./01.base-category.md)：全局分类体系与一级路由决策树。
- [01.base-rules.md](./01.base-rules.md)：全局核心规则与评分标准。
- [01.base-acceptance.md](./01.base-acceptance.md)：全局自动化门禁与验收标准。

## 2. 全链路主干阶段划分

所有分类共享以下三阶段主干骨架，平台专属解析算子在各分类的工作流专册（[C1](./C1.douyin-media-workflow.md) / [C2](./C2.xhs-kuaishou-workflow.md) / [C3](./C3.bili-weibo-global-workflow.md)）中定义：

| 主干阶段        | 阶段名称与核心产出契约                                                          |
| :-------------- | :------------------------------------------------------------------------------ |
| `Stage 1 (CP1)` | 口令净化、短链 302 重定向追踪、平台分类路由与作品唯一 ID 提取                   |
| `Stage 2 (CP2)` | 无水印最高码率视频直链探测、非 WebP 原图图集与实况动图列表提取                  |
| `Stage 3 (CP3)` | 分块流式落盘、首帧截图提取、可选 VS Code Preview 转码与 `Gate G1 ~ G4` 门禁验收 |

## 3. 各阶段通用执行协议

### 3.1 Stage 1：口令净化与重定向解包

1. **输入契约**：接收用户复制的原始分享口令字符串或目标 URL。
2. **执行动作**：调用 [`mk_video_download.py`](../scripts/mk_video_download.py) 中的 `extract_first_url()` 与 `classify_platform_and_category()`，跟随首跳 302 重定向获取真实长链与作品 `item_id`。
3. **输出契约**：确定所属分类标签（`C1` / `C2` / `C3`）、平台标识与 `item_id`。

### 3.2 Stage 2：无水印最高画质直链解析

1. **输入契约**：携带分类标签的真实长链与 `item_id`。
2. **执行动作**：跳转执行对应分类专册的解析函数，剔除带水印流标识（如 `playwm`、`!nd_dft`），锁定最高可用分辨率（如 `1080p` 原画流）与完整作者、标题、封面元数据。
3. **输出契约**：构造内存态 `ParsedMediaResult` 数据对象（当传入 `--parse-only` 时直接序列化输出 JSON）。

### 3.3 Stage 3：流式下载、预览生成与门禁归档

1. **输入契约**：验证通过的 `ParsedMediaResult` 与目标目录 `--output-dir`（默认值为 `./.gdrive/downloads`）。
2. **执行动作**：
   - 使用 `.part` 临时文件执行 256KB 分块流式下载，校验字节数无截断后原子重命名为正式文件。
   - 对视频资产自动调用 `ffmpeg` 抽取高清预览帧 `*_frame.jpg` 及封面图 `*_cover.jpg`。
   - 若指定 `--vscode-preview`，按仓库 `VP9 + MP3` 铁律额外生成 `*_preview_vp9.mp4`。
   - 调用 [`video_download_evaluator.py`](../scripts/video_download_evaluator.py) 执行 `Gate G1 ~ G4` 校验。
3. **输出契约**：落盘媒体文件、`*_metadata.json` 元数据清单及 100 分制评测报告。
