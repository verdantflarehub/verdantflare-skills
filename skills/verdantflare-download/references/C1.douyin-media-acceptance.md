## 2. 分支文字评分规则与数据评分准则（`Gate G4 · C1`）

调用 [`video_download_evaluator.py`](../scripts/video_download_evaluator.py) 指定 `--category C1` 完成测量后，必须同时满足以下文字评分规则与数据评分准则：

| 验收维度               | 关键考核要求与阈值简述                                 |
| :--------------------- | :----------------------------------------------------- |
| 去水印直链与画面纯净度 | 无 `playwm`、图集非 `.webp` 原图（违规封顶 `59.0` 分） |
| 1080p 原画分辨率对齐度 | `expected_width >= 1080` 时实测 $\ge 1920 \times 1080$ |
| 容器与字节完整性       | 误差 $\Delta_{\text{size}} \le 1\%$ 且音视频双轨完备   |
| 综合质量总分门禁       | 100 分制总分 $\text{Score} \ge 90.0$ 分                |

- **去水印直链与画面纯净度**：
  - **文字评分规则**：视频源流必须为无台标原片，画面四角及片尾不得残留“抖音号：xxx”动态跳动贴片或推广黑屏帧。
  - **数据评分准则**：`video_url` 不含 `playwm`；图文笔记 `image_urls` 全部经 `select_non_webp_url()` 过滤为非 `.webp` 原图；违规直接触发 `Gate G1/G4` 封顶 `59.0` 分。
- **1080p 原画分辨率对齐度**：
  - **文字评分规则**：凡源作品支持 1080p 高清流，必须通过 `snssdk` 探针拉取原画，严禁退化为默认的 540p 低码率模糊流。
  - **数据评分准则**：当源片 `expected_width >= 1080` 时，`ffprobe` 实测落盘视频必须满足 $\max(W, H) \ge 1920$ 且 $\min(W, H) \ge 1080$（得满分 $S_1 = 40.0$）。
- **容器与字节完整性**：
  - **文字评分规则**：CDN 流式传输无中途断流截断，音视频轨道同步解封装。
  - **数据评分准则**：实际文件大小与 CDN `Content-Length` 相对误差 $\Delta_{\text{size}} \le 1\%$，`ffprobe` 检出完整音视频双轨（得满分 $S_2 = 30.0$）。
- **综合质量总分门禁**：
  - **文字评分规则**：全维度测量汇总得分达到高清交付标准。
  - **数据评分准则**：100 分制总分 $\text{Score} \ge 90.0$ 分（高清 1080p 完整交付标准分为 `100.0` 分）。

## 3. 异常自愈与熔断回退机制

1. **接口双路自愈**：当普通 `slidesinfo` 返回空列表时，脚本自动追加 `&request_source=200` 二次请求，仍为空时自动回退至 `_ROUTER_DATA` 页面解析。
2. **CDN 节点防过期重连**：抖音 CDN 直链具有时效签名（`dy_q` / `x-expires`），若流式下载中途遭遇 `403` 或字节截断，自动重新请求 `snssdk` 探针刷新 CDN 签名地址后重试。

## 4. 人工终审核对清单

1. **画面水印核对**：确认视频首尾及四角无“抖音号：xxx”半透明贴片与片尾黑屏推广帧。
2. **画质锐度核对**：确认画面为 `1080p` 原生锐利画质（非 `540p` 糊片）。
3. **声画同步核对**：确认人声旁白、背景音乐与画面口型/动作完全同步。
