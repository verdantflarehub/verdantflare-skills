## 2. 本分类专属操作禁令与物理锁死规则

### 2.1 专属操作禁令

1. **禁令一（严禁直接保存小红书 `urlDefault` 带水印压缩图）**：小红书 `imageList` 中的 `urlDefault` 默认带有 `!nd_dft_wlteh_webp_3` 水印与 WebP 压缩后缀；凡原链接含 `notes_pre_post` 路径，必须剥离 `!` 后缀并重构至 `ci.xiaohongshu.com` 节点拉取 JPG 原图。
2. **禁令二（严禁丢弃小红书 `xsec_token` 查询参数）**：解析小红书链接时必须完整保留 URL 查询串中的 `xsec_token` 与 `xsec_source`，严禁在请求前截断查询参数导致返回空状态树。
3. **禁令三（严禁快手长视频走 `/fw/long-video/` 异构模板）**：快手重定向链接若命中 `/fw/long-video/`，必须在二次请求前归一化替换为 `/fw/photo/` 并透传首跳 `share_response.cookies`。

### 2.2 专属算子参数与节点映射

| 算子或节点参数       | 固定取值与约束说明                                                                   |
| :------------------- | :----------------------------------------------------------------------------------- |
| 小红书无水印原图模板 | `https://ci.xiaohongshu.com/notes_pre_post/[spectrum/]<token>?imageView2/format/jpg` |
| 小红书状态树解析器   | 将 `undefined` 替换为 `null` 后调用 `yaml.safe_load()`                               |
| 快手路径归一化规则   | `location_url.replace("/fw/long-video/", "/fw/photo/")`                              |

## 3. 本分类专属评分权重与加减分项

在 [01.base-rules.md](./01.base-rules.md) 全局评分公式基础上，本分类执行以下专属规则：

1. **图文原图满分判定**：当小红书或快手图集全部图片成功落盘且单张体积 $> 2\text{ KB}$、格式为非损坏原图时，$S_1 = 40.0$、$S_2 = 30.0$、$S_3 = 20.0$。
2. **过期链接熔断**：当 `currentNoteId == "undefined"` 或快手 `photo_data.result != 1` 时，直接触发 `Gate G1` 熔断报错。
