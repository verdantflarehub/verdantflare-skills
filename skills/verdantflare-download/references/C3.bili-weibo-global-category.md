## 2. 分类定义与自动化命中判据

### 2.1 视觉与业务特征定义

1. **输入链接与口令形态**：包含哔哩哔哩（`bilibili.com/video/BV...`、`b23.tv/...`）、新浪微博（`weibo.com/tv/show/...`、`video.weibo.com/show?fid=...`）、X / Twitter（`x.com/.../status/...`、`twitter.com/.../status/...`、`t.co/...`）、YouTube（`youtube.com/watch?v=...`、`youtu.be/...`、`youtube.com/shorts/...`）以及 Reddit、Instagram、TikTok 等全网公开媒体链接。
2. **媒体资产形态**：涵盖 B 站单 P / 多 P 投稿视频、微博高清视频与九宫格原图、X / Twitter 最高码率 MP4 推文视频、纯多图推文画廊（`?format=jpg&name=orig` 原图）与图文视频混合推文（`media_type == "mixed"`）、YouTube `1080p/2K/4K` 音视频分离 DASH 混流视频及全网通用流媒体。

### 2.2 自动化分类器数学判据

由 [`mk_video_download.py`](../scripts/mk_video_download.py) 中的 `classify_platform_and_category()` 判定，需满足以下条件：

| 特征指标名         | 命中阈值区间                                                 |
| :----------------- | :----------------------------------------------------------- |
| `host_domain`      | 未命中 `C1` 与 `C2` 域名集合的所有合法 `http/https` 域名     |
| `sub_parser_route` | `bilibili`、`weibo`、`twitter`、`youtube` 及 `ytdlp_generic` |

- `sub_parser_route` 细分为 `bilibili`、`weibo`、`twitter`、`youtube` 四个一级专用解析器及 `ytdlp_generic` 全网兜底引擎。

## 3. 相邻分类边界与降级/升级条件

1. **与 `C1 / C2` 的边界**：凡属于抖音、西瓜、小红书、快手的链接严禁流入 `C3` 的 `ytdlp_generic` 分支（因其反爬签名会导致 `yt-dlp` 无 Cookie 报 `403 Forbidden`）。
2. **典型正例与反例编号**：
   - 正例样本：`BV1xx411c7mD`（B 站视频）、`x.com/user/status/1234567890`（X 推文视频）。
   - 反例样本：受 DRM 加密的流媒体或需付费会员解锁的番剧（触发 `Gate G1` 阻断）。
