## 2. 本分类专属操作禁令与物理锁死规则

### 2.1 专属操作禁令

1. **禁令一（严禁 B 站 CDN 下载漏传 `Referer`）**：B 站音视频 CDN 强制校验防盗链头，下载时必须携带 `Referer: https://www.bilibili.com/` 与桌面端 `User-Agent`，否则直接触发 `403 Forbidden`。
2. **禁令二（严禁 X/Twitter 混入 `.m3u8` 索引、最低码率流或漏采图文混合推文）**：遍历 `mediaDetails` 时，视频节点必须先过滤 `content_type == "video/mp4"` 再按 `bitrate` 降序取首项；图片节点必须升级为 `?format=jpg&name=orig` 原图；当同一推文内同时含图片与视频（`media_type == "mixed"`）时，必须双路全量落盘，严禁只下视频丢弃配图或因推文正文含外链导致 `yt-dlp` 报错中断。
3. **禁令三（严禁 YouTube 1080p+ 仅下载单轨或缺失 JS 运行时）**：YouTube `1080p` 及以上画质均为 DASH 音视频分离流，必须显式传入 `--js-runtimes node` 挂载本机 Node.js 运行时并调用 `ffmpeg` 混流封装为含 AAC 音轨的标准 MP4。

### 2.2 专属算子参数与计算公式

| 算子或接口参数           | 固定取值与约束简述                                      |
| :----------------------- | :------------------------------------------------------ |
| B 站免登 1080p DASH 参数 | `qn=80&fnval=16&platform=pc&high_quality=1&try_look=1`  |
| Twitter Syndication 令牌 | 基于 `tweet_id / 10^15 * pi` 去零与小数点（公式见下）   |
| Twitter 原图画质升级参数 | `?format=jpg&name=orig`                                 |
| YouTube DASH 优选格式    | 优先锁定 `height<=1080` 的 `avc1` 视频流加 `m4a` 音频流 |

- **B 站免登 1080p DASH 参数**：`qn=80&fnval=16&platform=pc&high_quality=1&try_look=1`（含 `backupUrl` 16 线程 Range 并发 + `ffmpeg -c copy` 混流）。
- **Twitter Syndication 令牌公式**：$\text{token} = \text{str}((\text{float}(\text{tweet\_id}) / 10^{15}) \times \pi)\text{.replace}("0", "")\text{.replace}(".", "")$。
- **YouTube DASH 优选格式表达式**：`bestvideo[height<=1080][vcodec^=avc1]+bestaudio[ext=m4a]/bestvideo[height<=1080][ext=mp4]+bestaudio[ext=m4a]`。

## 3. 本分类专属评分权重与加减分项

在 [01.base-rules.md](./01.base-rules.md) 全局评分公式基础上，本分类执行以下专属规则：

1. **最高码率变体命中奖励**：X / Twitter 或微博成功选取 `variants` / `urls` 中最高码率项且音画双轨完整时，$S_3$ 赋满分 `20.0` 分。
2. **有画面无声音熔断**：当 B 站或 YouTube DASH 分离流未执行音画合并导致成片缺失音轨（非原片静音）时，触发 `Gate G3` 扣分告警。
