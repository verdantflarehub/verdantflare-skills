## 2. 分支文字评分规则与数据评分准则（`Gate G4 · C3`）

调用 [`video_download_evaluator.py`](../scripts/video_download_evaluator.py) 指定 `--category C3` 完成测量后，必须同时满足以下文字评分规则与数据评分准则：

| 验收维度                     | 关键考核要求与阈值简述                                        |
| :--------------------------- | :------------------------------------------------------------ |
| 最高码率变体与原图升级合规性 | 视频取最大 `bitrate`，图片取 `orig`，混合推文双路保存         |
| 容器封装与双轨完备性         | 标准 `.mp4` 容器，`ffprobe` 检出有效视频流与音频轨            |
| 字节完整度                   | 误差 $\Delta_{\text{size}} \le 1\%$（或 `yt-dlp` 退出码 `0`） |
| 综合质量总分门禁             | 100 分制总分 $\text{Score} \ge 80.0$ 分                       |

- **最高码率变体与原图升级合规性**：
  - **文字评分规则**：X/Twitter 视频须取最高码率 MP4 流、图片须取 `orig` 原图，图文视频混合推文须双路全量保存；YouTube 1080p+ 须完成 DASH 音画合并。
  - **数据评分准则**：X/Twitter 视频满足 `content_type == "video/mp4"` 且取最大 `bitrate`，图片带 `?format=jpg&name=orig`；`media_type == "mixed"` 时视频与 `_gallery/*.jpg` 同时存在。
- **容器封装与双轨完备性**：
  - **文字评分规则**：合并后的 `.mp4` 容器必须同时包含正常可解码的视频轨与音频轨，杜绝 DASH 分离流未合并导致的有画无声。
  - **数据评分准则**：标准 `.mp4` 容器，`ffprobe` 检出有效视频流（$W > 0, H > 0, \text{duration} > 0$）及有效音频轨（原片无声除外）。
- **字节完整度**：
  - **文字评分规则**：流媒体传输完整无截断。
  - **数据评分准则**：实际文件大小与 `expected_size` 相对误差 $\Delta_{\text{size}} \le 1\%$（或 `yt-dlp` 退出码为 `0` 且文件体积 $\ge 10\text{ KB}$）。
- **综合质量总分门禁**：
  - **文字评分规则**：全维度测量汇总得分达到通用平台交付标准。
  - **数据评分准则**：100 分制总分 $\text{Score} \ge 80.0$ 分。

## 3. 异常自愈与熔断回退机制

1. **原生 API 失败自动降级 `yt-dlp`**：当 B 站、微博或 X 的轻量 API 因平台风控临时返回非 `200` 状态码时，总控脚本支持无缝回退至 `parse_via_ytdlp()` 完成下载。
2. **硬门禁熔断**：若目标视频需登录大会员或含 DRM 加密导致流不可读，直接输出 `FAIL` 并阻断落盘。

## 4. 人工终审核对清单

1. **画质核对**：确认下载视频为该平台公开可获取的最高清晰度版本。
2. **音轨核对**：确认视频播放有声且音画同步。
3. **元数据核对**：确认文件命名包含平台、作品 ID、作者昵称与净化后的标题。
