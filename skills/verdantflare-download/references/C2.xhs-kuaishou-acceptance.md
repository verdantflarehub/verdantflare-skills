## 2. 分支文字评分规则与数据评分准则（`Gate G4 · C2`）

调用 [`video_download_evaluator.py`](../scripts/video_download_evaluator.py) 指定 `--category C2` 完成测量后，必须同时满足以下文字评分规则与数据评分准则：

| 验收维度                     | 关键考核要求与阈值简述                                               |
| :--------------------------- | :------------------------------------------------------------------- |
| 小红书无水印原图节点合规性   | 指向 `ci.xiaohongshu.com` 且不含 `!nd_`（违规封顶 `59.0` 分）        |
| 图集与 Live Photo 序列完备性 | 落盘数量 $N_{\text{saved}}$ 等于 `images` 长度，单图 $> 2\text{ KB}$ |
| 视频流解封装健康度           | `ffprobe` 双轨正常且字节误差 $\Delta_{\text{size}} \le 1\%$          |
| 综合质量总分门禁             | 100 分制总分 $\text{Score} \ge 85.0$ 分                              |

- **小红书无水印原图节点合规性**：
  - **文字评分规则**：图文笔记图片必须剥离右下角小红书半透明水印与 WebP 有损压缩，还原作者上传的 JPG 原图。
  - **数据评分准则**：凡含 `notes_pre_post` 路径的图集 URL 必须指向 `ci.xiaohongshu.com` 且不含 `!nd_` 缩略水印后缀；残留 `!nd_` 触发 `Gate G4` 封顶 `59.0` 分。
- **图集与 Live Photo 序列完备性**：
  - **文字评分规则**：多图笔记的所有轮播图及附带的实况动图必须按原始顺序完整落盘，不得漏图或产生空文件。
  - **数据评分准则**：本地落盘图片数量 $N_{\text{saved}}$ 与笔记 `images` 列表长度严格相等，单张文件体积 $> 2\text{ KB}$，含 `livePhoto` 的项同步生成 `img_XX_live.mp4`。
- **视频流解封装健康度**：
  - **文字评分规则**：小红书视频笔记或快手 `mainMv` 视频必须音画完整，无花屏或音轨丢失。
  - **数据评分准则**：视频文件通过 `ffprobe` 双轨检测，$W > 0$、$H > 0$、$\text{duration} > 0$，相对字节偏差 $\Delta_{\text{size}} \le 1\%$。
- **综合质量总分门禁**：
  - **文字评分规则**：全维度测量汇总得分达到平台交付标准。
  - **数据评分准则**：100 分制总分 $\text{Score} \ge 85.0$ 分。

## 3. 异常自愈与熔断回退机制

1. **非 `notes_pre_post` 路径自适应回退**：当小红书早期历史图片不含 `notes_pre_post` 关键字导致 `ci.xiaohongshu.com` 不支持替换时，脚本自动回退使用原始 `urlDefault` 确保图片成功落盘。
2. **风控硬门禁熔断**：若分享短链已失效或笔记被作者隐藏（`currentNoteId == "undefined"`），脚本立即输出明确错误原因并终止，严禁写入空目录。

## 4. 人工终审核对清单

1. **右下角无水印核对**：确认小红书图片右下角无“小红书号：xxx”半透明水印字样。
2. **多图顺序一致性**：确认 `img_01.jpg ~ img_NN.jpg` 顺序与原笔记轮播顺序完全一致。
3. **Live Photo 动图核对**：若原笔记含实况图，确认同级已生成对应的 `img_XX_live.mp4`。
