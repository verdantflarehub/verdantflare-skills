## 2. 本分类专属操作禁令与物理锁死规则

### 2.1 专属操作禁令

1. **禁令一（严禁盲目依赖 SSR `videoInfoRes`）**：抖音分享页 `window._ROUTER_DATA` 已在常规请求中移除 `videoInfoRes` 字段，严禁只写单一 HTML 正则解析器导致 `KeyError: 'videoInfoRes'`，必须以 `slidesinfo` 双路 API 为第一主干。
2. **禁令二（严禁盲取 `play_addr.url_list[0]` 导致 540p 降质）**：`slidesinfo` 返回的默认 `play_addr` 恒为 `ratio: "540p"` 低码率流（体积仅为原画的 $1/3$）；凡 `video.play_addr.uri` 非空，必须通过 `aweme.snssdk.com/aweme/v1/play/?video_id=<uri>&ratio=1080p&line=0` 探测 1080p 原画流。
3. **禁令三（严禁图集保留 `.webp` 有损缩略图）**：抖音图文笔记的 `images[i].url_list` 中混有 `.webp` 与 `.jpeg` 地址，必须通过 `select_non_webp_url()` 优先提取非 `.webp` 原图并同步保存 `live_photo_url` 实况视频。

### 2.2 专属算子参数与接口契约

| 算子或接口参数            | 固定取值与约束说明                                                            |
| :------------------------ | :---------------------------------------------------------------------------- |
| `slidesinfo` 视频端点     | `https://www.iesdouyin.com/web/api/v2/aweme/slidesinfo/?aweme_ids=%5B<id>%5D` |
| `slidesinfo` 图集端点     | 追加查询参数 `&request_source=200`                                            |
| `snssdk` 原画探针端点     | `https://aweme.snssdk.com/aweme/v1/play/?video_id=<uri>&ratio=1080p&line=0`   |
| 移动端请求头 `User-Agent` | 固定为 iOS 16.6 Safari 移动端标识，携带 `Referer: https://www.iesdouyin.com/` |

## 3. 本分类专属评分权重与加减分项

在 [01.base-rules.md](./01.base-rules.md) 全局 100 分制公式基础上，本分类执行以下细则：

1. **1080p 原画满分项（$S_1 = 40.0$）**：当源片 `expected_width >= 1080` 且成功通过 `snssdk 1080p` 探针落盘 `1920×1080`（或竖屏 `1080×1920`）视频流时，$S_1$ 赋满分 `40.0` 分。
2. **画质退化扣分项**：若源片支持 1080p 但实际落盘流短边仅为 `540`，$S_1$ 降为 `25.0` 分并触发 `Gate G4` 警告。
3. **带水印熔断项**：若下载 URL 中检出 `playwm` 字符串，总分强制封顶 `59.0` 分并判 `FAIL`。
