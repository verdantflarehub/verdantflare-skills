## 2. 工作流步骤概览

| 步骤编号 | 步骤名称与输出产物                                                    |
| :------- | :-------------------------------------------------------------------- |
| `Step 1` | 短链重定向与 Cookie 保持，定位标准详情页 URL                          |

## 3. 分步执行指令与调用协议

### 3.1 Step 1：短链解包与路径归一化

1. **小红书分支**：使用桌面端 Chrome `User-Agent` 跟随 `xhslink.com` 重定向至携带 `xsec_token` 的笔记详情页。
2. **快手分支**：先以非跟随模式请求 `v.kuaishou.com` 获取首跳 `Location` 与下发 Cookie，并将路径中的 `/fw/long-video/` 统一替换为 `/fw/photo/` 以保证返回结构一致。

### 3.2 Step 2：SSR 状态树解析与去水印 URL 重构

1. **小红书视频与原图提取**：
   - 使用 `yaml.safe_load` 解析 `window.__INITIAL_STATE__`（将 JS `undefined` 预替换为 `null`）。
   - 视频笔记直接提取 `note.video.media.stream.h264[0].masterUrl`。
   - 图文笔记从 `urlDefault` 提取 `image_token`，重构为 `https://ci.xiaohongshu.com/notes_pre_post/[spectrum/]<image_token>?imageView2/format/jpg` 去除底部小红书水印，同时提取 `livePhoto` 对应的 `stream.h264[0].masterUrl`。
2. **快手视频与图集提取**：
   - 正则提取 `window.INIT_STATE` 并遍历包含 `result == 1` 与 `photo` 的节点。
   - 视频直链取 `photo.mainMvUrls[0].url`；图集遍历 `ext_params.atlas.list` 拼接 `https://<cdn[0]>/<path>`。

### 3.3 Step 3：执行下载与门禁校验

执行以下命令完成下载与自动化门禁校验：

```powershell
$env:PYTHONUTF8="1"; python skills/verdantflare-download/scripts/mk_video_download.py --input "<小红书或快手分享口令>" --output-dir "./.gdrive/downloads" --evaluate
```

执行完成后，生成符合 [C2.xhs-kuaishou-acceptance.md](./C2.xhs-kuaishou-acceptance.md) 的无水印视频或 `*_gallery/img_01.jpg` 原图序列。
