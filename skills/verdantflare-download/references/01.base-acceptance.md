## 2. 前置测量流程与四道自动化门禁体系（`Gate G1 ~ G4`）

### 2.1 前置测量流程（Measurement Pipeline）

在计算质量得分或向用户交付下载产物前，必须先运行 [`video_download_evaluator.py`](../scripts/video_download_evaluator.py) 对已落盘文件与 `*_metadata.json` 执行以下四项实测采集：

1. **直链与元数据字段探针**：读取 `*_metadata.json` 中的 `item_id`、`video_url`、`image_urls`、`title`、`author` 及 `expected_size`，扫描 URL 是否残留水印特征串（`playwm`、`!nd_`、`.webp`）。
2. **文件物理字节探针**：调用 `os.path.getsize()` 测量本地 `.mp4` 或 `_gallery/*.jpg` 的真实字节数 $\text{actual\_size}$，确认同目录无未完成的 `.part` 临时文件残留，并计算与 `expected_size` 的相对误差 $\Delta_{\text{size}}$。
3. **`ffprobe` 容器与双轨探针**：对所有视频资产执行 `ffprobe -v quiet -print_format json -show_format -show_streams`，实测提取视频编码 `vcodec`、宽高 $(W, H)$、帧率 $\text{fps}$、总时长 $\text{duration}$ 及音频编码 `acodec`。
4. **预览资产校验探针**：校验同级目录是否已生成可正常解码的 `*_frame.jpg` 或 `*_cover.jpg` 预览图，并将全部测量指标与 `Gate G1 ~ G4` 判定结果写回评估报告。

### 2.2 四道门禁的文字评分规则与数据评分准则

| 门禁代号  | 门禁名称与否决条件简述                                              |
| :-------- | :------------------------------------------------------------------ |
| `Gate G1` | 口令提链与无水印直链解析门禁（不满足封顶 `59.0` 分）                |
| `Gate G2` | 落盘字节完整性与防截断门禁（$\Delta_{\text{size}} \le 0.01$）       |
| `Gate G3` | `ffprobe` 容器轨道与音画完备门禁（返回码 `0` 且双轨有效）           |
| `Gate G4` | 分分类画质极值与原图纯净度终检门禁（未过封顶 `59.0` 分并判 `FAIL`） |

- **`Gate G1`（口令提链与无水印直链解析门禁）**：
  - **文字评分规则**：必须从输入口令中成功定位真实作品并取得纯净源流地址，严禁解析出空 ID 或带平台叠印水印的预览流。
  - **数据评分准则**：`item_id` 非空，且 `video_url` 不含 `playwm`、图集 URL 不含 `!nd_` 水印后缀；不满足则 `Gate G1 = False`，总分封顶 `59.0` 分。
- **`Gate G2`（落盘字节完整性与防截断门禁）**：
  - **文字评分规则**：流式下载必须完整落盘，严禁将网络中断导致的半截文件或空文件当作合格品。
  - **数据评分准则**：本地媒体文件真实存在、无 `.part` 残留，视频体积 $\ge 10\text{ KB}$（单张图片 $\ge 2\text{ KB}$），且当 `expected_size > 0` 时满足 $\Delta_{\text{size}} \le 0.01$；不满足则 `Gate G2 = False`。
- **`Gate G3`（`ffprobe` 容器轨道与音画完备门禁）**：
  - **文字评分规则**：视频容器必须可由标准解码器无报错解封装，画面宽高与时长有效，且有声源视频不得丢失音轨。
  - **数据评分准则**：`ffprobe` 返回码为 `0`，$W > 0$、$H > 0$、$\text{duration} > 0$，视频流属于 `{h264, hevc, vp9, av1}` 且包含有效音频轨（原片静音或纯图集除外）；不满足则 `Gate G3 = False`。
- **`Gate G4`（分分类画质极值与原图纯净度终检门禁）**：
  - **文字评分规则**：成品画质必须达到所属平台分类的最高可用原画标准，且综合评分达标。
  - **数据评分准则**：按 `C1 / C2 / C3` 分支验收专册执行分辨率、原图格式与分类合格线（`C1` $\ge 90.0$ 分、`C2` $\ge 85.0$ 分、`C3` $\ge 80.0$ 分）校验；任一门禁未过均强制封顶 `59.0` 分并输出 `status: "FAIL"`。

### 2.3 `Gate G4` 分分类验收路由

落盘成品根据其所属分类标签（`C1 ~ C3`），分别对照对应的分类验收专册（[C1](./C1.douyin-media-acceptance.md) / [C2](./C2.xhs-kuaishou-acceptance.md) / [C3](./C3.bili-weibo-global-acceptance.md)）执行差异化硬指标校验。

## 3. 通用安全落盘与防乱码验收标准

1. **元数据闭环**：每次下载必须在同级目录输出 `*_metadata.json` 与 `*_frame.jpg`（或 `*_cover.jpg`），完整记录源链接、解析直链、作者信息、文件字节数与 `ffprobe` 实测指标。
2. **全链路 UTF-8**：所有 CLI 执行与 JSON 读写强制开启 UTF-8 编码，严禁中文标题、作者昵称或 Emoji 标签出现乱码。
