## 3. 分步执行指令与调用协议

### 3.1 Step 1：口令净化与 `aweme_id` 解包

1. **输入数据**：原始抖音分享文案或 `v.douyin.com` 短链。
2. **解析逻辑**：调用 `extract_first_url()` 提取短链，以移动端 iOS Safari `User-Agent` 发起非跟随请求读取 `Location` 响应头，从 `/share/video/<id>/` 或 `modal_id=<id>` 提取 `aweme_id`。

### 3.2 Step 2：双路 `slidesinfo` 与 `snssdk 1080p` 原画探针

1. **绕过 SSR `videoInfoRes` 缺失风控**：依次请求以下两个移动端 Web 接口获取 `aweme_details[0]`：
   - 视频主路：`https://www.iesdouyin.com/web/api/v2/aweme/slidesinfo/?aweme_ids=%5B<aweme_id>%5D`
   - 图文/实况辅路：`https://www.iesdouyin.com/web/api/v2/aweme/slidesinfo/?aweme_ids=%5B<aweme_id>%5D&request_source=200`
2. **突破 `540p` 默认流降质陷阱**：提取 `video.play_addr.uri`（如 `v0200fg10000...`），按 `1080p -> 720p -> 540p` 顺序向 `https://aweme.snssdk.com/aweme/v1/play/?video_id=<uri>&ratio=<ratio>&line=0` 发起重定向探针，锁定真实 `Content-Length` 最大的 CDN 节点直链。

### 3.3 Step 3：一键下载与自动化门禁验收

执行以下命令完成下载与自动化门禁校验：

```powershell
$env:PYTHONUTF8="1"; python skills/verdantflare-download/scripts/mk_video_download.py --input "4.84 复制打开抖音... https://v.douyin.com/7OV8i9Vikss/" --output-dir "./.gdrive/downloads" --quality "1080p" --evaluate
```

执行完成后，在目标目录生成符合 [C1.douyin-media-acceptance.md](./C1.douyin-media-acceptance.md) 的无水印 1080p `.mp4`、封面 `*_cover.jpg`、预览帧 `*_frame.jpg` 与 `*_metadata.json`。
