# 小红书与快手状态树直解下载（03.xhs-kuaishou）

## 1. 输入与输出

- **输入**：小红书 APP 分享口令（`xhslink.com/...`、`xiaohongshu.com/explore/...`、`xiaohongshu.com/discovery/item/...`）与快手 APP 分享口令（`v.kuaishou.com/...`、`kuaishou.com/short-video/...`）。
- **输出**：小红书无水印视频笔记、多图 JPG 原图序列（`*_gallery/img_01.jpg` 及实况 `img_XX_live.mp4`）、快手无水印短视频/长视频及图集（`atlas`）、`*_metadata.json` 及 `C2` 门禁评测报告。
- **公共依据**：[公共规范](./00.common.rules.md)、[公共验收标准](./00.common.acceptance.md)、[通用下载与路由入口](./01.generic-http.entrypoint.md)。

## 2. 分类

由 [mk_video_download.py](../scripts/mk_video_download.py) 中的 `classify_platform_and_category()` 判定为 `C2` 类：

| 特征指标名       | 命中阈值区间                                                                        |
| :--------------- | :---------------------------------------------------------------------------------- |
| `host_domain`    | 命中 `xiaohongshu.com`、`xhslink.com`、`kuaishou.com` 或 `chenzhongtech.com`        |
| `state_tree_key` | 页面内联脚本包含 `window.__INITIAL_STATE__`（小红书）或 `window.INIT_STATE`（快手） |

- **视频与图集自动切换边界**：小红书笔记中当 `note.video.media.stream.h264` 列表非空时判为 `video`，为空时自动遍历 `imageList` 切换为 `gallery`；快手作品当 `photo.mainMvUrls` 非空时判为 `video`，否则读取 `ext_params.atlas` 切换为 `gallery`。
- **典型正例**：携带有效 `xsec_token` 的小红书分享短链 `xhslink.com/a/xxx` 及快手短链 `v.kuaishou.com/xxx`。
- **典型反例**：已过期的小红书链接（`currentNoteId` 为 `"undefined"`，触发 `Gate G1` 拦截）。

## 3. 工作流

| 步骤编号 | 步骤名称与输出产物                                                    |
| :------- | :-------------------------------------------------------------------- |
| `Step 1` | 短链重定向与 Cookie 保持，定位标准详情页 URL                          |
| `Step 2` | 提取 SSR 状态树（`__INITIAL_STATE__` / `INIT_STATE`）并重构无水印直链 |
| `Step 3` | 批量落盘视频或无水印原图图集（含 Live Photo），输出 `*_metadata.json` |

1. **Step 1（短链解包与路径归一化）**：
   - 小红书分支：使用桌面端 Chrome `User-Agent` 跟随 `xhslink.com` 重定向至携带 `xsec_token` 的笔记详情页。
   - 快手分支：先以非跟随模式请求 `v.kuaishou.com` 获取首跳 `Location` 与下发 Cookie，并将路径中的 `/fw/long-video/` 统一替换为 `/fw/photo/` 以保证返回结构一致。
2. **Step 2（SSR 状态树解析与去水印 URL 重构）**：
   - 小红书视频与原图：将 JS `undefined` 预替换为 `null` 后调用 `yaml.safe_load` 解析 `window.__INITIAL_STATE__`；视频提取 `note.video.media.stream.h264[0].masterUrl`；图文从 `urlDefault` 提取 `image_token` 重构为 `https://ci.xiaohongshu.com/notes_pre_post/[spectrum/]<image_token>?imageView2/format/jpg` 去除底部小红书水印，并提取 `livePhoto` 对应的 `stream.h264[0].masterUrl`。
   - 快手视频与图集：正则提取 `window.INIT_STATE` 并遍历包含 `result == 1` 与 `photo` 的节点；视频直链取 `photo.mainMvUrls[0].url`；图集遍历 `ext_params.atlas.list` 拼接 `https://<cdn[0]>/<path>`。
3. **Step 3（执行下载与门禁校验）**：

```powershell
$env:PYTHONUTF8="1"; python scripts/mk_video_download.py --input "<xhs_or_kuaishou_share_text>" --output-dir "./.gdrive/downloads" --evaluate
```

4. **异常自愈与熔断回退**：
   - **非 `notes_pre_post` 路径自适应回退**：小红书早期历史图片不含 `notes_pre_post` 关键字导致 `ci.xiaohongshu.com` 不支持替换时，自动回退使用原始 `urlDefault` 确保图片成功落盘。
   - **风控硬门禁熔断**：分享短链失效或笔记被作者隐藏（`currentNoteId == "undefined"` 或快手 `photo_data.result != 1`）时，立即输出明确错误原因并终止，严禁写入空目录。

## 4. 规范

### 4.1 专属操作禁令

1. **严禁直接保存小红书 `urlDefault` 带水印压缩图**：`imageList` 中的 `urlDefault` 默认带有 `!nd_dft_wlteh_webp_3` 水印与 WebP 压缩后缀；凡原链接含 `notes_pre_post` 路径，必须剥离 `!` 后缀并重构至 `ci.xiaohongshu.com` 节点拉取 JPG 原图。
2. **严禁丢弃小红书 `xsec_token` 查询参数**：解析小红书链接时必须完整保留 URL 查询串中的 `xsec_token` 与 `xsec_source`，严禁在请求前截断查询参数导致返回空状态树。
3. **严禁快手长视频走 `/fw/long-video/` 异构模板**：快手重定向链接若命中 `/fw/long-video/`，必须在二次请求前归一化替换为 `/fw/photo/` 并透传首跳 `share_response.cookies`。

### 4.2 专属算子参数与评分细则

| 算子或节点参数       | 固定取值与约束说明                                                                   |
| :------------------- | :----------------------------------------------------------------------------------- |
| 小红书无水印原图模板 | `https://ci.xiaohongshu.com/notes_pre_post/[spectrum/]<token>?imageView2/format/jpg` |
| 小红书状态树解析器   | 将 `undefined` 替换为 `null` 后调用 `yaml.safe_load()`                               |
| 快手路径归一化规则   | `location_url.replace("/fw/long-video/", "/fw/photo/")`                              |

- **图文原图满分判定**：小红书或快手图集全部图片成功落盘且单张体积 $> 2\text{ KB}$、格式为非损坏原图时，$S_1 = 40.0$、$S_2 = 30.0$、$S_3 = 20.0$。
- **过期链接熔断**：`currentNoteId == "undefined"` 或快手 `photo_data.result != 1` 时，直接触发 `Gate G1` 熔断报错。

## 5. 验收

调用 [video_download_evaluator.py](../scripts/video_download_evaluator.py) 指定 `--category C2` 完成测量，必须同时通过 `Gate G1 ~ G3` 与以下 `Gate G4 · C2` 维度：

| 验收维度                     | 关键考核要求与阈值简述                                               |
| :--------------------------- | :------------------------------------------------------------------- |
| 小红书无水印原图节点合规性   | 指向 `ci.xiaohongshu.com` 且不含 `!nd_`（违规封顶 `59.0` 分）        |
| 图集与 Live Photo 序列完备性 | 落盘数量 $N_{\text{saved}}$ 等于 `images` 长度，单图 $> 2\text{ KB}$ |
| 视频流解封装健康度           | `ffprobe` 双轨正常且字节误差 $\Delta_{\text{size}} \le 1\%$          |
| 综合质量总分门禁             | 100 分制总分 $\text{Score} \ge 85.0$ 分                              |

- **小红书无水印原图节点合规性**：凡含 `notes_pre_post` 路径的图集 URL 指向 `ci.xiaohongshu.com` 且不含 `!nd_` 缩略水印后缀，残留 `!nd_` 触发 `Gate G4` 封顶 `59.0` 分。
- **图集与 Live Photo 序列完备性**：本地落盘图片数量 $N_{\text{saved}}$ 与 `images` 列表长度严格相等，单张体积 $> 2\text{ KB}$，含 `livePhoto` 的项同步生成 `img_XX_live.mp4`。
- **视频流解封装健康度**：小红书视频笔记或快手 `mainMv` 视频通过 `ffprobe` 双轨检测，$W > 0$、$H > 0$、$\text{duration} > 0$，相对字节偏差 $\Delta_{\text{size}} \le 1\%$。
- **综合质量总分门禁**：$\text{Score} \ge 85.0$ 分。
- **人工终审核对清单**：核对小红书图片右下角无“小红书号：xxx”水印、`img_01.jpg ~ img_NN.jpg` 与原笔记轮播顺序一致、实况图对应 `img_XX_live.mp4` 齐全。
