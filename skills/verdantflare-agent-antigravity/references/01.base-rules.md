## 2. 跨智能体调度硬约束

1. **默认采用 VS Code 前台面板注入模式（`mode="panel"`）**：除非本机未运行 VS Code Antigravity Hub 或用户显式要求后台无头运行，否则一律使用 `mode="panel"`，确保用户在 VS Code 面板中能直观看到双子座的实时执行动态。
2. **以文档路径传递复杂交接书**：跨智能体派发复杂任务时，上游智能体应先将方案与交接书落盘为工作区文档，在 `prompt` 中传入文档相对路径与核心指令摘要，避免在 MCP JSON 参数中直接拼接数万字符的超长文本。
3. **桌面焦点最小干扰与 CLI 输入隔离及显式报错**：`agy_dispatch_task` 的 `focus_panel` 默认值固定为 `False`，利用 Hub 的 `SetBrowserOpenConversation` 与 Reactive Stream 实现零抢焦点面板同步；`mode="cli"` 必须使用独立 `stdin` 传递 `--input-format stream-json --output-format stream-json` 事件（禁止继承外层 MCP `stdio` 管道导致挂起），默认不附加 `--dangerously-skip-permissions`，且任何启动失败或异常退出都必须返回 `ok: false` 与明确错误原因（含 `--log-file` 尾部诊断回退），严禁静默成功。
4. **续接基线步数校验与超时显式标记**：向已有会话派单前先记录基线步数 `baseline_steps`，轮询等待必须看到 `RUNNING` 或总步数达到 `baseline_steps + 2` 后才判空闲退出（容忍轮询期间瞬时 RPC 抖动）；若超时未完成，显式返回 `timed_out: true` 且 `ok: false`，防止把上一轮旧回复误判为新轮次结果。
5. **禁止递归自调死锁**：当 Antigravity（双子座）自身作为当前执行智能体时，严禁通过 MCP 再次向当前正在运行的同一 `conversation_id` 阻塞派发任务；内部并发子任务应使用原生 `invoke_subagent`。

## 3. 底层 Connect-RPC 协议与安全契约

1. **动态发现端口、工作区绑定与本地状态 CSRF 令牌**：`agy.exe --hub` 随 VS Code 启动时分配本地端口（`--hub-port`）并通过 `--add-dir` 绑定窗口工作区；自 `agy` 1.5.x 起进程命令行不再携带 `--csrf_token`，而是将 `csrfToken`、`httpPort`、`pid` 与 `lsVersion` 写入 `~/.gemini/<app_data_dir>/daemon/hub_<httpPort>.json`（默认 `<app_data_dir>` 为 `antigravity`）。`discover_hubs` 必须优先兼容显式环境变量与旧版 `--csrf_token` 参数，缺失时按端口读取对应 `daemon/hub_<httpPort>.json`，并在进程扫描回退时校验 PID 存活且排除非 `--hub` 的临时 CLI 进程，严禁硬编码端口与令牌。
2. **`StartCascade` 必填枚举与项目归属互斥契约**：经对 `agy.exe` 内嵌 Protobuf 描述符与运行期 Hub 实测校验，调用 `/exa.language_server_pb.LanguageServerService/StartCascade` 时必须显式传入 `"source": "CORTEX_TRAJECTORY_SOURCE_CASCADE_CLIENT"` 与 `"trajectoryType": "CORTEX_TRAJECTORY_TYPE_CASCADE"`（缺省触发 HTTP 400 `CortexTrajectorySource is unspecified`）；同时应通过 `ListProjects` 与 `ReadProjects` 解析目标工作区所属的 `projectId`：命中项目时只传 `"projectEnvConfig": {"projectId": "<id>", "defaultProjectEnvironment": {}}` 且**不传 `workspaceUris`**（两者同时传入会触发 HTTP 400 `cannot specify both workspace URIs and project environment config`），仅在未命中任何项目时回退传 `workspaceUris`，否则新建会话缺少 `trajectoryMetadata.projectId` 会被侧边栏归入 `Conversations`（`outside-of-project`）而非对应 `Projects` 分组。
3. **配置写入隔离**：[install.py](../scripts/install.py) 注册 MCP 时，只更新 `~/.claude.json` 的 `mcpServers.verdantflare-agent-antigravity` 键及 `~/.codex/config.toml`、`~/.grok/config.toml` 的 `[mcp_servers.verdantflare-agent-antigravity]` 节（并清理旧版 `antigravity` 键），完整保留用户原有的其他 MCP 服务与项目配置，且不在仓库文档中写入本机绝对路径或隐私凭据。
