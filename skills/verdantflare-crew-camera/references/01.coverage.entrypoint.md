# 摄影与机位设计专员的机位覆盖工作流

## 1. 输入与输出

领取场景版本、实际画幅、站位与走位、表演的动作起止、相邻剪点和导演指定视角。交付每个镜号的相机位置、高度、朝向、画幅、景别、视角或焦距及有效传感器信息，以及能直接看到关键动作的预览。

## 2. 分类

两人对话先定视线轴和主镜一侧；移动或转身时记录轴线切换的可见过渡。手部插入镜以动作接点和持物侧为主。片场尺寸未知时用门窗、桌沿、演员站位等相对锚点记录，注明待现场标定的距离。

## 3. 工作流

1. 画出空间锚点、两人面向与视线轴，在主镜标清左右屏幕位置。按动作列出观众必须看到的内容，例如拇指先松开和对手抬眼；每项分配到明确的镜号。
2. 放主镜、反打及必要的插入镜，在目标画幅下试摆动作的接触前、中、后三个状态。叠看手、前景肩、话筒及裁切边缘；每个候选的构图必须由实景或固定布局支撑。
3. 遮挡已出现在固定构图时，优先试改相机侧移、高度或演员间距。改变站位涉及既定调度时交导演取舍。改变焦距时核对相机位置与透视关系，单纯裁切难以恢复被遮住的手。
4. 粗接主镜、反打、插入镜，复核屏幕方向、视线高度、动作余量和画面出口。底片静止时可见、移动时才丢失的覆盖，把丢失区间连同机位基准交运镜设计专员。

## 4. 规范

- 单镜输入保留片场版本与机位 ID。会改变轴线的提议需带跨轴过渡或可用的重新定向画面。
- 只从有比例基准的素材填写公制位置和镜头参数，依据不足时交可复摆的相对位置和取景要求。

在本单的项目、任务、轮次和输入修订中工作。接单回执注明目标、首件预估与下一检查点。把结果、已知缺口和 QC 写回本轮，引用候选文件和被检的区间。导演明确的要求若需改动，提交依据和备选。连续两次局部修正仍出现同一缺陷，暂停该方向并汇报两轮差异。按委托期限上报超时及恢复条件，等待人工意见时停止主动工时。换 Session 从本轮任务和版本恢复，正式选用由受控项目入口记录。

## 5. 验收

在同一片场打开主镜与反打，另一位专员应能从图上复摆相机并找到失遮手指的时刻。保留问题构图、调整后的同拍构图及正常播放的试接。下游可据覆盖表辨认每项动作由哪一镜承担。
