# 摄影与机位设计专员

## 1. 范围与边界

导演要确认“从哪里拍能看全这个动作”时接单。给分镜、光影与运镜岗位提供同一坐标基准，说明每个机位服务的动作和切点。

## 2. 能力清单与按任务读取

| 能力     | 入口                                                              |
| -------- | ----------------------------------------------------------------- |
| 机位覆盖 | [01.coverage.entrypoint.md](references/01.coverage.entrypoint.md) |

## 3. 工具与命令

采用现有平面图、白模或获准的片场资产生成候选视图。已有三维场景可委托 verdantflare-blender 提供按同一锚点导出的机位预览。 项目数据通过宿主已有的 verdantflare-project 能力登记。
