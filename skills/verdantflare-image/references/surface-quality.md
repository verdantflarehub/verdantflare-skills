# 表面质感与过度纹理控制

## 1. 何时使用

写实图像出现随机砂砾、重复纹路、边缘光晕、油腻高光或暗部脏斑时，按当前参考和目标选用本指引。以下是待实图验证的可选写法，不是默认后缀、效果保证或固定负向词表；不覆盖用户指定画风。

先判断问题来自生成内容还是源图噪声、压缩、低像素或预览缩放。查看原图与相关局部，不从聊天缩略图直接判定。文字约束不能恢复不存在的细节，也不证明输出为原生高分辨率。

## 2. 怎样写

明确什么材质、哪个区域、当前景别下应有多大细节。焦点细节清楚，其他区域按物距和景深自然衰减；大面保持可信的整体明暗，避免无来源纹理覆盖。皮肤毛孔、雀斑、木纹、布纹、旧墙和剧情污损依真实尺度保留；干净不等于全画面平整、磨皮或塑料质感。

柔和明暗与克制锐度适合部分写实目标；硬光、高反差、胶片颗粒、风化和厚涂等若属于当前风格就保留。不要把 `film grain`、`weathered`、`HDR` 等做成禁词；优先描述实际问题，删去与既定画风冲突的可选句。

### 2.1 生成时的可选补充

以下示例适用于自然摄影感场景，应替换材质与焦点后再使用：

```text
画面具有自然摄影质感。人物与关键道具保留当前景别下可辨的真实细节，皮肤、布料与木材各有符合尺度的纹理。墙面、天空和阴影保持连续的明暗层次，背景细节随距离和景深自然衰减。边缘过渡自然，锐度克制；不额外叠加随机斑点、重复纹路或锐化光晕。保留参考中既有的材质磨损、角色特征和剧情污损。
```

### 2.2 编辑时的可选补充

在明确实际缺陷与范围后使用，不把样例中的问题当作每张图都有：

```text
仅清理背景木墙上新增的随机砂砾状细纹和边缘锐化光晕，恢复与原场景参考一致的木纹尺度与明暗。保留木板接缝、固定裂缝和磨损位置。人物面部特征、毛孔与雀斑、发丝、衣层和布纹、道具、构图、机位及光向保持。该处理不改变人物身份、动作或场次状态。
```

这只是编辑目标，不代表像素硬锁。当前能力确实支持遮罩时限定修改区并核对边缘；普通整图编辑仍须检查人物和空间是否被重画，失败候选不能成为新基线。

## 3. MCP 参数归属

视觉目标写入现有 `prompt`。只对模型实际支持的字段赋值，不新增 `denoise`、`texture_strength` 或锐化参数；不因“太脏”自动切换模型、提高分辨率、调低采样或追加后处理。

`instructions` 是中介模型的指令，不是通用负向提示词槽。独立 `negative_prompt` 按当前 Schema 与引擎能力使用，现有支持面向 MOSS；其他渠道把少量必要限制和保留项放进自然语言目标。Codex 兼容链路可能清理带“负向提示词／negative prompt”标题的块，避免把截图的 AVOID 清单作为长块原样贴入正向字段；不要据此声称所有否定句都会被删除。

## 4. 如何判断有效

对比原始候选、可信参考与新候选，先看实际交付尺度，再看相同倍率的原像素局部。分别看背景随机纹理／暗部斑点、边缘光晕、皮肤与衣料／木材真实细节，以及身份、Look、道具、空间和光线连续性。出现蜡皮、丢失雀斑、木纹变糊或剧情污损消失，应退回或调整范围；不能仅凭画面更平滑放行。

若做成对试验，保持模型、参考、机位、画幅及参数一致，支持 seed 时固定 seed 并保留请求；相同 seed 不保证完全可复现。记录改善、退步和未验证项，不用一个样本推导跨模型效果。只有说明维护要求时不自动生图；新生成沿用已有次数与预算，不为 A/B 另行扩大授权。
