# verdantflare-image：文生图与视觉规格（01.t2i）

## 1. 输入与输出

- **输入**：目标画面描述（正向 `prompt`）、可选逻辑模型 `model`（默认 `gpt-image-2.6-sunburst`，可选 `nano2` / `grok` / `moss-image`，渠道自动映射见 [channels.md](channels.md)）、所属 Studio 项目 `project_id`（UUIDv7）、固定 `idempotency_key`、画幅与分辨率目标及已有批准资产引用。
- **输出**：经解码核验真实宽高、MIME 与 SHA-256、且完成 K09 内容分级（`image.rate_content`）的原子图像资产候选，按项目工作目录与 `project.commit` 规范归档。
- **公共依据**：[公共契约、质感与内容分级](00.common.rules.md)、[18+ 评估规范](content-rating-rubric.md)。

## 2. 分类

按用途选择视觉资产规格；用户指定三视图、全身造型或其他视角时按要求执行，不强制补成四张身份卡：

- **角色设计四视图（Visual Bible）**：建立项目人物身份基准（`01-front-neutral.png`、`02-front-smile.png`、`03-left-15deg.png`、`04-right-15deg.png`），批准后复用；跨项目复用需先在来源 Project 审核再登记 World `character-image` 固定版本。
- **角色服装无脸人台三视图（Wardrobe Design）**：单元情节（如 `B01`、`B02`）审核服装造型、身材比例与配饰（`05-wardrobe-turnaround.png`）；用户要求同一角色全身三视图时保留该角色身份，不强制改人台。
- **分镜单格图（Storyboard Frames F01–F08）**：面向多格动态视频模型（如 MiniMax H3、Picture 2）的单格画面输入。
- **纯场景设计图（Environment / Set Design）**：空镜或环境全景，锁定叙事段落的环境氛围、时代感与天气光影。
- **角色五视图合成板（旧版 2+3 / 3+2）**：标准人物五视图、人物半身照与 16:9 档案卡优先转[人物设定技能](../../verdantflare-crew-character/SKILL.md)；仅当项目明确选用旧版合成板时，固定身份长相优先 **3+2（三脸+身体正背）**，衣装造型优先 **2+3（两脸+身体正侧背）**，两种模式并存。

## 3. 工作流

1. **确认会话与项目**：通过真实 Studio 会话执行 `tools/list`，取得当前 `project_id`（新项目调 `project.create`），检查已有任务与批准身份/造型避免重复生成。
2. **编写提示词与参数**：描述目标画面、参考职责及保留项（四段式 `[Scene]` / `[Subject]` / `[Details]` / `[Constraints]` 为可选写实模板，不要求固定标签）；未指定引擎时默认 `engine="codex"`、`model="gpt-image-2.6-sunburst"`。
3. **提交 `image.create` 并轮询**：示意请求如下（占位字段须替换为真实返回值）：

```json
{
  "project_id": "<当前Studio项目ID>",
  "idempotency_key": "B01/wardrobe-v1/attempt-01",
  "prompt": "A single full-body wardrobe reference on a plain neutral background.",
  "engine": "codex",
  "model": "gpt-image-2.6-sunburst",
  "aspect_ratio": "3:2",
  "resolution": "2k",
  "quality": "high",
  "background": "opaque"
}
```

4. **下载、核验、分级与归档**：通过受控下载路由取得原图，校验实际宽高、MIME 与 SHA-256；按[公共规则第 4 节](00.common.rules.md#4-生成后内容分级评估步骤k09-强制步骤)调用 `image.rate_content`；仅 `general` 产物按以下工作副本结构归档并经 `project.commit` 提交：

```text
<project-root>/source/
├── identity/                         # 01-front-neutral.png ~ 04-right-15deg.png
├── wardrobe/                         # B01-wardrobe-turnaround.png ...
└── storyboards/                      # B01/F01.png ~ F08.png ...
```

## 4. 规范

### 4.1 角色设计四视图与防涂抹准则

- **四格构图**：`01-front-neutral` 正脸中性自然闭嘴；`02-front-smile` 正脸微笑不露夸张牙齿；`03-left-15deg` 与 `04-right-15deg` 微转头 10–15° 且双眼完整可见。
- **身份卡基准**：建议目标 `1:1`（`2048x2048`）或 `16:9`（`2048x1152`），已批准 `1024x1024` 可复用；胸部以上中近景，柔和中性漫射光与浅灰/米白/深蓝单色纯净背景，严禁装饰物、边框、第二个人物、水印、文字或视图标签；保留真实皮肤细纹、毛孔与自然血色，严禁磨皮塑料感。
- **参考职责分离**：身份参考只负责面部骨相/肤色/发型/稳定标记，不推断身材或画外服装；造型参考负责本段服装/鞋/配饰/体型，换装建新版本，不让另一张有脸时装图与身份图争夺面部定义；镜头参考负责构图与站位，缺失侧面/背面保守补全并标待验证。
- **防涂抹协议（Anti-Smearing）**：支持时使用 `quality="high"`（不臆造 `xhigh`/`max`）；核对各引擎 2K 实际像素上限（见[公共规则第 1.1 节](00.common.rules.md#11-各渠道画幅与分辨率实际行为与防坑指南)）；可选四段式写实模板：`[Scene]` 空间与自然采光、`[Subject]` 真实骨相与成年年龄姿态、`[Details]` 35mm/50mm 镜头与毛孔/细纹/睫毛/织物纹理、`[Constraints]` 排除重度磨皮、塑料感、美颜滤镜、CGI 感、文字与水印。

### 4.2 服装人台、分镜单格与纯场景

- **无脸人台三视图**：正面/左侧/背面全身立姿横向排布或单出，默认 7.5 头身成年基准（创作者意图优先）；头部仅保留发型轮廓、发色、头饰或帽子，面部光滑无五官极简灰白或木质人台，完整呈现衣裤裙鞋袜与配饰。
- **分镜单格图（F01–F08）**：默认目标 `16:9`、`2048x1152`，命名 `F01.png`–`F08.png`；主体动作、站位朝向与视线唯一确定，景别（CU/MS/FS/EWS）过渡自然，色调遵从冻结的 Visual Bible，`F01` 起幅与 `F08` 落幅呼应。
- **纯场景设计图**：`16:9` 2K，空镜或环境全景，不出现主体人物，着重空间透视、材质反射与天气光影。

### 4.3 旧版角色五视图合成板（2+3 与 3+2）

- **衣装优先 2+3（上二下三）**：左上正面脸部特写（完整头顶、发型与肩颈）；右上微侧脸（约 30° 起，双眼可见、同表情尺度光线）；左下正面、中下严格 90° 侧面（明确解剖侧别与朝向，不以回头或斜背代替）、右下正背面，下排均从颈部裁至鞋、头部画外，不生成断颈/悬空/无五官人台头，手鞋完整，长发自然延续；上下各排等宽、下排等比例且颈线与鞋底齐平，默认纯白底窄留白无文字标签。
- **身份优先 3+2（中央脸部区+左右身体栏，不得误排为上三下二）**：中央上方正面大头像（中线竖直、双眼水平、完整头顶与肩颈）；中央下方左右两格为人物解剖左侧脸与右侧脸（同角度默认严格 90°，选 45° 则两侧同为 45°，保留真实不对称，严禁镜像一侧充当另一侧）；左侧整栏身体正面、右侧整栏身体背面（均颈部至鞋、头部画外、同尺度基线）。本模式**无身体侧视**，不擅自加第六格。
- **参考与用途红线**：记录身份、造型与版式参考职责及 SHA-256；版式参考只传构图，不复制其脸/造型/风格词；缺失侧脸/背面保守补全并标推断；五视图仅作概览资产，不能代替短剧主要角色含头全身独立正侧背，任一格出错不作视频唯一人物参考。

## 5. 验收

- **文件与像素验收**：核对文件非空、完整解码、真实 MIME、字节数与 SHA-256，实测宽高低于目标时如实记录，不靠文件名、转码或插值放大宣称原生 2K/4K。
- **画面与规则验收**：检查皮肤微纹理、五官比例、服装连续性、纯净背景、无文字水印污染；五视图合成板逐格核对格数、位置、裁切、解剖侧别与基线，3+2 交付时明确告知“未包含身体侧视”。
- **分级与同步验收**：确认 `image.rate_content` 已提交；`nsfw` 产物脱敏隐藏且不入 Project/World；`general` 产物完成 `project.commit` 并回读验证。技术完成不等于艺术批准，不自动更新 `selections` 或注册 World。
