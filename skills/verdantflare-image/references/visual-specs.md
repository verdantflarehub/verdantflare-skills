# VerdantFlare 视觉资产制作与规格规范

本文档详述通过 VerdantFlare Image MCP 生产原子图像资产时的视觉规格、构图约束与交付物组织规范。用于上层编排（如 `verdantflare-music-mv`）与技能内部生成。

以下是按用途选择的制作建议。用户指定三视图、全身造型或其他视角时按其要求执行，不强制补成四张身份卡。目标尺寸需在宿主支持范围内提交，并以下载后的实际像素尺寸验收；质量档位、模型名称或提示词都不保证输出达到指定分辨率。

---

## 1. 角色设计四视图（人物圣经 / Visual Bible）

用于建立项目中人物的身份基准（Identity Design）。一经用户批准，后续段落复用并核验一致性；用户要求更改身份设计时新建版本，不覆盖旧资产。若该形象需要跨项目复用，先在来源 Project 中保存并审核，再登记为 World `character-image` 固定版本。

### 1.1 资产清单与构图标准

- `01-front-neutral.png`，**正脸中性**：视线正对镜头，面部放松自然，自然闭嘴。锁定五官基准比例、双眼间距、鼻梁起点、自然肤色与真实皮肤毛孔质感。
- `02-front-smile.png`，**正脸微笑**：视线正对镜头，嘴角自然上扬，眼角微动，不露出夸张牙齿。锁定动态表情下肌肉形变，防止模型出图微笑时面部崩坏。
- `03-left-15deg.png`，**微转头左侧 15 度**：头部向左微转 10~15 度，保持双眼完整可见。锁定面颊立体轮廓线、鼻尖高度与左侧耳廓发际线。
- `04-right-15deg.png`，**微转头右侧 15 度**：头部向右微转 10~15 度，保持双眼完整可见。锁定右侧面部三维立体深度。

### 1.2 身份卡构图建议

- **画幅与分辨率**：建议目标 `1:1`（`2048x2048`）或 `16:9`（`2048x1152`），以宿主支持和实际输出为准；已批准的 `1024x1024` 历史身份图可复用。
- **景别**：面部身份卡采用胸部以上（Bust-level）中近景；全身比例与服装通过另有职责的造型参考呈现。
- **纯净背景**：采用柔和中性漫射光，浅灰、米白或深蓝单色纯净背景。严禁装饰物、边框、光晕噪点、第二个人物。
- **严禁文字污染**：严禁任何水印、文字、签名、LOGO、视图说明标签（如在图上印 FRONT / SIDE）。
- **真实质感（防涂抹硬性红线）**：保留真实皮肤细纹、毛孔与自然血色感，严禁磨皮塑料人感与涂抹感。

### 1.3 身份、造型与镜头参考的职责

建新角色时先确认身份是否已有批准版本。已有身份图直接复用；没有时先制作候选并选定一版，再将批准的身份视图登记为身份事实。探索候选不能自动成为后续镜头的权威参考。用户修改身份时新建资产版本，保留旧版来源。

- **身份参考**：身份视图负责面部骨相、肤色、发型和稳定可见标记；胸像不推断身材比例、鞋或画面外服装。
- **当前造型参考**：负责本段服装、鞋、配饰、体型与可见层次；独立服装参考可采用无脸全身人台，同一角色全身或状态视图保留其身份。同一角色换装时建立新的造型版本，不让另一张有脸时装图与身份图争夺面部定义。
- **镜头 / 动作参考**：分镜格负责构图与站位，动作视频负责时序和力学。每份参考只声明本次要继承的属性；缺失的侧面、背面和遮挡细节保守补全，不写成已被参考图验证的事实。

提交前逐张列明参考职责，并检查身份、造型和镜头之间是否冲突。结果图只验证画面实际可见部分；未展示的永久标记或服装背面继续保留为待验证项。交付与审核仍按 Image MCP 的 Artifact、哈希及上层项目流程执行。

### 1.4 防涂抹与高频微观质感保真准则 (Anti-Smearing Protocol)

写实人像可参考以下建议；具体要求取决于批准的视觉风格，模型与参数不能保证消除所有瑕疵：

1. **参数与验收**：
   - **质量等级**：按当前工具支持的枚举选择；支持时可使用 `quality="high"`，不臆造 `xhigh` / `max` 等值；
   - **尺寸约束**：核对所选模型和宿主支持的尺寸、像素上限与步长，不把某个模型的限制套给其他渠道。提交后读取实际宽高，低于目标时如实记录，不用文件名或提示词宣称已达 2K / 4K；
   - **模型选择**：保留用户明确选择；否则按 Skill 默认与宿主实际可用模型执行。无论采用哪个模型，都检查皮肤、五官与服装细节，不承诺消除涂抹或身份漂移。
2. **可选四段式写实提示词模板**：
   - **[Scene]**：空间尺度与真实采光（如 `Directional natural daylight, subtle shadow gradation, neutral studio backdrop`）；
   - **[Subject]**：明确真实真人脸骨相特征、具体成年年龄、视线与姿态；
   - **[Details]**：镜头与微观质感（`Shot like a 35mm film photograph, 50mm lens, visible skin pores, natural wrinkles, individual eyelashes, fine fabric weave`）；
   - **[Constraints]**：严格排除项（`No heavy retouching, no airbrushed smooth skin, no porcelain doll effect, no beauty filter, no CGI look, no text, no watermarks`）。

## 2. 角色服装无脸人台三视图（Wardrobe Design）

用于单元情节中（如 `B01`、`B02`）审核服装造型、身材比例与体态配饰（“角色 = 人物 + 服装”）。

### 2.1 资产形态：`05-wardrobe-turnaround.png`

- **形态**：正面全身（Front）、左侧全身（Side）、背面全身（Back）三立姿视角横向排布（或单独生成）。
- **头身比基准**：默认以 **7.5 头身** 写实成年人物为工业参考基准（创作者有特殊艺术设计时以创作者意图为准）。
- **独立服装参考可采用无脸人台（Faceless Mannequin）**：
  - 用途：减少独立服装参考与身份卡的面部冲突。用户要求同一角色全身三视图时保留该角色身份，不强制改成人台。
  - 头部只保留发型轮廓、发色、头饰或帽子，面部采用光滑无五官极简人台处理（灰白或木质质感）。
- **服装与配饰细节**：
  - 完整呈现上衣、下装（裤/裙）、鞋袜剪裁与材质色彩；
  - 完整呈现剧本所需的墨镜、包袋、手链、项链等道具配件。

## 3. 分镜单格图（Storyboard Frames F01~F08）

用于多格动态视频模型（如 MiniMax H3、Picture 2 Storyboard Grid）的单格画面输入。

### 3.1 规格参数

- **画幅与分辨率**：默认目标为 `16:9`、`2048x1152`；按项目画幅调整，以实际输出尺寸验收。
- **文件命名**：`F01.png`, `F02.png`, ..., `F08.png`。

### 3.2 镜头语言规范

- **主体明确**：每格画面主体动作、站位朝向与视线方向必须唯一确定；
- **景别设计**：特写（CU）、中景（MS）、全景（FS）、大远景（EWS）过渡自然，符合电影视听语言；
- **光影与色调**：色彩饱和度、色温、对比度必须严格遵从 Visual Bible 视觉圣经中冻结的基准色调；
- **起落幅呼应**：`F01` 为镜头起始帧，`F08` 为镜头结束帧，中间格体现连续运动轨迹。

---

## 4. 纯场景设计图（Environment / Set Design）

用于锁定叙事段落的环境氛围、时代感与地理特征：

- **规格**：`16:9` 2K。
- **内容要求**：空镜或环境全景，不出现主体人物，着重刻画空间透视、材质反射、自然天气（雨夜、雾气、黄昏阳光）。

## 6. 角色五视图合成板

用户要求五视图，或项目明确选用身份与造型同板概览时采用本模式。原有身份四视图、服装三视图仍按各自用途交付；已有批准身份图直接复用。用户明确要求全身含头时按该要求执行，不强套颈部裁切。

### 6.1 五格布局与裁切

同一角色、同一造型，上排两格、下排三格：

- 左上：正面脸部特写，头顶与发型轮廓完整，保留肩颈。
- 右上：微侧脸特写，明确转向，可从约 30 度开始；保持双眼可见，与正面图使用相同表情、脸部尺度和光线。
- 左下：正面，从颈部裁至鞋，头部在画面之外。
- 中下：严格侧面，目标为 90 度，明确人物解剖侧别和画面朝向；从颈部裁至鞋，不能以回头或斜背姿态代替。
- 右下：正背面，从颈部裁至鞋，展示可见发尾、衣服背面、裙裤结构及鞋后跟。

下排通过取景裁切让头部在画外，颈部从格子上边缘进入；不生成断颈、悬空身体或无五官人台头。手和鞋完整落在画面内，侧视允许远侧肢体自然遮挡，不能为了露出它们扭转身体。长发自然延续到肩背，不为露出衣服而凭空剪短或移除。

上下各排内等宽，区域高度按脸部可辨和服装完整调整，不固定为某一种画幅。下排人物等比例、颈部裁切高度与鞋底基线一致，平视自然站姿。默认纯白背景、干净窄留白，不添加视图标签、水印或额外格子；用户明确的视觉风格优先。

### 6.2 参考职责与连续性

分别记录身份、当前造型和版式参考的职责及输入 SHA-256。身份参考锁定面容、肤色、发型与稳定标记；造型参考锁定衣层、材质、颜色、鞋袜、配饰和可见比例；版式示例只传递构图，不将其脸、服装、BJD 等风格词或“8k”复制为通用要求。

上排核对同一身份，下排核对同一 Look：领型、袖口、腰线、衣长、裤裙剪裁、鞋型和发长应连续；有方向性的标记按人物解剖左右记录，避免镜像。参考未展示的背部扣合、缝线、鞋后跟等只能保守补全并标为推断或新设计，不新增无依据的醒目装饰。用户批准补全的设计不改变原始参考实际展示的内容。

### 6.3 交付与用途限制

逐格检查格数、顺序、头部与鞋的裁切、侧别、手脚、身份及衣装一致性，保留原始候选并记录失败项。略偏背侧不能记为严格 90 度；尺寸以解码后的真实像素为准，提示词和放大处理不能证明原生高清。返修针对已发现问题，在授权尝试范围内建立新候选。

保存合成板、实际提示词、参考职责、输入摘要、任务及 Artifact 映射和审核记录。需要拆出单格时，记录母图摘要与像素裁切框，不将裁切图当作独立生成。制作可直接生成整板，也可用已有合格独立视图确定性排版，以实际输入和用途选择。

五视图是概览资产：颈部以下三格不能验证完整头身比或后脑发型，不能代替短剧主要角色每个状态所需的含头全身独立正侧背；MV 原有四张身份图加服装三视图流程继续适用。任一格存在身份、服装或比例错误时，不把整板作为视频生成的唯一人物参考。
