# VerdantFlare 视觉资产制作与规格规范

本文档详述通过 VerdantFlare Image MCP 生产原子图像资产时的视觉规格、构图约束与交付物组织规范。用于上层编排（如 `verdantflare-music-mv`）与技能内部生成。

---

## 1. 角色设计四视图（人物圣经 / Visual Bible）

用于建立并永久锁定项目中人物的唯一身份事实（Identity Design）。一经用户批准，后续段落直接复用；用户要求更改身份设计时新建版本，不覆盖旧资产。

### 1.1 资产清单与构图标准

| 序号   | 标准文件名             | 视角与表情           | 构图规范与控制重点                                                                                         |
| :----- | :--------------------- | :------------------- | :--------------------------------------------------------------------------------------------------------- |
| **01** | `01-front-neutral.png` | **正脸中性**         | 视线正对镜头，面部放松自然，自然闭嘴。锁定五官基准比例、双眼间距、鼻梁起点、自然肤色与真实皮肤毛孔质感。   |
| **02** | `02-front-smile.png`   | **正脸微笑**         | 视线正对镜头，嘴角自然上扬，眼角微动，不露出夸张牙齿。锁定动态表情下肌肉形变，防止模型出图微笑时面部崩坏。 |
| **03** | `03-left-15deg.png`    | **微转头左侧 15 度** | 头部向左微转 10~15 度，保持双眼完整可见。锁定面颊立体轮廓线、鼻尖高度与左侧耳廓发际线。                    |
| **04** | `04-right-15deg.png`   | **微转头右侧 15 度** | 头部向右微转 10~15 度，保持双眼完整可见。锁定右侧面部三维立体深度。                                        |

### 1.2 严格硬性约束

- **画幅与分辨率**：默认 `1:1`（`2048x2048`）或 `16:9`（`2048x1152`）；已批准的 `1024x1024` 历史身份图可复用。
- **景别限制**：严格胸部以上（Bust-level）中近景。严禁全身或大半身，杜绝全身比例干扰人脸高频特征。
- **纯净背景**：采用柔和中性漫射光，浅灰、米白或深蓝单色纯净背景。严禁装饰物、边框、光晕噪点、第二个人物。
- **严禁文字污染**：严禁任何水印、文字、签名、LOGO、视图说明标签（如在图上印 FRONT / SIDE）。
- **真实质感（防涂抹硬性红线）**：保留真实皮肤细纹、毛孔与自然血色感，严禁磨皮塑料人感与涂抹感。

### 1.3 防涂抹与高频微观质感保真准则 (Anti-Smearing Protocol)

写实人像可参考以下建议；具体要求取决于批准的视觉风格，模型与参数不能保证消除所有瑕疵：

1. **工程参数强约束**：
   - **强制指定质量等级**：生图接口显式指定 `quality="high"`（使用宿主实际支持的枚举，不臆造 `xhigh` / `max` 等值）；
   - **严格对齐官方尺寸约束**：单边尺寸严格不得超过 3,840 像素且为 16 的整倍数（如 16:9 4K 为 `3840x2160`，9:16 4K 为 `2160x3840`，1:1 2K 为 `2048x2048`），严禁使用历史超限尺寸（`4096x2304`）导致尺寸被拒或拉伸失真；
   - **默认收敛至 Codex 旗舰模型**：优先采用 `gpt-image-2.5-sunburst`（OpenAI Responses 原生），其微观细节采样与高频皮肤毛孔纹理全面领先，彻底告别传统塑料平滑感；极速交互可选用 `gpt-image-2.5-flare`。
2. **可选四段式写实提示词模板**：
   - **[Scene]**：空间尺度与真实采光（如 `Directional natural daylight, subtle shadow gradation, neutral studio backdrop`）；
   - **[Subject]**：明确真实真人脸骨相特征、具体成年年龄、视线与姿态；
   - **[Details]**：镜头与微观质感（`Shot like a 35mm film photograph, 50mm lens, visible skin pores, natural wrinkles, individual eyelashes, fine fabric weave`）；
   - **[Constraints]**：严格排除项（`No heavy retouching, no airbrushed smooth skin, no porcelain doll effect, no beauty filter, no CGI look, no text, no watermarks`）。

## 2. 角色服装无脸人台三视图（Wardrobe Design）

用于单元情节中（如 `B01`、`B02`）审核服装造型、身材比例与体态配饰（“角色 = 人物 + 服装”）。

### 2.1 资产形态：`05-wardrobe-turnaround.png`

- **形态**：正面全身（Front）、左侧全身（Side）、背面全身（Back）三立姿视角横向排布（或单独生成）。
- **头身比基准**：默认以 **7.5 头身** 写实成年人物为工业参考基准（创作者有特殊艺术设计时以创作者意图为准）。
- **强制无脸人台化（Faceless Mannequin）**：
  - 核心原理：面容特征由人物设计四视图锁定。如果服装图上出现第二张人脸，下游多模态视频模型会发生“双脸融合特征混淆”。
  - 头部只保留发型轮廓、发色、头饰或帽子，面部采用光滑无五官极简人台处理（灰白或木质质感）。
- **服装与配饰细节**：
  - 完整呈现上衣、下装（裤/裙）、鞋袜剪裁与材质色彩；
  - 完整呈现剧本所需的墨镜、包袋、手链、项链等道具配件。

## 3. 分镜单格图（Storyboard Frames F01~F08）

用于多格动态视频模型（如 MiniMax H3、Picture 2 Storyboard Grid）的单格画面输入。

### 3.1 规格参数

- **画幅与分辨率**：`16:9` 电影画幅，权威分辨率 **2K**（`2048x1152`）。
- **文件命名**：`F01.png`, `F02.png`, ..., `F08.png`。

### 3.2 镜头语言规范

- **主体明确**：每格画面主体动作、站位朝向与视线方向必须唯一确定；
- **景别设计**：特写（CU）、中景（MS）、全景（FS）、大远景（EWS）过渡自然，符合电影视听语言；
- **光影与色调**：色彩饱和度、色温、对比度必须严格遵从 Visual Bible 视觉圣经中冻结的基准色调；
- **起落幅呼应**：`F01` 为镜头起始帧，`F08` 为镜头结束帧，中间格体现连续运动轨迹。

---

## 4. 纯场景设计图（Environment / Set Design）

用于锁定叙事段落的环境氛围、时代感与地理特征：

- **规格**：`16:9` 2K。
- **内容要求**：空镜或环境全景，不出现主体人物，着重刻画空间透视、材质反射、自然天气（雨夜、雾气、黄昏阳光）。

## 5. 项目归档与目录规范

所有生产成功的不可变图像统一落盘归档至项目专属原子素材目录：

```text
.output/projects/<project_id>/source/
├── identity/                         # 全局人物设计
│   ├── 01-front-neutral.png
│   ├── 02-front-smile.png
│   ├── 03-left-15deg.png
│   └── 04-right-15deg.png
├── wardrobe/                         # 单元角色服装设计
│   ├── B01-wardrobe-turnaround.png
│   └── B02-wardrobe-turnaround.png
└── storyboards/                      # 分镜单格画面
    ├── B01/
    │   ├── F01.png
    │   ├── F02.png
    │   └── ...
    └── B02/
```
