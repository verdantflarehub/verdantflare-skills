# 规则约束

## 1. 授权与权限

上游任务授权与 Codex 权限审批分别记录。沿用目标会话的模型和权限设置；不通过任务参数覆盖安全策略。插件权限审批保留在插件 UI，独立后端没有人工审批入口时保持等待，不伪造批准。

禁止递归委托同一个服务。用户未指定插件会话时不得选择正在运行的其他任务。只在明确指定的空闲会话做写调用验收。

## 2. 参数与幂等

提示词非空且 UTF-8 不超过 64 KiB；任务超时为 30～86400 秒，默认 3600 秒，包含等待人工时间。未知字段拒绝。

同一请求编号和相同参数返回原任务；相同编号不同内容报冲突。读请求可重试；写请求超时不说明没有执行，必须先核对原任务。

续接和取消绑定预期轮次，过期编号拒绝。不能将任务编号、会话编号、轮次编号或待处理请求编号混用。

## 3. 工作区与存储

工作目录须为有效绝对路径（配置 `allowed_roots` 为 `["*"]` 或 `[]` 时不限制仓库根；配置具体路径列表时限定在允许根内），按真实路径处理目录联接和 Windows 大小写。同一会话及父子目录写任务互斥。服务租约不能阻止人工或其他软件写入，任务交接须约定修改范围。

任务、命令队列、事件和租约保存在用户数据目录 SQLite 中，技能目录只保存静态指导及启动器。未知状态保留租约，数据库不作为可随意清理的临时文件。

## 4. 兼容与维护

本规则来自已验证的插件派单、续接、取消、重启恢复与参数测试。插件协议是版本相关的内部接口，升级后重新校验版本、快照修订号及写调用行为。快照缺失或事件修订号断档时停止依赖旧状态执行写请求。

技能源码唯一维护，安装副本修改须先合回源码。全局技能不绑定某个仓库或个人绝对路径；运行目录与服务入口由配置提供。
