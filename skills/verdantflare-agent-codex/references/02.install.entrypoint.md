# Codex 本机 MCP 服务安装与启动（02.install）

## 1. 输入与输出

- **输入**：维护源目录 `skills/verdantflare-agent-codex/`、本机 Python 3.11+ 环境、已安装的 VS Code `openai.chatgpt` 扩展及安装参数（`--replace`、`--register-mcp`、`--panel-transport`、`--workspace-sessions`）。
- **输出**：确定性运行清单 `service_build`、同步到 `~/.agents/skills/verdantflare-agent-codex/` 的全局安装副本、独立虚拟环境运行时、用户数据目录下的 `verdantflare-agent-codex/service.json` 及对端智能体 MCP 注册配置。
- **公共依据**：[公共规则](00.common.rules.md)、[技能入口](../SKILL.md)。

## 2. 分类

| 操作分支     | 适用场景与核心动作                                                                |
| :----------- | :-------------------------------------------------------------------------------- |
| 安装并注册   | 生成运行清单、同步全局技能、构建独立虚拟环境并向对端智能体注册 MCP                |
| 仅同步技能   | 仅更新全局技能副本与运行时，不改动对端 MCP 注册文件                               |
| 服务探测启动 | 通过 [launch.py](../scripts/launch.py) 探测能力（`codex_capabilities`）或启动服务 |

## 3. 工作流

1. **生成运行清单并安装注册**：安装前先执行 `generate_build.py` 生成确定性运行清单，再运行 [install.py](../scripts/install.py) 同步全局技能、构建独立虚拟环境并注册 MCP：

```powershell
python -X utf8 scripts/generate_build.py
python -X utf8 scripts/install.py --replace --register-mcp
```

仅更新全局技能与运行时而不改动对端 MCP 配置时，省略 `--register-mcp`。

2. **服务配置与启动探测**：配置入口由 `VERDANTFLARE_AGENT_CODEX_SERVICE` 指定，默认读取用户数据目录的 `verdantflare-agent-codex/service.json`。启动器仅读取配置并调用已安装服务，不在调用时下载依赖：

```powershell
python -X utf8 scripts/launch.py --call codex_capabilities
python -X utf8 scripts/launch.py
```

3. **版本切换与运行摘要核对**：核对维护源、安装副本与实际连接进程的 `service_build` 与 `verified` 字段；`verified=false` 或旧进程缺少标识时，不报告新版本已加载。版本切换等待在途任务安全窗口，不混跑新旧租约语义。

## 4. 规范

- 遵循[公共规则](00.common.rules.md)：运行时自动探测当前已安装的 Codex 扩展目录与 IPC 方法版本，不锁定扩展版本号；服务仅本机 `stdio`，不提供公网监听。
- 技能源码在仓库 `skills/verdantflare-agent-codex/` 唯一维护，安装副本通过安装脚本同步；更新已有安装前核对无副本独有改动，不借 `--replace` 覆盖无关配置。
- 公开文档与配置示例严禁写入本机绝对路径、账号或认证凭据。

## 5. 验收

- **静态检查**：在仓库内与不含兄弟技能的临时隔离目录运行 `lint_skill.py --style numbered`，并对全部 `.md` 运行 `md_format.py --check` 与 `check_md.py`，均为 0 errors。
- **单测与哈希比对**：运行 `python -X utf8 -m unittest discover -s scripts -p "test_*.py" -v` 与运行时内测试全部通过；维护源与 `~/.agents/skills/verdantflare-agent-codex/` 逐文件 SHA-256 哈希一致。
- **协议与接入验证**：标准 MCP 客户端初始化、列出八项工具、调用 `codex_capabilities` 且返回有效 `service_build`；技能可见、MCP 已注册、真实工具可调用和人工确认分别报告。
