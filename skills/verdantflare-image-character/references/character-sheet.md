# 人物视觉档案卡

面向 GPT Image 的 `16:9` 横版角色设定卡（Character Anatomy Atlas），用于角色建档、跨镜头复用或将单张定妆图展开为全维度角色母版。按[执行流程](01.base-workflow.md)选择纯文生图直出或参考图锁定编辑。

## 1. 纯文生图通用模板（十段式参数化）

适用于无参考图直接建卡。将大括号 `{...}` 替换为明确设定；需要强辨识度或古风/特定题材角色时，务必填实五官、标志特征（按人物自身解剖学左右侧）、发型配饰、服饰纹样与匹配鞋履，不留空给模型自由发挥。

```text
CHARACTER ANATOMY ATLAS ｜AI原创人物·全自动视觉档案导演系统

00｜USER INPUT
人物性别：{女性 / 男性}
人物年龄：{成年年龄与外貌观感}
人物背景/国籍：{时代背景或国籍}
人物身份/职业：{角色身份}
人物身高：{如 168 cm}
人物体重：{如 49 kg}
人物体型：{自然协调体态描述}
人物五官：{脸型、眉眼、鼻唇及按解剖学左右侧锁定的标志特征}
人物肤色：{肤色与真实自然肤质}
人物发型：{发色、发髻/发型、刘海与发饰结构}
人物服饰：{面料、版型、纹样、留白、配饰与匹配鞋履；非现代题材注明严禁现代高跟鞋}
人物气质：{核心神态与气质关键词}
视觉风格：{超写实真人棚拍摄影}
背景环境：{简洁统一的灰白中性摄影棚纯色背景}
画幅比例：{16:9横版}
图像质量：{4K}
文字语言：{简体中文}

01｜核心任务
根据上述参数为该成年原创角色生成一张完整的 16:9 人物视觉档案板，包含左侧中文资料与比例标尺、中央等高正面/严格90度侧面/180度背面三张全身图、右侧面部多角度及局部细节矩阵。所有分格必须属于同一角色，身份、体型、发型、服饰与棚拍质感完全统一。

02｜人物视觉基因锁定
保持独立辨识度的颅面骨相、五官组合与自然皮肤细节，避免模板化网红脸与过度磨皮。非对称特征（如美人痣、疤痕）严格按人物自身解剖学左右侧固定，在多角度中不得镜像漂移或消失。

03｜身体比例导演
按输入身高、体重与体型设计自然协调的头身比与四肢比例，所有数值均为虚构角色设定且前后自洽。三张全身图自然站姿，头顶与鞋底完整入画且高度对齐。

04｜服饰连续性导演
三视图使用 100% 同一套服饰，缝线、褶皱、垂坠、背面剪裁、发饰背面穿插与鞋履完全连续可信，无跨时代元素穿帮。

05｜固定视觉版式
16:9 横版，灰白中性色系，细线分割为三个纵向主区：
- 左侧 14%：简体中文人物视觉档案信息栏、垂直身高刻度尺，底部附正/侧/背三幅白色细线人体轮廓线稿。
- 中央 53%：三张等高全身站姿视图，底部标注“正视图（Front View）”“侧视图（Side View）”“后视图（Back View）”。
- 右侧 33%：面部观察矩阵——上层 1 张大幅正面脸部近景；中层 3 张并排面部特写（45°侧脸、90°正侧脸、低机位仰视）；底层 4 张并排微距特写（眼部、鼻部、唇部、耳部）。

06｜镜头与棚拍摄影
统一使用柔和自然的室内棚拍中性散射光，肤质毛孔、虹膜、唇纹与面料纹理清晰真实。禁止过度磨皮、虚假皮肤、夸张美颜、多余人物或结构畸变。

07｜简体中文信息栏
清晰整齐列出姓名、年龄、背景/国籍、身份/职业、身高、体重、体型、气质、标志特征、服饰及参考体型参数（肩宽/三围/腿长），文字无乱码、数值前后一致。

08｜跨组创意重置与自检
每次建新角色独立设计，不继承上一组模板。生成前自检身份统一、三视图准确、服饰与发饰连续、标志特征未跑位、中文整齐、背景干净，存在冲突时优先保证身份一致、三视图准确与完整布局。
```

## 2. 参考图锁定模板（单张定妆图转 16:9 设定卡）

适用于已生成或已有单张满意的定妆/写真母版（作为**参考图 1**），需剥离原图环境光与坐姿遮挡、展开为 `16:9` 棚拍角色设定卡的场景：

```text
【参考图职责与不变项锁定】
参考图 1 是本角色的唯一绝对身份与造型母版。所有分格画面必须 100% 严格锁定参考图 1 中成年角色的真实面容骨相、五官比例、标志性特征（按人物自身解剖学左右侧固定，不得镜像跑位）、肤色、发型发饰与核心服饰材质纹样。

【变更边界（严格隔离）】
仅改变画幅版式、人物姿态与拍摄环境：完全剥离参考图 1 的原有场景背景、道具遮挡与环境色温光影，切换为干净统一的灰白中性棚拍纯色背景与柔和自然散射光；将原姿态展开为正面、严格 90 度侧面、180 度背面三张完整站姿全身图，自然补全原图未露出的衣摆长度、背面服饰与发饰结构，以及与题材匹配的鞋履（写明时代/风格，严禁混入现代高跟鞋或无关元素）。

【目标交付物与 16:9 固定视觉版式】
输出一张 16:9 横版、4K 超写实真人棚拍《人物视觉档案》，灰白中性专业排版，细线分割为三个纵向主区：
1. 左侧 14%：简体中文人物信息栏（填入角色姓名、年龄、背景、身高体重、气质、标志特征、服饰与参考体型参数）、垂直身高刻度尺，底部附正/侧/背三幅白色细线人体轮廓线稿。
2. 中央 53%：三张等高站姿全身视图，头顶与鞋底完整留白并严格齐平，底部依次标注“正视图（Front View）”“侧视图（Side View）”“后视图（Back View）”。
3. 右侧 33%：面部观察矩阵。上层为大幅正面脸部近景特写；中层并排 3 格为“45°侧脸”“90°正侧脸”“低机位仰视”；底层并排 4 格为“眼部特写”“鼻部特写”“唇部特写”“耳部特写”。

【棚拍摄影与硬性约束】
统一柔和自然棚拍散射光，真实呈现自然肤质毛孔与服装材质细节。严禁过度磨皮、网红脸变形、标志特征镜像跑位、原图背景残留、鞋服穿帮、中文乱码以及多余人物或肢体。
```
