# 人物设定素材分类

## 1. 人物五视图

H3 或 SD2.5 视频生成使用的一张人物设定图，记录同一角色在同一套服装下的身份与造型。用户说“人物五视图”即选此规格。

## 2. 人物半身照

一张胸部以上、正对镜头的单人正脸照。单独索取时只出这一格。

## 3. 人物视觉档案卡

面向 GPT Image 的 `16:9` 横版完整角色设定卡（又称人物设定表、Character Anatomy Atlas），在一张图中整合左侧中文资料栏与比例标尺、中央等高正/侧/背全身三视图，以及右侧多角度面部与眼鼻唇耳微距矩阵。适用于角色建档、跨镜头长期复用或把单张定妆图展开为全维度角色母版。用户说“人物设定表”“角色设定卡”“人物视觉档案”即选此规格。
