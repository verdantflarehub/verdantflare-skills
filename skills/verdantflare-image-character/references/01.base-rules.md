# 人物取景与版式

## 1. 五视图

一张图，上排三格，下排两格，各排从左到右排列。

| 上排全身无头，颈部至鞋底                        | 下排胸部以上，头顶完整                           |
| ----------------------------------------------- | ------------------------------------------------ |
| 左格为正面，中格为严格侧面（90°），右格为正背面 | 左格为正脸，右格为头部和上身从正面向同一侧转 60° |

上排通过取景将头部留在画外，同排人物等比例站立，鞋底齐平。下排两格取景尺度一致，清楚呈现脸型、耳侧轮廓、发型及服装领口。各格沿用同一身形、衣层、配饰与光照，使用干净背景。

## 2. 半身照

胸部处为画面下沿，双肩和头顶完整，面部与肩膀正对镜头。

## 3. 人物视觉档案卡

一张 `16:9` 横版灰白中性棚拍档案图，柔和自然室内散射光，细线分割为三大纵向区域：

| 画布区域     | 占比与排布要求                                                              |
| :----------- | :-------------------------------------------------------------------------- |
| 左侧信息区   | `14%`；简体中文资料、体型参考参数、垂直身高标尺，底部附正/侧/背人体轮廓线稿 |
| 中央全身区   | `53%`；等高正面、严格 90° 侧面、180° 背面全身站姿，发髻/头顶与鞋底完整齐平  |
| 右侧观察矩阵 | `33%`；上层正面近景，中层 45°/90°/仰视三格面部，底层眼/鼻/唇/耳四格微距     |

- **解剖学方位锁定**：美人痣、疤痕等非对称特征必须按人物自身解剖学左右侧声明（如“人物自身左眼下方”），不写相对画面的“画面左侧/右侧”，防止 45°/90° 侧脸和微距镜像漂移。
- **非现代题材显式补全**：古风、奇幻等题材必须显式写清全身下摆长度、背面发饰穿插结构与时代匹配的鞋履，并在提示词中排除现代门框、现代高跟鞋及原参考图环境光残留。
- **反默认模板收敛**：需要强辨识度角色时，显式填实骨相、肤色、发饰与服饰槽位，不将关键项大面积留空为“AI 自主设计”。
