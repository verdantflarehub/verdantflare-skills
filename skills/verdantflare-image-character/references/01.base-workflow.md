# 从参考人脸和服装出图

## 1. 准备参考

- **有参考图（人物五视图、人物半身照、参考图锁定档案卡）**：用一张参考人脸确定身份，用指定服装确定造型。两者已在同一张参考图时直接使用该图；分开提供时以人脸为编辑源图，服装图作为附加参考；文字指定的服装写入提示词。
- **无参考图（纯文生图档案卡）**：直接按[人物视觉档案卡](character-sheet.md)的参数槽位补齐角色五官、标志特征、发型服饰与体态设定；若追求更高跨图稳定性，可先生成单人定妆母版，再以该母版作为参考图 1 走图像编辑生成档案卡。

## 2. 提交生成或编辑

由 `verdantflare-image` 执行：有参考图时导入参考并调用 `image.edit`，无参考图直出人物视觉档案卡时调用 `image.create`。沿用当前项目、引擎选择、任务恢复、结果下载、分级和交付流程。[图像技能](../../verdantflare-image/SKILL.md)

提交时按所需产物选用[人物五视图提示词](character-five-views.md)、[人物半身照提示词](character-portrait.md)或[人物视觉档案卡提示词](character-sheet.md)。

## 3. 回收

取得原图后，按[验收标准](01.base-acceptance.md)检查实际画面，再交付评审。
