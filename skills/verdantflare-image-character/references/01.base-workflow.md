# 从参考人脸和服装出图

## 1. 准备参考

用一张参考人脸确定身份，用指定服装确定造型。两者已在同一张参考图时直接使用该图。分开提供时以人脸为编辑源图，服装图作为附加参考；文字指定的服装写入提示词。

## 2. 提交编辑

由 `verdantflare-image` 导入参考并调用 `image.edit`。沿用当前项目、引擎选择、任务恢复、结果下载、分级和交付流程。[图像技能](../../verdantflare-image/SKILL.md)

提交时按所需产物选用[人物五视图提示词](character-five-views.md)或[人物半身照提示词](character-portrait.md)。

## 3. 回收

取得原图后，按[验收标准](01.base-acceptance.md)检查实际画面，再交付评审。
