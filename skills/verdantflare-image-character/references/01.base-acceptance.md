# 人物设定图验收

## 1. 五视图

- 打开原图，核对单图五格以及上三下二的顺序。
- 逐格检查上排的正、侧、背，三格均从颈部裁到鞋底。五个带头全身人像横排应判为版式失败。
- 下排两格下沿均在胸部。左格核对正脸与输入身份，右格核对头和上身同向侧转 60°。视觉检查角度时注明估计，参考图未展示的侧脸轮廓交由用户评审。
- 对照服装参考检查领口、袖长、衣摆、鞋与配饰。格位或造型有误时记录具体格位，返修保留其余已符合的约束。

## 2. 半身照

交付单张胸部以上正脸照。检查头顶、双肩、胸部裁切、朝向及身份。

## 3. 人物视觉档案卡

- 打开原图，核对 `16:9` 横版三区布局：左 `14%` 中文信息栏与底部三视图线稿、中 `53%` 等高正/侧/背全身三视图、右 `33%` 大正面近景 + 3 格多角度面部 + 4 格眼鼻唇耳微距。
- 核对中央三视图头顶与鞋底是否完整齐平，侧面是否为严格 90°、背面是否为 180°；检查服装材质、纹样、背面发饰与鞋履在三视图中连续统一，无现代鞋服或原背景光影残留。
- 核对右侧面部矩阵与全身正视图是否为同一身份，标志性特征（如美人痣、耳饰）在正面、侧脸与局部微距中位置一致、未镜像翻转。
- 核对左侧简体中文信息栏无明显错字乱码，身高、体重、体型参数前后自洽。
- 局部格位、文字或特征有误时记录具体区域，返修保留其余已通过约束。
