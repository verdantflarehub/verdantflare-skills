# verdantflare-image-character：公共规则与调用约束

## 1. 参考素材准备

- **有参考图（人物五视图、人物半身照、参考图锁定档案卡）**：用一张参考人脸确定身份，用指定服装确定造型。两者已在同一张参考图时直接使用该图；分开提供时以人脸为编辑源图（`source_artifact_id`），服装图作为附加参考（`reference_artifact_ids`）；文字指定的服装写入提示词。
- **无参考图（纯文生图档案卡）**：直接按[人物视觉档案卡](03.character-sheet.entrypoint.md)的参数槽位补齐角色五官、标志特征、发型服饰与体态设定；若追求更高跨图稳定性，可先生成单人定妆母版，再以该母版作为参考图 1 走图像编辑生成档案卡。

## 2. 生成与交付路由

- 实际出图统一由[图像技能](../../verdantflare-image/SKILL.md)执行：有参考图时先将参考图受控导入当前项目并调用 `image.edit`，无参考图直出人物视觉档案卡时调用 `image.create`。
- 沿用 `verdantflare-image` 的当前项目归属（`project_id`）、默认引擎与模型（GPT Image 2.6）、任务恢复、结果下载校验、生成后 18+ 内容分级评估（`image.rate_content`）及交付归档流程。
- 取得原图后，必须按对应能力入口的第 5 节检查实际画面，再交付评审；局部格位、文字或特征有误时记录具体区域，返修保留其余已通过约束。

## 3. 跨能力通用视觉约束

- **解剖学方位锁定**：美人痣、疤痕等非对称特征必须按人物自身解剖学左右侧声明（如“人物自身左眼下方”），不写相对画面的“画面左侧/右侧”，防止侧脸和微距镜像漂移。
- **非现代题材显式补全**：古风、奇幻等题材必须显式写清全身下摆长度、背面发饰穿插结构与时代匹配的鞋履，并在提示词中排除现代门框、现代高跟鞋及原参考图环境光残留。
- **反默认模板收敛**：需要强辨识度角色时，显式填实骨相、肤色、发饰与服饰槽位，不将关键项大面积留空为“AI 自主设计”。
- **背景与文字洁净**：人物五视图与半身照使用干净纯色背景且无文字；人物视觉档案卡使用灰白中性棚拍纯色背景，仅左侧信息栏与视图标注按规范呈现简体中文。
