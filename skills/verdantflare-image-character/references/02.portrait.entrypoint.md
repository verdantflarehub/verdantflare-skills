# verdantflare-image-character：人物半身照（02.portrait）

## 1. 输入与输出

- **输入**：1 张参考人脸图（确定身份），以及指定服装（与人脸同图、独立服装参考图或文字描述）；所属 Studio 项目的 `project_id` 与固定幂等键。
- **输出**：单张胸部以上、正对镜头的单人正脸半身照，附带 SHA-256、实际宽高与 K09 分级记录。
- **公共依据**：[公共规则与调用约束](00.common.rules.md)、[图像技能](../../verdantflare-image/SKILL.md)。

## 2. 分类

- **适用场景**：用户单独索取“人物半身照”或单张胸部以上正脸照，只出这一格。
- **不适用场景**：需要 H3 / SD2.5 五格设定图请转[人物五视图](01.five-views.entrypoint.md)；需要 16:9 完整设定表请转[人物视觉档案卡](03.character-sheet.entrypoint.md)。

## 3. 工作流

1. **准备参考**：按[公共规则](00.common.rules.md#1-参考素材准备)准备参考人脸与服装输入；人脸与服装分图时以人脸为主编辑源图，服装图作附加参考。
2. **组织提示词**：使用以下标准出图提示词并按实际服装补充领口与发型细节：

> 使用参考人脸和指定服装，生成一张单人正面半身照。面部与双肩正对镜头，双眼平视。画面下沿裁在胸部，完整保留头顶、双肩与领口。保持参考人物的脸型、五官比例和发型，背景干净，无文字。

3. **提交图像编辑**：通过[图像技能](../../verdantflare-image/SKILL.md)导入参考并调用 `image.edit`；沿用当前项目、默认引擎、幂等恢复与下载流程。
4. **分级与回收**：下载校验原图，完成 `image.rate_content` 分级评估后，按第 5 节验收再交付评审。

## 4. 规范

- 胸部处为画面下沿，双肩和头顶完整入画，完整呈现领口。
- 面部与双肩正对镜头，双眼平视，保持参考人物的脸型、五官比例与发型。
- 使用干净背景，无文字、水印或多余人物。

## 5. 验收

- 交付单张胸部以上正脸照，不误出多格拼图或全身照。
- 逐项检查头顶完整度、双肩完整度、胸部下沿裁切、正面平视朝向及与参考人脸的身份一致性。
- 若存在身份漂移、裁切过紧或领口服装不符，记录具体缺陷并在返修时保留其余已符合的约束。
