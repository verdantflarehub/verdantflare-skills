# verdantflare-crew-character：人物视觉档案卡（03.character-sheet）

## 1. 输入与输出

- **输入**：无参考图时提供完整角色设定参数（性别、成年年龄、背景、身份、身高体重、体型、五官与解剖学左右侧标志特征、肤色、发型发饰、服饰与鞋履、气质）；有参考图时提供 1 张满意的定妆或写真母版作为参考图 1；所属 Studio 项目的 `project_id` 与固定幂等键。
- **输出**：单张面向 GPT Image 的 `16:9` 横版 4K 超写实真人棚拍《人物视觉档案》（Character Anatomy Atlas），附带 SHA-256、实际宽高与 K09 分级记录。
- **公共依据**：[公共规则与调用约束](00.common.rules.md)、[图像技能](../../verdantflare-image/SKILL.md)。

## 2. 分类

- **适用场景**：用户说“人物设定表”“角色设定卡”“人物视觉档案”，用于角色建档、跨镜头长期复用或把单张定妆图展开为全维度角色母版。
- **子模式判定**：无参考图直接建卡走纯文生图（`image.create` + 第 3.1 节十段式模板）；已有单张定妆母版需剥离原背景光影展开为设定卡走参考图锁定编辑（`image.edit` + 第 3.2 节参考图锁定模板）。追求更高跨图稳定性时，也可先生成单人定妆母版再转参考图锁定编辑。
- **不适用场景**：只需 H3 / SD2.5 五格设定图请转[人物五视图](01.five-views.entrypoint.md)；只需单张胸部以上正脸照请转[人物半身照](02.portrait.entrypoint.md)。

## 3. 工作流

1. **判定子模式与准备输入**：按[公共规则](00.common.rules.md#2-参考素材准备与跨能力视觉约束)准备参数槽位或导入参考图 1。需要强辨识度或古风/特定题材角色时，填实五官、标志特征（按人物自身解剖学左右侧）、发型配饰、服饰纹样与匹配鞋履，不留空给模型自由发挥。
2. **套用对应模板**：无参考图套用第 3.1 节模板；有参考图 1 套用第 3.2 节模板。
3. **提交生成或编辑**：通过[图像技能](../../verdantflare-image/SKILL.md)调用 `image.create`（无参考图）或 `image.edit`（有参考图），默认走 GPT Image 2.6 与 `16:9` 画幅。
4. **分级与回收**：下载校验原图，完成 `image.rate_content` 分级评估后，按第 5 节逐区验收再交付评审。

### 3.1 纯文生图通用模板（十段式参数化）

将大括号 `{...}` 替换为明确设定后提交：

```text
CHARACTER ANATOMY ATLAS ｜AI原创人物·全自动视觉档案导演系统

00｜USER INPUT
人物性别：{女性 / 男性}
人物年龄：{成年年龄与外貌观感}
人物背景/国籍：{时代背景或国籍}
人物身份/职业：{角色身份}
人物身高：{如 168 cm}
人物体重：{如 49 kg}
人物体型：{自然协调体态描述}
人物五官：{脸型、眉眼、鼻唇及按解剖学左右侧锁定的标志特征}
人物肤色：{肤色与真实自然肤质}
人物发型：{发色、发髻/发型、刘海与发饰结构}
人物服饰：{面料、版型、纹样、留白、配饰与匹配鞋履；非现代题材注明严禁现代高跟鞋}
人物气质：{核心神态与气质关键词}
视觉风格：{超写实真人棚拍摄影}
背景环境：{简洁统一的灰白中性摄影棚纯色背景}
画幅比例：{16:9横版}
图像质量：{4K}
文字语言：{简体中文}

01｜核心任务
根据上述参数为该成年原创角色生成一张完整的 16:9 人物视觉档案板，包含左侧中文资料与比例标尺、中央等高正面/严格90度侧面/180度背面三张全身图、右侧面部多角度及局部细节矩阵。所有分格必须属于同一角色，身份、体型、发型、服饰与棚拍质感完全统一。

02｜人物视觉基因锁定
保持独立辨识度的颅面骨相、五官组合与自然皮肤细节，避免模板化网红脸与过度磨皮。非对称特征（如美人痣、疤痕）严格按人物自身解剖学左右侧固定，在多角度中不得镜像漂移或消失。

03｜身体比例导演
按输入身高、体重与体型设计自然协调的头身比与四肢比例，所有数值均为虚构角色设定且前后自洽。三张全身图自然站姿，头顶与鞋底完整入画且高度对齐。

04｜服饰连续性导演
三视图使用 100% 同一套服饰，缝线、褶皱、垂坠、背面剪裁、发饰背面穿插与鞋履完全连续可信，无跨时代元素穿帮。

05｜固定视觉版式
16:9 横版，灰白中性色系，细线分割为三个纵向主区：
- 左侧 14%：简体中文人物视觉档案信息栏、垂直身高刻度尺，底部附正/侧/背三幅白色细线人体轮廓线稿。
- 中央 53%：三张等高全身站姿视图，底部标注“正视图（Front View）”“侧视图（Side View）”“后视图（Back View）”。
- 右侧 33%：面部观察矩阵——上层 1 张大幅正面脸部近景；中层 3 张并排面部特写（45°侧脸、90°正侧脸、低机位仰视）；底层 4 张并排微距特写（眼部、鼻部、唇部、耳部）。

06｜镜头与棚拍摄影
统一使用柔和自然的室内棚拍中性散射光，肤质毛孔、虹膜、唇纹与面料纹理清晰真实。禁止过度磨皮、虚假皮肤、夸张美颜、多余人物或结构畸变。

07｜简体中文信息栏
清晰整齐列出姓名、年龄、背景/国籍、身份/职业、身高、体重、体型、气质、标志特征、服饰及参考体型参数（肩宽/三围/腿长），文字无乱码、数值前后一致。

08｜跨组创意重置与自检
每次建新角色独立设计，不继承上一组模板。生成前自检身份统一、三视图准确、服饰与发饰连续、标志特征未跑位、中文整齐、背景干净，存在冲突时优先保证身份一致、三视图准确与完整布局。
```

### 3.2 参考图锁定模板（单张定妆图转 16:9 设定卡）

将已有定妆或写真母版作为**参考图 1** 传入 `image.edit`：

```text
【参考图职责与不变项锁定】
参考图 1 是本角色的唯一绝对身份与造型母版。所有分格画面必须 100% 严格锁定参考图 1 中成年角色的真实面容骨相、五官比例、标志性特征（按人物自身解剖学左右侧固定，不得镜像跑位）、肤色、发型发饰与核心服饰材质纹样。

【变更边界（严格隔离）】
仅改变画幅版式、人物姿态与拍摄环境：完全剥离参考图 1 的原有场景背景、道具遮挡与环境色温光影，切换为干净统一的灰白中性棚拍纯色背景与柔和自然散射光；将原姿态展开为正面、严格 90 度侧面、180 度背面三张完整站姿全身图，自然补全原图未露出的衣摆长度、背面服饰与发饰结构，以及与题材匹配的鞋履（写明时代/风格，严禁混入现代高跟鞋或无关元素）。

【目标交付物与 16:9 固定视觉版式】
输出一张 16:9 横版、4K 超写实真人棚拍《人物视觉档案》，灰白中性专业排版，细线分割为三个纵向主区：
1. 左侧 14%：简体中文人物信息栏（填入角色姓名、年龄、背景、身高体重、气质、标志特征、服饰与参考体型参数）、垂直身高刻度尺，底部附正/侧/背三幅白色细线人体轮廓线稿。
2. 中央 53%：三张等高站姿全身视图，头顶与鞋底完整留白并严格齐平，底部依次标注“正视图（Front View）”“侧视图（Side View）”“后视图（Back View）”。
3. 右侧 33%：面部观察矩阵。上层为大幅正面脸部近景特写；中层并排 3 格为“45°侧脸”“90°正侧脸”“低机位仰视”；底层并排 4 格为“眼部特写”“鼻部特写”“唇部特写”“耳部特写”。

【棚拍摄影与硬性约束】
统一柔和自然棚拍散射光，真实呈现自然肤质毛孔与服装材质细节。严禁过度磨皮、网红脸变形、标志特征镜像跑位、原图背景残留、鞋服穿帮、中文乱码以及多余人物或肢体。
```

## 4. 规范

一张 `16:9` 横版灰白中性棚拍档案图，柔和自然室内散射光，细线分割为三大纵向区域：

| 画布区域     | 占比与排布要求                                                              |
| :----------- | :-------------------------------------------------------------------------- |
| 左侧信息区   | `14%`；简体中文资料、体型参考参数、垂直身高标尺，底部附正/侧/背人体轮廓线稿 |
| 中央全身区   | `53%`；等高正面、严格 90° 侧面、180° 背面全身站姿，发髻/头顶与鞋底完整齐平  |
| 右侧观察矩阵 | `33%`；上层正面近景，中层 45°/90°/仰视三格面部，底层眼/鼻/唇/耳四格微距     |

其余解剖学方位锁定、非现代题材显式补全与反默认模板收敛要求遵守[公共规则第 3 节](00.common.rules.md#2-参考素材准备与跨能力视觉约束)。

## 5. 验收

- 打开原图，核对 `16:9` 横版三区布局：左 `14%` 中文信息栏与底部三视图线稿、中 `53%` 等高正/侧/背全身三视图、右 `33%` 大正面近景 + 3 格多角度面部 + 4 格眼鼻唇耳微距。
- 核对中央三视图头顶与鞋底是否完整齐平，侧面是否为严格 90°、背面是否为 180°；检查服装材质、纹样、背面发饰与鞋履在三视图中连续统一，无现代鞋服或原背景光影残留。
- 核对右侧面部矩阵与全身正视图是否为同一身份，标志性特征（如美人痣、耳饰）在正面、侧脸与局部微距中位置一致、未镜像翻转。
- 核对左侧简体中文信息栏无明显错字乱码，身高、体重、体型参数前后自洽。
- 局部格位、文字或特征有误时记录具体区域，返修保留其余已通过约束。
