# 角色设计专员：跨能力公共规则与取证审计（00.common.rules）

## 1. 三层隔离、制片检查点与生成路由

- **三层信息隔离**：人类只提角色视觉意图与审美审批；本专员（`crew`）负责版式硬规范、参考素材分工、逻辑模型选型、返工止损与逐格验收；底层原子技能（`verdantflare-image` / `verdantflare-video`）自管底模权重、LoRA、采样器、节点与渠道网关，本专员严禁硬编码底层实现细节。
- **首轮母版人工检查点与止损**：角色首轮正面定妆母版、服装设定页与首批视觉档案卡必须先交人类审定通过后方可批量衍生；同类缺陷连续返修未收敛时立即止损（默认单图/单镜不超过 3 轮），核对参考输入与提示词冲突后再推进，禁止无上限盲目重试。
- **生成与归档委托**：实际出图统一委托[图像技能](../../verdantflare-image/SKILL.md)（有参考图走 `image.edit`，纯文生图走 `image.create`，默认逻辑模型 GPT Image 2.6）；视频取姿态委托 Studio 版 `verdantflare-video`（核对 Studio 客户端契约标识，不硬编码渠道上限）；归档委托 `verdantflare-artifact` 与 `verdantflare-project`。沿用 `project_id`、幂等恢复、结果下载校验与 K09 内容分级流程。

## 2. 参考素材准备与跨能力视觉约束

- **有参考图（五视图、半身照、参考锁定档案卡）**：一张参考人脸锁定身份，指定服装确定造型；同图直用，分图时以人脸为 `source_artifact_id`、服装为 `reference_artifact_ids`，文字服装写入提示词。无参考图直出档案卡时按[人物档案卡](03.character-sheet.entrypoint.md)补齐槽位，或先出定妆母版再锁定编辑。
- **解剖学方位与题材锁定**：美人痣、疤痕等非对称特征按人物自身解剖学左右声明（如“人物自身左眼下方”），不写相对画面左右；古风/奇幻等题材显式补全下摆长度、背面发饰与鞋履，排除现代元素；强辨识度角色填实骨相、肤色、发饰与服饰槽位，不留空给模型自由发挥。
- **背景与文字洁净**：五视图与半身照使用干净纯色背景且无文字；人物视觉档案卡使用灰白中性棚拍背景，仅左侧信息栏与视图标注按规范呈现简体中文。
- **坐标与锁脸红线**：先取证再分流，优先复用合格素材，不因局部缺陷重置全库。列清身体朝向、头部朝向、视线、表情、平视／俯视／仰视及缺失角度。**相机高低不等于人物抬头低头，侧身不等于回头，镜像不等于另一侧参考**；文件名与提示词不能证明实际机位，未经测量只标目标或视觉估计，`target_angle` 不写入实测字段。增强或延展正脸须与原始身份核对，不能让漂移图替代基准。
- **三图实验对照**：需要对照时，图 1 为原帧，图 2 为原帧＋正脸＋提示词，图 3 为仅原帧＋提示词（隔离正脸与隐藏会话参考，不误称无图生成），保持模型参数一致并记录差异。

## 3. 可复现测量（`audit_images.py`）与技术验收条件

创建 UTF-8 JSON 清单（`images` 非空数组，每项含唯一 `id`、相对 `path`、已知来源 `sha256` 及可选 `expected_dimensions`，可选 `expected_ids`）：

```json
{"expected_ids":["A01"],"images":[{"id":"A01","path":"images/A01.png"}]}
```

```text
python -X utf8 scripts/audit_images.py /path/to/manifest.json --output /path/to/audit.json
```

报告仅输出编号、尺寸、摘要和错误代码，不输出输入绝对路径；退出码 `0` 通过、`1` 失败、`2` 清单或依赖不可用。技术验收采用确定的五项通过条件，不编造综合美学分数：

- **可读取与完整解码**：失败文件数为 `0`；坏图或缺图不计成果。
- **来源一致**：提供期望哈希的每项摘要完全相等，不符项不得入库；尺寸按实际解码值记录，提示词中的“高清/4K”不作输出规格。
- **覆盖齐套**：目标编号缺失数、额外编号数及重复编号数均为 `0`；数量齐全不证明姿态正确。
- **归档一致**：领域引用悬空数为 `0`；固定修订回读哈希与本地一致；无关字段变化数为 `0`。
- **授权批准**：入库图片 100% 落在当前真实授权范围内，不把旧单图批准扩展到新批次。

## 4. 视觉核查与测量边界

- **全图与局部放大对照**：每张候选看全图并放大脸部与原始身份基准及原帧对照；背影或遮挡时身份可见性记为不足。逐项核查身份（眼/眉/鼻/嘴/脸部体积）、皮肤（防皱纹/颗粒/锐化/蜡化）、表情、姿态与机位，填写“观察符合／观察不符／证据不足”。
- **无未验证数值阈值**：视觉核查尚无跨人物验证的数值阈值，不宣称自动放行或直接用像素宽度判胖。技术完成、允许展示、人工审定与 World 发布授权分别记录，互不替代。
