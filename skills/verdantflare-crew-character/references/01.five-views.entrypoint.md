# verdantflare-crew-character：人物五视图（01.five-views）

## 1. 输入与输出

- **输入**：1 张参考人脸图（确定身份），以及指定服装（与人脸同图、独立服装参考图或文字描述）；所属 Studio 项目的 `project_id` 与固定幂等键。
- **输出**：单张上三格、下两格的人物五视图设定图（供 H3 或 SD2.5 视频生成使用），附带 SHA-256、实际宽高与 K09 分级记录。
- **公共依据**：[公共规则与调用约束](00.common.rules.md)、[图像技能](../../verdantflare-image/SKILL.md)。

## 2. 分类

- **适用场景**：用户说“人物五视图”，或为 H3 / SD2.5 视频生成制作单张记录同一角色在同一套服装下身份与造型的五格设定图。
- **不适用场景**：单独索取胸部以上正脸照请转[人物半身照](02.portrait.entrypoint.md)；需要面向 GPT Image 的 16:9 完整设定表（含信息栏与面部微距矩阵）请转[人物视觉档案卡](03.character-sheet.entrypoint.md)；明确点名旧版三脸 3+2 或衣装优先 2+3 合成板时遵循 `verdantflare-image` 的既有合成板规格。

## 3. 工作流

1. **准备参考**：按[公共规则](00.common.rules.md#2-参考素材准备与跨能力视觉约束)准备参考人脸与服装输入；人脸与服装分图时以人脸为主编辑源图，服装图作附加参考。
2. **组织提示词**：使用以下标准出图提示词并按实际服装补充必要细节：

> 使用参考人脸和指定服装，生成一张上三格、下两格的人物设定图。五格都是同一人物、同一套造型。上排从左到右依次为全身正面、严格 90° 侧面、正背面。每格从颈部取景到鞋底，头部在画外，鞋底对齐。下排从左到右依次为胸部以上正脸、胸部以上侧身 60°。侧身时头和上身从正面向同一侧转动。下排两格均保留完整头顶和双肩，使用相同的人脸尺度。背景干净，无文字。

3. **提交图像编辑**：通过[图像技能](../../verdantflare-image/SKILL.md)导入参考并调用 `image.edit`；沿用当前项目、默认引擎、幂等恢复与下载流程。
4. **分级与回收**：下载校验原图，完成 `image.rate_content` 分级评估后，按第 5 节逐格验收再交付评审。

## 4. 规范

一张图，上排三格，下排两格，各排从左到右排列：

| 上排全身无头，颈部至鞋底                        | 下排胸部以上，头顶完整                           |
| :---------------------------------------------- | :----------------------------------------------- |
| 左格为正面，中格为严格侧面（90°），右格为正背面 | 左格为正脸，右格为头部和上身从正面向同一侧转 60° |

- 上排通过取景将头部留在画外，同排人物等比例站立，鞋底齐平。
- 下排两格取景尺度一致，清楚呈现脸型、耳侧轮廓、发型及服装领口。
- 各格沿用同一身形、衣层、配饰与光照，使用干净背景，无文字与水印。

## 5. 验收

- 打开原图，核对单图五格以及上三下二的顺序。
- 逐格检查上排的正、侧、背，三格均从颈部裁到鞋底；五个带头全身人像横排判为版式失败。
- 下排两格下沿均在胸部；左格核对正脸与输入身份，右格核对头和上身同向侧转 60°。视觉检查角度时注明估计，参考图未展示的侧脸轮廓交由用户评审。
- 对照服装参考检查领口、袖长、衣摆、鞋与配饰；格位或造型有误时记录具体格位，返修保留其余已符合的约束。
