# 分类与边界

## 1. 适用场景

将有明确工作目录、输入材料、分析或修改范围和验收标准的任务交给 Claude Code（克劳德）。适用于问题诊断、方案设计、执行交接书编制、代码评审及受授权的本地工作区操作。

## 2. 模式选择

- `panel`：指定 VS Code 中已打开且在线的 Claude Code 面板会话；`claude_capabilities` 须显示 `panel_reachable=true` 且 `panel_status="idle"`。通过本机 Named Pipe 注入消息并实时同步至面板与 `.jsonl` 轨迹，不会擅自新建插件标签页。
- `managed`：调用者明确选择受管 CLI 流式执行（`claude.exe -p --output-format stream-json --verbose`）；自动写入 `.claude/projects/<encoded-cwd>/<sessionId>.jsonl`，VS Code 面板 Past Conversations 可直接加载查看。

`claude_capabilities` 返回版本、会话摘要、面板在线状态、过滤计数和分页游标。`read_verified` 只证明当前会话探测可达；任务成败以真实返回与文件证据判定。

## 3. 环境边界

运行时自动探测本机最新已安装的 VS Code 扩展 `anthropic.claude-code` 及内置 `claude.exe`，不硬编码锁定扩展版本号；命名管道握手或二进制不可达时返回明确错误，不盲目试写。服务为本机 stdio，不提供公网监听。

认证由 Claude Code 本机配置管理。技能文件不保存密钥或 `peerToken`，也不把账号凭据写入任务参数。
