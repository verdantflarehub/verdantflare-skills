# 规则约束

## 1. 授权与权限

上游任务授权与 Claude Code 面板权限确认分别记录。`panel` 模式下的工具权限确认保留在 VS Code 面板 UI（调用 `claude_task_respond` 或 `claude_task_cancel` 均返回 `APPROVAL_REQUIRES_UI`，不篡改运行态或强杀用户面板）；`managed` 模式面向无人值守子进程，默认启用 `--permission-mode bypassPermissions` 自动放行工具调用。

禁止递归委托同一个服务：`managed` 模式通过注入 `VERDANTFLARE_AGENT_CLAUDE_DEPTH=1` 环境变量硬拦截；`panel` 模式因复用已启动的面板进程，通过防递归提示词前缀与工作区写租约双重拦截。不在忙碌会话上强行注入消息。

## 2. 参数与幂等

提示词非空且 UTF-8 不超过 64 KiB；任务超时为 30～86400 秒，默认 3600 秒。未知字段直接拒绝。

同一 `request_id` 与相同参数幂等返回原任务；相同 `request_id` 不同内容报 `REQUEST_CONFLICT`。续接和取消绑定 `expected_turn_id`，过期轮次报 `STALE_TURN`。

## 3. 工作区与存储

工作目录须为有效绝对路径（配置 `allowed_roots` 为 `["*"]` 或 `[]` 时支持任意绝对工作区路径；配置具体路径列表时限定在允许根内），按真实路径校验父子目录写任务互斥与同一 `session_id` 租约互斥。

任务、命令队列、轮次、事件和租约保存在用户数据目录 SQLite 中，技能目录只保存静态指导与启动器。

## 4. 兼容与维护

本规则基于 VS Code `anthropic.claude-code` `2.1.322` Named Pipe（`uds-messaging`）与 `.claude/projects/` 轨迹实测。扩展升级后须重新运行探测脚本校验管道握手与事件字段。

技能源码在仓库 `skills/verdantflare-agent-claude/` 唯一维护，安装副本更新通过安装脚本同步。公开文档严禁写入本机绝对路径、用户名或 `peerToken`。
