# Claude Code 本机 MCP 服务启动与全局安装（02.install）

## 1. 输入与输出

- **输入**：维护源目录 `skills/verdantflare-agent-claude/`、本机 Python 环境、已安装的 VS Code `anthropic.claude-code` 扩展及内置 `claude.exe`。
- **输出**：同步到 `~/.agents/skills/verdantflare-agent-claude/` 的全局安装副本、独立虚拟环境运行时、用户数据目录下的 `verdantflare-agent-claude/service.json` 与对端智能体 MCP 注册配置。
- **技能入口**：[SKILL.md](../SKILL.md)。

## 2. 分类

| 操作分支     | 适用场景与核心动作                                                                 |
| :----------- | :--------------------------------------------------------------------------------- |
| 安装并注册   | 同步技能至 `~/.agents/skills/`、构建独立虚拟环境并向对端智能体注册 MCP             |
| 仅同步技能   | 仅更新全局技能副本与运行时，不改动对端 MCP 注册文件                                |
| 服务探测启动 | 通过 [launch.py](../scripts/launch.py) 探测能力（`claude_capabilities`）或启动服务 |

## 3. 工作流

1. **同步技能与注册 MCP**：在技能目录运行 [install.py](../scripts/install.py)：
   - 完整安装并注册 MCP：`python -X utf8 scripts/install.py --replace --register-mcp`
   - 仅同步全局技能与运行时：`python -X utf8 scripts/install.py --replace`
2. **验证服务配置与启动探测**：服务配置入口由 `VERDANTFLARE_AGENT_CLAUDE_SERVICE` 指定，默认读取用户数据目录的 `verdantflare-agent-claude/service.json`。执行以下探测与启动命令：

```powershell
python -X utf8 scripts/launch.py --call claude_capabilities
python -X utf8 scripts/launch.py
```

3. **扩展升级后复检**：运行时自动探测本机最新已安装的 VS Code 扩展 `anthropic.claude-code` 及内置 `claude.exe`；扩展升级后须重新运行探测脚本校验 Named Pipe（`uds-messaging`）握手与 `.claude/projects/` 事件字段。命名管道握手或二进制不可达时返回明确错误，不盲目试写。

## 4. 规范

- **环境与安全边界**：不硬编码锁定扩展版本号；服务为本机 `stdio`，不提供公网监听。认证由 Claude Code 本机配置管理，技能文件不保存密钥或 `peerToken`，也不把账号凭据写入任务参数。
- **兼容基线与唯一维护源**：当前规则基于 VS Code `anthropic.claude-code` `2.1.322` Named Pipe（`uds-messaging`）与 `.claude/projects/` 轨迹实测。技能源码在仓库 `skills/verdantflare-agent-claude/` 唯一维护，安装副本更新通过安装脚本同步；公开文档严禁写入本机绝对路径、用户名或 `peerToken`。

## 5. 验收

- **静态检查**：在仓库内与不含兄弟技能的临时隔离目录运行 `lint_skill.py --style numbered`，并对全部 `.md` 运行 `md_format.py --check` 与 `check_md.py`，均为 0 errors。
- **单测与哈希比对**：使用运行时虚拟环境 Python 执行 `-m unittest discover -s scripts -p "test_*.py"` 全部通过，且维护源与 `~/.agents/skills/verdantflare-agent-claude/` 安装文件全量 SHA-256 哈希一致。
- **协议与接入验证**：标准 MCP 客户端能够初始化、列出八项工具、调用 `claude_capabilities`；非法字段、超限提示词和错误编号返回结构化错误码。技能可见、MCP 已注册、真实工具可调用和人工确认分别报告。
