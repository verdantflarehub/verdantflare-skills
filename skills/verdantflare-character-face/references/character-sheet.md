# 角色设定页规范

## 1. 当前依据

- [技能入口](../SKILL.md)：锁脸与多角度参考的总流程。
- [中文提示词](prompts.md)：身份参考与目标帧的提示词组织。
- [交付和恢复](delivery.md)：编号、来源映射与展示范围。

## 2. 适用范围

用于为影视复刻、反串出演或新角色制作“角色设定页”，即审定服装与造型的母版，供后续关键帧和视频生成引用。锁脸多角度面部参考库仍按技能入口流程制作，二者分开交付。

## 3. 版式（硬性）

每个角色一张设定页，由两部分组成：

1. **半身照**：胸部以上正面，负责锁定面孔身份；含发型、头饰、帽冠与领口，面孔沿已审定的定妆母版。
2. **无头三视图**：正面、90 度侧面、背面全身服装，脖颈以上不画头；只用于审服装款式、颜色、纹样、长度与配件。

禁止交付带脸的全身三视图作为设定页：侧面与背面带脸最容易让面孔漂移，并分散对服装的核对。三部分统一中性灰背景、均匀光线、同一比例尺；设定页旁附原片或设计来源的服装参考裁图。

## 4. 服装还原核对

复刻已有影视角色时，服装以原片为准，演员只换面孔。生成前从原片截图列出服装清单：每件的款式（有袖／无袖、开襟／交领、长度）、颜色、纹样走向（横条／竖条）、配件、鞋与腿部；每项注明来源时间码。生成后逐项对照，任一项不符即退回，不以“配色接近”代替款式核对。原片看不到的部分（常见为背面）标“推断”，不得写成原片证据。

## 5. 交付与审定

设定页标注角色、演员、面孔母版编号、版本与“待审定”状态，原片参考裁图与设定页并排。审定通过后作为该角色服装母版，后续关键帧、H3 与视频人物镜头一律引用；审定前不出场景关键帧。被退回或格式不符的版本保留为过程稿，不得自动选用。
