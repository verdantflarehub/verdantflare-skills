# 中文提示词与输入角色

## 1. 正脸参考纠正

实际提交两张输入，明确哪张是待编辑帧、哪张是身份参考。按本轮缺陷删改下文，不把所有修复叠加到每张图。

> 编辑图1；图2仅用于人物身份校准。保持图1的身体朝向、头部角度、视线、镜头高度、景别、发型、服装、背景和构图。依据图2恢复同一个人的五官比例与脸部体积，纠正视频带来的脸部膨胀和肤质退化，保留自然细腻的皮肤纹理，清晰但不过度锐化、不蜡化、不新增皱纹。表情遵循本轮要求，不改变人物身份。

纯提示词对照只提交图1，将身份参考句删除，改为“保持图1的人物身份和五官比例”；确认没有复用含正脸附件的会话。

## 2. 局部去笑

适用于用户明确要求“不笑”的图；目标图加正脸参考，不批量重做合格图。

> 将目标图人物表情改为自然中性、不笑。嘴唇自然闭合，嘴角放松、不上扬，脸颊放松，眼睛自然睁开，不做微笑或眯眼表情。正脸参考仅用于保持身份与五官比例。严格保持目标图的脸型、肤质、头肩姿态、视线、机位、发型、服装、背景和构图。只修改表情，不改变其他内容。

这是编辑约束，结果仍须核验，不能声称模型保证其他像素不变。

## 3. 视频分镜写法

每镜写时间段、初始姿态、身体运动、头部运动、视线、机位、表情和切换方式。高低机位写水平距离与相对眼睛水平线的夹角，不能只写“抬头／低头”。以人物自身左右为例，镜头固定，用户已要求不回正时可写：

> 0—3秒：人物从正面向自身左侧转身至约90度，头肩自然协调，保持中性不笑，结束直接切镜。3—6秒：从正面向自身右侧转身至约90度，结束直接切镜。6—8秒：从正面仰头约20度，结束直接切镜。8—10秒：从正面低头约20度。每镜独立开始，不插入回正过程；全程不微笑、不露齿，镜头保持平视。

该示例不覆盖高低机位或回头矩阵，不自动授权10秒生成。回头需分别写身体背向镜头、肩膀转动、头部回望与最终侧身；左右和三种机位各有明确段落，按渠道允许时长分配。先满足覆盖再核对总时长，不能漏掉平视来凑时长。

## 4. 从正脸进入低机位回头

只有正脸身份参考、背身起步丢失身份或低机位不明显时，可采用已实践的连续路径：正脸建立身份→镜头绕至背后→相机降低→人物转肩回望→侧身。按实际模型时长分配动作窗口，分别生成左右方向更易核对；仍需按成片确认，不能保证方向或首帧与指令一致。

中文动作骨架：先清楚展示正面身份，保持当前表情；人物暂不转身，相机连续绕到背后，再降低至本轮指定的眼睛水平线下方机位，并朝向人物眼睛。相机稳定后，人物从指定肩侧回头，肩膀自然配合，依次保留准备回头、回望、侧身的清晰取帧窗口。镜头留足头顶与肩部空间，避免裁头；不要用人物仰头或弯腰代替镜头降低。

目标15°与30°分别输入，保持其他条件可比；不将具体角度或本案例“不笑”强制套到其他任务。只有当来源帧机位可用时才进行保机位的正脸纠正，不能指望纠正提示词把平视原帧自动变成正确仰视。
