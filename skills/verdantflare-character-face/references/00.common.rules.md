# 角色锁脸与多角度参考：跨能力公共规则与取证审计

## 1. 输入确认、坐标与锁脸红线

- **先取证再分流**：先读取用户当前要求、原始正脸、已有视频／原帧／修复图、任务 ID 及目标项目修订，优先复用合格素材。区分仅设计提示词、抽帧、生成、返修和入库，只执行当前授权阶段，已有授权不重复询问。新建、补角度、局部修复与仅入库分别处理，不每次重跑整链。
- **坐标与机位定义**：列清身体朝向、头部朝向、视线、表情、平视／俯视／仰视及缺失角度。左右沿用已定义坐标，缺少且影响生成时先澄清。**相机高低不等于人物抬头低头，侧身不等于回头，镜像不等于另一侧参考**；文件名与提示词不能证明实际左右或仰俯机位，不把头姿估计器输出当相机俯仰角。角度未经测量只能标为目标或视觉估计，`target_angle` 不能写入实测字段。
- **身份基准保护**：增强或延展正脸须与原始身份核对，不能让漂移图替代基准。角色年龄、体型、表情和图数取当前任务，不把案例参数写成默认基线；新要求覆盖旧要求但保留历史记录。两张笑脸通常只修两张，不重置全库。
- **生产调用与幂等**：默认图像路线沿 `verdantflare-image` 的 GPT Image 设置；视频按用户选择、实际能力与预检执行，不硬编码 H3 时长或参考上限。生成前记录实际中文提示词、输入素材角色与批次范围；实时 Schema、渠道能力与预检优先，不可提交即停并留原因；提交结果未知时恢复原任务／幂等身份，禁止重复生成；生成后按生产技能完成内容分级与结果核验。
- **三图实验对照规范**：需要实验对照时，图 1 为原帧，图 2 为原帧＋正脸＋提示词，图 3 为仅原帧＋提示词（隔离正脸输入及隐藏会话参考，不能误称为无图生成）；模型参数尽量一致并记录差异。

## 2. 可复现测量（`audit_images.py`）与技术验收条件

创建 UTF-8 JSON 清单：`images` 为非空数组，每项含唯一 `id`、相对该 JSON 的 `path`、已知来源 `sha256` 及可选 `expected_dimensions`（宽、高）；可选 `expected_ids` 列出本轮应有编号。路径为本地输入，不提交凭据：

```json
{"expected_ids":["A01"],"images":[{"id":"A01","path":"images/A01.png"}]}
```

```text
python -X utf8 scripts/audit_images.py /path/to/manifest.json --output /path/to/audit.json
```

报告仅输出编号、尺寸、摘要和错误代码，不输出输入绝对路径。退出码 `0` 表示清单技术检查通过，`1` 表示有失败，`2` 表示清单或依赖不可用。未提供期望摘要时只记录实测摘要，不能声称来源一致；Pillow 缺失时使用当前环境依赖管理方式安装，不更换已有文件。

技术验收采用确定的逐项通过条件，不制造综合美学分数：

- **可读取与完整解码**：失败文件数为 `0`；坏图或缺图不计成果。
- **来源一致**：提供期望哈希的每项摘要完全相等，不符项不得入库；尺寸按实际解码值记录，提供期望尺寸时必须相等，提示词中的“高清”或“4K”不作输出规格。
- **覆盖**：完成数／当前目标数，目标编号缺失数、额外编号数及重复编号数均为 `0` 才叫齐套；数量齐全不证明姿态正确。
- **归档**：领域引用悬空数为 `0`；指定修订的文件回读哈希与本地一致；与任务无关的字段、引用变化数为 `0`，授权修改单独列明。
- **批准**：入库图片必须落在当前真实授权范围内；批准覆盖数等于本次入库数，不能把旧单图批准扩展到新批次。

## 3. 视觉规则、测量边界与停止条件

- **全图与局部放大对照**：对每张候选看全图并打开脸部局部放大，与原始身份基准及原帧对照。仅背影或脸部遮挡时身份可见性记为不足，不能因文件有正脸参考就宣称锁脸通过。
- **逐项视觉核查**：身份看眼型、眉形、鼻翼、嘴形、脸部体积是否相对原型漂移；皮肤看新增皱纹、颗粒、锐化和蜡化；表情看嘴角、嘴唇、脸颊与眼周；姿态看头肩关系、左右与动作阶段；机位看全图透视及视频运动。逐项填写“观察符合／观察不符／证据不足”，附原帧、纠正图与局部对照。
- **无未验证数值阈值**：上述视觉规则尚无跨人物验证的数值阈值，不宣称量化评分、百分制或自动放行；不能直接比较正脸与侧脸像素宽度判胖。需新增指标时先固定测量方法、适用姿态、人工通过与失败样本，验证阈值和误判后再采用。
- **经验升级与停止条件**：先分类与设计工作流，再用真实变更考题验证，考过后沉淀；失败保留原因与输入，不为写技能重跑付费任务。静态走查、脚本实跑、用户审阅及线上验证分别标注。同类失败先核对输入和实际视频，不无上限重复提示词；沿用户批准批次和生产技能重试边界执行，技术完成、允许展示和 World 发布授权不得互相替代。
