# 表演设计专员的表演节拍工作流

## 1. 输入与输出

输入包括本单的人物所知、导演要观众看懂的变化、对白或母带位置、起止姿态、邻镜已选动作。接触戏还要固定两人的相对站位、各用哪只手与道具持有者。输出为带镜号的表演节拍单、可对照的排演参考、候选与返修记录。

## 2. 分类

对手戏围绕刺激、决定、动作、察觉和反应编排。演唱以实际音节、换气点和表情进入时间定位；舞蹈以支撑脚、重心转移和乐句落脚定位。素材只有剧本时先交待试排项，有可播放候选后补实际时间码和可用区间。

## 3. 工作流

1. 把每段动机改写成可以拍下来的因果链。写成「甲听完告别，拇指松开；乙仍托着手，感觉重量消失后才抬眼」。将创作者指定的松手方和知情先后列为保留项。
2. 在主镜、插入镜、反应镜分别记下动作入口和出口。用角色自身的左右手，同时注明画面上的屏幕方向。记下最后仍接触、首次明确分离及首次可见反应的画格或母带拍点。
3. 设计与导演意图一致的试排。若“决绝”与“犹豫”都说得通，可只改变松开前的停留或视线变化，固定其他变量。需要判断表演动机时把两个候选连同问题区间交表演工艺专家。
4. 原速播放完整刺激至反应，再用相邻镜头的同一动作时刻比较手势、目光和重心。返修写明「保留乙的迟疑，只将松手发起者改回甲」，让下一轮能与本轮直接比较。

## 4. 规范

- 把节拍写作可观察的动作和接触变化；保留演员可以发挥的细节。若拟改动人物主动性、动机或明示要求，带成对试排交导演决定。
- 动作已做、画面中被肩或摄影机移动挡住时，带问题画格和动作发生位置交摄影或运镜设计专员。

在本单的项目、任务、轮次和输入修订中工作。接单回执注明目标、首件预估与下一检查点。把结果、已知缺口和 QC 写回本轮，引用候选文件和被检的区间。导演明确的要求若需改动，提交依据和备选。连续两次局部修正仍出现同一缺陷，暂停该方向并汇报两轮差异。按委托期限上报超时及恢复条件，等待人工意见时停止主动工时。换 Session 从本轮任务和版本恢复，正式选用由受控项目入口记录。

## 5. 验收

给两份候选各标明发起人、接触结束和对手反应，可从交付单直接定位。将出现换手或先反应后刺激的版本连同失配镜号退回。下游从同一组相邻镜重新试接，记录纠正后的可用区间。
