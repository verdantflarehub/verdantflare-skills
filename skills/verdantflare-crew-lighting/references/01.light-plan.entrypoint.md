# 光影设计专员的光位设计工作流

## 1. 输入与输出

领取镜号、场景时间、实景光源和固定机位，读取演员路线、肤色与服装参考、必须读出的主体及刻意保留的阴影。交付俯视光位图、按机位成对的预览、问题画格和光线变化时点。

## 2. 分类

自然光或场景灯具形成方向性时，先锁定空间中的发光点；舞台亮灯按母带位置或表演动作定义。静帧只支持检查该姿态，在移动或亮灯跨剪点时应按实际顺序试放。

## 3. 工作流

1. 标出主光、补光、遮光物和反射面相对演员及机位的位置，记录哪一侧脸或手指朝向光源。标出观众应先发现的区域和导演要求首拍以前保持不可辨认的部分。
2. 在同一输出变换、取景和动作时刻比较基准与候选。针对指尖陷入暗部，可固定演员试局部补光，再固定光源试移动手的落点。保留两次预览，分别检查手与背景的分离、眼神和脸部阴影。
3. 用同一物理灯位切换到反打。检查鼻影、脸颊受光、衣袖反射和背景亮区；动作变清楚但反打像换了时间或提早暴露主唱时，记录副作用，缩小补光范围或提出选择。
4. 记录灯光变化的触发点、可读首帧与持续时段，和分镜、运镜岗位连看。亮暗失效只在相机移动途中出现时，共享轨迹和问题画格复核光位。技术取舍无法确认时，附成对参考咨询光影工艺专家。

## 4. 规范

- 优先保留导演指定的阴影和揭示时点。样张曝光、显示变换或构图不一致时先对齐比较条件。
- 对光照预演、真实生成结果和正式选用分别标记，样张只说明该机位和时刻的可见性。

在本单的项目、任务、轮次和输入修订中工作。接单回执注明目标、首件预估与下一检查点。把结果、已知缺口和 QC 写回本轮，引用候选文件和被检的区间。导演明确的要求若需改动，提交依据和备选。连续两次局部修正仍出现同一缺陷，暂停该方向并汇报两轮差异。按委托期限上报超时及恢复条件，等待人工意见时停止主动工时。换 Session 从本轮任务和版本恢复，正式选用由受控项目入口记录。

## 5. 验收

复验者能在主镜看清目标动作并在反打辨认同一光源方向。提交受影响区域、正常与修正版、各预览适用的机位与时刻。改后脸部提前可辨认时标为需再修或导演决定。
