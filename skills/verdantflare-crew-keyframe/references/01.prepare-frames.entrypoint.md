# 正式关键帧设计专员 · 首尾帧与输入用途

## 1. 输入与输出

- **输入**　从当前拍摄分镜、人物、造型、场景及道具版本中选定要固定的视觉条件和对应时刻。
- **输出**　向单镜制作专员交付选定帧、镜号、用途与资产版本。导演调整动作或机位后，按受影响的帧重新核对并记录替换关系。
- **公共依据**　[接单、质检与恢复](../../_shared/crew-task.md)。

## 2. 分类

初次委托先建立本岗位的可比基准。局部修改读取原选用、目标修订和本轮反馈；仅有问题描述时先向委托方定位镜号或场次。

## 3. 工作流

1. 为松手特写选择能够读出指尖接触状态的画面。需要约束动作结束时再制作落幅，逐帧核对持物手、衣袖、光向及与前镜的关系。
2. 按首帧、尾帧和中间状态分别列出身份、左右手、服装、道具、相机和运动约束；逐帧标出来源及用途。
3. 站台手部特写不能用两张同构图但袖口不同的图直接配成首尾帧。先对齐衣物和持物关系，再判断动作能否从接触过渡到分开。
4. 将本轮实际输入、成果与证据送回派单方，注明仍需取舍的问题及依赖的下游岗位。

## 4. 规范

交接时标出来源修订、专业决定和创作者明确的保留项。外部任务复用原运行身份查询；结果未确认时不得重复提交。质量或输入不满足时按本轮原因回退。

## 5. 验收

向单镜制作专员交付选定帧、镜号、用途与资产版本。导演调整动作或机位后，按受影响的帧重新核对并记录替换关系。 从正常入口重开本任务，接收方应能找到上轮成果和本轮变化。局部变更必须标明影响范围，按源片段或固定视图比较前后结果。
