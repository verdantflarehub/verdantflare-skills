# 短剧剧本审核标准与记录模板

适用于故事梗概、分集大纲、逐场剧本和人物小传进入导演拆解前的创作审核。它给审核者一套可重复的证据与交接要求，不把某个平台的推荐算法或“前 3 秒公式”当成普遍事实。目标平台、受众、长度、题材和发行用途未定时，记录为待决，不虚构市场验证。

## 审核输入与证据边界

至少记录剧本文件/项目修订、人物小传版本、分集规格、原著或原创来源、已批准下游资产和既有审核决定。若有目标平台/受众、竞品与试播数据，写明样本和日期；没有时仅能评价文本的注意力设计，不能宣称留存、转化或商业达标。媒体验片、观众测试、版权审校和模型能力验证另有各自结论。

审核者先区分三类内容：

- **可核事实**：镜号、时长总和、人物与道具出现/转手、对白和字幕、来源异文、已存在的 Artifact/任务状态。用文件、镜号、版本或哈希作证。
- **编辑判断**：人物动机是否可信、反转是否铺垫、情绪是否成立、冲突是否可见。说明文本证据与可能的观众误解，不用分数代替理由。
- **待验证假设**：实际表演、配音语速、竖屏可读性、前段留存、完播和续看。安排朗读、字卡、animatic 或真实粗剪验证，并记录结果；不能把脚本估计写成测试通过。

## 检查维度

| 维度 | 审核问题 | 通过时应能指出的证据 |
| --- | --- | --- |
| 来源与改编 | 原著事实、异文、原创增写及权利边界是否分清？关键字词是否经可靠版本核对？ | 来源记录、异文选择、需复核的具体画面或台词；不把新增结局说成原著 |
| 完整剧本包与设计基础 | 正文、人物小传、地点/场次、道具、Look、逐镜连续性是否齐全且有实质内容？版本、唯一 ID、状态转移与正文是否一致？ | 包索引及固定文件版本；逐镜全集覆盖；原件/复制件、角色身份/Look、地点/场次分开，缺项已返修或有明确范围说明 |
| 剧本形态与可表演性 | 交付的是分集大纲、逐镜提纲，还是可供表演和导演拆解的剧本？每场是否有内/外景、地点、时间、人物站位与动作、明确说话者及台词/有意沉默？ | 场次标题与连续镜号；能按文本复现人物进入、相对位置、说话对象、行动和离场，不用泛化场景描述冒充完整剧本 |
| 故事承诺 | 开场实际给了谁的处境、目标和危险？每集尾的问题下一集是否兑现？高潮是否回报前文承诺？ | 可定位的画面/台词及其后续回收镜号；不以无关噱头硬留悬念 |
| 分集推进 | 每集是否有新信息、行动或代价，是否重复前集解释？静态说明能否由动作、旁白或短字幕承接？ | 每集进入状态、行动、改变、离开状态；删除说明不会破坏因果 |
| 人物 | 人物行为是否由身份、能力、关系和代价推动？人物小传与最新剧本是否一致？主角是否作出关键选择？ | 人物小传固定版本、动机与选择所在镜号；配角不代替主角完成核心行动 |
| 因果与证据 | 线索从哪里来、谁持有、何时交给谁；反派为何出现、官府或其他外力为何到场；结局能否由已展示事实推出？ | 关键物件/消息的交接链与前置线索；关键结果不能只靠事后字幕补一条不存在的证据 |
| 时间与空间 | 闪回、时间跳跃、人员移动、场景入口/出口和相邻集承接是否清楚？ | 时间标记、地点与同场物件/人物状态；跨集剪接能辨认先后 |
| 对白与声画 | 标注秒数是否足以容纳说话、停顿、反应和动作？字幕是否可在目标画幅读完？画外音是否补充而非复述已见画面？ | 朗读/粗剪时码或待测标记；关键文字后期合成方案与安全区 |
| 氛围与音乐 | 每场的环境、声效、音乐或明确无音乐是否有叙事功能？Cue 何时进出、对白时如何避让，是否把拟制作音乐误称现成获批资产？ | 分场氛围、环境声/音效、音乐 Cue 编号及进出/停顿；Cue 表写情绪、配器、节奏与版本状态，实际音频留待制作与授权审核 |
| AI 制作 | 身份/Look/道具能否固定引用，动作是否可拆成可生成的单元，复用画面是否改变镜号或口型，候选是否被误写为获批？ | 版本引用、镜头/生成单元区分、需人工合成的文字与难镜返修入口 |
| 发行适配 | 目标受众和平台明确后，长度、信息密度、合规标识及作品定位是否适配？ | 真实简报与粗剪/试播数据；无数据时只写待验证，不给“市场达标”结论 |

“前 3 秒、15 秒、集尾”可作为逐集观看检查点，含义是观察观众在这些位置能否识别风险、目标或新问题，不是所有作品统一的秒数门槛。悬疑、历史和人物题材可以用不同节奏；只要承诺明确并持续兑现，不要求机械地每隔固定秒数反转。精确镜头秒数的加总只证明预算自洽，不证明配音或表演可执行。

## 严重度与阶段决定

| 级别 | 判定 | 处理 |
| --- | --- | --- |
| P0 / 阻断 | 核心结局无因果支撑、关键角色/证物前后矛盾、关键来源误引或不能被当前产物形态表达；继续制作会使主线或不可逆投入失效 | 锁稿和受影响导演/生成任务前必须返修并复审；不依赖该段的整理可继续 |
| P1 / 必修 | 重要铺垫、角色动机、跨集交接、资产版本或时长/可读性存在可定位缺口，影响目标观众理解或后续制作 | 在受影响镜头锁定前返修；允许无依赖场景或资料工作继续，结论保持有条件 |
| P2 / 建议 | 风格、句式、镜头经济性或可在粗剪验证的偏好，不破坏当前因果 | 记录备选方案、验证方式与责任阶段；不凭 P2 一项阻断独立工作 |

机器检查只验证格式与可数事实；Agent 的“建议通过”不是人工批准。批准必须绑定具体剧本/人物小传版本、审核范围、审核人和日期。返修不覆盖旧版；旧版下游镜头、配音、字幕或资产若受影响，列出失效引用并按需重做，不把所有历史成果一律撤销。

若交付目标是**可拍剧本**，缺少关键场次的台词、说话对象、空间站位或昼夜地点而无法表演与拆解，按 P1 记录；只有明确以“分集大纲/逐镜提纲”为交付目标时才可接受摘要式场景描述。音乐写入剧本的是声音意图和 Cue 需求，不等于已经创作、授权或通过混录。没有音乐的镜头也应明确留白及由何种现场声承担节奏。

## 执行与复审

1. **建基线**：固定输入版本、项目修订和审核范围；查看相关来源、人物小传、连续性表及已做资产，不自动把历史候选标为批准。
2. **做两遍检查**：第一遍核对数字、镜号、角色/物件/消息与来源；第二遍按观众顺序读每集，不查设定能否看懂目标、危险、转折与回收。
3. **记录发现**：每条写严重度、精确位置、观察到的事实、影响、最小返修建议、责任阶段与受影响下游。多条症状同源时合并为一条问题。
4. **决定范围**：P0/P1 未解时标“建议返修”或“有条件推进无依赖部分”；无阻断才可建议人工创作审核。未作粗剪时，不把商业留存标为通过。
5. **复审改稿**：对照旧版逐条核销，重算结构和时长，核实人物小传、镜头计划与媒体引用。真正的朗读、字卡和粗剪结果单独记录，不能由文本推测代替。

## 审核记录最小模板

```markdown
# <作品> 剧本 <版本> 审核

- 审核对象：<文件/Studio 项目修订/哈希>；关联人物小传：<版本>
- 范围与限制：<读过的来源/资产；未执行的朗读、粗剪、观众测试>
- 建议结论：可进入下一阶段 / 有条件推进无依赖部分 / 返修后复审
- 人工决定：待审核 / 已批准 / 需修改 / 已否决（决定人、日期、版本）

## 发现（按严重度）
| ID | 级别 | 位置 | 证据与影响 | 最小返修及受影响下游 | 状态 |

## 分集检查
| 集 | 开场承诺 | 关键行动/变化 | 集尾兑现与下一集承接 | 待验证项 |

## 版本与交接
- 镜号/场次/时空/站位/台词/声音 Cue 与时长等确定性检查：<方法和结果>
- 人物/道具/证据的交接：<固定版本和状态>
- 朗读、字卡、粗剪、试播：<实际结果或未执行>
- 返修后复审：<逐项核销记录、受影响资产/任务>
```
