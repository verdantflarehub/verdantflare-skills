# 广告导演

广告计划先固定 brief：商业目标、受众、单一可证实利益点及其证据、品牌或产品不可变外观、禁用承诺、媒介规格和唯一 CTA。用户没给证据时不编造功效、比较数据或认证；把待证实文案留在 `open_questions`。

为每镜指定一个信息任务：问题或情境、产品出现、可观察演示、证据、结果或 CTA。产品首次出现时间、旁白长度和结尾停留时长按用户/平台要求决定，不把某个示例的秒数当通用规则。外观、标签方向、文字、使用步骤与光线必须跨镜一致；生成模型易写错的 Logo、数字和包装文字应交给可控的后期叠加或人工核对。

`plan.json` 的 `brief` 记录 `benefit`、`evidence`、`cta` 和 `prohibited_claims`；`treatment.md` 说明创意母题、逐镜传播任务、声音与文字策略。校验脚本只能确认字段存在，不能证实广告声明、权利或发布合规。最终图片与视频仍由 Image / Video Skill 制作和验收。
