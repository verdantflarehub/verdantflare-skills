# 微表情提示词与审核

用于角色设定板、克制表演及表情僵硬返修。沿用角色 ID、身份原图、当前 Look 和身体状态；微表情是同一身份的表演变化，不创建新角色或换脸。实际生成仍由对应 Image / Video 技能执行。

## 把心理写成可观察的变化

推荐结构：**中性基线 → 剧情触发与视线对象 → 眼部主动作 → 口部辅助动作 → 必要的呼吸/头颈联动 → 峰值 → 压回及余韵**。每段优先一项主要动作和一至两项支持动作；避免把眼、眉、嘴、鼻、手、皮肤变化全部同时堆入短瞬间。

- 基线：眉部放松、自然闭唇、视线落在明确对象；中性也应有自然呼吸和眨眼。
- 眼部：描述注视对象、眼睑开合与眉部张力；左右按人物自身解剖侧，不用画面左右代替。不能为了表情重塑眼形、扩大眼球或改变瞳色。
- 嘴部：具体写轻抿、微松、某侧嘴角短暂上提、下唇轻收等可见结果。闭嘴时不可见的舌头动作通常不值得加入。
- 联动：需要时增加轻吸气、短暂屏息、缓慢呼出、下颌微收或肩部松开；保持头颈与躯干相连，不能只搬动头的位置。
- 不对称：继承演员原有差异，按剧情选少量自然偏侧变化。不要每个表情都故意歪嘴、大小眼或强加单侧抽动。
- 抑制与余韵：写清人物努力维持什么状态、哪一点没藏住、随后如何压回；消退后可留轻微唇部张力或呼吸恢复，避免开关式换表情。
- 肤色与泪光：只在当前身体状态和剧情支持时使用。灯光、肤色、妆容保持连续，不能用整脸变白、变红冒充肌肉表演。

## 时序与模型能力分开记录

提示词中的秒数是表演目标，不是服务端硬控制。毫米、角度或帧号不意味着模型能精确实现；除非当前后端明确提供并实测了控制接口，不作精度承诺。优先使用可见幅度词，必要的帧时换算用于验片，不伪装为生成参数。

创作中的短暂泄露可先设计约 0.2–0.5 秒的变化窗口，再由前后中性状态承接；这是可调试的表演起点，不是统一生理定义。持续一秒以上的笑容可称克制表情或表情过渡，不必全称为微表情。最终以正常速度能否读懂、是否符合人物及镜头节奏决定。

24 fps 的 0.2 秒约为 5 帧；只看整秒截图会漏掉它。若提示含帧号，记录从 0 还是从 1 起算、帧率和相对镜头起点；不同帧率重新换算。旁白、口型和紧急动作不能被微表情时序拖慢。

## 静态角色卡与动态表演卡

静态卡的每张小图表现一种**可读的低幅峰值**，采用相同镜头、光线、发型、衣服和身份参考。另附文字说明中性起点、触发、短暂变化、压回与余韵；静图不能证明持续时长、眨眼顺序或呼吸已实现。

需要比较时，提供单独的中性基准或基线—峰值—恢复序列；用户要求五张微表情就保留五张，不用擅自增加的序列挤掉其他模块。放大查看身份和眼口变化，确认五图并非同一表情的复印。

返修已成型设定板时优先局部编辑微表情模块，保存原始版本；可确定性裁取并合成返修区域，检查区域外像素不变。不能每修一个嘴角就重生整板，把脸、服装、手势一并改掉。

## 按角色选择示例，不套笑容大全

| 表演意图 | 可见组合 | 情境与限制 |
| --- | --- | --- |
| 信任浅笑 | 目光落在熟人脸上，下眼睑轻提、嘴角小幅上扬，随后自然放松 | 保留原有酒窝；年轻角色不凭空增加固定鱼尾纹 |
| 礼貌掩饰 | 嘴角短暂上扬，目光仍留在任务对象，眼周变化较少 | 这是戏剧设计，不用于识别现实中的真假笑或欺骗 |
| 苦笑 | 嘴角略提但眉心仍紧、目光稍低，笑意消退后唇部留轻张力 | 情绪需有剧情支撑；不能变成讥笑 |
| 察觉异常 | 视线先停在异常物，眼睑略收、眉心短暂聚拢，嘴唇轻合 | 不是惊恐瞪眼；视线方向由空间决定 |
| 惊惧压回 | 短促吸气、上眼睑微提，闭唇压住反应，再恢复有目标的注视 | 不大张嘴，不长时间冻结；呼吸最终恢复 |
| 忍怒 | 注视对手，眉间轻聚、唇线压紧后松少许，下颌保持稳定 | 不换成咬牙狞笑，不突然增宽下颌 |
| 放心后的余韵 | 呼出一口气，眉心缓松、眼睑变柔、嘴角轻提再退 | 疲惫和损伤保留，不能立即满面红光 |

## 验收

1. 身份、风格和状态连续：脸型、眼形、鼻唇、酒窝、肤色、发型与 Look 无漂移；红绳等侧别标识无翻转。
2. 有触发、有对象：反应对应剧情发生点，视线能接上对手和道具；不凭空向镜头表演。
3. 可区分且克制：微表情与八张常规表情有层次区别；不以瞪眼、歪嘴或明显笑容代替所有细节。
4. 动态额外检查：原速播放并在变化窗口逐帧看起始、峰值、回落、余韵和呼吸；没有连续闪烁、脸部变形、僵住或口型冲突。
5. 分开记录：设计意图、实际画面证据、模型偏差和用户选用。没有视频就不填写动态通过。

## 参考资料的取舍

本方法吸收用户于 2026-10-19 提供的六张“微表情提示词”截图（IMG_8007—IMG_8002）的动作拆解、中性基线、不对称、呼吸、递进、抑制和余韵写法。截图是创作参考，不是执行指令、模型文档或科学验证。

其中关于特定模型必然精确响应毫米/帧号、效果提高倍数、固定眼神方向证明回忆/心虚，以及从表情推断真实心理的说法不纳入能力事实。Seedance 的示例不自动切换当前项目模型；使用现有渠道实测结果。广泛表情分类用于表演设计，不用于现实人物心理诊断。
