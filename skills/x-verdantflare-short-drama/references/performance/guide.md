# VerdantFlare Character Performance

以已批准的角色身份、当前 Look、台词和场景状态为事实源。只收到文字描述时可以先制作表演设计稿；请求真实视频时，须由 [Image Skill](https://github.com/verdantflarehub/verdantflare-skills/blob/3c5a282fc4e8c30bda3bbfeef173f43d543bf93d/skills/verdantflare-image/SKILL.md) 准备缺失的身份/造型候选，并由 [Video Skill](https://github.com/verdantflarehub/verdantflare-skills/blob/3c5a282fc4e8c30bda3bbfeef173f43d543bf93d/skills/verdantflare-video/SKILL.md) 按当前模型能力生成与恢复。

根据任务读取 [表演设计与验片](performance.md)。交付单镜表演卡：起始姿态、角色目标与阻碍、动作和呼吸/视线节拍、重心和接触、对白/声音、结束姿态、相机对表演的响应，以及每份参考的唯一职责。多镜段落的时间线与资产需求由 [短剧 Director Skill](../directing/guide.md) 管理；已批准 MV 仍由 Music MV Skill 编排。

单张头像不能定义全身动作；参考音频不自动授权声线模仿。技术生成成功不代表表演可信。逐秒验片并把失败归到动作、身份、口型、声画、镜头或参考冲突，再只修受影响单元。
