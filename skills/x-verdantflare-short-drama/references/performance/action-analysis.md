# 任意复杂动作的判断与拆解

## 1. 判断复杂性，不按动作名称分类

逐镜询问：是否多主体互相驱动；接触目标会移动；手脚有占用或切换；支撑／重心改变；工具须施力才改变物体；遮挡会隐去关键原因；有离地、冲击、液体等阶段；对白触发别人行动；摄影机与演员同时移动；前后镜须保持精确状态。任一项影响理解或连续性，就做事件／状态拆解。普通开门也可能复杂，远景打斗也可能只需一个可读动作。

写具体风险和可观察失败，不打笼统分数。区分创作、空间、输入冲突和能力缺口，不能全部塞入长提示词。

## 2. 状态与事件

先列每人朝向、支撑足／承重面、自由与占用手、接触对象、视线；列物体连接／受力／运动状态。每个事件写：

1. 前置：谁先在哪里、哪只手空闲、目标是否可达。
2. 发起：角色为了什么先动什么，另一人看见／听见什么才反应。
3. 接触与受力：哪侧肢体哪部分接触目标哪个表面，力向哪里，谁主动谁跟随；不用画面左代替角色左。
4. 重心与结果：支撑如何切换，哪部分先被带动，物体状态何时改变。
5. 释放与落态：何时解除接触，手回到什么合理位置，持物、朝向、速度、视线如何交给下一事件。

并发逐项检查：一手不能同时持印又撑窗；听者不能在喊声前惊觉；受击者不能在有效击打前倒下。同段允许多部位动作，但依赖必须成立。时间表达先后和节奏窗，除真实同步点外不强求按小数秒执行。

## 3. 单元与控制选择

保持接近→接触→施力→结果的因果链可见；超出模型承载能力时，在稳定握持、落地、离手等状态分单元，用覆盖镜头保留过程。不可删掉割绳的压入拉切、跳跃的蹬离或游泳的换气。

Blender用于可达性、空间路径、接触区域、相机关键角度和遮挡，不用代理骨骼插值规定人类运动。动作参考与身份／服装分工，避免错误衣层与脸。只有真实支持的姿态、首帧、视频等控制才进入请求；不支持就调整镜头方案，不假装文本能精确控制一切。

先写动作和听者反应，再编译模型格式；禁止矛盾姿态与逐帧指令。不得用全片加速修复缺失受力。适合局部修复时锁定可用区域，时序修复还须验证跨帧稳定。

## 4. 非穷举示例

- 打斗：守势／距离→攻势→接触／闪避→顺势重心变化→恢复。明确一攻一守与目标，假动作不写成命中；反应晚于原因。
- 割绳：绳绷紧→刀刃压入表面→手腕带动有位移的拉切→纤维分离→断端回弹／悬物释放。接触前不能断，刀掠过不算切割；必须看见刃口相对绳运动。
- 跳跃：支撑→屈膝蓄力→蹬离→飞行→落地缓冲。核对高度、落点、占用，不能空中再蹬地。
- 入水：离船→下落→触水→水花与水下轨迹→浮出。水花不能早于接触，船尾与水面距离不跳变。
- 游泳：浮力／姿态→入水抓水→划水推进与腿配合→换气→回臂。持物时选可行泳姿或先收纳，不同时双臂完整划水。

## 5. 迁移与验收

用陌生动作验证：端满杯开门应发现持杯手被占用、门扇扫掠、侧身与液体惯性；双人抬箱转角应发现共同负载、内外侧不同步幅、视线遮挡和窄处通行。必须从新状态推导依赖，不能只是替换示例名称。

请求中核对每个关键事件的输入与描述，产物标实际发生帧及未实现项。关键事件遮挡、消失、逆序或无因结果则失败；返修后重验受影响链，复用未变身份／衣层证据。顺序正确仍不等于力度、自然性和原速节奏通过。
