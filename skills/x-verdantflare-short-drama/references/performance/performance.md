# 角色表演设计与验片

## 表演卡

先确认角色此刻想得到什么、什么阻碍它，以及情绪在镜头中为何变化。把抽象心理转成可见事件：视线先落在哪里、何时呼吸或停顿、手与物体何时接触、身体重心如何移动、结尾停在什么状态。一个短单镜保持一条主要动作链；复杂表演拆 Shot 或 Generation Unit，不堆“自然、强烈、电影感”。

为每个 beat 写可观察的起止与因果。镜头跟随演员，而非无原因地重构机位；屏幕方向、对手站位和视线高度保持可读。镜头时长与台词长度不匹配时，修改表演节奏或切分计划，不擅自删改已批准台词。

## 参考职责与编译

身份卡只锁脸；当前造型全身卡锁衣服、鞋和比例；动作参考负责节奏、受力和镜头路径；音频参考只承担经授权的声音或节拍职责。每份输入在 Video Skill 的 `subject_definitions` 与 `retention_analysis` 中写清保留范围，不把参考图的背景、边框和文字一起复制。

H3 Ref2VA 的正式 Prompt 使用 Video Skill 的六段式结构。对白放在 `detailed_description`，以稳定说话人 ID 和 `<d>[Language] ...</d>` 标记；环境声放 `overall_soundscape`，非场内音乐放 `non_diegetic_music`。当前渠道不支持的首尾帧或音频模式不能靠改写提示词假装支持。

## 动态验片

完整播放并按约一秒间隔检查接触表。核对表演节拍、口型与说话人、视线对象、步态与重心、手和道具的接触、服装物理反应、背景位移和落幅。拒绝用人物放大、静帧溶解、重复摆臂或表情微变冒充走路和情绪转折。只报告可观察证据；模型做不到时缩短单元、改善对应参考或拆镜，保留原任务与候选记录。
