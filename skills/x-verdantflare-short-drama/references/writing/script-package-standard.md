# 完整剧本包规范

本规范定义编剧交付给人物、美术、服装、导演与声音设计的文字基础。适用于短剧及影视剧；不把示例项目的六集、60 镜、450 秒或特定服饰推广成统一规格。

## 交付组成和责任

| 必需文档 | 内容事实源 | 下游用途 |
| --- | --- | --- |
| 剧本正文 | 叙事顺序、发生的动作、独立对白、声音意图、时间与状态变化 | 表演、导演拆解、配音及剪辑 |
| 人物小传 | 身份、身形面貌、背景关系、性格与行动动机、人物弧 | 角色身份设计、表演指导 |
| 地点与场次设定 | 地点空间、固定陈设与特定场次的时间/天气/光线状态 | 环境设计、机位与动线预演 |
| 道具设定 | 单件物品身份、形态、原件数量和状态/持有链 | 道具图、交互表演、证据连续性 |
| 服装 Look 设定 | 同一角色的分阶段衣层、妆发、配饰、旧化和穿脱 | 造型设计及跨镜穿着复现 |
| 逐镜连续性表 | 剧本与以上资产版本的逐镜绑定、入镜到出镜的状态 | 分镜、生成参考选择及剪辑接续 |

另附 `package-index` 与 `script-review`：前者定位六类文档、固定版本与哈希，后者记录发现、返修与验证。创作简报、原著、引用/授权材料可复用现有文件并从索引引用；原创项目写明原创与制作假设。文件存在但内容是空模板，不算交付。

## 通用约定

**维护说明：** 六类文件分别回答“发生什么、是谁、在哪里、用什么、穿什么、怎样接续”。正文负责事件，设定负责固定特征，连续性表负责逐镜选用；修改一个事实时沿这些依赖同步，避免三份文件各自形成不同答案。

**编号示例：** `CH_XE` 表示同一个人物，`LOOK_XE_TRAVEL` 与 `LOOK_XE_COURT` 表示她的两套服装；`LOC_SHOP` 表示同一家商行，`SC_SHOP_DAY` 与 `SC_SHOP_NIGHT` 表示发生在其中的两场戏。ID 示例只解释关系，实际项目沿用原编号；版本改变也不意味着人物或地点换了身份。

- 每份文件声明作品/项目引用、版本、依赖的剧本和资产版本、来源与状态。每项设定区分原文事实、改编创作、制作提案、已审参考；尚未做图写“文字设定/图像未制作”。未出场的主观设定不能冒充已发生剧情。
- 稳定键与版本分开：角色 CH、地点 LOC、场次 SC/S、道具 P/PROP、Look W/LOOK、镜头 SH 均可沿用现有格式。别名指向同一人物；同一地点多场戏不是多个地点；同一物品的持有状态不是新原件。
- 字段无内容时写明确理由，如“无饰品”“无对白”“M0 无配乐”。“待定”应说明影响、当前可工作的假设和负责阶段；能用普通创作判断解决的细节应直接写实，不给下游留一串空格。
- 正文中的事件和状态必须同步到设定与连续性表。固定外观在对应文档定义一次；正文重复描述只为镜头可见信息。修改时输出受影响镜号、旧引用继续有效范围和要返修的资产。

## 1. 剧本正文

作品级：题材/时代/改编边界、梗概、主要关系、集数与时长预算、画幅、声音和可读字处理原则。集级：进入处境、人物目标、冲突与代价、转折、新信息和结尾承接；写实际戏剧行为，不机械追求固定秒数反转。

场次级：稳定场次 ID、地点 ID、内/外景、昼夜/具体时段、故事日期或相对时间、天气、现实/回忆/梦境、在场人物及进出、主要轴线、氛围。跨场蒙太奇和闪前必须注明来源镜头及切回位置。

镜头/编剧动作单元级：稳定 ID、预计时长、场次与地点、角色和 Look 引用、关键道具引用；人物左右/前后位置、可见动作、起落状态；说话者、说话对象、对白/画外/旁白；环境声、音效、音乐 Cue 进出及对白避让；需要合成的字幕/道具字。无对白或无配乐必须明确，不以动作摘要代替完整台词。

音乐 Cue 表列编号、用途、情绪、配器/音色意向、进出点与状态；拟原创描述不等于现成音乐。时长加总只是预算检查，朗读、字卡可读性、动作耗时、口型及市场留存必须真实验证。

## 2. 人物小传

每个具名人物以及重复出场、承担证词/辨认的配角都要有独立条目，不能漏掉主角家人或把关键证人藏在群众统称中。一次性群众可按组写，近景身份应可区分。

每项包含：角色键、本名/别名、年龄或年龄段、性别呈现（剧情相关时）、身份职业、时代/地域与家庭背景、亲属及利益关系、剧情职责；身高/身形比例、体型、肤色、脸形、五官、头发、疤痣等固定识别点；性格、欲望、恐惧、矛盾、技能/限制、说话习惯、行为小动作、弧线与关键选择；各阶段服装/发型/饰物概要并引用 Look；出场范围、禁止混淆对象和现有身份图状态。尺寸可用合理区间，精确数值若属创作设定须注明，不假称考据。

## 3. 地点与场次

地点本体写：稳定键、名称、叙事用途、建筑/地形类型、年代风格、尺度及人物比例、空间布局、入口出口、门窗楼梯、前中后景、固定陈设、材质色彩纹理、磨损、光源和声学环境；与相邻地点的连接关系、可用动线和不能改变的地标。

场次另写：场次键→地点键、故事时间、昼夜/天气、现实或主观空间、光源开关、陈设移动、损坏、人员进出和镜号范围。对门内/门外、窗内/窗外、不同楼层保留同一构件关系；雨棚、石阶、窗洞等关键可通行尺寸给可预演的关系，不让后续镜头凭空穿越。梦境可以改变感受，不自动重建同一地点。

## 4. 道具

每件叙事关键实物独立键：名称/功能、来源/归属、形状轮廓、尺寸或手持比例、材质/颜色/纹样、缺口磨损、数量、正侧/持用方向、字面内容与后期字层、拿取方式/作用、初始持有者、转手/收纳/毁损/归还/留存链、首次和后续镜号、不可变锚点及参考图状态。

道具组可以共享总类，但组内会单独转移或承担独立证据的实物必须有子键：例如原钥匙与复制钥匙、两名人物的刀、原油灯与后带入的提灯、旧账与新账。原件、复制件、印模、梦中影像分别记录；藏在怀中的东西不可无动作瞬移到手中。饰品在道具处管理物品身份，在 Look 中管理穿戴位置，不建立两份相互冲突的定义。

## 5. 服装 Look

每套 Look 绑定一个角色身份、阶段与使用场次；列从内到外的衣层、颜色、款式/领型/袖型/长度、面料与光泽、裁剪轮廓、腰带系结、鞋袜、帽饰、发型发色、妆容与伤势、饰品及左右位置。区分固定造型、可拆外层、随动作出现的变化。

记录干/湿、洁/污、破损、伤愈、摘帽/束发等状态及触发镜头，换装在哪个故事时间完成，跨日是否换洗；同一人不因改名或性别装扮换脸、改身高。衣服细节不能只用“古装”“黑衣”概括，人物小传内写概览并引用本表的精确 Look。

## 6. 逐镜连续性表

覆盖所有正文镜号且一镜一行；多场蒙太奇在同一行列有序子段或拆子行，共用父镜号。列明集/场/镜、故事时间及叙事层、地点+场次版本、在场人物身份+Look/状态、关键道具入镜位置/持有人→动作→出镜位置/持有人、轴线/门窗/灯光变化、承接镜及回忆来源、既有素材版本、待决或检查项。

表的“当前状态”要与本镜正文一致：已被没收的戒指不能还在手上，熄灭的灯不能继续给暖光，逃跑的人不能无切回标记出现在原门口。相邻镜头检查动作中手是否被占用；同一物品不能由两个人同时持有。未入画但仍随身的证物可写“贴身未显”，不要误成新增展示动作。

## 验收与交接

**检查边界说明：** “60 个镜号都能找到引用”只能证明引用覆盖，不能证明第 31 镜的灯在第 35 镜熄灭后没有重新亮起。先做结构检查，再按故事时间核状态链；朗读和动态分镜还要检查动作与台词是否真能装进预算时长。这三种结果分别记录。

1. 六类实质文档与版本索引齐全；全部文件可打开，来源/假设和状态明确。验证包中同名 ID 唯一、引用落到真实条目及固定版本，新增/拆合镜有映射。
2. 正文与连续性镜号全集一致，无漏镜/重复；逐镜包含时空、表演、台词和声音；重算分集及总时长预算，核对字幕与跨时段标记。
3. 人物、道具、衣着、空间、光线状态逐链核对；发现可修复矛盾即返修相关文件后重查，不靠改审核标签完成任务。
4. 按剧本审核标准记录叙事判断与未执行的实测，固定人工决定实际范围。外部缺口只影响依赖部分，不能假称所有审核点通过。
5. 下游获得“文件路径+版本+哈希”的包索引、受影响镜号、图像/Look 的独立状态，以及需要预演的难点；不以文字版本替代图像 AssetVersion 或批准的导演计划。
