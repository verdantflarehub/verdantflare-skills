# AI 短剧阶段同步

## 1. 项目归属

用户要求创作或修改 AI 短剧项目内容时，默认将本阶段成果同步到 Studio。先打开已有项目并固定基线；新项目使用真实返回的 project_id，分类为 ai_short_drama。工作区保存该映射，后续写作、Image、Video、Music 与 Blender 均沿用，不因换技能或机器新建项目。仅讨论、只读审核、用户指定仅本地时不产生远端写入。

## 2. 保存范围与固定版本

明确列出本阶段交付文件，不扫描整个目录替用户选取数据。正文、人物小传、地点与场次、道具、服装 Look、逐镜连续性、场景时间天气与光源开关、灯光方案，以及生成的图片、声音、配乐、白模工程、镜头和交付均按实际产出保存；未制作内容记录缺口，不创建假成果。

所有经 Image、Speech、Music、Video 生成的新媒体产物，在同步到 Studio 项目之前必须先按[生成后内容分级评估步骤](content-rating-step.md)与[18+ 评估规范（rubric v1.0）](content-rating-rubric.md)完成评估并调用对应 `*.rate_content` 提交分级结果。判定为 `nsfw` 的产物**不同步到 Studio 项目（不写入 `project.commit` 及 `project-content`），也不登记到 World**，在阶段记录中只写“已隐藏产物 N 个”，由用户决定是否改写提示词后重新生成。

保留稳定对象 ID，区分同一素材的状态与多次生成版本。每版记录修改原因、来源设定、实际任务与输出引用；引用固定文件、素材及资产版本。保存人物身份与造型分工、场景状态和光照，镜头引用不可随“最新版本”漂移。旧结果不覆盖，失败尝试与返修原因保留为记录，不能冒充有效媒体。

通过当前 Studio tools/list 发现 Project / Artifact 契约。文本可用 project.commit 的小文本写入；媒体先经 Artifact 受控传输获得中央 ContentRef，原生生成服务 ID 不能直接替换中央引用。生成服务已完成 Project 提交时回读该修订，避免重复写入。Blender 的实例 project.save 使用实例入口。

文件、业务关系与索引一起更新；已有 AI 短剧 project-content 领域文档时维护它的固定引用，不能只上传字节却把页面停留在旧版本。只使用当前契约支持的字段；缺少必要能力时保留待同步清单，不虚构 JSON 或工具参数。

对每份素材明确核对所属 `globals.key / kind`、`states.key`、`versions.key` 与 `file_refs`。人物身份图归人物，服装板归 Look，并通过 `input_global_keys` 关联穿戴者；同衣的雨湿、入水、摘帽、污损归各自状态，返修留在对应状态的版本历史。不同实物或不同群体服装不能误并成同一物件的状态。字层归实际载体，保留后期字层用途，不替代载体外观图。

`definition_refs` 定位到该对象或状态的章节；原稿是整表时可建立有来源记录的分项索引，保留原稿。多人审核拼图保留为项目汇总资料，不批量挂到每个人物的身份参考；不得凭文件前缀、上传顺序或数组末项推定归属、制作先后及正式选用。

## 3. 校验与恢复

提交前保存稳定 commit_id、expected_revision_id、原请求和上传 journal，不含凭据。上传响应未知使用原 write_id/upload_id 恢复；提交响应未知先查 project.commit_status。并发冲突重新读取 head，合并本次明确修改后使用新的提交 ID，不覆盖其他人的修订。

提交后回读固定修订，验证文件与业务引用、实际字节数及 SHA-256。只有回读成功才报告“已同步”，并返回项目、修订及未完成项。连接不可用时保留本地成果与待同步清单；恢复时先对账，不能重新生成收费内容掩盖同步失败。

逐项核对本次成果可从对应分类、对象和状态找到，引用的图片与原始文件一致；只有 Manifest 文件记录而没有领域关联时标为“已归档，素材关联待完成”。Project负责经MCP回读页面消费的领域内容与文件引用，这项数据核验不代表实际渲染或交互通过。

若本轮明确包含页面交付，另按任务和环境允许的界面能力检查返回修订的呈现、状态切换、旧候选与修改说明，以及详情返回所属列表和关联来源。当前流程仅允许MCP或没有界面能力时，完成数据核验并将实际页面验收标为未验证，不以消费契约推断、图片数量或HTTP成功替代；也不让这项缺口阻塞已授权的素材归档。没有页面交付要求时不额外增加浏览器检查。

## 4. 审核与入库

同步是项目保存，候选保留实际审核状态。不得自动批准、选用、进入下一创作阶段或发布 World。World 入库仍须明确选定素材状态和固定版本，并保留来源项目及修订；网页或 MCP 操作执行同一契约。用户已批准的旧版本与证据持续有效，修改生成新版本不继承新批准。
