# 执行规则

## 1. 不可丢失的约束

每次请求从固定上游依据派生必要参考，不允许请求方通过删“必需项”解除身份、衣层或道具约束。输入锁定不是视觉批准；代理动画只能用于空间核对。身体左右按角色解剖侧，画面左右另记。

场景、全部镜头及复杂道具按[白模规范](production/blender-whitebox.md)提供可恢复空间依据。单剧沿用指定唯一实例。不能因模型失败改墙体、换船体或新开实例。

新镜头核对身高、脚底／支撑点、视线与通路；持物占用持续到明确交接／收纳。衣料和头颈自然性留给实际审片，不能通过代理“算对”追认。

## 2. 授权与记录

已有批准不重审；暂停与局部限制持续生效。MCP Token即业务调用授权，不另设审批令牌；用户限定次数、仅本地、禁止上传等仍须遵守。缺项只阻断依赖它的提交。

按[Studio同步](studio-sync.md)和用户当前范围归档。生成后依[内容分级](content-rating-step.md)提交对应域分级；nsfw隐藏，不同步Project或World。同步不等于选用，技术成功不等于合格。

## 3. 证据与能力

核对实际回执与冻结请求；本地入口可能被绕开，不能宣传为服务端强制。未看原速／未听原声不得填通过；语义观察说明看见了什么及依据位置，不以“自然、合格”替代。离线测试通过不代表模型已提升确定性。
