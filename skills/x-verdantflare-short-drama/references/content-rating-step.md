# 短剧阶段生成后内容分级评估步骤（K09）

## 1. 当前依据

- [18+ 评估规范（rubric v1.0）](content-rating-rubric.md)：判定类别（S1–S4、V1）、图像/视频/音频/文本判定标准及输出 JSON 格式。
- [AI 短剧阶段同步](studio-sync.md)：短剧阶段成果同步到 Studio 项目的规则与 NSFW 产物阻断边界。

## 2. 适用阶段与步骤位置

本步骤适用于短剧制作、表演、对白交接与广告适配阶段中，调用 Image、Speech、Music、Video MCP 生成新媒体产物的所有操作；纯文本策划、剧本写作、本机拆解、只读查询与 Blender 白模工程不执行 `*.rate_content`。

评估放在“取得生成产物”之后、“阶段交付摘要与 Studio 项目同步”之前：

1. 媒体生成任务完成并取得产物（此时尚未评估）。
2. 按第 3 节准备评估输入，对照 [18+ 评估规范（rubric v1.0）](content-rating-rubric.md) 判定，得到评估 JSON（`rubric_version` 取副本文首的 `"rubric v1.0"`）。
3. 调用对应生产域的 `image.rate_content`、`speech.rate_content`、`music.rate_content` 或 `video.rate_content` 提交结果；`general` 也必须提交以留下“已评估”记录。
4. 按第 4 节处理阶段记录、交付摘要与 Studio 项目同步。

一次生成多个候选时逐个评估、逐个提交；提交超时使用相同内容幂等重试，不得因此重新生成媒体。

## 3. 各媒体评估输入要点

- **图像（角色卡、服装 Look、场景关键帧、分镜格）**：读取图像本身，同时评估正向提示词与标题（反向提示词不作为 `nsfw` 依据）。
- **视频（镜头生成候选、动作参考生成）**：在本机临时目录对下载的视频抽帧，**至少每 2 秒一帧、全片至少 8 帧，另补镜头切换处的关键帧**，结合帧序列、音轨、正向提示词与标题判定；**评估后立即删除本机临时抽帧文件，不上传 Artifact、不入 Git**，并在 `reasons` 中记录抽帧数量。
- **对白与配乐（Speech take、Music 候选/母带）**：读取转写文本（如 Speech `report.json` 的 `asr`）并结合台词、歌词、正向提示词与标题判定；**无转写能力或纯器乐时，依据文本资料判定并在 `reasons` 中注明 `"未转写音频"`**。
- **不确定从严**：无法取得完整输入或无法完成判定时，按规范第 5.1 节**“不确定即标 nsfw”**处理，并在 `reasons` 中写明原因。

## 4. 阶段记录、交付摘要与项目同步约束（H1 已确认）

- **交付摘要脱敏**：判定为 `nsfw` 的产物，交付摘要只写“N 个产物已标记为 NSFW 并隐藏”，**严禁展示预览、链接、`ContentRef` 或提示词全文**；`general` 产物照常交付。
- **不同步到 Studio 项目与 World**：因为 Project 与 World 当前不感知分级，判定为 `nsfw` 的产物**不同步到 Studio 项目（不写入 `project.commit` 及 `project-content` 领域文档），也严禁登记到 World（不调用 `world.register`）**。
- **短剧阶段记录写法**：短剧阶段遇到 `nsfw` 产物时，在阶段记录中只写**“已隐藏产物 N 个”**，由用户决定是否改写提示词或台词后重新生成；若存在误标，提示用户可在 Studio 设置页开启本机“显示 NSFW 内容”开关（24 小时有效）后人工取消 NSFW 标记。
