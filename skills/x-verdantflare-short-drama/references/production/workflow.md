# 影视制作流程

## 1. 剧本拆解

确认交付是短片、场景、预告片还是纪录片段落。提取用户已给定的角色目标、阻碍、转折、场景边界、对白和禁用元素；按可观察的进入状态、动作、离开状态拆场景。完整短剧使用剧本做生产输入时，先读取[审核模块](../review/guide.md)规定的固定版本与审核结论；未解决的 P0/P1 所影响的剧情、镜头和资产保持草案状态。纪录片不能编造被摄者行为或采访事实，预告片遵守用户指定的剧透边界。

原始剧本事实密集时，可先逐场使用 `x-verdantflare-short-drama` 的本机模型提取原文锚定候选；人工核对拒收项、推断和语义分类后，再使用 `x-verdantflare-short-drama` 编写 `treatment.md` 和 `plan.json`，并运行其校验器。Shot 时间线连续覆盖目标段落；每镜有叙事目的、主要动作、起落状态、相机与声音。Generation Unit 是模型调用提案，与 Shot 分开；同一角色造型、地点和连续时间才考虑组合，模型上限以当前 Video Skill 为准。

## 2. 资产与生成

先核对已批准的身份、当前 Look、场景和道具 Artifact。需要跨镜复用时，按[数字资产圣经模板](asset-bible-template.md)分别建立地点及场次变体、道具与状态链、服装 Look、逐镜引用；文字设定与已审图像的状态分开记录。没有资产时列需求并通过 Image Skill 制作候选；候选通过项目审核后再作为 Video Skill 的引用。逐张注明身份、造型、空间、动作的职责，不把一张头肩图当成全身动作参考。

正式镜头生成前，按[白模规范](blender-whitebox.md)完成场景、复杂道具和每镜机位／调度白模，并固定工程与预览引用。人物身份图可以先行，空间依赖缺失只阻塞受影响镜头。

场景照片、正反方向、人物站位和动作表情关键帧按[场景—关键帧—视频规范](scene-keyframe-video.md)逐层确定。白模提供空间约束，正式照片补齐货物陈设与剧情光线；多图参考不等于硬首尾帧控制。

将已冻结的 Generation Unit 交给 Video Skill 编译目标模型 Prompt，预检真实 `project_id`、route、时长、参考 Artifact、预算和幂等键。用户只要前期方案时到此为止；请求成片时沿 Video Skill 提交、查询、恢复和下载，不在本 Skill 另造 API 客户端。缺少已批准的输入或宿主能力时保存计划与缺口。

## 3. 验片与交接

候选逐秒检查叙事动作、表演、重心与接触、背景视差、身份和造型、道具状态、光线方向、声音与剪辑点。技术解码和时长合格不等于创作合格。仅返修有问题的 Shot 或 Generation Unit，保留旧候选、任务 ID 和输入版本；跨镜头身份或场景事实变更需上游新版本。最终成片装配、字幕、授权和发行由项目既有流程验收，不以本 Skill 的计划校验代替。

姓名条及身份字幕核对当前成片的实际出场，而非仅检查旧图层存在。内部角色名不自动等于观众已知身份；未揭名时使用剧情已展示的称谓。文字位置既要避开脸、手、证物，也要防止贴近同框另一人而造成误认。跨切点持续的文字逐个检查新构图，不把旧位置的静帧通过沿用到新剪辑；阅读不足时先缩短说明，不冻结、拖慢动作凑字卡时长。

局部重封装或字幕合成后的片段，在无转码拼接前核对轨道时间基，拼接后检查逐帧时间戳间隔及音轨采样数。相同帧率、总帧数及解码成功不能排除切点时间跳变；统一时间基可仅重封装完成，不因此改速。保留无字源段与独立文字层，区分合成前遮罩外像素一致和有损编码后的画面检查。

总片剪辑变化后，由当前片段起帧和段内事件帧重算音效、字幕及跳转入口的总片时码，绑定所用时间线摘要。先确认实际媒体位置是否已正确；仅记录过期时修映射，不把正确音效一起挪动。未变的声音可按采样或文件摘要复用检查，原速观看、阅读和听感仍分别验证。

当前片段局部替换后，同步无字画面、独立姓名／字幕层、工程实际引用的源片和交付清单，不能只更新播放器成片。景别变成单人时检查原同框姓名是否仍指向正确人物。可移交工程包须用自身依赖重建并对照当前时间线；旧包的摘要或播放检查不得沿用为新包通过。未变音轨与固定参考复用字节证据，不重复生成。

多轮媒体审阅页折叠历史内容时，核对浏览器是否仍读取隐藏音视频和封面；仅折叠节点不会阻止 `preload="metadata"` 或 `poster` 请求。优先加载当前成片，历史素材在其实际展开后加载，嵌套折叠保持按需，关闭时暂停对应声音；保留原链接与试听入口，并实测首次请求、展开播放和收起暂停，不将少请求等同画面或听感通过。
