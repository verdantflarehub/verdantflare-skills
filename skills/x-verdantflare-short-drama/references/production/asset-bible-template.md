# 短剧数字场景、道具与服装资产模板

适用于剧本和人物小传已有固定版本、需要跨集稳定生成的项目。交付四份独立文字资产：`locations-vN.md`、`props-vN.md`、`wardrobes-vN.md`、`continuity-vN.md`。它们是项目制作输入；没有选版、权限和 Artifact 记录时，不称获批图像或 World 资产。

完整剧本交付的六类文件规范由[剧本包规范](../writing/script-package-standard.md)维护。本模板用于影视制作阶段承接文字设定并准备图像；若剧本需要返修，同步正文、人物与这四份设定，不能仅在下游补一份不相容的资产说明。

## 输入与顺序

1. 固定剧本版本、人物小传版本、已有首帧/资产审核记录和镜号；区分原著事实、剧本事实、已有获批图像事实、制作提案。
2. 先提地点本体，再按昼夜、天气、时间跳跃和梦/现实拆场次变体。一个物理空间复用同一地点 key，改变光、陈设或损伤用场次/版本表达；跨空间的镜头同时引用多个场次。
3. 道具按“单一实物/复制件/印模”分别建 key，写可辨外观、尺度、磨损、文字合成面、持有人、转手和损伤链。服装按角色身份与 Look 分离，写层次、材质、颜色、发型、穿脱、湿污伤势与左右佩饰。
4. 对每个镜号写场次 key、关键道具状态、角色身份+Look、必须核验的前后连续性。镜头有蒙太奇或回忆时逐段列变体。核对首尾镜号覆盖、入镜物件先被取得、离镜物件不再出现、换装有过渡、左右方位不翻转。
5. 文字选版后先做地点总览/反向机位、道具正侧与手持比例、服装正侧背及过渡状态；对应角色/地点/道具图片各自审核，再绑定 Generation Unit。不要拿首帧批准推定视频动作、口型、声音或其他镜头通过。

## 每类资产最低字段

| 文件 | 每项必填 | 验证重点 |
| --- | --- | --- |
| 地点 | 稳定 key、叙事用途、空间平面/动线、固定地标、材质光线、场次变体、镜号、参考图及审核状态 | 门窗、轴线、远近层次与跨镜重复地点一致；日夜不凭空搬家具 |
| 道具 | 稳定 key、形状色材与尺寸关系、唯一特征、可读字层、持有/转交/损坏链、镜号、审核状态 | 原件数量、左右手、缺口/纹样、字卡校勘和证据链 |
| 服装 | Look key、角色身份 key、衣层颜色材质、鞋帽发型饰物、湿污/伤势/换装、镜号、参考图状态 | 同脸不同 Look、同 Look 不漂移、左右佩饰与道具绑定 |
| 连续性 | 每镜场次、关键道具状态、角色 Look、前后镜变化及待决点 | 镜号全集覆盖；已有审核只继承准确范围 |

## 状态和版本

新增视觉细节标“制作提案”，不可写成原著或既有批准事实。已有图片必须记精确文件/Artifact 版本及审核范围，不能只记一个模糊 Approved。变更稳定锚点时升版本、列受影响镜头和旧版继续有效范围；批准版本不覆盖。项目草案入 Studio 与 `world.register` 发布是两步，World 发布另核权利、依赖与选定修订。
