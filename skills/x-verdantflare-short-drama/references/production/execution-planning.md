# 多版本媒体执行方案

## 1. 何时使用

用于宣传片、广告、影视段落的执行方案、分批生成或已有项目续作。只改一句台词、一个画面时只更新受影响记录，不要求建立全套文件。需要从零写方案时按[方案模板](execution-plan-template.md)选取适用项；模板是创作交接说明，不是新的服务Schema或生成许可证。

## 2. 先收敛当前要求

从当前主方案、最近交付索引和用户最新决定开始读，发现具体冲突才回溯相关历史。新要求只取代它明确影响的范围；旧版本保留但标明被哪条决定替代，不把历史限制、助手建议或参考片内容当成用户新指令。

记录项目、当前阶段、目标交付、正在采用的方案版本，以及用户决定原话对应的对象、版本、范围和下一动作。收到“继续”时，已有唯一待执行节点且授权清楚就执行；存在无法查明的多个对象且选择影响成本或内容时，才集中澄清。

把要求写成可核验结果。例如“恢弘”需落到哪个节目段落、配器密度和动态；“科技感”需落到AI完成了什么可见操作；“更快”需说明哪些动作可缩短、哪些因果信息仍须看懂。不能只把这些词追加到提示词末尾。

## 3. 故事与素材在生成前对齐

每个案例先写观众能看懂的链条：谁遇到什么问题或有什么想法，如何用工具做成作品，谁实际使用或看到了结果。按批准结构连续讲完或穿插；不能因为转场漂亮就更改案例归属、引入新案例。AI介入需要可见输入、处理或输出，设备之间切换本身不说明AI价值。

同时固定有影响的连续性事实：身份与服装Look分别引用；空间进出方向、车辆与道闸相对位置；手机／电脑的正背面；同一本书、同一张旧照与同一作品。若贯穿物表示累计成果，记录进入集合、这一案例新增项及离开集合；回顾或复用作品不自动再加一个。

素材逐项记录来源版本、实际规格、可用源区间、可观察动作、缺项和结论：可用、需返修或缺失。已换角、换Look或换作品内容时，标出依赖旧版的首尾帧、视频、屏幕、回顾镜头；返修只涉及这些依赖。文件存在和技术成功都不是“可用”的充分条件。

## 4. 从剪辑意图变成可执行单元

用现有[导演计划契约](../directing/plan-contract.md)表达Shot与Generation Unit；需要固定提交准备时沿用[生成准备](generation-review.md)的可选记录。不要增加未经服务支持的字段或把本地策划ID当项目ID。

保留三层对应：剧本／锁定剪辑行 → 实际剪辑镜头与源入出点 → 模型生成单元。源时长、目标时长、可用动作区间分别记录；处理分段、生成条数、剪辑行数和实际切镜数不能互相充数。

时序安排沿用户要求。未指定时，按风险选择先验证故事、旁白窗口或音乐结构；不要强制所有任务先做音乐或先做配音。样段用于验证明确风险，例如连续运镜或作品出屏，而非默认新增检查点。用户取消样段后，继续已授权的正式工作。

提示词先明确起始状态、按顺序发生的主要动作和结束状态，再说明摄影机运动、人物动作、环境运动及连续性。一个单元装不下多个关键动作时按因果拆分，不靠更多形容词强塞。模型只支持多图参考时，不承诺精确首尾帧控制；摄影机参考和第三方素材是否可输入按用户要求与实际能力处理。

## 5. 执行、审核与返修

本轮工作记录包括可直接执行项、真正依赖项、明确的次数／费用限制和停止条件。用户未规定数量时不设默认零额度，也不把代理建议数量升级为硬上限。用户追加或明确要求返修后，更新已有记录直接执行授权范围；不要为同一追加再索取许可。

用户要求首尾帧先审时，仅依赖这些帧的视频等待；提示词、其他批准单元、格式检查和归档继续。批准构图不代表动作验收，批准声线不代表新take听审，粗剪允许缺项不代表最终质量通过。只能引用实际要求建立停点。

区分结果未知、技术失败和创作失败：未知按原任务ID／幂等键查询；已成功但下载失败只恢复下载；动作错误按授权范围返修。每项保留输入摘要、模型渠道、原生任务或Artifact ID、实测结果和下一步。渠道恢复不重生已成功素材，接口不可用不触发擅自切渠道或修改集群。

返修描述写清“保留什么、只改什么、如何判定改变成功”。比较图应让变化可见，不能交两张看不出差异的图代替修正证据。精确Logo、节目名及界面字优先复用真实设计素材或受控排版；只有海报图片时，原字形可提取，新字不能宣称已取得同款字体。缺三维能力时只使用已允许的替代，不用平面推拉冒充三维或真实运镜。

## 6. 粗剪、精修与交付

按阶段给出实际可看的成果。粗剪验证结构、信息、动作和声音关系；阶段允许暂留的屏幕、字形或特效缺项单列，并附已有批准，不借“粗剪”绕过硬约束。最终交付逐项关闭或取得对应范围的接受决定。

剪辑前用实际帧数与音频采样数核对窗口。重解释24fps为25fps会缩短时长，重采样到25fps则是另一种处理，不能混称。将非整帧边界的量化结果和对相邻镜头的影响写清；锁定边界无法满足时给出具体最小改动方案，不静默移位。

留存独立画面、配音、音乐和混音配置。只换音乐或配音时复用无旧音轨的画面母版，核对源版本及时间线；具备相应工具时可比较视频流摘要，避免把重新编码当作“画面字节不变”。工程可重建需依赖真实素材及处理参数，只有成片和JSON不代表依赖已完整归档。

交付说明同时回答：改了什么、相对主方案的差异、机器验证了什么、哪些创作效果仍待听看、哪里可恢复。具备播放能力时做完整动态和听感检查；无法实际听看时明确标记，不能用ASR、接触表、响度或哈希代替。上传、项目提交、实际回读和领域关联分别记录，保持候选，不自动选用或发布。
