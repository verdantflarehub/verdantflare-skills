# 场景、关键帧与视频一致性工作规范

适用于从已确定剧本推进有角色表演的影视镜头，以及站位、表情或场景漂移返修。按实际任务范围执行；既有决定持续有效，用户要求先确认关键帧时，先交付可查看图片，收到对应确认或生成指令再提交视频。局部返修只重做受影响的帧或生成单元。

## 1. 制作顺序与交接

1. 明确单镜任务：读取固定剧本与连续性版本，写出镜头目的、人物目标、刺激事件、起落状态、时间线、画幅和声音意图；用可观察动作解释目标。
2. 确定场景：依据地点、场次、道具和灯光设定，固定场景版本、平面布局、白模工程、相机参数与正反方向预览；核对门窗、通路、关键道具和遮挡。
3. 确定正式场景外观：依据同机位白模、材料与陈设说明，交付场景照片、空间对照和差异记录；核对货物陈设、光源开关及时间天气。
4. 确定人物站位与状态：依据场景照片、身份、身体状态和 Look，记录入场位置、视线目标、移动路径、接触与遮挡；核对人物和物体的前后关系及路径可行性。
5. 确定关键帧：依据固定资产与动作节拍，交付所需的起始、必要转折、结束关键帧及对应表演节拍说明和版本索引；核对空间、表演递进与动作可达性。
6. 生成视频：固定已选关键帧、表演时间线和模型能力，保存输入引用、Prompt、请求、任务 ID 与原始候选；核对本单元授权，不把多图参考称为硬首尾帧控制。
7. 验片与归档：核对原始候选和输入版本，保存技术检查、动态验片、问题定位及项目归档回读；分别记录技术成功、创作选用、完整声画验收和正式发行。

可以并行准备无依赖资料，不以某个镜头缺少批准阻塞全项目。完整剧本包仍按[剧本包规范](../writing/script-package-standard.md)交付六类独立文档。

## 2. 场景确定性：白模与正式照片各有职责

先选择戏份多、复用价值高的关键场景验证流程，再扩展其他地点。白模用于确定尺寸、相机、通路、遮挡与复杂道具结构；正式场景照片负责真实材质、货物、陈设与剧情光线，二者都要保留固定版本。云端 Blender 的要求按项目约定与[白模规范](blender-whitebox.md)执行，不用本地替代后声称云端完成。

记录世界坐标、相机位置/朝向/高度/焦距或视场角、画幅、门窗、主要家具、关键道具位置、光源位置与开关。正式照片若偏离白模，明确修正哪一侧并升版；白模只是约束辅助，不能保证生成模型严格遵守几何。

正反打要在空间中改变观察方向，先渲染对应机位的白模再生成照片。用门窗、货架、桌案和货物的可见面校验关系，不能把镜像或几乎相同的两张图称为反打。相邻人物镜头同时记录轴线与视线匹配；跨轴须有叙事或镜头衔接依据。

货物不是可任意填充的背景：明确种类、容器、数量级、摆放区、破损/开启状态。关键剧情道具单独建资产，文字与纹样需要精确时保留独立字层，视频中再次检查可读性。

## 3. 角色状态与表演

人物身份、身体状态、服装 Look 分开引用。身体状态包括疲惫、伤口位置和恢复阶段、肤色、呼吸、警觉、年龄或长期劳作变化；服装状态记录破损、烧毁、湿污等真实变化。疲惫不等于目光失焦或反应迟钝。

表情随事件和行动变化：刺激发生 → 眼神先定位 → 眉眼/嘴唇/呼吸回应 → 身体作出决定 → 动作后稳定。分别写出可见变化，避免全程同一中性脸、持续皱眉或只堆叠“惊恐、机警”。身份特征随表情自然显现，不能为保留酒窝而强迫微笑或刻出固定凹坑。

为每个动作安排明确时间窗口，区分快速反应与短暂停留；避免所有动词都写“缓慢”。改善节奏先修动作与停顿，不以整体加速伪装表演改善。时间点是目标，验片记录实际发生时间，不能把提示词当结果。

## 4. 关键帧确认与引用

涉及多人站位、转身、交接物件或运镜时，在同一 Blender 场景中固定人物关键位置与朝向，必要时补接触／支撑姿态；摄影机单独设置位置、旋转、焦距与运镜时间曲线。核对关键位置图和必要的相机预演后制作正式图。自然连续动作交由视频模型完成，不以完整骨骼动画或逐帧关节曲线作为前置条件；具体分工与能力降级见[白模规范](blender-whitebox.md#21-空间与运镜辅助模型连续表演)。白模坐标与正式图若不一致，先解决偏差，不把整帧编辑指令当作几何锁定。

同一固定镜头优先以已确定场景/前帧为编辑底图，仅修改人物所需区域。局部修复优先使用实际能力支持的遮罩或局部合成，并记录保留区域；普通 image.edit 仍可能重绘整帧，不称为局部重绘。逐帧对照门窗、桌角、柱宽及货物等固定锚点。藏身帧必须表现真实遮挡：人物身体在柱/架后，不能靠扩大柱子、挪动背景或改变机位制造效果。检查各帧之间是否有足够空间和时间完成动作。

每张参考只有明确职责；身份头像不定义全身动作，模特衣板不定义人物面孔，疲惫参考不自动授权改变发型。裁切参考保留原件、裁切范围和哈希。优先使用已穿好指定衣装、置于目标场景的表演关键帧，减少参考职责冲突。

关键帧记录模板（每镜按需填写）：

```yaml
shot_id: <稳定镜头ID>
scene_version: <场景照片与白模固定引用>
camera: <机位、朝向、焦距、画幅、固定或运动>
character_refs: <身份、身体状态、Look固定引用>
keyframes:
  - id: <帧ID>
    target_time: <目标时间>
    stimulus_and_intent: <刺激、辨认、决定>
    blocking: <位置、朝向、支撑点、遮挡物、露出范围>
    gaze_expression_breath: <视线目标与具体变化>
    action_and_contact: <动作、重心、手与道具接触>
    invariant_anchors: <门窗/桌角/柱宽等>
    image_ref: <固定文件/Artifact/哈希>
selection: <待确认或用户选择证据；沿用真实决定>
model_control: <实际支持的首尾帧/多图参考/运动控制及限制>
```

关键帧确定的是目标画面，视频仍需重新验证。模型仅支持多图参考时，不保证图片按序出现或精确落在指定秒数；执行仍遵循 Video Skill 与现有[表演规范](../performance/performance.md)的 Prompt 要求。

### 4.1 连续性返修：按画面证据放行

遇到手性、凭空持物、服装串样或重复人物时，先停用该帧及其衍生输入，保留拒绝原因，再检查引用的单人参考。多人状态图不能直接充当单人身份参考；先裁切或重做干净身份与指定 Look，分别记录来源。

逐帧记录角色人数与身份、解剖左右手、持物、Look、身体状态；逐对记录姿态和空间锚点变化。饰物左右取角色自身解剖方向，沿肩—肘—腕追踪，并核对掌背与拇指；画面左右只作定位。遮挡或分辨率不足记为“不可确认”，必要时另做清晰核对帧，不能记为通过。禁止靠翻转整图修饰物而破坏空间轴线。

转身同时检查头颈连接、肩线、胸背可见面、胯、膝、支撑脚；只移动头部或翻脸不算转身。道具记录持有人、左右手、取出/交接/收纳动作；刀、印、饰物不可无来源出现。服装用袖长、护腕、腰带、下摆和完整/湿污/破损状态核对，湿透不自动允许撕裂。相似衣色人物以脸型、年龄与服装结构分辨；倒地前后总人数守恒，不能同时保留站立副本，已死亡人物不得在后景复活。

每次生成后查看实际图片及相关局部，与前后帧比较；发现错误先改变导致错误的引用、姿态或局部区域，再修受影响单元。审核记录写具体可见证据、失败版本、替代版本与未验证项，不能从提示词或任务成功推导“已通过”。同类问题要追查其关联镜头；技术检查通过与用户终审分开记录。

## 5. 验片、返修与同步

先验证下载哈希、可解码性、实际时长/帧率/尺寸/音轨；画幅与目标不符应记录，保留原片，不静默拉伸。抽帧用于定位动作、表情与背景漂移；完整1倍速声画回放用于判断节奏、呼吸、对白和声音，不得以接触表代替。

- 反打像同一张图：检查相机方向及可见面，返修白模相机和场景照片。
- 藏不住或站位不可信：检查人物与遮挡物的前后关系及身体露出范围，返修关键帧和移动路径。
- 表情僵硬或呆滞：检查视线目标、刺激后的反应及冲突参考，返修表演节拍和关键帧。
- 动作拖沓：检查无动作等待、反应时间和动作后停留，返修单镜时间线。
- 人物变脸、散发或衣装串样：检查参考职责与冲突内容，返修参考筛选及裁切。
- 背景移动或新增火光、雨：检查空间锚点、相机约束及灯光天气状态，返修场景引用和受影响生成单元。

保留旧候选及失败证据，修改原因与新版本绑定。未知任务状态先恢复原任务；查询、下载或归档出现502/503不等于生成失败，不重复付费提交。返修次数与额度沿用本轮授权。

归档遵循[Studio同步](../studio-sync.md)：媒体字节上传、项目文件登记、领域资产版本关联与实际页面可见性分别核实。回读固定修订和哈希后才能报告对应完成状态；项目复盘是文档资料，不伪装成媒体版本。用户接受样片只记录该范围，不推定全部技术偏差消失或已获发行批准。
