# 验收

## 1. 交付层级

- 文稿：正文能排演，完整对白有目的、触发和听者响应；分镜交代因果及前后状态。
- 输入：实际槽位、字节摘要、顺序、用途、完整上游约束通过；能力与服务预检另核。
- 视觉：原始身份／Look对照、手臂全链、道具和空间有真实观察；不能由输入检查代替。
- 动态：原速完整播放、原声听审、关键事件连续帧、上下文接点分别记录。过程缺失不能因末帧正确通过。
- 选用与发布：沿用当前用户检查点及上传／发布范围；不由自检或静帧批准自动提升。

## 2. 回归与边界

执行`python3 -m unittest discover -s tests -p 'test_*.py'`。至少测试缺参考、删必需项、输入变更、代理动作冒充、已退回候选、静帧冒充视频、假播放证据、重复无效返修、未知提交恢复、过期相机证据和动作前置冲突；还测试合法提交一次、只改音轨复用视觉及纯相机预演。

结构检查只能拒绝明确冲突与缺项。听者是否真受惊、割绳是否有拉切过程、推送是否自然，仍由内容审查判定；离线反例只验证“未通过的判断无法进入提交／接画”，不宣称自动理解动作。
