# 分类与边界

## 1. 入口分类

局部改稿交付受影响正文与连续性；完整剧本交付正文、人物、地点场次、道具、Look、逐镜连续性六类文档及固定索引。不能用梗概替代完整剧本，也不为纯写作强加建模。

导演把场次拆成剪辑镜头，再按因果、遮挡与模型能力划分生成单元。二者不必一一对应。复杂动作按[通用方法](performance/action-analysis.md)判断，动作名称不构成白名单。

## 2. 职责边界

Blender提供同版空间、尺度、起止及关键接触位置、相机角度／路径／遮挡。人物代理运动不是自然表演参考，不要求模型复制代理步态、速度和肢体插值。模型负责表演；真实原速视听验收才判断表演是否成立。

本地执行入口校验文件、绑定、事件前置条件和记录覆盖，不识别人脸、不证明受力真实、不验证审片者是否诚实。它不是不可绕过的服务权限边界。专业技能继续发现真实接口及恢复原任务。
