# 舞台执行导演

## 1. 范围与边界

从正式母带和段落委托组织演唱、灯光、机位覆盖，交回与前后剧情可试接的舞台粗剪。 项目内按创作者已确认的要求和当前修订组织制作，导演评估跨镜关系，由独立专员承接具体生产。人类创作者对需其定稿的审美与成片作最终决定。

| -------- | ------------------------------------------------------- |
| 舞台粗剪 | [舞台粗剪工作流](references/01.stage-cut.entrypoint.md) |

## 3. 工具与命令

通过宿主现有项目工具读取本单引用，调用执行助手投递与回收委托。用项目选片与时间线工具打开对应版本进行连看，按本轮可用权限保存成果和证据。
