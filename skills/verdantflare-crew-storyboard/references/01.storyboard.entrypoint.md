# 分镜设计专员的段落分镜工作流

## 1. 输入与输出

领取段落目标、观众在进出段前后应知道什么、角色与场景版本和已定决定。MV 领取母带版本、指定区间与拍点；对白段领取台词、节拍及视线方向。交付有稳定格号、构图、动作、时长和试放顺序的分镜，在拍摄稿中增加镜号、专业方案与正式输入需求。

## 2. 分类

粗稿先验证信息能否在指定时间被读懂，角色和场景探索稿注明当前版本。拍摄稿将选定的格转为镜号，按委托加入机位、光位、动作和运镜；一个格到多个镜头或多个格在同一镜头内时，记录实际关系。

## 3. 工作流

1. 拆出本段必须呈现的起点、信息变化和出口。把“副歌第一拍才看清主唱”拆成首拍前仍无法确认身份、首拍正脸可辨、后续接回剧情三处检查点。记录确定项与导演留白。
2. 为每格写构图中的主体、观众获得的信息、动作进出、相邻格的连接与时长。把反光、饰物、台词或背影这些可能提前透露身份的细节画出来，实际以这组稿检验假设。
3. 绑定本轮母带源区间或对白参考，把画格按相应时长装到同一时间线。先完整原速试放，再定位首次能认出主唱的画格。记录切入点、首个可辨帧及依据。纯对白段同样使用台词或反应节拍作时序依据。
4. 粗稿交委托导演审看。一处话筒反光提前露脸时，退回该格，另存修订，保留其他格及其时序。若想保留倒影带来的提前揭示，把两种试放交总导演，由其与创作者决定。
5. 在拍摄稿将表演触发、机位、光位、相机起动、落幅与关键帧需求放到同一镜号。定位专业意见之间的冲突，附差异画格交执行导演取舍。按实际选择交关键帧与单镜制作岗位。

## 4. 规范

- 记录每个画格的角色、场景和决定版本。正式生成所需关键帧由相应岗位按镜头用途制作和审核。
- 导演可直接委托粗分镜探索。角色或场景尚在比较时，标明草案依赖与后续必须复查的格。

在本单的项目、任务、轮次和输入修订中工作。接单回执注明目标、首件预估与下一检查点。把结果、已知缺口和 QC 写回本轮，引用候选文件和被检的区间。导演明确的要求若需改动，提交依据和备选。连续两次局部修正仍出现同一缺陷，暂停该方向并汇报两轮差异。按委托期限上报超时及恢复条件，等待人工意见时停止主动工时。换 Session 从本轮任务和版本恢复，正式选用由受控项目入口记录。

## 5. 验收

下游能从指定镜号找到画格、母带或对白区间和拍摄要求。保存可试放稿、反馈所指格、修订差异与相邻剪点检查。对提前揭示的版本保留退回记录；人工决定只引用真实开出的意见或选用。
