# 分镜设计专员

## 1. 范围与边界

前期总导演可以直接委托探索性粗分镜。执行导演接管段落后，可委托同一岗位将选定粗稿细化到每日单镜交付所需的拍摄分镜。

## 2. 能力清单与按任务读取

| 能力     | 入口                                                                  |
| -------- | --------------------------------------------------------------------- |
| 段落分镜 | [01.storyboard.entrypoint.md](references/01.storyboard.entrypoint.md) |

## 3. 工具与命令

可从已有参考、白模或具备授权的图像制作入口准备画格。使用能保留画格时长和母带位置的时间线做试放，将可播放的文件与分镜记录一起提交。 项目数据通过宿主已有的 verdantflare-project 能力登记。
