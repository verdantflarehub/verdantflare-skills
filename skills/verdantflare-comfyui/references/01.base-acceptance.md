## 2. 分阶段可观察完成条件

每类任务必须满足对应的服务端客观回执后方可报告完成，禁止将“请求已发出”或“脚本未报错”表述为已完成：

1. **模型依赖齐套完成**：目标工作流全部依赖模型在 `model.status` 中状态精确为 `ready`，返回非空 `sha256`（与目录 `expected_sha256` 一致）与真实 `size_bytes`；对运行中交互实例已完成 `repair.reload_models` 且 `diag.object_info` 可见对应模型枚举项。
2. **白盒排障与自愈完成**：
   - 执行层排障：修复后重新提交 `task.submit` 取得 `status == "succeeded"`，且 `diag.execution_trace` 零节点异常。
   - 实例换代重启：`instance.status` 显示 `lifecycle_state` 恢复就绪、`generation` 较重启前严格递增、返回全新 `boot_id`，且未落入 `quarantined` 状态。
3. **工作流 API 发布完成**：`api.publish` 成功返回不可变 `(endpoint_slug, semver)`、`prompt_sha256`、`canonical_model_lock_v1` 摘要及 `vram_budget_mib`；通过 `/mcp/comfyui-api` 调用 `api.describe(endpoint_slug, version)` 可完整回读该版本契约。若启用了 `mount_channel` 投影，还须在对应媒体目录可见 `本地` 渠道条目。
4. **无头生产调用完成**：`api.invoke` 关联的 `task.get` 到达 `succeeded`，产出的每个 Studio `Artifact` 均返回有效 `artifact_id`、非零字节大小、合法媒体尺寸与 `sha256`；需落盘核验时实际下载解码确认非黑图、非空帧。技术校验通过不代替人类审美或业务终审。

## 3. 典型错误码与未通过处置

| 服务端错误码                             | 含义与规定恢复动作                                              |
| :--------------------------------------- | :-------------------------------------------------------------- |
| `202 MODEL_APPROVAL_REQUIRED`            | 超体积、非商用许可或净空不足需审批；待批或腾空间后重提          |
| `400 UNSAFE_MODEL_FORMAT`                | 非 `.safetensors` 或头部偏移帧非法；禁止入库并换安全权重        |
| `403 TOOL_NOT_ALLOWED_ON_HEADLESS_ALIAS` | 在 `comfyui-api` 误调会话或自愈工具；改走交互实例或无头允许工具 |
| `403 MODEL_PAID_ACCESS_FORBIDDEN`        | 目标模型需付费解锁；立即终止拉取并说明限制与开源替代方案        |
| `403 MODEL_SOURCE_SSRF_BLOCKED`          | 下载源命中内网或非白名单地址；停止重试并核查目录源 URL          |
| `409 BOOT_ID_MISMATCH`                   | 实例重启使游标失效；丢弃旧 `since_seq` 并重取新 `boot_id`       |
| `409 MODEL_NOT_READY`                    | 引用的依赖模型尚未 `ready`；先执行 `model.ensure` 至 `ready`    |
| `409 ADMISSION_RESERVATION_EXPIRED`      | 跨库预留超时已被撤销；生成新 `idempotency_key` 重新提交         |
| `409 OPERATION_IN_PROGRESS`              | 同实例栅栏或同幂等键执行中；轮询等待收敛，禁换新幂等键冲撞      |
| `409 IDEMPOTENCY_CONFLICT`               | 复用旧 `idempotency_key` 却改参数；核对原结果后用新键提交       |
| `409 MODEL_IN_USE`                       | 模型被在途任务或已发布 API 引用；保留模型并报告引用计数         |
| `503 RECLAMATION_UNVERIFIED_QUARANTINED` | GPU 回收未获三重证明，实例已隔离；立即停手并上报底座排查        |

## 4. 交付报告必填要素

任务收尾汇报保持简洁，按实际执行的阶段如实列出以下可核验事实：

- **通道与身份记录**：实际调用的网关别名（如 `comfyuiA` 或 `comfyui-api`）、`project_id`、涉及重启前后的 `(generation, boot_id)`。
- **模型与 API 锁定信息**：新增或复用的 `MDL-*` 编号、`model_id` 与 `sha256` 前缀；已发布或调用的 `endpoint_slug@semver`、`vram_budget_mib` 与挂载渠道（`none` / `image` / `video`）。
- **任务与产物证据**：冒烟或生产调用的 `task_id`、确定性复现所需的 `resolved_seeds`、归档 Studio `Artifact` ID 及实际尺寸/字节校验结论，以及尚未验证或需人工审美确认的事项。
