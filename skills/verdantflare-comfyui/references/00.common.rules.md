# ComfyUI 跨能力公共规则与边界

## 1. 三类执行通道判定

收到与 ComfyUI、节点工作流、开源权重供应或本地定制生成相关的请求时，先按任务性质选择唯一匹配的受控通道，严禁混用交互实例与无头生产池：

| 任务特征与目标                                         | 选用通道与连接路径                           |
| :----------------------------------------------------- | :------------------------------------------- |
| 画布调试、节点报错排查、模型热刷新、提取并发布新 API   | 交互实例通道 `/mcp/comfyui<id>`              |
| 调用已固化 `WorkflowAPISpec`、不打扰创作者编辑会话     | 无头生产通道 `/mcp/comfyui-api`              |
| 调用管理员已投影至全局媒体目录的成熟本地图像或视频模型 | 中央 `/mcp` 下 `image.*` 或 `video.*` 工具集 |

通道判据与切换约束：

- **交互实例通道（如 `/mcp/comfyuiA`）**：绑定具体 `AppInstance`（匹配 `^comfyui[A-Za-z0-9]{1,57}$`）。适用于读取或修改画布草稿、沙箱冒烟（`task.submit`）、查看实例脱敏日志（`diag.logs`）、热刷新模型字典（`repair.reload_models`）、软卸载显存（`repair.free_vram`）、单实例换代重启（`repair.restart_worker`）以及从冒烟成功的工作流提取并发布 API（`api.extract_spec` -> `api.publish`）。若目标实例被他人持有编辑租约或不可用，如实报告阻塞，不得擅自改连其他个人实例或强行重启抢锁。
- **无头生产通道（固定别名 `/mcp/comfyui-api`）**：路由至与个人画布逻辑分离的单并发无头 API Worker 池，与交互实例共享 `/models:ro` 只读模型池及 Station `:5056` 物理卡显存账本。原研发实例处于 `stopped` 休眠态或被他人编辑时仍可稳定调用。该通道仅开放 `api.list`、`api.describe`、`api.invoke`、`task.get`、`task.cancel`、`diag.execution_trace`、`model.list` 与 `model.status`；对其调用 `session.*` 或实例级 `repair.*` 会确定性返回 `403 TOOL_NOT_ALLOWED_ON_HEADLESS_ALIAS`。
- **媒体目录 `本地` 渠道投影**：当组织或站点管理员已将工作流 API 通过 `mount_channel="image"` 或 `"video"` 投影为 `本地` 渠道模型（前端角标统一显示中文 `本地`）且业务只需标准文生图/图生视频接口时，直接移交 `verdantflare-image` 或 `verdantflare-video` 调用，无需进入 ComfyUI 专属工具链。

## 2. 排除范围与职责边界

以下请求不在本技能执行范围内，应在入口直接说明边界并转交对应流程：

- **裸集群写操作与容器命令执行**：不执行 `kubectl apply / delete / patch / exec / port-forward`，不读取 Kubernetes `Secret` 或原始未脱敏 `pods/log`。平台研发或验收核验阶段如需核对底层 Pod 事件，仅限在授权环境使用只读 `vf-agent-readonly` 凭据观测事件与状态。
- **付费解锁与不安全权重格式**：对 Civitai `paidAccess`、`Early Access` 或任何需付费订阅解锁且无开源镜像的模型，不触发下载、不编制绕过方案，直接告知付费受限状态；对 `.ckpt`、`.pt`、`.bin`、`.pkl` 等高危 Pickle 序列化权重一律拒绝引入。
- **运行时动态安装第三方节点**：容器根文件系统保持只读，禁止在运行期执行 `git clone` 或 `pip install` 安装未知节点；缺失高频开源节点时记录 Commit SHA 与依赖清单，走受控镜像版本评审更新。
- **平台底座部署与数据库迁移**：Helm Chart 升级、Station Core 迁移与集群网络策略变更属底座运维范畴，不通过实例 MCP 工具执行。

## 3. 硬性安全与合规约束

以下条款属于平台安全、计费与资产合规底线，在任何任务中均不可绕过：

- **零裸集群写与零容器侵入**：日常排障、模型热刷新、清显存与换代重启 100% 通过 Studio MCP `diag.*`、`repair.*`、`model.*` 完成；禁止请求或使用 `kubectl` 写权限、`kubectl exec`、`pods/log` 或读取 Kubernetes `Secret`。
- **严禁触碰付费解锁模型**：调用 `model.ensure` 或登记本地模型前必须确认目录项 `paid_access == false` 且许可证为明确开源免费协议；凡标记 Civitai `paidAccess`、`Early Access` 或需付费会员才可拉取的模型，一律不拉取、不写替代抓取脚本。
- **权重格式、哈希与配额四重硬门禁**：仅允许扩展名与二进制头部均合法的 `.safetensors` 权重入库，严禁 `.ckpt`、`.pt`、`.pkl` 等可执行反序列化格式；调用 `model.ensure` 必须提供与权威目录一致的 64 位小写十六进制 `expected_sha256`，自动拉取单模型体积上限为 `25 GiB`，且宿主机模型盘必须保留 `>= 200 GiB` 可用净空（超限转人工审批或先通过受控清理释放无引用缓存）。
- **租户隔离六元组幂等键铁律**：所有写操作与状态变更工具（`task.submit`、`api.publish`、`api.invoke`、`model.ensure`、`repair.reload_models`、`repair.free_vram`、`repair.restart_worker`）必须携带标准 UUID（v4 或 v7）`idempotency_key`。同一幂等键下严禁篡改请求参数（否则服务端确定性拒绝并返回 `409 IDEMPOTENCY_CONFLICT`）；不同操作必须生成全新 UUID。
- **日志增量游标强制绑定 `boot_id`**：调用 `diag.logs` 传入 `since_seq` 时必须同步携带 `boot_id`，防止实例重启序号重置后漏读或跨代混读日志；日志输出仅包含当前 `project_id` 归属行与平台级守护事件，不得尝试探测其他项目日志或解码已脱敏的 `[REDACTED]` 标记。
- **`WorkflowAPISpec v1` 严格类型与防注入边界**：`api.invoke` 仅允许传入 `exposed_inputs` 白名单内的标量或受控 `artifact_*` ID，严禁传入未知键、节点连接数组（如 `["4", 0]`）、用浮点数 `1.0` 或布尔值冒充整数，或传入超出 IEEE-754 安全整数范围 `0..9007199254740991` 的随机种子；客户端不得指定底层文件路径、`[input]/[output]` 后缀或覆盖已锁定的模型文件名。
- **跨项目授权与管理员投影门禁**：每次工具调用传入的 `project_id` 必须具备真实读写成员权限；`api.publish` 中 `mount_channel` 设为 `"image"` 或 `"video"` 仅限组织或站点管理员执行，且必须与 `spec.output_modality` 完全一致。

## 4. 默认值、例外与冲突处置

| 参数项                              | 默认推荐值与调整条件                                                          |
| :---------------------------------- | :---------------------------------------------------------------------------- |
| `diag.logs.tail_lines`              | 默认 `100` 行（定位深层堆栈可调至 `200..500`，单次上限受契约 Schema 约束）    |
| `force_after_drain_timeout_seconds` | `repair.restart_worker` 默认 `30` 秒（允许范围 `5..120` 秒）                  |
| `vram_budget_mib`                   | 默认采用服务端基于冒烟实测峰值乘以 `1.10` 安全系数推导值，不手工压低          |
| `mount_channel`                     | 默认 `"none"`（仅在管理员明确要求上架至全局图像/视频模型选择器时开启）        |
| `reproducibility_level`             | 含固定种子与确定性采样器时设为 `"strict"`，含非确定性算子时标 `"best_effort"` |

常见例外与冲突处置：

- **模型被占用拒绝清理（`409 MODEL_IN_USE`）**：当存储清理遇到活跃任务或已发布 API 版本引用锁保护时，不得尝试手工删除底层文件或强制下线生产中的 API，应保留该模型并向用户列出引用来源。
- **编辑租约冲突（`409 INSTANCE_EDIT_LEASE_HELD`）**：交互实例正由用户在网页画布或其他会话编辑时，只读诊断工具仍可按项目权限执行，但不得调用会中断用户工作的 `repair.restart_worker`、`repair.free_vram` 或抢占编辑会话；纯推理需求改走 `/mcp/comfyui-api`。
- **冷备休眠态节点字典查询**：当交互实例处于零显存冷备或 `stopped` 状态时，直接调用 `diag.object_info` 读取免 GPU 缓存字典核对节点签名，不为单纯查参数而强行唤醒 GPU Worker。

## 5. 标准错误码与交付报告必填要素

| 服务端错误码                             | 含义与规定恢复动作                                              |
| :--------------------------------------- | :-------------------------------------------------------------- |
| `202 MODEL_APPROVAL_REQUIRED`            | 超体积、非商用许可或净空不足需审批；待批或腾空间后重提          |
| `400 UNSAFE_MODEL_FORMAT`                | 非 `.safetensors` 或头部偏移帧非法；禁止入库并换安全权重        |
| `403 TOOL_NOT_ALLOWED_ON_HEADLESS_ALIAS` | 在 `comfyui-api` 误调会话或自愈工具；改走交互实例或无头允许工具 |
| `403 MODEL_PAID_ACCESS_FORBIDDEN`        | 目标模型需付费解锁；立即终止拉取并说明限制与开源替代方案        |
| `403 MODEL_SOURCE_SSRF_BLOCKED`          | 下载源命中内网或非白名单地址；停止重试并核查目录源 URL          |
| `409 BOOT_ID_MISMATCH`                   | 实例重启使游标失效；丢弃旧 `since_seq` 并重取新 `boot_id`       |
| `409 MODEL_NOT_READY`                    | 引用的依赖模型尚未 `ready`；先执行 `model.ensure` 至 `ready`    |
| `409 ADMISSION_RESERVATION_EXPIRED`      | 跨库预留超时已被撤销；生成新 `idempotency_key` 重新提交         |
| `409 OPERATION_IN_PROGRESS`              | 同实例栅栏或同幂等键执行中；轮询等待收敛，禁换新幂等键冲撞      |
| `409 IDEMPOTENCY_CONFLICT`               | 复用旧 `idempotency_key` 却改参数；核对原结果后用新键提交       |
| `409 MODEL_IN_USE`                       | 模型被在途任务或已发布 API 引用；保留模型并报告引用计数         |
| `503 RECLAMATION_UNVERIFIED_QUARANTINED` | GPU 回收未获三重证明，实例已隔离；立即停手并上报底座排查        |

任务收尾汇报保持简洁，按实际执行的阶段如实列出以下可核验事实：

- **通道与身份记录**：实际调用的网关别名（如 `comfyuiA` 或 `comfyui-api`）、`project_id`、涉及重启前后的 `(generation, boot_id)`。
- **模型与 API 锁定信息**：新增或复用的 `MDL-*` 编号、`model_id` 与 `sha256` 前缀；已发布或调用的 `endpoint_slug@semver`、`vram_budget_mib` 与挂载渠道（`none` / `image` / `video`）。
- **任务与产物证据**：冒烟或生产调用的 `task_id`、确定性复现所需的 `resolved_seeds`、归档 Studio `Artifact` ID 及实际尺寸/字节校验结论，以及尚未验证或需人工审美确认的事项。
