# Video 生成后内容分级评估步骤（K09）

## 1. 当前依据

- [18+ 评估规范（rubric v1.0）](content-rating-rubric.md)：判定类别（S1–S4、V1）、视频抽帧与音轨判定标准及输出 JSON 格式。
- [MCP 调用说明](video-mcp.md)：`video.result`、`video.rate_content` 与 Project 归档边界。

## 2. 步骤位置

评估放在“取得生成产物（`video.result` 下载完成）”之后、“交付摘要与项目同步”之前：

1. 视频生成或插帧任务完成，按原流程通过受控路径下载视频到本地（此时尚未评估）。
2. 按第 3 节在本机临时目录完成视频抽帧，结合帧序列、音轨、正向提示词与标题，对照 [18+ 评估规范（rubric v1.0）](content-rating-rubric.md) 判定，清理临时抽帧文件，得到评估 JSON。
3. 调用 `video.rate_content` 提交评估结果；判定为 `general` 的产物也必须提交，以留下“已评估”记录。
4. 按第 5 节处理交付摘要、Studio 项目归档与 World 登记。

一次生成多个视频产物（或原生视频与插帧成品构成新的固定 `version_id`）时，逐个评估并逐个调用 `video.rate_content` 提交。评估未完成前，不得将视频同步到 Studio 项目，也不得在交付摘要中展示。只读查询或恢复已完成且已评估的任务时，不重复评估。

## 3. 本机视频抽帧与多模态评估输入

- **本机临时抽帧规则（H1 O5 已确认）**：
  - 在本机临时目录（如系统临时目录或受控 `.tmp/` 下的独立子目录）对已下载视频抽帧。
  - **抽帧密度**：**至少每 2 秒一帧，且全片不少于 8 帧**（例如 4 秒视频至少均匀抽取 8 帧，20 秒视频至少抽取 10 帧），**另补镜头切换处的关键帧**。
  - **临时帧清理**：抽帧仅在本机临时目录进行，**评估完成后立即删除全部抽帧图片，严禁上传到 Artifact、严禁写入 Project 修订、严禁提交 Git**。
  - **记录抽帧数**：评估者必须在 `reasons` 中记录实际抽帧数量（例如 `"已抽取 10 帧（含切镜关键帧），未触发类别"` 或 `"S3：抽取 12 帧中可见裸露内容"`）。
- **帧序列与音轨联合评估**：
  - 结合连续帧序列判断动作（单帧不露骨但连续画面构成性行为或性化强调时按 S2、S4 判定）。
  - 视频含内生音轨、配音或配乐时，按规范第 4.3 节同时评估音轨（无转写能力时在 `reasons` 中注明 `"未转写音频"`）。
  - 同时评估正向提示词（`prompt`）与任务标题（`title`）；反向提示词不作为 `nsfw` 依据。画面、音轨、提示词任一项触发即判整个视频为 `nsfw`。
- **不确定从严（O2）**：无法完整解码抽帧或画面模糊无法排除 18+ 时，按规范第 5.1 节**“不确定即标 nsfw”**处理，并在 `reasons` 中写明原因。

## 4. 规范版本与 `video.rate_content` 调用

- **规范版本**：`rubric_version` 固定取自同目录 [content-rating-rubric.md](content-rating-rubric.md) 文首声明的版本号（当前为 `"rubric v1.0"`），不得自行编造版本号。
- **调用参数**：先发现当前 `tools/list`。现行 `video.rate_content` 接收 `version_id`、`rating`、`reason`、`rubric_version` 和可选的 `project_id`。此工具的 `version_id` 使用 Video 原生 `art_*` 产物 ID，或已完成的 `video_task_*` 任务 ID（服务解析到最终产物）；不能传中央 Artifact 的 `ContentRef.version_id`。将评估 JSON 的 `reasons` 合并为单个 `reason` 字符串，保留抽帧数量和音轨判断；评估模型与时间保留在本地评估记录，不作为工具未声明的参数发送。

```json
{
  "version_id": "<Video 原生产物 ID 或已完成任务 ID>",
  "project_id": "<实际项目 ID>",
  "rating": "general",
  "rubric_version": "rubric v1.0",
  "reason": "已抽取 10 帧（含切镜关键帧），未触发类别；未转写音频"
}
```

- **幂等与超时重试**：`video.rate_content` 是幂等的。若提交超时或响应未知，用相同产物标识和相同评估 JSON 重试，**严禁因此重新生成视频或重复扣费**。

## 5. 交付摘要与项目同步约束

- **交付摘要脱敏**：判定为 `nsfw` 的视频产物，交付摘要只写“N 个产物已标记为 NSFW 并隐藏”，**严禁展示视频预览、联系表、下载链接、`ContentRef`、原生 `artifact_id` 或提示词全文**；`general` 产物照常交付。
- **项目同步与 World 阻断（H1 已确认）**：判定为 `nsfw` 的视频产物**不同步到 Studio 项目（不写入 `project.commit`），也不登记到 World（不调用 `world.register`）**。短剧或 MV 阶段遇到 `nsfw` 视频时，在阶段记录中只写“已隐藏产物 N 个”，由用户决定是否改写提示词后重新生成。
- **不提供撤销**：MCP 与本技能均不提供、也不尝试撤销标记；若存在误标，提示用户可在 Studio 设置页开启本机“显示 NSFW 内容”开关（24 小时有效）后人工取消 NSFW 标记。
