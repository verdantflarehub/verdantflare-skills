# 叙事动作与选段验收

## 1. 适用范围

用于有明确剧情动作、运镜、首尾构图或跨镜连续性的视频；与各渠道媒体规格校验并行。用户已有审核点时复用，不因本页另设每镜人工审批。技术成功、构图批准、动态验收与最终选用分别记录。

统计首轮通过与返修时，按实际请求目的区分静帧载体、局部补片／独立元素、动态背景和人物动作，保留原任务及失败记录。容器是视频不代表任务要交付完整动作镜头；首次实际动作产出也可能只覆盖子动作。将请求摘要、原审核及可剪区间关联到稳定制作单元，完整镜头与跨镜验收缺失时通过率记为未知，不用技术成功数、分类后的较小分母或已接入剪辑推算质量通过。

## 2. 提交前把动作变成可检查结果

每个单元记录起始状态、人物动作、摄影机运动、环境运动和结束状态。相机跟随物体跨场景、屏幕内容变化、人物交付作品等动作各自有可见证据；“全程连续运动”可补充提示词，但不保证真实执行。

核对参考职责及当前输入模式。身份图不代替造型，首尾帧不能证明中间动作，多图参考也不承诺精确首尾控制。用户要求大运镜草稿先审时先交真实运动草稿；没有运动参考可在授权能力内准备自有预演，不自动输入第三方参考片。

使用动作视频参考时，核对预检实际消费的条件帧数、时长与采样范围；上传完整视频不代表模型使用了全部动作。参考中的切镜、裁幅变化与停顿也可能影响输出，先检查真实输入接点；软视频参考不提供硬动作或固定机位保证。缩短动作参考后，另量输出的接触、离手与起步时刻；全帧消费不能证明原参考的绝对节奏被保留。若仍按目标总时长摊慢动作，不把相同参考再变速当作已证明的新控制方法。后期变速可以缩短停顿，但不能将先后释放变成同时释放，也不能修正手性或衣物错误。

制作接触动作代理时，将首帧中每只手的所属手臂、接触部位及双方躯干朝向逐一映射到代理；两掌同侧接触不能默认改成左右对称背部接触，已经转身的代理也不能覆盖尚未转身的首帧。先并看手、肩、头部与真实布景的投影；骨段可达、脚部落地和同步离手的数值通过，不证明起态、相机或遮挡已匹配。代理未匹配时留作诊断，不能因动作曲线平滑就交给模型。

定妆中的可变道具状态也属于输入核验：拔刀后仍把带刀柄的整张定妆作为外观参考，会与手中唯一刀刃冲突。保留原定妆不变，派生工作参考只去除已取走的物体或刀柄，保留服装、空鞘及身份；实际并看后绑定新摘要，不能只靠提示词要求“唯一”来消除图片冲突。

## 3. 观察原片和实际选段

完整解码后提供覆盖关键动作的帧与源时码；有播放能力时按正常速度观察动作起因、过程、结果及环境视差。抽帧间隔按动作速度决定，短促动作不能只依赖每秒一帧。无法完整播放时只报告实际检查范围。

生成片可能在中途擅自切镜。裁出可用动作前检查实际选段全部帧及每个接点，不能仅凭均匀抽样和首尾图排除内部切镜；裁切无法消除原片已经改变的背景、机位或人物。退回跨越该切镜的选段，另记保留区间及其局限，不把局部接入记成整条产物通过。

跨景别接动作时，逐帧比较前镜末段与后镜起段的头、肩、视线和接触状态。已转向后又无因回头，先检查原片未使用的起势与切点能否连续衔接；可提前切镜保留同向视线，但不能把跳过的全身转向或接触释放记为已完成。保持时长的换帧仍须核验范围外画面、原音频和工程包一致，不能因时码未变而复用过期工作包。

新增插镜的长度以实际解码帧数和时间戳为准，旧清单、容器帧数字段或时长乘帧率只作交叉核对。声明与实际不符时先修选段和时间线，不通过补重复帧凑数；拼接后检查时间戳间隔、总采样数及对白顺延。 局部调色等无变速重编码也须核对各段视频时间基准；相同 FPS 不代表相同 time_base。 音频也须核对实际编码、位深、采样率与声道；只改画面时优先复制原音频流。原声一致性不能用降位深后的解码对比证明；按源精度或音频包摘要核验。FFmpeg 返回码为零仍可能带解码错误，装配须检查错误日志或启用遇错退出，并解码实际交付文件。直接复制码流拼接前统一封装时间基准，保留真实帧数与原音轨，再查整片 PTS 和变动接点播放；全帧解码或静帧像素相等不能排除时间戳压缩及播放丢帧。插镜导致段号变化时按稳定镜头标识重定位对白，不能沿用旧数组下标。 局部修复仅影响片段前部时，先核对未变后部的真实关键帧边界；可以独立解码时直接复制其码流，并逐帧验证复制后的原画一致性，避免反复转码已认可画面。不存在可用关键帧边界时，不假称任意帧切分都可无损复制。

局部删帧使用同一份原帧到新帧映射，同时更新对白采样区间、字幕、音效、配乐停乐点、稳定镜头覆盖及便携工程；不能只改播放器时长。先确认删除区间是否包含对白或固定音效，环境声去爆音仅作用于实际接缝。已有配乐原生任务、音符请求及源文件保持不变，另记录贴片修订，检查新的声画对照确实复制当前画面；整片重建与逐句PCM比较通过后再消除工程过期标记。

服装跨镜核对须检查部件的连续覆盖：下摆仍有同色布料，不代表肩部披帛或背部衣层仍在。若新产物的缺件或道具变形已存在于实际起态参考，先将该参考排除出后续生成，保留原文件和历史批准范围；在像素输入修复前，不靠重复附加定妆图继续动作生成。 局部衣料从静帧迁移到动作时，分别检查近侧、远侧及转身遮挡；同一平面变换不能证明两侧都贴合，累计光流也可能把缺纹理衣料拉变形。遮罩外像素不变只证明修改范围，不能证明遮罩内没有越出身体或覆盖前景。

重点检查设备正背面、手部交互、车辆和入口方向、同一作品内容与跨镜道具。贯穿物若有累计要求，分别核对进入、增加和离开；不能只数尾帧而漏掉中途提前出现或重复。换角后连同回顾与屏内人物检查，不只换主镜头。

实际可剪区间需包含要求的动作，不用片尾结果代替生成过程，也不以轻推、照片溶解或黑场填补用户要求的真实动作。动画字标若只得到已成形字样，应记录“缺少拼合”，不能因首尾正确而通过。

听见命令的反应与执行命令的动作分别核验；听者近景不能充当后退、逃跑等未拍出的身体动作。 反应插镜须对应具体事件和视线目标；同一角色提前出场不能代替后续目击。复用旧区间时核对当时看向谁，必要时用同机位相机右向量与目标方位确认画面左右；不能靠镜像改变视线，因为脸部标记、持物手性和场景轴线会一起反转。新增反应不能推迟或覆盖现有的即时喊声、转头起势和接触动作。 反应延迟从实际触发事件量起，不从整段后果镜头结束量起；必要时将已有反应与原声一同插入事件之后，再接后果，保留每个源帧及其声音对应关系。重排后同步对白样本区间、字幕、事件音效和剪辑工程；同一空间的连续环境声可保持连续，不能为移动一句喊声切断整条雨声。

姓名条随当前可识别人物检查，而不只跟随对白时长：从说话者切到听者、局部裁切使人物离画时，结束该人物姓名条，避免把身份挂在另一人上。修订剪辑后，审阅页的局部入口直接定位当前连片；独立旧预览移入历史并标明已被取代，不能同时作为本轮审阅依据。字幕对白与人物姓名条分别处理，但须在实际播放器同时开启时检查空间占用；移动姓名条后同步调整受影响对白的安全区，并核对导出VTT与页面内嵌字幕一致，不能只看未显示字幕的原帧。

### 3.1 接触动作的因果证据

对切割、推送、交接、收纳等接触动作，分别检查接触建立、作用过程和接触释放的源帧区间。末态正确只证明结果可见，不证明中间动作成立。按动作补充必要的受力或遮挡证据：切绳看刃口持续接触、绳索受力及纤维破坏，不能把刀掠过后出现断口当作割开；收物看物体越过真实开口、布边形成遮挡后再撤手，不能把被另一只手挡住或末帧空手当作收好。无须为每个动作指定同一种表演，快速单次切割也可成立，但接触与结果之间必须有可辨认的因果。

若现有采样不足以分辨，先加密接触区间并看原尺寸，再判断通过或返修；无法确认时保留未验证，不以提示词、摘要或接点连续补足证据。用户否定过程时撤回该动作及其依赖接画，不撤销独立获批的其他片段。

两手均持物而其中一手还需操作布边时，先核对握持是否给操作手指留出空间；生成后沿同一手腕追踪所有手指，禁止将“原持物手还在＋另一只新手完成动作”误判为保留道具的一致性通过。局部形状修复不能放松手臂归属、服装或空间约束。

## 4. 返修与保留

指出哪段源时码不符合哪项要求，保留已正确的人物、空间、道具及字形；仅局部有错时优先修该依赖。依当前额度和审核规则执行，不给每类错误另造一套审批。无新生成必要时复用其他可用区间，但不得擅自改变锁定内容。

局部剪辑抢救先对照已批准剧本的必要事件，区分剧情要求与助手自行添加的动作设计； 线索只要求短暂看清缺角、纹样等特征时，不自动扩大成完整底面展示、翻面表演或产品多视图；先检查现有交付尺寸中的可读性。新增展示动作必须解决原要求的实际缺口，不能为满足助手自行增加的验收项反复生成。可去掉失败的附加表演，不可剪掉必需因果。裁幅只证明画内内容可用，不证明画外持物、身份或空间已修好；保留整幅退回结论，另记可用源帧、裁区与前后接点。补接行动时先回看原片中尚未使用的准备动作，例如赴窗后的转身必须连接坐窗，不能靠裁切跳过朝向变化。服装纹理疑似变化时直接并看原定妆，不凭缩略图的光滑程度判换装。 旧批准局部照片仍须核对当前完整Look；其中附带的袖口、饰物或持物状态不自动获得现行批准。道具微小缺损的局部编辑先看原尺寸真实轮廓，旧遮罩可能漏掉实际边角；可见上部参考不能证明未显示的底面，补出的几何须保留候选状态。

用户允许粗剪暂留缺项时，记录范围和依赖版本，候选可继续交接；不将例外写成缺陷修复或最终验收。编码、时长、接触表与实际动作结论一同交付，不把处理分段数当剪辑点数量。

局部表情修复先检查同一情绪状态的完整可见区间，避免只修后半段而让开头残留相反表情。扩展已有形变时扣除原区间已施加的位移，检查重叠区及交界连续帧，防止重复累加或强度跳变；保留未授权变化的五官与动作。嘴角形状改善仅是局部修正，不能据此判整段恐惧、疼痛或求生表演通过。

局部替换移动背景时，遮罩范围还要覆盖原物体的倒影、投影及其他可见影响；主体移走而旧倒影留下，不能算修好。 新增光源也须核对灯座和投射光；只清除火焰不代表原场景已恢复。补墙供区与接边须在原尺寸检查，遮罩外像素不变不能放行亮度突变或矩形补丁。水面／衣料等供区应检查实际连续帧，避免把进入供区的袖口或肢体复制到别处；首尾帧干净不足以证明中段干净。验证保护区时注明是编码前像素一致还是编码后对比，并保留原片时长、声音和淡出；合成完成后回到实际播放器检查接缝与残影。 材质区域固定在场景表面，人物遮挡单独处理；脚抬起时遮挡变化不能使同一块地板从亮面逐渐变成哑面。跨裁切镜头先恢复共同原帧坐标，再复用材质映射；固定机位也须检查实际画面位移，不能凭提示词假定纹理无需跟踪。 压低湿木高光时，颜色／亮度阈值还可能选中刀刃等金属物体；单独保护其轮廓与暗边，并检查遮挡变化，不能把整片亮部一起压暗当作材质修复。

天气后期先区分露天、遮雨区域、水下和黑场；雨线仅证明可见降雨，不证明风浪、打湿、落点与光照全部成立。粒子轨迹应跨帧连续，接触波纹限定在已核对的水面范围，不能绘到人物或栏杆上；文字层位于天气层之上，原片淡出同步作用于天气。先并看实际尺寸与最终观看尺寸，再检查连续帧，保留未解决的物理和空间问题，不以一层雨覆盖整集冒充一致性修复。

局部压制湿木高光时，先限制到确实露出的木板，避开肤色、衣物、道具与低亮细节。亮度映射须保留明暗顺序；随亮度增强的乘法压暗可能使原亮纹比邻近暗纹更黑，产生反相污斑，应退回并改用单调压缩。检查人物经过遮罩的连续帧，分别记录编码前保护区与原音轨一致性；降低亮带不等于整场材质或摄影风格已经统一。

局部材质替换先追溯当前片段实际使用的首帧及材质版本；同一工程、相机和轮廓不代表旧材质渲染可用作当前纹理的匹配基准。低匹配率时先核对来源，不直接放宽阈值。修复范围应沿实际可见表面和遮挡确定，整面纹理改变只覆盖一部分会形成新接缝；像素保护或重投影误差合格后仍须并看原图、相邻镜和完整补片边界。

基于白模或部分网格做局部材质投影时，原几何未包含的灯具、箱子等成片遮挡物仍须另行保护；投影落在木板上不代表当前像素也是木板。先并看实际合成图，检查遮挡物、完整表面边界及内部接缝，再扩展到连续帧。多个相接材质面逐个收缩遮罩可能留下旧纹理亮带；外轮廓与内部材质接边分别处理，不为抹缝覆盖真实结构。纹理尺度改善不等于整体摄影已匹配，未改善的生成供片不得因技术成功而接入。

交付可重建剪辑工程时，将媒体与分轨收齐为包内相对引用，移到独立目录实际重建；原工作区内路径存在不能证明包可移交。核对重建画面的逐帧内容及时间戳、分轨混音采样与原混音的误差，避免带声视频轨与对白分轨重复发声。浮点混音按源精度说明舍入误差，不假称逐字节相等；复制的预览与素材另用摘要验证。保留未听审、未选用和缺失配乐状态，来源追溯路径与运行依赖分开；存在透明文字素材也不证明所有当前画面都有无字底片。独立重建成功不替代目标剪辑软件的真实导入、渲染和创作验收。

若文件清单也收录验证报告，报告与来源说明全部落盘后再更新清单摘要，并回读最终磁盘文件逐项比对。先核验清单、后改写报告会使刚通过的包立即失配；只改报告时复核元数据与未变媒体摘要，无须重复生成或重跑未受影响的混音。
