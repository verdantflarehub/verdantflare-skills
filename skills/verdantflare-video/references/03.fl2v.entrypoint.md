# verdantflare-video：首尾帧条件视频（03.fl2v）

## 1. 输入与输出

- **输入**：1 张首帧图像 Artifact ID 与 1 张尾帧图像 Artifact ID（FL2VA；或仅尾帧的 L2VA）、描述起止帧之间连续动作路径与相机过渡的 Prompt、真实 `project_id`、固定 `idempotency_key` 及经核实支持首尾帧模式的 `route` 与 `model`。
- **输出**：满足起止构图约束且中间过渡物理连续的视频候选，或在当前渠道不支持硬 FL2VA 时的明确能力缺口说明与替代拆分方案。
- **公共依据**：[公共 MCP 契约](00.common.rules.md)、[公共校验与 K09 分级](00.common.acceptance.md)、[渠道差异指南](channels.md)。

## 2. 分类

- **适用场景**：上层需要严格起止构图（FL2VA，首尾帧之间生成连续路径）或向目标尾帧收敛（L2VA）。
- **Provider 与当前 Studio 开放边界**：
  - MiniMax 官方规范将首尾帧定义为 FL2VA（不同于 T2VA / I2VA / Ref2VA）；fal 公开契约中 `image-to-video` 支持可选 `image_url` 首帧与 `end_image_url` 尾帧。
  - **但当前 Studio 网关已批准契约中**：`route=fal` 仅锁定 `minimax/h3/reference-to-video`（不开放 fal I2V / FL2V）；`route=google-flow` 不接受 `purpose=first_frame` / `last_frame`；`route=higgsfield` 的 `wan3_0` 与 `seedance_2_5_draft` 亦不混用 `first_frame/last_frame`。
  - 仅当真实会话 `video.capabilities` 与创建 `inputSchema` 明确声明支持首尾帧模式（及 `last_frame` 用途）且 `configured=true` 时，方可执行 FL2V 提交。
- **不适用场景**：只需固定开场构图请转[02.i2v.entrypoint.md](02.i2v.entrypoint.md)；只需身份/造型/动作/声线参考请转[04.ref2v.entrypoint.md](04.ref2v.entrypoint.md)。

## 3. 工作流

1. **实时能力核验（强制前置）**：执行 `video_client.py check` 或读取 `video.capabilities`，核对目标 `route + model` 是否真实声明 `first_last_frame` / `image_to_video` 双帧模式及 `last_frame` 参数；若宿主未开放该模式，**立即停止提交**，向用户如实说明当前渠道能力边界，并提供“先锁定写实首帧走 I2V + 剪辑衔接”或“拆分为多段 Generation Unit”的替代方案，严禁拿纯多参考 Ref2VA 假装等价完成。
2. **首尾帧一致性与规格准备**：确认首帧与尾帧的人物身份、服装、道具、光向与空间几何逻辑连贯，分辨率与画幅满足目标渠道预检要求；按分块导入协议导入同项目并保存 SHA-256 映射。
3. **编译中间路径 Prompt**：明确写出首帧起态到尾帧落态之间的物理过渡、重心转移、视线变化与单一相机路径，避免起止跨度过大导致中段瞬移或溶解。
4. **预检、提交与恢复**：调用 `video.preflight` 核对双帧绑定与时长/画幅，`can_submit=false` 立即停止；提交后保存 `task_id`，按原幂等键与任务 ID 轮询恢复。
5. **下载、K09 分级与全段验收**：受控下载校验解码与 SHA-256，执行本机临时抽帧与 `video.rate_content`，重点核验中间过程连续性后再归档 `general` 产物。

## 4. 规范

- **严禁以 Ref2VA 冒充 FL2VA**：多图参考不承诺精确首尾帧控制，不得将普通 `reference` 图片伪装为首尾硬锁。
- **新模式准入红线**：任何新 FL2VA 渠道模式必须先具备声明式部署、领域 MCP 字段、输入校验、Provenance 与真实验收，再纳入生产调用；静态文档或上游公开 API 列表不代表当前 Studio 已开放。
- **中间过程不可省略**：首尾帧锚定在经验等级中属“中高”，首尾构图对齐绝不代表中间动作成立。

## 5. 验收

- 分别核对首帧与尾帧是否与输入参考构图、身份、服装及光线一致，同时逐秒检查中段接触表与 1 倍速回放。
- 拒绝以照片溶解、形态畸变、肢体穿模、瞬移或无因果切镜勉强拼合首尾帧的候选。
- 确认 K09 `video.rate_content` 已提交且仅 `general` 产物归档 Project；技术通过仍为候选，艺术与剪辑选用单独记录。
