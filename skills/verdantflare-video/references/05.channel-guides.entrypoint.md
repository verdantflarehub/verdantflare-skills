# verdantflare-video：渠道差异与配置指南（05.channel-guides）

## 1. 输入与输出

- **输入**：用户指定的目标渠道/模型（或待解析的宿主默认配置）、所需模式（T2V / I2V / Ref2V / 视频编辑 / 后置 2K 与插帧）、时长、画幅、参考清单及已授权预算上限。
- **输出**：经 `video.capabilities` 核验的合法 `route + model + mode` 组合、渠道专属参数边界与报价/预算字段，以及对应的渠道参考附录指引。
- **公共依据**：[公共 MCP 契约](00.common.rules.md)、[Google Flow 调用](google-flow.md)、[Google AI Studio 调用](google.md)、[Grok 调用](grok.md)、[Higgsfield 适配](higgsfield.md)、[历史 SD2 API](api.md)。

## 2. 分类

按渠道定位与默认路由规则选择入口，严禁失败后静默跨渠道切换：

| 渠道（`route`）                | 定位与专册                                                  |
| :----------------------------- | :---------------------------------------------------------- |
| `h3-fasth3` / `h3-singularity` | 5090 本地 H3，见[公共契约](00.common.rules.md)              |
| `fal`                          | 云端 H3 Ref2VA 与 SD2，见[04.ref2v](04.ref2v.entrypoint.md) |
| `google-flow`                  | Google 默认渠道，见[google-flow.md](google-flow.md)         |
| `google`                       | Google AI Studio（仅显式），见[google.md](google.md)        |
| `grok`                         | xAI Grok（T2V/I2V），见[grok.md](grok.md)                   |
| `higgsfield`                   | 会员渠道与私有 CLI，见[higgsfield.md](higgsfield.md)        |

各渠道核心规格：5090 本地 H3 默认 `h3-fasth3`（`fasth3-nvfp4` 8-NFE）、冷备 `h3-singularity`（`du-0` 4-NFE），支持 2K IC 与 RIFE 48 FPS；`fal` 含 `minimax-h3-ref2va`（480P、5–15s）与 `bytedance-seedance-2.0-reference-to-video`；`google-flow` 含 `veo-lite`/`veo-fast`/`veo-quality`/`omni-1.2-flash`；`grok` 支持 1–15s、`480p/720p`；`higgsfield` 含 `wan3_0`、`seedance_2_5_draft` 等。

## 3. 工作流

1. **渠道发现与匹配**：执行 `python scripts/video_client.py check` 或调用 `video.capabilities`，按 `route + model`（含 `models[]` 别名）`+ mode` 精确匹配能力行，确认 `configured=true`、`enabled` 与创建 `inputSchema`。
2. **核对渠道专属规则**：
   - **Google Flow（`route=google-flow`）**：凡调用 Veo / Omni 1.2 Flash 默认走此渠道；`veo-quality` 仅 `text_to_video`（`ref_cap=0`，**严禁传参考图或 `reference_to_video`**）；多图锁脸/场景用 `veo-fast`/`veo-lite`（最多 3 图）或 `omni-1.2-flash`（最多 7 图，3–15s，且唯一支持 `video_editing` 1 段 `>=3s` `.mp4` 原片 + 最多 7 图）；`omni-1.2-flash`/`veo-fast`/`veo-quality` 可选 `upscale="1080p"`（0 积分，失败降级 720p 并标 `upscale_status="fallback_original"`，`veo-lite` 不支持）；`--budget-limit` 为正整数积分。详见[google-flow.md](google-flow.md)。
   - **Google AI Studio（`route=google`）**：仅用户显式指定时使用，退役模型返回 `model_retired` 保留原错不自动切收费模型，详见[google.md](google.md)。
   - **Grok（`route=grok`）**：1–15s 整数时长、`480p/720p`，不传 `quality_profile`/种子/音频开关或 H3 标签，最长观测 24 小时，详见[grok.md](grok.md)。
   - **Higgsfield（`route=higgsfield`）**：无宿主默认模型必须显式 `--model`；`seedance_2_5_draft` 固定 `480p`、4–15s、最多 4 图 + 1 视频 R2V，不替换普通 2.5 或首尾帧；`--price-ceiling` 单独表示 Credits 上限；管理员 OAuth 与服务器 PVC 交接通过私有运行时 `scripts/higgsfield.py`（固定 CLI 1.1.26、DMIT 出口 `127.0.0.1:19081 -> openclash:1081`）执行，详见[higgsfield.md](higgsfield.md)。
3. **配置与本地环境校验**：需要校验本地环境变量或配置状态时可使用 `scripts/check-config.py` / `scripts/config.py`；历史 `install-config-macos.sh` / `install-config-windows.ps1` 仅作旧公共 API/S3 维护参考，**不是** Studio 认证修复入口。
4. **预检与提交**：按渠道能力调用 `video.preflight` 确认报价、积分/币种预算与参考限制，`can_submit=false` 立即停止。

## 4. 规范

- **严禁跨渠道参数混用**：不把 H3 的参考上限、24 FPS、`<Picture 1>` 标签或 `quality_profile` 套给 Grok、Google Flow、Google 或 Higgsfield；不把 Higgsfield 的 `--price-ceiling`（Credits）与其他渠道币种 `--budget-limit` 换算。
- **凭据隔离红线**：所有供应商 Key、会员 Token 与刷新凭据均留存服务端 Secret 或服务器 PVC，成员通过 Studio MCP Token 调用，Skill 不读取、输出或发送任何供应商凭据。
- **报价与扣费区分**：服务报价（`quoted_credits`）或预算预留不等于实际结算扣费，未知价格保留未知，不填零，不因官网促销假定免费。
- **错误透传**：`model_retired`、`authorization_required`、`limits_unavailable`、`unsupported_references`、`mode_reference_mismatch`、`quota_exhausted`、`media_contract_mismatch` 均保留原码、原因与可重试性并停止。

## 5. 验收

- 核对提交记录中的 `route`、`model`、实际能力行声明与预算/积分参数一致，确认未发生未授权静默切渠道。
- 按对应渠道附录核对产物真实 MIME、宽高、FPS、时长、SHA-256 及超分降级标记（如 `fallback_original`），并完成 K09 `video.rate_content` 提交与归档。
- 管理员执行 Higgsfield 私有 CLI 交接时，另须通过 `reconcile` 核验脱敏回执与独占锁状态，且不将私有 `.runtime/` 凭据提交 Git。
