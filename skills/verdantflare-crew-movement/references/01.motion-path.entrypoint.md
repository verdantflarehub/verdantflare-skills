# 运镜设计专员的运镜预演工作流

## 1. 输入与输出

读取画幅、起始机位、场景锚点、表演的关键动作、焦点主体、出口目标及必要落拍。交付起落幅、路线路标和时序、触发事件、跟焦对象、中途预览、可用剪接区间。

## 2. 分类

摇摄和俯仰由固定机位转动完成；平移、跟随或推进还需检查空间和前景视差。按导演给定的一镜到底、可切换镜头、或仍在探索的条件选择覆盖方式。

## 3. 工作流

1. 用两张参考画面锁起幅和落幅，在动作和音乐上标出最早能离开原主体、最晚必须看到目标的时间。这两个时刻决定允许运动的区间。
2. 画俯视路径、相机高度、朝向及焦点目标，在遮挡物、转弯和对焦交接处增加中间检查点。给加减速留时，按原速走完整段；只看首尾图会漏掉肩部遮住手的帧。
3. 对照表演的接触与分离帧。例如在两手分开之前已开始上摇，应试推迟起动、缩短路线或改变中段朝向，再核对乙抬眼时能否抵达落幅。
4. 记录第一处遮挡与解除的位置、持续区间和受影响动作。若固定视图已经遮住，回摄影与机位岗位；若移动途中才出现，沿原起落幅提出路径修订。若只能靠切镜满足时长，且导演明确一镜到底，把两种预览和各自损失交执行导演。

## 4. 规范

- 表演节拍与相机触发点采用同一时钟。先记动作触发再换算具体时间，演员节奏变化后能沿事件复查，保留原时钟版本。
- 运动的终点需要覆盖剪点之后的表情或动作。时间余量按受托剪辑区间判断。

在本单的项目、任务、轮次和输入修订中工作。接单回执注明目标、首件预估与下一检查点。把结果、已知缺口和 QC 写回本轮，引用候选文件和被检的区间。导演明确的要求若需改动，提交依据和备选。连续两次局部修正仍出现同一缺陷，暂停该方向并汇报两轮差异。按委托期限上报超时及恢复条件，等待人工意见时停止主动工时。换 Session 从本轮任务和版本恢复，正式选用由受控项目入口记录。

## 5. 验收

交付原速动态证据与遮挡区间的画格。确认关键动作从发起到完成可读，焦点转移后能看到目标，落幅能接相邻镜头；返修候选沿用同一场景锚点和表演输入，记录实际改动。
