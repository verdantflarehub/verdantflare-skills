# verdantflare-director-mv：30 秒高潮版 MV 导演与装配

## 1. 输入与输出

- **输入**：已通过 Music Gate 的批准 Master WAV 与目标高潮 30s 时码区间、歌曲/项目名称与目标画幅（如 `9:16`）、演员清晰正面肖像或已授权 World `character-image` 固定版本、用户一句话故事圣经或创意方向。
- **输出**：根 `project.json`、`treatment.md`、`visualbible.md`、两级 `review.md`、各 Block 单元 `source/` 与 `input/`（`01-character-card.png`、`02-storyboard-grid.png`、`03-scene-design.png`、`04-audio-excerpt.wav`、`manifest.json`）、批准 Shot 候选视频与接触表、Picture Lock 成片（主视频、无字幕版、字幕版、封面及元数据）。
- **公共依据**：[公共规范](00.common.rules.md)、[公共验收与审核门](00.common.acceptance.md)、[JSON 机器契约样例](schemas.md)。

## 2. 分类

- **适用场景**：聚焦歌曲 30 秒核心高潮/副歌传播版，按 8–15 秒 Block 逐段精修，采用“人物设计四视图 + 服装无脸三视图 → Character Card + Storyboard Grid + Scene Design + Audio Excerpt”四输入契约（H3 Ref2VA）。
- **不适用场景**：90 秒+ 全长 TV Version 素材池制作或 Google Omni Flash 1.2 / Seedance 2.5 多参考路线转[02.mv-tv-pool.entrypoint.md](02.mv-tv-pool.entrypoint.md)；单张角色图转 `verdantflare-image`；歌曲生成转 `verdantflare-music`。

## 3. 工作流

### 3.1 五步人机协同闭环

1. **步骤 1（项目初始化）**：打开 Studio Project 取得 `project_id`，生成领域根 `project.json`（登记至 `domain_documents`）锁定全局时钟与时码范围并 `project.commit`；旧 `project.yaml` 仅导入一次后停止维护。
2. **步骤 2（人物设计冻结）**：基于人类肖像或 World `character-image` 固定版本生成全局**人物设计胸部以上四视图**（`01-front-neutral.png` 正脸中性、`02-front-smile.png` 正脸微笑、`03-left-15deg.png` 左转 15 度、`04-right-15deg.png` 右转 15 度），过 Character Gate 后冻结写入 `visualbible.md`。
3. **步骤 3（故事圣经与 Block 拆分）**：聚焦 30 秒高潮，复用用户创意与歌词，将一句话故事圣经展开为剧情起承转合、情绪曲线、场景构想与 8–15 秒 Block 规划，再按三同定律拆分为 4–15 秒 Generation Unit。
4. **步骤 4（单元资产制作与三维一体审核）**：
   - 生成单元**角色设计无脸三视图**（`05-wardrobe-turnaround.png`：正面/左侧/背面全身，默认 7.5 头身工业基准由人类定审美，平视中长焦无透视畸变，头部只保留发型帽饰、面部无特征人台化）。
   - 用确定性脚本 `source/build/compose_inputs.go` 编译 **Picture 1 Character Card**（`2048×2048`：上区约 38% 人物四视图 + 下区约 62% 无脸三视图）、**Picture 2 Storyboard Grid**（6/8/9 格左到右、上到下，左上角微缩 `F01~F08`）、**Picture 3 Scene Design**（无人物纯景）及 `output/review/` 首尾帧条带图。
   - 按[跨镜连续性检查](https://github.com/verdantflarehub/verdantflare-skills/blob/d52d2ad317ab8cd220c03682b1a88b212b995d45/skills/verdantflare-video/references/01.t2v.entrypoint.md#跨镜连续性检查)核对相邻镜头造型、道具、方向、地标与光线，在单元 `review.md` 完成 Story Gate（角色/剧情/分镜）并回填根 `review.md`。
5. **步骤 5（提交渲染）**：AI 按三同定律与 4–15 秒 / 最多 2–3 Shot 边界组合 GU 并在单元 `review.md` 呈现 Task Manifest；过 Render Submission Gate 后冻结 `input/manifest.json`，调用 Video Skill 经 H3 MCP 渲染。

### 3.2 分级质检、装配交付与恢复

1. 取得新媒体产物后立即执行[K09 生成后内容分级](00.common.rules.md#5-生成后内容分级评估k09-强制步骤)，隐藏并阻断 `nsfw` 产物。
2. 在单元 `review.md` 执行 Shot Gate：抽 1 秒 1 帧接触表并与 `output/baseline/` 横向对比，1 倍速全片播放后追加选用/重做/否决决定。
3. 全部 30 秒区间过审后回根 `review.md` 执行 Picture Lock & Release Gate：静音内生音轨、零时码挂载批准 Master WAV、按批准 LRC 生成字幕、输出交付包并 `project.commit` 归档。
4. **迭代与恢复**：日志与缓存放受控临时目录且不入 Git；保留任务 ID、错误与恢复入口，先排查冲突不猜测已完成；不批量重命名历史资产，不把唯一原件当作垃圾删除；跨机以同一 `project_id` 打开最近修订恢复。

## 4. 规范

- **人物与角色严格分离**：人物四视图严控胸部以上、柔和漫射光、纯色中性背景、真实皮肤毛孔、无文字/边框/第二人；角色三视图强制无脸人台防两脸融合污染。
- **Picture 1 提示词防泄漏声明**：提交视频模型时必须显式声明：“Picture 1 is a reference composite: the top section defines the actress's exact facial features, eye structure, and smile; the bottom section defines her body proportions, height, and wardrobe turnaround only. The faceless mannequin head is for wardrobe reference only and must never appear in the generated video.”
- **分镜关键帧参考策略**：明确角色镜头直接用已批准 `01-character-card.png` 作底图参考（`--image`）；角色归属不明先问人类；无图像参考纯文本生成含人物关键帧一律标 `Warning`，未获人类显式批准严禁入分镜网格或渲染。
- **Picture 2 标签防泄漏**：`F01~F08` 仅表时间顺序，Prompt 显式禁止生成标签文字、边框与画中画；标签泄漏记为明确失败条件。
- **单元资产目录规范**：`units/B01/source/` 下分 `character/`、`scene/scene-design.png`、`storyboard/F01.png~F08.png`、`audio/master-clip.wav`、`build/compose_inputs.go`，全英文 ASCII 命名。

## 5. 验收

- 依次通过 Character Gate、Story Gate、Render Submission Gate、Shot Gate 与 Picture Lock & Release Gate（详见[公共验收与审核门](00.common.acceptance.md)）。
- 全部新生成图像与视频均完成 `*.rate_content` 提交且 `nsfw` 产物零泄露、零入库。
- 30 秒成片覆盖完整目标音频区间、无 `storyboard_placeholder`、无黑帧/抽搐/标签泄漏、Master WAV 严格同步、LRC 字幕无越界。
