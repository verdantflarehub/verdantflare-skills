# Grok 本机 MCP 服务安装与启动（02.install）

## 1. 输入与输出

- **输入**：维护源目录 `skills/verdantflare-agent-grok/`、本机 Python 环境、Grok CLI（`~/.grok/bin/grok.exe`）与 VS Code 扩展 **AFK Pilot**（`pawelhuryn.grok-vscode-phuryn-*`）。
- **输出**：同步到 `~/.agents/skills/verdantflare-agent-grok/` 的全局安装副本、独立虚拟环境运行时、用户数据目录下的 `verdantflare-agent-grok/service.json` 与对端智能体 MCP 注册配置。
- **技能入口**：[SKILL.md](../SKILL.md)。

## 2. 分类

| 操作分支     | 适用场景与核心动作                                                               |
| :----------- | :------------------------------------------------------------------------------- |
| 安装并注册   | 同步技能至 `~/.agents/skills/`、构建独立虚拟环境并向对端智能体注册 MCP           |
| 仅同步技能   | 仅更新全局技能副本与运行时，不改动对端 MCP 注册文件                              |
| 服务探测启动 | 通过 [launch.py](../scripts/launch.py) 探测能力（`grok_capabilities`）或启动服务 |

## 3. 工作流

1. **同步技能与注册 MCP**：在技能目录运行 [install.py](../scripts/install.py)：
   - 完整安装并注册 MCP：`python -X utf8 scripts/install.py --replace --register-mcp`
   - 仅同步全局技能与运行时：`python -X utf8 scripts/install.py --replace`
2. **服务配置与启动探测**：配置入口由 `VERDANTFLARE_AGENT_GROK_SERVICE` 指定，默认从用户数据目录的 `verdantflare-agent-grok/service.json` 读取。执行探测与启动命令，核对 `acp="read_verified"`、`afk_pilot_ui="read_verified"` 及现有会话列表：

```powershell
python -X utf8 scripts/launch.py --call grok_capabilities
python -X utf8 scripts/launch.py
```

3. **扩展与 CLI 升级后复检**：运行时跳过 `.obsolete` 动态探测最新有效 AFK Pilot 扩展版本与 Grok CLI，不锁定单一版本号；扩展或 CLI 升级后须重新运行探测校验 `~/.grok/sessions/` 目录结构与 `client-state/session-meta.json` 字段。

## 4. 规范

- **环境与安全边界**：当前适配面向 Windows、Grok CLI 与 VS Code AFK Pilot 扩展；服务为本机 `stdio`，不提供公网监听。认证由 `~/.grok/config.toml` 或环境变量管理，技能文件不保存 API 密钥，也不把凭据写入任务参数。
- **兼容基线与唯一维护源**：当前规则基于 Grok CLI `1.0.77` ACP stdio 协议与 AFK Pilot `4.15.8` 实测。技能源码在仓库 `skills/verdantflare-agent-grok/` 唯一维护，安装副本通过安装脚本同步；公开文档严禁写入本机绝对路径、用户名或 API 密钥。

## 5. 验收

- **静态检查**：在仓库内与不含兄弟技能的临时隔离目录运行 `lint_skill.py --style numbered`，并对全部 `.md` 运行 `md_format.py --check` 与 `check_md.py`，均为 0 errors。
- **单测与哈希比对**：运行 `python -X utf8 -m unittest discover -s scripts -p "test_*.py" -v` 全部通过；维护源与 `~/.agents/skills/verdantflare-agent-grok/` 逐文件 SHA-256 哈希一致。
- **协议与接入验证**：标准 MCP 客户端初始化、列出七项工具、调用 `grok_capabilities`；技能可见、MCP 已注册、真实工具可调用和人工确认分别报告。
