# 短剧生成授权与额度

## 1. 适用范围

短剧生成前先发现当前 Studio MCP 的生成控制工具及参数。这里只说明 Project 侧固定清单和恢复；人物、服装、道具、场景、声音、配乐仍按统一短剧技能准备并保存到同一项目。工具未上线、适配器未接入或额度未知时保持待确认，不改走直接媒体接口绕过。

## 2. 操作顺序

1. 固定真实 project_id、依据修订、准备摘要、对象、状态、用途和每次尝试的完整参数。预期服务版本从实际能力返回或当前工具服务事实取得，不猜测版本，不静默采用新模型或默认高质量参数。
2. 若实际工具目录包含 `project.generation_propose`，按其 Schema 保存不可变待审清单；保留 plan_id 和各 operation_id。这一步不生成、不批准、不占用生成额度。
3. 使用 `project.generation_status` 回读服务端决定、固定摘要和剩余额度。人工确认由独立受控入口完成；Skill 不索取、读取或提交账户密码来替真实项目批准额度，不把普通 MCP Bearer 或项目文件中的 approved 当作批准权限。隔离软件测试的确认不能沿用到真实作品。
4. 只有服务端批准且实际适配器覆盖本轮请求时，按 `project.generation_submit` 的 Schema 提交固定操作标识。不能附加新提示词、扩大范围、变换模型或把软件验收当作创作批准。
5. 完成后按原任务回读结果，经 Artifact 和 Project 归档候选、修改原因及固定版本；生成提交成功不表示作品已选用或已入库 World。

## 3. 重试、暂停与恢复

相同操作的重放只读取原操作，不取得新执行权。返回 unknown 或记录响应失败时，保留原 plan_id、operation_id 和已知 task_id；查询原状态，不更换幂等键、再建一份清单或重发生成来尝试修复。预占与未知调用都占额度，不能自行当作免费或已退款。

真正的新尝试须在已批准清单及阶段剩余额度内；扩大清单、模型、范围或有效期需新的真实决定。用户要求停止后可用实际提供的 `project.generation_revoke` 阻止后续执行；撤销不代表已经发出的供应商任务已取消、未收费或结果被删除。

## 4. 消费边界

以服务端实际覆盖为准。调用数上限不等于金额或 Token 封顶；客户端助手会话 Token、未接入适配器的内部模型调用、音频、视频或渲染不能被笼统写成已受控。明确费用未知项，限定必要的准备与验证，等待审核期间不继续付费生成或模型互审。
