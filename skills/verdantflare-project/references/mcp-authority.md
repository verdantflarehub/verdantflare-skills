# MCP Token 授权与恢复

## 1. 调用权限

有效 MCP Bearer Token 即调用授权，Studio 将其解析为真实用户和组织，按该用户已有权限执行。客户端不提交用户映射、不再次登录、不输入密码，也不需要独立审批令牌或生成批准清单。失效 Token、伪造身份和业务越权由服务端拒绝。

## 2. 媒体执行

按用户当前任务及已有选择，使用实际工具目录中的 Image、Video、Music 等媒体入口。项目类别、制作准备记录或作品选用状态不增加 MCP 调用审批。沿用真实 project_id、固定参考、模型渠道和任务参数；用户明确的范围、次数或费用限制继续有效，未提供的额度不能自行设为零来阻断任务。

## 3. 恢复与保存

响应未知时沿原任务 ID 和幂等键查询，不重复提交生成，不自行切换模型渠道。完成后按 Project／Artifact 契约保存候选、来源、修改记录和固定版本。调用授权、候选选用及 World 发布是各自的业务动作，生成成功不自动修改选用或发布作品。
