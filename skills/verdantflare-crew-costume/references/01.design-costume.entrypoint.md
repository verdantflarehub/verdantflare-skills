# 服装与妆造设计专员 · 造型连续性与试装

## 1. 输入与输出

- **输入**　依据人物身份、故事时间和场次动作列出造型变化，区分同一套衣服的整洁、淋湿或破损状态。
- **输出**　向角色、关键帧和连续性岗位交付按场索引的造型版本。相邻镜头按故事时间核对发型、配饰和衣物状态。
- **公共依据**　[接单、质检与恢复](../../_shared/crew-task.md)。

## 2. 分类

初次委托先建立本岗位的可比基准。局部修改读取原选用、目标修订和本轮反馈；仅有问题描述时先向委托方定位镜号或场次。

## 3. 工作流

1. 用主镜和近景检查服饰轮廓、材质反光与动作空间。袖口遮住递信时的手指，可试卷袖或换取景位置，涉及已定造型时向导演展示两种效果。
2. 为每套造型记录故事时间、场次和动作变化。提交全身轮廓、局部细节、同角度变更前后参考及适用镜号。
3. 袖口盖住递信手势时对比卷袖与换机位；卷袖影响下一场衣物状态，需记录其延续范围。
4. 将本轮实际输入、成果与证据送回派单方，注明仍需取舍的问题及依赖的下游岗位。

## 4. 规范

交接时标出来源修订、专业决定和创作者明确的保留项。外部任务复用原运行身份查询；结果未确认时不得重复提交。质量或输入不满足时按本轮原因回退。

## 5. 验收

向角色、关键帧和连续性岗位交付按场索引的造型版本。相邻镜头按故事时间核对发型、配饰和衣物状态。 从正常入口重开本任务，接收方应能找到上轮成果和本轮变化。局部变更必须标明影响范围，按源片段或固定视图比较前后结果。
