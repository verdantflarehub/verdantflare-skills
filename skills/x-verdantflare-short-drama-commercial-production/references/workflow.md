# 商业广告制作流程

## 1. Brief 与证据

记录品牌、产品版本、受众、商业目标、单一利益点、证据、媒介规格、唯一 CTA 和禁用表达。利益点与画面演示必须能对应证据；证据缺失时把声明留在 `open_questions`，只可讨论可见外观或使用动作。已有产品资产的包装结构、标签、颜色、尺寸比例与授权 Logo 是跨镜头事实。

用 Director 的广告模式输出创意母题、逐镜信息任务、`treatment.md` 与 `plan.json`。镜头顺序服从用户目标和媒介要求，不固定“一定三镜五秒”。生成单元按当前模型实际限制拆分；Video MCP 的 Ref2VA 图片不是自动首帧，不能把文档示例里的 2K/768P、first_frame 或 FL2VA 当作当前渠道通用能力。

## 2. 素材与制作

需要新产品图或分镜时通过 Image Skill 生成候选并核对外观与标签；对于高风险文字，优先使用批准的原始包装图、版式文件或后期叠加。人物与产品参考各自标注职责，角色 Look、背景和主光方向跨镜保持一致。Video Skill 负责受控 Artifact、模型/route 预检、提交与恢复；本 Skill 不改写其调用参数或私自换渠道。

## 3. 审核与交付

逐镜检查产品出现时机、演示是否真实可读、包装和道具连续性、CTA 留屏、字幕安全区、旁白与证据对应关系。声明审校记录“表达 / 证据 / 画面位置 / 结论”，无法核实标为待审，不自动判通过。对生成视频里错误的文字或 Logo，不靠反复生成冒充确定性排版；用批准素材修正并重新检查成片。保留候选版本与来源，最终发布仍由项目负责人批准。
