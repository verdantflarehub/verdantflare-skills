# 通用 HTTP(S) 下载、协议取证路由与研究主干（01.generic-http）

## 1. 输入与输出

- **输入**：HTTP(S) 文件/网页 URL、压缩包/数据集/文档直链，或待分类路由的原始分享口令文本；可选 `--mode file|media`、`--research`、`--parse-only`、`--vscode-preview` 与 `--output-dir`。
- **输出**：原始响应文件与 `manifest.json`（通用下载/研究模式），或经前置协议取证路由后的分类结果 `ParsedMediaResult`、无水印落盘媒体、`*_metadata.json` 与 100 分评测报告。
- **公共依据**：[公共规范](./00.common.rules.md)、[公共验收标准](./00.common.acceptance.md)、[下载后的分析与研究](./research.md)。

## 2. 分类

### 2.1 前置协议取证（Classification Pipeline）

在决定调用哪个解析器与下载协议前，严禁仅凭口令文案猜测媒体类型或盲调通用提取器，必须先通过 [mk_video_download.py](../scripts/mk_video_download.py)（支持 `--parse-only`）执行两步自动化取证：

1. **口令提链与首跳 302 协议探针**：运行正则 `URL_EXTRACT_RE` 剥离分享口令中的文案噪音，提取首个合法 `http/https` 链接；发起非跟随或带 Cookie 保持的首跳请求读取 `Location` 响应头，提取真实主域名 `host_domain`、路径模板（如 `/share/video/`、`/share/note/`、`/fw/photo/`）与作品唯一标识 `item_id`。
2. **远端状态树与多模态结构探针**：根据主域名请求对应轻量元数据端点（`slidesinfo`、`__INITIAL_STATE__`、`INIT_STATE`、`syndication` 或 `yt-dlp -J`），实测判定资产形态 `media_type`（`video` / `gallery` / `mixed`）、标称分辨率 `(expected_width, expected_height)` 及 CDN `Content-Length`（`expected_size`），写入 `ParsedMediaResult` 与 `*_metadata.json`。

### 2.2 一级路由决策树（按严格优先级匹配）

分类器 `classify_platform_and_category()` 按以下优先级执行，命中即终止后续匹配：

| 优先级与分类 | 路由去向                                                                            |
| :----------- | :---------------------------------------------------------------------------------- |
| 1. 空链红线  | 触发 `Gate G1` 拦截并判 `0.0` 分                                                    |
| 2. `C1` 字节 | 抖音与字节系，见 [02.douyin-media](./02.douyin-media.entrypoint.md)                 |
| 3. `C2` 社交 | 小红书与快手，见 [03.xhs-kuaishou](./03.xhs-kuaishou.entrypoint.md)                 |
| 4. `C3` 通用 | B站/微博/X/YouTube，见 [04.bili-weibo-global](./04.bili-weibo-global.entrypoint.md) |

- **空链红线**：`URL_EXTRACT_RE` 未检出合法 `http://` 或 `https://` 链接，直接触发 `Gate G1` 拦截并判 `0.0` 分。
- **`C1`（抖音与字节系）**：`host_domain` 命中 `douyin.com`、`iesdouyin.com`、`ixigua.com`、`365yg.com` 且匹配 15~22 位数字 ID，绑定 `slidesinfo` 双路与 `snssdk 1080p` 探针。
- **`C2`（小红书与快手）**：`host_domain` 命中 `xhslink.com`、`xiaohongshu.com`、`kuaishou.com`、`chenzhongtech.com` 且含 SSR 状态树（`__INITIAL_STATE__` 或 `INIT_STATE`）。
- **`C3`（开放 API 与通用）**：其余合法媒体 URL，优先匹配 `bilibili`、`weibo`、`twitter`、`youtube`，未命中移交 `ytdlp_generic`。

- 非媒体平台的普通网页、PDF、表格、JSON、数据集或压缩包直链，由 [download.py](../scripts/download.py) 按原始文件模式保存；普通站点需解析内嵌视频时传 `--mode media`，已知平台需保存原始文件时传 `--mode file`。

## 3. 工作流

### 3.1 通用文件与资料研究下载（`download.py`）

1. 确认意图：纯下载只交付文件与元数据；带“分析/总结/拆解/研究”意图时追加 `--research` 生成 `manifest.json` 与采样证据，随后按 [下载后的分析与研究](./research.md) 读取正文、页码、工作表、JSON 字段或视频采样帧并回答。
2. 执行命令：

```powershell
python -X utf8 scripts/download.py --input "<url_or_share_text>" --output-dir "./.tmp/download-research" --research
```

### 3.2 媒体三阶段主干骨架（`mk_video_download.py`）

所有媒体分类（`C1 / C2 / C3`）共享以下三阶段主干：

| 主干阶段        | 阶段名称与核心产出契约                                                          |
| :-------------- | :------------------------------------------------------------------------------ |
| `Stage 1 (CP1)` | 口令净化、短链 302 重定向追踪、平台分类路由与作品唯一 ID 提取                   |
| `Stage 2 (CP2)` | 无水印最高码率视频直链探测、非 WebP 原图图集与实况动图列表提取                  |
| `Stage 3 (CP3)` | 分块流式落盘、首帧截图提取、可选 VS Code Preview 转码与 `Gate G1 ~ G4` 门禁验收 |

1. **Stage 1**：调用 `extract_first_url()` 与 `classify_platform_and_category()` 跟随首跳 302 获取真实长链与 `item_id`。
2. **Stage 2**：转入对应平台能力入口（`02 / 03 / 04`）剔除带水印流标识（`playwm`、`!nd_dft`），锁定最高可用分辨率与完整元数据；传 `--parse-only` 时直接输出 JSON。
3. **Stage 3**：默认输出至 `./.gdrive/downloads`（可 `--output-dir` 覆盖），通过 `.part` 临时文件 256KB 分块流式落盘并原子重命名；视频自动用 `ffmpeg` 抽 `*_frame.jpg` 与 `*_cover.jpg`；指定 `--vscode-preview` 时按 `VP9 + MP3` 规则生成 `*_preview_vp9.mp4`；调用 [video_download_evaluator.py](../scripts/video_download_evaluator.py) 执行 `Gate G1 ~ G4` 校验。

## 4. 规范

- 严格遵守 [公共规范](./00.common.rules.md) 的全局物理不变量、一票否决红线、Artifact 直显边界与全链路 UTF-8 约定。
- `C1` 与 `C2` 域名严禁流入默认 `yt-dlp` 提取器，防止网页端 `403 Forbidden` 或状态树缺失失败。
- 下载用于分析研究的素材时，先读本地证据再回答，区分可见事实与推断；外部事实核查须另找独立来源并列出处。

## 5. 验收

- 通用 HTTP(S) 下载：文件非空、无 `.part` 残留、`manifest.json` 完整且按实际文件类型可读；研究回答附可核对的时间码、图号、页码或段落。
- 媒体三阶段下载：通过 [公共验收标准](./00.common.acceptance.md) 的 `Gate G1 ~ G4` 全部门禁并输出 `*_metadata.json` 与预览资产；各平台专属 `Gate G4` 阈值见 `02 / 03 / 04` 能力入口。
