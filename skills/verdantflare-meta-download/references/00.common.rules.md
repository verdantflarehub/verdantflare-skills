## 2. 全局物理不变量与一票否决红线

### 2.1 全局物理不变量（黄金标尺）

1. **零平台后期叠印水印**：视频直链必须转换为纯净源流（如 `playwm` 强制替换为 `play` 或走 `aweme.snssdk.com/aweme/v1/play/` 原画接口；小红书图片必须走 `ci.xiaohongshu.com` 无水印节点；X/Twitter 图片升级为 `?format=jpg&name=orig`）。
2. **最高可用画质优先**：当平台同时存在多档分辨率（如 `4K`、`2K`、`1080p`、`720p`、`540p`）时，必须按降序主动探测并优先落盘最高分辨率与最高码率版本。
3. **默认存储目录、原子写入与文件名净化**：媒体下载产物默认存储于 `./.gdrive/downloads`（可通过 `--output-dir` 显式覆盖；临时研究下载可输出至 `./.tmp/download-research`）；下载过程必须先写入 `.part` 临时文件，待流式传输完成且字节校验通过后方可重命名为正式 `.mp4` / `.jpg`；文件名统一按 `<platform>_<item_id>_<author>_<title>` 净化非法字符。
4. **VS Code 预览音视频编码兼容**：当输出视频需嵌入仓库 `images/comparisons/` 供 VS Code Markdown Preview 内联有声播放时，必须遵循 `-c:v libvpx-vp9 -pix_fmt yuv420p -c:a libmp3lame -b:a 192k -af "loudnorm=I=-16:TP=-1.5:LRA=11" -movflags +faststart` 转码标准。
5. **取证读盘与合规约束**：下载内容仅作合法资料保存与研究证据处理；全链路 CLI 执行与 JSON 读写强制开启 UTF-8 编码，严禁中文标题、作者昵称或 Emoji 标签乱码。

### 2.2 全局一票否决红线（`0.0` 分或封顶 `59.0` 分拦截）

凡命中以下任一红线，直接判定门禁失败（`FAIL`），严禁将残损文件作为合格交付物：

1. **红线一（带水印直链残留）**：解析出的下载 URL 仍包含 `playwm`、`!nd_dft` 等水印后缀参数，或成片四角检出平台动态叠印的水印贴片。
2. **红线二（流媒体截断或解封装失败）**：落盘视频字节数小于 `10 KB`，或与 HTTP `Content-Length` 偏差超过 `5%`，或 `ffprobe` 无法读取有效视频流。
3. **红线三（画质降级陷阱未解除）**：源作品明明提供 `1080p` 原画流（如抖音 `expected_width >= 1080` 且 `snssdk 1080p` 节点可达），却因未探测 URI 而错误下载了默认的 `540p` 低清流。

### 2.3 聊天汇报与 Artifact 直显边界规范

向用户汇报已下载的视频或图集时，须将抽取的封面/预览帧及待展示媒体同步复制到当前会话的 Artifact 目录下，使用绝对路径内联渲染图片，并将所有可点击的二进制媒体 `file:///` 链接指向 Artifact 目录副本，防止直接指向工作区 `./.gdrive/downloads/` 或 `.tmp/` 触发文本编辑器打开报错。

## 3. 兼备「文字评分规则」与「数据评分准则」的 100 分制模型

综合得分由四个正交维度相加构成，每个维度同时定义**文字评分规则**（定性描述业务质量要求）与**数据评分准则**（定量定义实测变量、梯度分值与扣分条件）：

$$\text{Score} = S_1 + S_2 + S_3 + S_4$$

| 评分维度                         | 满分与核心考核指标                                                       |
| :------------------------------- | :----------------------------------------------------------------------- |
| `$S_1$ 画质与分辨率等级`         | 满分 `40.0` 分：宽高档位 $\min(W, H)$ 与非压缩原图比例                   |
| `$S_2$ 字节完整性与容器健康度`   | 满分 `30.0` 分：文件体积、`ffprobe` 退出码与 $\Delta_{\text{size}}$ 偏差 |
| `$S_3$ 去水印纯净度与音轨完备度` | 满分 `20.0` 分：无水印 URL 参数与有效音频流 `codec_type == "audio"`      |
| `$S_4$ 元数据与预览资产完备度`   | 满分 `10.0` 分：`*_metadata.json` 字段与首帧/封面缩略图                  |

- **`$S_1$（画质与分辨率等级，满分 `40.0` 分）**：
  - **文字评分规则**：下载成品必须达到源作品公开提供的最高清晰度档位，画面锐利无马赛克模糊，不得把低码率预览流当成原画交付。
  - **数据评分准则**：测量落盘视频宽高 $(W, H)$：满足 $\min(W, H) \ge 1080$ 或 $\max(W, H) \ge 1920$ 得 `40.0` 分；$\min(W, H) \ge 720$ 得 `34.0` 分；$\min(W, H) \ge 540$ 得 `25.0` 分；其余得 `15.0` 分（纯图集全部为非压缩原图得 `40.0` 分）。
- **`$S_2$（字节完整性与容器健康度，满分 `30.0` 分）**：
  - **文字评分规则**：媒体文件流式落盘必须完整无截断，容器索引头正常，播放拖动无卡死或花屏损坏。
  - **数据评分准则**：测量实际文件大小 $\text{actual\_size}$ 与 `ffprobe` 退出码：文件 $\ge 10\text{ KB}$、`ffprobe` 退出码为 `0` 且相对偏差 $\Delta_{\text{size}} = |\text{actual\_size} - \text{expected\_size}| / \text{expected\_size} \le 1\%$ 得 `30.0` 分；$\Delta_{\text{size}} \le 5\%$ 得 `24.0` 分；$> 5\%$ 或解封装失败得 `0.0` 分。
- **`$S_3$（去水印纯净度与音轨完备度，满分 `20.0` 分）**：
  - **文字评分规则**：直链与画面须彻底剥离平台后期水印标识，且有声源视频须保留完整可解码的立体声音轨（不得出现有画无声的半成品）。
  - **数据评分准则**：直链 URL 不含任何水印参数（`playwm`、`!nd_`）得 `12.0` 分（含水印则得 `0.0` 分并触发 `Gate G1` 封顶）；`ffprobe` 检出有效音频流 `codec_type == "audio"`（或图集全部原图无损）再得 `8.0` 分。
- **`$S_4$（元数据与预览资产完备度，满分 `10.0` 分）**：
  - **文字评分规则**：同级目录必须配套保存完整的作品溯源元数据与可视化预览缩略图，支持一键检索与预览审阅。
  - **数据评分准则**：校验 `*_metadata.json` 与同级图片：非空作品标题得 `4.0` 分；非空作者昵称与 UID 得 `3.0` 分；成功生成高清首帧截图 `*_frame.jpg` 或封面 `*_cover.jpg` 得 `3.0` 分。
