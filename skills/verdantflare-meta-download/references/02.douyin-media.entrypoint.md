# 抖音与字节系无水印原画下载（02.douyin-media）

## 1. 输入与输出

- **输入**：抖音 APP 分享口令（如 `4.84 复制打开抖音，看看【...】https://v.douyin.com/xxx/`）、移动端短链 `v.douyin.com`、分享长链 `iesdouyin.com/share/video|note/...`、PC 端作品页 `douyin.com/video|note/...`、精选弹窗 `douyin.com/jingxuan?modal_id=...` 或西瓜视频 `ixigua.com`。
- **输出**：无水印最高可用分辨率（优先 `1080p` 原画）`.mp4` 视频、非 `.webp` 图文原图序列（含背景音乐 MP3 与 Live Photo 实况视频）、封面 `*_cover.jpg`、预览帧 `*_frame.jpg`、`*_metadata.json` 及 `C1` 门禁评测报告。
- **公共依据**：[公共规范](./00.common.rules.md)、[公共验收标准](./00.common.acceptance.md)、[通用下载与路由入口](./01.generic-http.entrypoint.md)。

## 2. 分类

由 [mk_video_download.py](../scripts/mk_video_download.py) 中的 `classify_platform_and_category()` 与 `parse_douyin()` 判定为 `C1` 类：

| 特征指标名    | 命中阈值区间                                                    |
| :------------ | :-------------------------------------------------------------- |
| `host_domain` | 命中 `douyin.com`、`iesdouyin.com`、`ixigua.com` 或 `365yg.com` |
| `item_id`     | 正则匹配出 15 至 22 位纯数字作品标识 `aweme_id`                 |

- **内部子形态分流边界**：当 `aweme_details[0].images` 列表长度大于 `0` 时，自动切换为 `media_type = "gallery"`（图文/实况图集模式），并将空的占位 `video_url` 置空，避免误下载无效视频流。
- **典型正例**：`7699423167659527443`（`v.douyin.com/7OV8i9Vikss/`，3 分 50 秒 `1920×1080` 横屏 AI 短剧教程视频）。
- **典型反例**：已设为私密或作者删除的链接（`slidesinfo` 返回 `filter_list` 非空且 `aweme_details` 为 `null`，触发 `Gate G1` 阻断）。

## 3. 工作流

| 步骤编号 | 步骤名称与输出产物                                                                 |
| :------- | :--------------------------------------------------------------------------------- |
| `Step 1` | 口令提链与 302 重定向解包，提取 19 位 `aweme_id`                                   |
| `Step 2` | 双路 `slidesinfo` 详情拉取与 `snssdk 1080p` 原画流探针寻优                         |
| `Step 3` | 原子流式下载、首帧提取与 `Gate G1 ~ G4` 门禁校验，输出 `.mp4` 与 `*_metadata.json` |

1. **Step 1（口令净化与 `aweme_id` 解包）**：调用 `extract_first_url()` 提取短链，以移动端 iOS 16.6 Safari `User-Agent` 发起非跟随请求读取 `Location` 响应头，从 `/share/video/<id>/` 或 `modal_id=<id>` 提取 `aweme_id`。
2. **Step 2（双路 `slidesinfo` 与 `snssdk 1080p` 原画探针）**：
   - 视频主路：`https://www.iesdouyin.com/web/api/v2/aweme/slidesinfo/?aweme_ids=%5B<aweme_id>%5D`
   - 图文/实况辅路：`https://www.iesdouyin.com/web/api/v2/aweme/slidesinfo/?aweme_ids=%5B<aweme_id>%5D&request_source=200`
   - 突破 `540p` 默认流降质陷阱：提取 `video.play_addr.uri`（如 `v0200fg10000...`），按 `1080p -> 720p -> 540p` 顺序向 `https://aweme.snssdk.com/aweme/v1/play/?video_id=<uri>&ratio=<ratio>&line=0` 发起重定向探针，锁定真实 `Content-Length` 最大的 CDN 节点直链。
3. **Step 3（一键下载与门禁验收）**：

```powershell
$env:PYTHONUTF8="1"; python scripts/mk_video_download.py --input "4.84 复制打开抖音... https://v.douyin.com/7OV8i9Vikss/" --output-dir "./.gdrive/downloads" --quality "1080p" --evaluate
```

4. **异常自愈与熔断回退**：
   - **接口双路自愈**：普通 `slidesinfo` 返回空列表时自动追加 `&request_source=200` 二次请求，仍为空时回退至 `_ROUTER_DATA` 页面解析。
   - **CDN 节点防过期重连**：抖音 CDN 直链具有时效签名（`dy_q` / `x-expires`），流式下载中途遭遇 `403` 或字节截断时，重新请求 `snssdk` 探针刷新签名地址后重试。

## 4. 规范

### 4.1 专属操作禁令

1. **严禁盲目依赖 SSR `videoInfoRes`**：抖音分享页 `window._ROUTER_DATA` 已在常规请求中移除 `videoInfoRes` 字段，严禁只写单一 HTML 正则解析器导致 `KeyError: 'videoInfoRes'`，必须以 `slidesinfo` 双路 API 为第一主干。
2. **严禁盲取 `play_addr.url_list[0]` 导致 540p 降质**：`slidesinfo` 返回的默认 `play_addr` 恒为 `ratio: "540p"` 低码率流（体积仅为原画的 $1/3$）；凡 `video.play_addr.uri` 非空，必须通过 `aweme.snssdk.com/aweme/v1/play/?video_id=<uri>&ratio=1080p&line=0` 探测 1080p 原画流。
3. **严禁图集保留 `.webp` 有损缩略图**：图文笔记 `images[i].url_list` 中混有 `.webp` 与 `.jpeg` 地址，必须通过 `select_non_webp_url()` 优先提取非 `.webp` 原图并同步保存 `live_photo_url` 实况视频。

### 4.2 专属算子参数与评分细则

| 算子或接口参数            | 固定取值与约束说明                                                            |
| :------------------------ | :---------------------------------------------------------------------------- |
| `slidesinfo` 视频端点     | `https://www.iesdouyin.com/web/api/v2/aweme/slidesinfo/?aweme_ids=%5B<id>%5D` |
| `slidesinfo` 图集端点     | 追加查询参数 `&request_source=200`                                            |
| `snssdk` 原画探针端点     | `https://aweme.snssdk.com/aweme/v1/play/?video_id=<uri>&ratio=1080p&line=0`   |
| 移动端请求头 `User-Agent` | 固定为 iOS 16.6 Safari 移动端标识，携带 `Referer: https://www.iesdouyin.com/` |

- **1080p 原画满分项**：源片 `expected_width >= 1080` 且成功落盘 `1920×1080`（或竖屏 `1080×1920`）时，$S_1 = 40.0$。
- **画质退化扣分项**：源片支持 1080p 但实际落盘流短边仅为 `540` 时，$S_1$ 降为 `25.0` 并触发 `Gate G4` 警告。
- **带水印熔断项**：下载 URL 检出 `playwm` 时，总分强制封顶 `59.0` 分并判 `FAIL`。

## 5. 验收

调用 [video_download_evaluator.py](../scripts/video_download_evaluator.py) 指定 `--category C1` 完成测量，必须同时通过 `Gate G1 ~ G3` 与以下 `Gate G4 · C1` 维度：

| 验收维度               | 关键考核要求与阈值简述                                 |
| :--------------------- | :----------------------------------------------------- |
| 去水印直链与画面纯净度 | 无 `playwm`、图集非 `.webp` 原图（违规封顶 `59.0` 分） |
| 1080p 原画分辨率对齐度 | `expected_width >= 1080` 时实测 $\ge 1920 \times 1080$ |
| 容器与字节完整性       | 误差 $\Delta_{\text{size}} \le 1\%$ 且音视频双轨完备   |
| 综合质量总分门禁       | 100 分制总分 $\text{Score} \ge 90.0$ 分                |

- **去水印直链与画面纯净度**：视频源流为无台标原片、四角及片尾无“抖音号：xxx”动态贴片或推广黑屏帧；`video_url` 不含 `playwm`，图集 `image_urls` 全部经 `select_non_webp_url()` 过滤为非 `.webp` 原图。
- **1080p 原画分辨率对齐度**：`expected_width >= 1080` 时 `ffprobe` 实测 $\max(W, H) \ge 1920$ 且 $\min(W, H) \ge 1080$（$S_1 = 40.0$）。
- **容器与字节完整性**：与 CDN `Content-Length` 相对误差 $\Delta_{\text{size}} \le 1\%$，`ffprobe` 检出完整音视频双轨（$S_2 = 30.0$）。
- **综合质量总分门禁**：$\text{Score} \ge 90.0$ 分（高清 1080p 完整交付标准分 `100.0` 分）。
- **人工终审核对清单**：核对画面首尾及四角无水印贴片与黑屏推广帧、画质为 1080p 原生锐利画质、人声/配乐与画面口型动作同步。
