规范版本：rubric v1.0

## 2. 规范定位与版本

### 2.1 职责边界

本规范只回答“一个生成结果是否属于 18+（nsfw）”。标记字段、存储位置、过滤、撤销与本机开关由内容分级契约规定，本规范不重复定义。

- 规范由人类修订和调整；AI 评估者只按当前版本执行，不得自行扩展、放宽或收紧判定标准。
- 评估由 Skills 指导的 Agent 在生成完成后执行（方式 B），结果通过对应 MCP 的 `*.rate_content` 工具提交；判定为 `general` 的结果也提交，用于留下“已评估”记录（见[生成后内容分级评估步骤](content-rating-step.md)，H1 R6 已确认）。
- 每次评估与标记必须记录所用规范版本（`rubric_version`），便于规范修订后追溯和抽样复评。
- 人工撤销是人类对单个产物的最终决定；同一产物版本撤销后，AI 不再依据本规范重新标记。

### 2.2 版本号规则

版本号采用 `rubric v<主>.<次>` 形式，当前版本为 **rubric v1.0**。

- **主版本递增**：分级档位、判定类别的增删或判定倾向改变，可能使同一内容得到不同结论。
- **次版本递增**：措辞澄清、补充边界案例或误判场景，不改变既有结论。
- 规范版本变化不触发对存量产物的自动复评；是否复评由人类在修订记录中决定。

## 3. 分级定义

分级只有两级：

| 分级 | 含义 |
| --- | --- |
| `general` | 不含第 3.1 节所列成人内容，可在默认状态下显示 |
| `nsfw` | 含第 3.1 节所列任一类成人内容，属于 18+，默认完全隐藏 |

### 3.1 nsfw 判定类别

只要生成结果中出现以下任一类别，即判为 `nsfw`：

- **S1 露骨性内容**：以引起性兴奋为主要目的的画面、声音或文字。
- **S2 性行为描写**：直接呈现或具体描写性行为、性接触或模拟性行为，无论写实或卡通风格。
- **S3 生殖器官或性器官裸露**：生殖器官清晰可见，或以性化方式呈现的裸露胸部、臀部。
- **S4 性化强调**：虽未完全裸露，但以特写、姿态、透视或遮挡方式明显突出性器官、性特征或性暗示动作，整体意图为性化。
- **V1 极端血腥暴力（H1 已确认计入）**：露骨呈现肢解、严重创伤细节、虐杀等极端血腥内容。

### 3.2 不计入 nsfw 的内容

以下内容在不触发第 3.1 节类别时判为 `general`：

- 一般性的亲密表达，如拥抱、亲吻、牵手，且无性行为或性化强调。
- 非性化的日常着装，包括泳装、运动服、内衣广告式的常规展示（见第 5.2 节）。
- 非露骨的动作、打斗、战争场面，以及不展示伤口细节的一般暴力。
- 对性、健康、生育的知识性、医学性陈述，且不含露骨描写。
- 粗口、脏话本身不构成 nsfw；与性行为描写结合时按 S1、S2 判定。

## 4. 按媒体的判定标准

各类媒体统一套用第 3 节类别；本节说明每类媒体的评估输入与判定方式。评估者只能依据实际可获得的输入判定，无法获取的部分在 `reasons` 中注明。

### 4.1 图像

- **评估输入**：生成的图像本身，以及生成时的提示词与标题（按第 4.4 节同时评估）。
- **判定方式**：对整张图像按第 3.1 节类别逐项检查；多图批量生成时逐张判定，每张独立分级。
- **注意**：小尺寸、局部或背景中可辨识的生殖器官裸露同样计入 S3；风格化、动漫、雕塑感渲染不改变判定。

### 4.2 视频

- **抽帧评估**：按固定间隔抽帧（不少于每 2 秒一帧且全片不少于 8 帧，具体执行见[生成后内容分级评估步骤](content-rating-step.md)），并补充镜头切换处的关键帧；任一帧触发第 3.1 节类别即判 nsfw。
- **整体评估**：结合帧序列判断连续动作，单帧不露骨但连续画面构成性行为或性化动作时按 S2、S4 判定。
- **音轨**：视频含音轨或配音时，按第 4.3 节同时评估；画面、音轨、提示词任一项判 nsfw，则整个视频判 nsfw。
- **注意**：抽帧存在漏检风险，评估者须在 `reasons` 中记录抽帧数量；无法完整抽帧时按第 5.1 节倾向处理。

### 4.3 音频与语音

- **评估输入**：语音转写文本、歌词（音乐类按第 4.4 节）、生成提示词，以及可识别的非语言声音内容。
- **判定方式**：
  - 转写文本按第 4.4 节文本标准判定。
  - 可识别的、以性兴奋为目的的非语言声音（如模拟性行为的声音）计入 S1、S2。
  - 无法转写或无法识别的部分不作推断，依据提示词与可识别部分判定，并在 `reasons` 中注明。
- **注意**：语气、音色本身（如低沉、气声）不构成 nsfw；仅在内容指向性行为时计入。

### 4.4 歌词与文本

- **适用对象**：生成提示词、反向提示词之外的正向描述、作品标题、歌词、配音台词与字幕。
- **判定方式**：
  - 文本直接、具体描写性行为、性器官或以性兴奋为目的时计入 S1–S3。
  - 隐喻、双关仅在上下文明确指向性行为时计入；含义模糊的按第 5.1 节处理。
  - 提示词明确要求生成第 3.1 节内容时，即使生成结果未完全呈现，也判为 nsfw（见第 7 节 O3）。
- **注意**：反向提示词中出现的成人词汇用于排除相关内容，不作为 nsfw 依据。

## 5. 边界案例与处理原则

### 5.1 不确定时的倾向

**不确定即标 nsfw。** 理由是：误标只造成默认隐藏，人类开启显示后可在 Studio 撤销；漏标则会让 18+ 内容在默认状态下暴露，且 MCP 不提供撤销以外的补救手段。

- 评估者在 `reasons` 中写明不确定的原因，便于人类撤销时判断。
- 本倾向已由人类在 H1 确认（见第 7 节 O2）。

### 5.2 常见误判场景

以下场景容易被误判，评估者按所列原则处理：

- **艺术作品**：古典雕塑、名画风格中的裸体，若生殖器官清晰可见仍计入 S3；仅有非性化的人体轮廓、无性器官细节时判 general。艺术风格不作为豁免理由。
- **医学与教育**：解剖图、医学插图、健康科普内容，以知识表达为目的且无性化处理时判 general；若生殖器官清晰呈现，首版按 S3 判 nsfw（见第 7 节 O4）。
- **泳装、运动与内衣**：常规泳装、运动服、内衣的正常展示判 general；姿态、镜头明显性化时按 S4 判定。
- **哺乳**：非性化的哺乳场景判 general。
- **卡通与非人类角色**：拟人化角色按人类标准判定；风格化不降低判定标准。
- **动作与恐怖题材**：一般打斗、惊悚氛围判 general；露骨血腥细节按 V1 处理。
- **亲密场景**：亲吻、相拥判 general；出现性行为暗示的连续动作按 S2、S4 判定。

## 6. 评估输出格式

每次评估产生一条 JSON 结果，供 Skills 决定是否调用加标记工具，并由各应用按契约保存。字段语义以内容分级契约为准。

```json
{
  "rating": "nsfw",
  "rubric_version": "rubric v1.0",
  "evaluator_model": "<评估所用模型标识>",
  "reasons": ["S3：图像中可见生殖器官裸露"],
  "evaluated_at": "2026-10-23T12:00:00Z"
}
```

| 字段 | 要求 |
| --- | --- |
| `rating` | 只能为 `general` 或 `nsfw` |
| `rubric_version` | 本次所用规范版本，如 `rubric v1.0` |
| `evaluator_model` | 执行评估的模型标识，不含账号或密钥 |
| `reasons` | 简要摘要列表，引用类别编号，判 general 时可写“未触发类别” |
| `evaluated_at` | ISO 8601 UTC 时间 |

- `reasons` 使用克制的类别描述，不复述露骨原文、不引用歌词或台词原句。
- 输出不得包含媒体原文件、媒体内容的 Base64 或下载链接、凭据、令牌、真实用户名或主机名。
- 产物标识（如 Artifact ID）由调用方按契约关联，不写入本结构。

## 7. H1 确认结论（2026-10-24，计划 R6）

以下事项已由人类在 H1（2026-10-24）确认作为 `rubric v1.0` 正式规则：

- **O1 极端血腥暴力是否计入 nsfw**：确认计入（类别 V1），因为本系统只有 `general` 与 `nsfw` 两级，不计入则此类内容会在默认状态下显示。
- **O2 不确定时的倾向**：确认采用“不确定即标 nsfw”，理由见第 5.1 节；误标率在 N3.2 真实样本中统计。
- **O3 提示词意图与生成结果不一致**：确认提示词明确要求成人内容时即判 `nsfw`，即使生成结果未完全呈现。
- **O4 医学与教育内容中的生殖器官**：确认首版仍按 S3 判 `nsfw`，由人类按需撤销。
- **O5 视频抽帧密度**：确认不少于每 2 秒一帧且全片不少于 8 帧，另补镜头切换处关键帧，经 N3.2 误判统计校准。

## 8. 不处理的范围

- **真人形象授权与未成年人拦截**：按用户 2026-10-23 决定（计划审批记录 R4）暂不讨论，本规范不作规定，也不在 H1 评审；恢复讨论时另列任务。
- **标记存储、过滤、撤销与本机开关**：由内容分级契约规定。
- **违法内容的拦截与上报**：不属于分级范畴，本规范不作规定。
- **不经过 Skills 的生成调用**：方式 B 下不会被自动评估，此局限由契约记录，本规范不提供补救流程。
