# verdantflare-music：RVC 换声、人声训练准备与保真返工

## 1. 输入与输出

- **输入**：已选定完整歌曲或对唱基线（`Demo_Selected`）、已批准人声模型（实际模型 ID）或 1–20 个获授权原始人声音频 Artifact；混音局部换声另需原人声、伴奏及逐句 `start/end/role`/歌词/置信度。
- **输出**：分轨（`instrumental.wav`、`vocal_dry_original.wav` 及可选 `vocal_wet_original.wav`/`vocal_reverb_original.wav`）、训练准备产物（`prepared-XX.wav`、`voice-training.wav`、`voice-segments.zip`、`voice-preparation-report.json`）、新模型包（`.pth`、`.index`、`validation.wav`、`voice-model.json`）、转换干声 `vocal_dry_cloned.wav`、等响度 A/B 试听与换声报告。
- **公共依据**：[公共规范](00.common.rules.md)、[公共工作流与预检](00.common.workflow.md)、[公共验收与审核门](00.common.acceptance.md)。

## 2. 分类

- **人声训练材料准备与训练**：用户提供 1–20 个获授权原始录音，经 `voice.prepare` 确定性处理与人工材料审核后调用 `voice.train` 生成新模型 ID，过审核点 3 后可登记至 World/Music。
- **标准单主唱分轨与换声**：对 `Demo_Selected` 执行 `stems.separate` → `voice.convert`（复用既有已批准模型时不重复审核点 3，分轨技术通过后直接转换至审核点 4）。
- **单歌手换声保真与混音返工**：在已通过听审的完整歌曲或对唱基线上替换指定歌手声线，保留原编曲、另一歌手、和声、叠唱与空间细节；用户指出换声后变薄时从已有资产定位返工，不默认重生成候选、重训模型或重做对齐。

## 3. 工作流

### 3.1 人声训练准备与建库

1. 将获授权原始录音归档到 `<创作者>/voice/recordings/`，调用 `voice.prepare(project_id, audio_asset_ids)`（1–20 个同项目唯一 Artifact ID，按合并顺序，禁传路径/URL/Base64）。
2. 服务执行固定无参处理：40 kHz、16-bit、mono PCM WAV；峰值 `<= -2 dBFS`；`-50 dBFS` 判静音，连续 `>= 1s` 切割，连接处保留约 `0.8s`，头尾静音 `<= 1s`，`< 0.2s` 孤立毛刺按静音处理，保留短停顿与呼吸。**严禁在准备阶段做 AI 修音、音高校正、降噪、压缩、共振峰改变或生成式增强**。
3. 将 `voice-training.wav`、逐来源 `prepared-XX.wav`、`voice-segments.zip` 与 `voice-preparation-report.json` 提交人工材料审核（`automatic_status: passed` 不自动跳过 `review_required=true`）。
4. 仅在明确批准 `voice-training.wav` 后调用 `voice.train`，得到不可覆盖的新模型 ID、权重、索引与验证音频，归档至 `<创作者>/voice/models/<模型ID>/` 并过审核点 3；确认可跨项目复用时以 `voice-model.json` 提交后由上层 `world.register(asset_type="voice-model")` 创建固定版本（原始录音与授权证据留来源 Project）。

### 3.2 分轨、转换与保真返工

1. 对 `Demo_Selected` 调用 `stems.separate` 得 `instrumental.wav` 与 `vocal_dry_original.wav`（如返回 `vocal_wet_original.wav`/`vocal_reverb_original.wav` 一并保存 ID，但绝不标为独立和声）；选定候选后先记录需保留的和声/叠唱、空间尾音、乐器瞬态与铺底。
2. 核对分轨格式与时长（无阻断问题直接用已批准模型执行 `voice.convert` 得 `vocal_dry_cloned.wav` 并完成[K09 分级](00.common.rules.md#5-生成后内容分级评估k09-强制步骤)），进入审核点 4。
3. **单歌手局部换声（完整歌曲/对唱基线）**：按[对唱与合唱工作流](03.duet-ensemble.workflow.md)运行 `audit_performance_voice_source.py` → 独唱直取、同唱先分离核串音 → 用 `replace_singer_in_mix.py` 或 `replace_performance_duet_voice.py` 短淡化替换 → 与上一版获认可混音做等响度 A/B。
4. **换声变薄与层次返工**：优先用原工程独立主唱/和声/乐器轨，或经授权分轨提取并逐条单听检查原唱泄漏、错词、相位与对齐（泄漏明显不混入，禁把原湿人声叠回新主唱）。仅替换主唱为批准转换干声，通过音量自动化、适度 EQ/压缩、共享空间效果（从新歌手生成，不跨入另一歌手独唱句）与伴奏避让融合；若 `mix.master` 支持 `backing_vocal_asset_id` 与 `backing_gain_db` 可传入已审独立和声。先出 1 版目标试听（确需对比再出第 2 版），等响度 A/B 选定后转[05.redraw-master.entrypoint.md](05.redraw-master.entrypoint.md)出终版母带。

## 4. 规范

- 换声只改变已唱对的声线，不能凭空补歌词、修源录音跑调或造第二位歌手；角色窗口轨不等于可独立重混干声。
- 定位频带差异时先查新旧伴奏再查转换人声咬字/齿音/声码器伪影，严禁仅因频带差盲目提亮高频放大缺陷。
- 核对部署能力边界：旧版双轨 `mix.master` 无法独立保留和声，新增湿人声归档也不等于多轨混音已可用；能力不足时先披露缺口与替代方案，不重复双轨混音冒充改善，不擅自升级部署。
- 保留原版本与所有中间资产，新试听与母带使用新版本号，不覆盖旧资产。

## 5. 验收

- **训练材料审核**：核对同一获授权目标人物、无伴奏/串音/底噪/爆音/削波/错切、朗读/旋律/快句/说唱/强弱与高音覆盖、F0 分布与试听一致；仅允许批准、剔除重备、补充重备或终止。
- **审核点 3 与 4**：新模型过审核点 3（既有批准模型直接复用）；转换干声与原始干声逐段对比快句、连续辅音、副歌高音与句尾气声，无不可辨识吞字或持续金属音，且已完成 `music.rate_content`。
- **保真 A/B**：等响度对比原候选与旧母带，确认未替换区、交接、和声/叠唱、空间尾音与编曲瞬态成立；人耳听审通过才进终版母带。
