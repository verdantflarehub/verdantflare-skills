# 编曲现代电子审核规范

本规范是现代电子项目的第五级门禁，只在编曲通用审核通过后执行。它审核电子律动、声音设计、段落能量与人声空间，不以预设音色、低频轰鸣、上升音效或 drop 标签代替编曲发展。

## 适用边界

- 适用于现代 electropop、synthpop、future bass、house 影响的流行电子、轻度 bass music 及相邻的人声电子作品。
- Techno、trance、drum and bass、dubstep、ambient 等具有独立节奏和结构规则的项目，应先明确子风格；不能把所有电子语汇同时堆入一首歌。
- 电子元素作为辅助时，以已批准的主风格规范为主；只有合成音色、鼓机或 sidechain 不足以把作品判定为现代电子。

## Groove 与低频

- 明确核心拍感、底鼓落点、军鼓或 clap 位置、hi-hat 密度与 swing。四拍底鼓、半拍律动、切分或 breakbeat 都必须与歌词重音和段落功能相容。
- Kick 与 bass 的时值、包络和频段职责清楚。Sidechain 用于腾挪和呼吸，不以过度抽吸掩盖低频冲突。
- Sub、mid-bass 与和声低音不能长期重复同一功能。主歌可减少延音或低频层，副歌再扩展重量；从 Intro 起持续满低频会消耗高潮余量。
- Percussion、clap、snap、top loop 和 glitch 只在建立律动身份或换段时加入，不把每个高频空隙填满。

## 声音设计与声部分工

- 至少定义一个核心音色身份，例如 synth motif、bass gesture、pluck、arp、vocal chop 或质感纹理；应说明节奏、音区或段落职责，而不是罗列预设名称。
- Pad、lead、pluck、arp、吉他、钢琴与人声按音区和节奏密度分工。多个宽立体声合成器不得长期占据主唱中高频。
- 音色变化服务结构：滤波、包络、失真、颗粒、重采样或自动化需要对应蓄力、释放、抽离或回收，不能作为无方向的持续运动。
- Vocal chop 或切片可以承担 Hook、回答或纹理，但不得让语义不明的重复切片遮蔽正式主唱与标题句。

## Build、Drop 与歌曲结构

- 人声歌曲不强制设置 drop。若设置，drop 必须延续歌曲的旋律、和声或节奏身份，不能像拼接另一首器乐作品。
- Build 通过鼓组密度、和声悬念、音区、滤波、留白或节奏缩减中的多项协同蓄力；白噪上升、军鼓滚奏和 pitch riser 不能单独承担全部发展。
- Drop 或 Chorus 的冲击来自低频进入、主题 Hook、瞬态、频宽和前段留白共同作用，不以总响度突然增加代替结构释放。
- 第二次 Chorus/Drop 应有可识别变化，例如反旋律、bass variation、鼓组替换、声部抽离或回答句；不能复制粘贴后只增加音轨。
- Bridge/Breakdown 应提供真实动态或和声对比，并为最终高潮保留重新进入空间。Outro 需完成滤波回收、动机终止、延迟尾音或明确停拍，不得在高能循环中突然截断。

## 人声、和声与可唱性

- 主唱始终具有清楚的音高中心、歌词可懂度和呼吸空间。Formant、vocoder、pitch effect 或 stutter 是设计层，不替代主唱表演。
- Chorus 的打开优先结合旋律音区、长短句、背景和声与电子 Hook；不要因为编曲密集而迫使主唱全程强混声或持续高音。
- 复杂和弦、bass note、arp 与 vocal melody 的音级关系必须相容。为制造未来感频繁叠加色彩音，却造成主旋律失去支点，属于需要修改的问题。
- 自动调音可以作为美学选择，但不能掩盖不可唱旋律、错误咬字或音域超限。

## 动态、空间与成品质感

- 保留 kick、snare、主唱与核心 Hook 的瞬态层级。Limiter 和总线压缩不得把 Verse、Build、Drop 与 Outro 压成同一响度平面。
- 低频保持中心稳定；宽度优先来自中高频和声、延迟或纹理。低频过宽、相位抵消或 mono 后核心消失属于阻断风险。
- Reverb 与 delay 按段落自动化，主唱主体清楚，尾音可在空隙展开；持续大空间不能吞没节奏边缘。
- 高亮音色、失真与空气感应控制累积，避免长时间高频刺耳或每层都追求最大亮度。

## 阻断条件

未明确电子子风格和核心拍感；Kick 与 bass 持续冲突；所有段落使用相同鼓型、低频和音色密度；Build 只靠上升音效；Drop 与歌曲主题脱节或只靠响度；预设和效果堆叠却没有核心音色身份；人声被宽合成器、vocal chop 或过度效果遮蔽；全曲过度 sidechain、压缩或限幅而失去动态；结尾停在未解决的高能循环，均为阻断。无阻断项才能汇总五级预审报告。
