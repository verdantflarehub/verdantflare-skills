# verdantflare-music：局部重绘、歌词对齐与母带收尾

## 1. 输入与输出

- **输入**：局部重绘需完整 16-bit/24-bit 整数 PCM WAV 源 Artifact、起止秒数（区间 `<= 60s`）、可听目标说明、区间批准歌词、`vocal_language`、区间外保持边界与交叉淡化秒数（`0.05–3.0s` 且 `<=` 区间一半）；歌词对齐与母带需已批准转换干声 `vocal_dry_cloned.wav`、伴奏 `instrumental.wav`、去标签批准歌词与批准 BPM。
- **输出**：完整重绘歌曲 `Demo_Redraw_<修订号>.wav`；UTF-8 毫秒级 `Aligned_Lyrics.lrc`；最终母带 `Final_Song_Master.wav`（48 kHz/24-bit 立体声）、`<创作者显示名>-<歌曲名>.mp3`（320 kbps）与 `<创作者显示名>-<歌曲名>.lrc`。
- **公共依据**：[公共规范](00.common.rules.md)、[公共工作流与预检](00.common.workflow.md)、[公共验收与审核门](00.common.acceptance.md)。

## 2. 分类

- **有界区间局部重绘（`music.redraw`）**：仅替换完整歌曲中的有限时间区间（尾奏、单句旋律、局部编曲或局部演唱），逐帧保持区间外音频不变；后端为 ACE-Step 1.5 `repaint`（`chunk_mask_mode=explicit`）。
- **保留人声、替换伴奏的重编检查**：保留已认可演唱而重写伴奏时的音乐一致性（和声、拍点、乐句）核验分支。
- **歌词对齐与母带收尾（阶段 3）**：执行 `lyrics.align` 与 `mix.master`，完成格式、响度、True Peak、K09 分级与审核点 5 终审交付，以及全链路定向返工路由。

## 3. 工作流

### 3.1 局部重绘执行流程

1. 预检确认 `workflow.preflight(workflow="redraw", require_local_redraw=true)` 返回 `ready`，且版权、人声与 ACE-Step 模型许可已确认。
2. 回读实际工具 Schema：Music MCP 0.12.0+ 须先调 `music.conditioning_check` 检查 ACE caption `192-token` 与格式化歌词 `1800-token` 预算（0.12.1+ 须确认结构化 `valid=true`，超限则精简可听目标，不让后端静默截尾；此限制不用于 Music3）。
3. 调用 `music.redraw` 传入项目 ID、源 Artifact ID、`start_seconds`/`end_seconds`、重绘说明、区间歌词、`vocal_language`（日语为 `ja`）、递增修订号、`seed`、`crossfade_seconds`、`preservation_mode` 与 `edit_strength`：
   - `conservative`：修尾音、接缝或轻微演唱问题，优先保原旋律配器。
   - `balanced`（默认）：允许调整目标区间演唱或编曲，`edit_strength` 范围 `0..1`（从 `0.35–0.6` 起步）。
   - `aggressive`：明显重写目标区间（会关闭后端源注入与融合，仍不改区间外内容）。
4. 下载完整歌曲 `Demo_Redraw_<修订号>.wav`，核验采样率/声道/位深/总帧数与源一致、双拼接边界无爆音/静音洞/拍错/声像跳变，完成[K09 分级](00.common.rules.md#5-生成后内容分级评估k09-强制步骤)后重进审核点 2。若重绘在分轨/转换/对齐/母带之后发生，下游 Artifact 全部失效须从分轨重做，旧资产保留。

### 3.2 保留人声、替换伴奏约束

先固定演唱来源并依据实际素材建立旋律、拍点/速度、和弦换位及分句时间线；重绘不保证区间内旋律和弦一致，不得仅凭提示词“保留和弦”认定成功。须用诊断混音核验音符与和弦、重拍相位、换和弦时间、句尾解决与接缝再实际合听，缺失约束或听审能力时停下披露，不把未匹配审核的诊断混音反复丢给用户挑错，否决版本不得再作基线。

### 3.3 歌词对齐、母带与定向返工

1. **歌词对齐**：以 `vocal_dry_cloned.wav` 与去除 Music3 段落标签和空行的批准歌词调用 `lyrics.align` 得 `Aligned_Lyrics.lrc`，核验行数、逐行文字、严格递增毫秒时间戳且不超实际人声时长；失败时自主排查修复，禁用原曲 LRC、线性缩放或手工伪造。
2. **混音母带**：按当前 MCP 签名调用 `mix.master`（传 `instrumental.wav`、`vocal_dry_cloned.wav`、已校验 LRC 文本、批准 BPM；响度与 True Peak 为检查目标，不虚构参数），下载交付目录直接命名为 `<创作者显示名>-<歌曲名>.mp3/.lrc`（不留 `Final_Song.mp3/.lrc` 兼容副本），完成 K09 分级后进审核点 5。
3. **全链路定向返工路由**（绝不重复已批准且无关的昂贵阶段）：
   - 企划/歌词/方向问题 → 回[01.song-compose.entrypoint.md](01.song-compose.entrypoint.md)（改批准方向或歌词须重过审核点 1）。
   - 旋律/编曲问题 → 保留企划重生成候选过审核点 2；有界区间且后端可用则用 `music.redraw` 过审核点 2。
   - 分轨污染 → 仅重做 `stems.separate`；训练材料缺陷 → 调来源重做 `voice.prepare` 与材料审；音色不像 → 补录音新 ID 重训过审核点 3。
   - 转换失真 → 调参仅重做 `voice.convert` 过审核点 4（原干声已吞字则回审核点 2）。
   - 字幕时间问题 → 仅重做 `lyrics.align`；响度/峰值/编码 → 仅重做 `mix.master`；人声融合或层次流失 → 按[04.voice-replace.entrypoint.md](04.voice-replace.entrypoint.md)返工；均重过审核点 5。

## 4. 规范

- 当前 Music3 不支持参考音频、续写或区间条件，严禁用 `music.generate` 冒充局部重绘；ACE 只编辑既有区间，不新增主歌或填满整曲；后端不可用时披露并给出留现版/换候选/整曲重生成选项。
- 区分后端 `preservation_mode`（latent/WAV 融合）与 MCP `crossfade_seconds`（最终 PCM 局部融合），不混为一谈；不覆盖源 Artifact。
- 等长、同源人声哈希、无削波及播放成功均不是音乐一致性证据。

## 5. 验收

- **局部重绘**：输出完整可解析 PCM WAV，格式与总帧数同源、区间外逐帧不变、双边界无异常、目标区间问题解决、K09 分级已提交并过审核点 2。
- **母带交付**：满足[公共规范第 3 节](00.common.rules.md#3-成品技术规范)（48 kHz/24-bit WAV、320 kbps MP3、`-14 ±0.5 LUFS`、`<= -1.0 dBTP`、时长一致、UTF-8 递增 LRC）、K09 分级已提交且通过审核点 5 人耳终审后归档。
