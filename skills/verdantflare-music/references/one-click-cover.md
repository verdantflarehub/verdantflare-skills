# 一键无曲谱翻唱

## 用途

使用参考音频、选定风格和匹配歌词生成翻唱候选，但不把自动提取的曲谱作为硬约束。模型或转换链可以改变旋律、节奏、编曲和歌手表现。

## 输入

- 用户有权处理的参考音频。
- 与目标演唱逐行对应的歌词。
- 目标风格、速度、调性倾向和人声模型/参考音色。
- 可选的“保留原编曲”或“允许重编”开关。

如果歌词不完整、参考演唱漏字或男女声部混在一条轨道中，先停在源素材检查，不用翻唱模型补歌词。

## 输出

- 导入后的参考音频 Artifact。
- 伴奏、人声源和（若可得）干声分轨。
- 翻唱候选、歌词对齐文件、审核报告和最终母带。

## 执行顺序

1. 按 `preflight.md` 检查授权、音频流、模型 ID 和实际后端签名。
2. 导入并计算 SHA-256；需要保留原编曲时运行 `stems.separate`。
3. 检查源人声的歌词、音准和完整覆盖，再执行 `voice.convert` 或实际可用的翻唱后端。
4. 逐段对照原曲检查歌词、旋律、人声身份、编曲变化、残留和削波。
5. 通过审核点 4 后才对齐歌词和制作母带。

## 能力边界

- 不输入曲谱不代表“保持原曲旋律”；它是无曲谱约束的翻唱/重演绎。
- 只有一条混合歌曲时，UVR/SVC/RVC 不能保证可靠分出不同歌手，也不能修复源录音的错词或跑调。
- 模型生成成功或自动转写正确不能替代逐句人耳验收。
