# 影视与宣传片器乐配乐

## 1. 先看内容，再写配乐要求

用于已有剧本、画面或时间线的器乐配乐，不套歌曲的歌词、歌手训练和换声流程。沿用当前主方案与用户已批准声音方向；未要求配乐时不自动进入生成。

按实际画面写内容映射：段落与时长、观众此时理解的内容、情绪和能量、旁白占用、需要的起音／转折／重击／留白。解释“恢弘”“神秘”“科技”对应的声音结构，例如低弦厚度、铜管展开、电子纹理和节奏密度；科技题材不必全程强鼓点，案例可读性和节目高潮需有层次。

参考分析分别记录实际听到的配器与表现、自动估计的节拍和未知项。能试听时将候选放进相应画面及旁白上下文，必要时等响度对照；不能以提示词相似或独立听起来激昂判定贴片。未实际听审就保留待审，不编造听感。

## 2. 生成前的具体编排

每条cue记录目标画面区间、最低可用连续长度、所需尾奏、段落能量、旁白避让、共同音色与允许的连接方式。选择单曲还是多cue服从用户目标和实际能力，不固定所有宣传片为三段或同一BPM。

用户要求纯器乐时明确无人声、演唱、哼唱、合唱、念白及人声切片。歌词字段如后端需要，只按当前Schema与已验证接口传器乐标签；完整编配要求写其支持的风格说明字段，不把旁白或故事说明放成歌词。独立生成不保留参考旋律；只供分析的参考不上传为生成输入。

当前 `music.generate` 使用 `project_id/lyrics/instructions/candidate_number`，可选 `seed/max_duration_seconds`；器乐可使用非空 `[Instrumental]`。每次仍发现实际 Schema，不发明 `instrumental=true`、最短时长或续写参数。仅通过 Studio 调用，优先 `workflow.preflight(workflow=generate)`；就绪失败不代表已有分轨或混音也不可用。技能不自行启动停驻 GPU 服务、停止其他任务或恢复已经撤销的跨集群代理。

按用户明确的候选数、费用与重试约束执行。规划里建议的数量不是用户预算上限；未给数量不默认两条。模型渠道从本次Studio发现，不能把过去可用的成都或某模型写成永久可用。

## 3. 长度与器乐验收

`max_duration_seconds`等上限不保证最低长度。每次下载后先核验字节和实际解码长度，再判断能否覆盖目标窗口；原生ID、请求上限、实际时长和停止信息分别记录。服务没返回独立任务ID或费用时写未返回，不杜撰。

长度不足先区分文件不完整与模型自然提前结束。若固定长度是硬约束，不靠循环、拉伸、跨候选拼接或静音伪造满足。根据已有授权给出可执行选择：补生成、选连续区间、调整窗口或明确停乐；必须改变锁定要求时再请用户决定。用户批准具体停乐后直接实施，并分别核对音乐静默、旁白继续和真正全静默的区间。

同一失败重复出现时更新可行性判断，不只反复抬高上限。把最低时长、长篇结构、后端能力证据和本轮剩余额度一起核对；不凭HTTP成功或一个stop字段断言特定提前结束机制。

纯器乐要实际听审。ASR无字不能排除合唱或哼唱，识别出词也可能是幻觉；需结合声音判断。已授权技术分轨时保留原件，检查器乐轨的人声残留与乐器损伤，再决定使用；ASR空结果不能升级为“纯音乐验收通过”。

当前分轨入口为 `stems.separate(project_id, audio_asset_id)`，调用前仍核对实际工具与输入。分离器乐保留来源，不称为原生分轨。原请求响应未知时先对账已有任务和 Artifact，不能换 seed 再生成来掩盖未知结果。

## 4. 贴片与交付

实测节拍、重音与尾奏后标注拍点来源及误差，不能把请求128 BPM写成输出已是128 BPM；自动估计有半拍／倍拍歧义，必要时人工校正。保留锁定锚点；未获准时不挪动镜头来掩盖音乐错位。明确未达到的要求，候选可供审阅但不标为最终通过。

曲间音量和情绪连续性与响度值分别检查；硬切、淡化、停乐、时间伸缩只在本项目允许范围内使用。旁白版配乐需在实际配音下核对压低与恢复，不把固定压低值推广为所有片种默认。

交付源文件、选用范围、独立音乐轨、实际使用的分轨版本、混音参数及原任务／用量。只做配乐时不擅自完成其他镜头或最终母带；粗剪处理与已听审的最终母带分开标记。按Project／Artifact保存固定依赖和候选状态。

保留未经旁白压低的音乐轨；避让在剪辑混音层执行，换声后重算避让，不重生成音乐。当前歌曲 `mix.master` 要求人声和歌词，纯器乐不伪造静音人声或 LRC 凑参数；使用实际可用的剪辑环境，不臆造未开放的 `edit.*` 工具。最终编码后的响度和真峰值再核验。

不变速、无重叠的线性编排可按[配乐计划检查](score-plan-checks.md)运行包内 `scripts/validate_score_plan.py`。它检查源长度、全片覆盖与静默冲突，不读音频或代替听审。
