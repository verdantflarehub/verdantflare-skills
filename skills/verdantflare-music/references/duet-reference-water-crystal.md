# 对唱参考拆解：《水晶》

这份拆解只提取声部编排方法，不复制原曲歌词或复刻 1990 年代音色。参考对象为徐怀钰与任贤齐演唱的《水晶》（1998），公开曲谱资料标注原调 C，终段转为 D-flat；公开 LRC 标出女声、男声和合唱的时间点。

## 可核对的结构

| 时间段 | 声部安排 | 编排作用 |
| --- | --- | --- |
| 0:12-0:37 | 女、男各唱一组完整句，严格交接 | 先建立两个人的身份和问答关系 |
| 0:37-1:19 | 女、男继续一人一句；第一次副歌仍没有整段同唱 | 让 Hook 由两个人接力完成，保持歌词清楚 |
| 1:19-1:52 | 器乐间奏 | 给听众消化前一轮，不用人声堆密度 |
| 1:52-2:33 | 重复前段的女、男交接 | 先用重复建立记忆，再保留终段升级空间 |
| 2:33-2:40 | 短间奏和转场 | 为最后合流准备和声与调性提升 |
| 2:40-2:57 | 先两人同唱 Hook，随后男声领唱，句尾再由两人合到一起 | 合唱是结论和高潮，不是默认底色 |

原曲的角色关系也服务于歌词语义：女声先观察或提出感受，男声接住并回应；同一主题句在前两轮由两人分别承担，最后才共同确认。每个交接点都落在完整乐句或小节边界，听众能在瞬间知道谁在唱。

## 对制作的硬规则

1. 默认模板使用 `call_response_final_merge`：主歌、预副歌和前两轮副歌均为单一声部；两人的独唱窗口不得重叠。
2. `both` 只表示有意的同唱，不能表示“这句重要所以两人都唱”。首次 `both` 应位于最后副歌或明确的终段合流，建议不早于全曲人声段的 65%。
3. 同唱必须有两个可编辑的旋律线：同度齐唱、三度/六度和声或明确的上/下声部。复制同一旋律、复制同一干声、降八度或只改变声像都不算和声设计。
4. 同唱覆盖不超过全曲有歌词时长的 18%；其余时间由单一主唱承担。终段可以让一人领唱、另一人只在长音或句尾进入，这应写成独立的 backing/harmony 区间，而不是整句 `both`。
5. 角色交接要保留 50-120 ms 的无重叠换气或自然尾音交接。交接处的平滑淡入不能把前一句尾音延进下一人的独唱窗口。
6. 两位歌手要有不同的声源、音区和旋律职责。低基频、文件名或 `male`/`female` 请求字段不能替代人耳确认。
7. 伴奏在独唱句给主唱留中频空间；终段合流用和声、转调、鼓组和频宽增加制造升级，不靠同时打开所有轨道。

## 计划字段

采用该模板的 `duet-score-v1` 计划应声明：

```json
{
  "duet_template": "call_response_final_merge",
  "both_policy": {
    "max_voiced_ratio": 0.18,
    "first_both_min_ratio": 0.65,
    "allowed_modes": ["unison", "third", "sixth", "lead_with_tail_harmony"]
  }
}
```

每个 `both` 句还需在两条 melody 中写明 `harmony_mode` 或纵向音程，不能只写相同歌词。若计划来自旧版 MCP，无法提供这些字段和逐字旋律，必须标为诊断计划，不能把 `duet_generate` 的成功回执当作合格对唱。

## 本项目的失败对照

《越过噪点》Candidate 9 把 15 个时间窗标成 `both`，首次同唱从第一轮副歌就开始，且没有两条可编辑旋律和实际和弦关系。后半段男声还出现缺失，剩余重叠只是两个不稳定生成轨的叠加。因此“有两条文件”和“同唱窗口有能量”都不能证明合唱成立；该版本应保持未通过。
