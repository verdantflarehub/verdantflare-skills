## 2. 审核基本原则

- 只在当前任务实际涉及的审核点停下；同版本同范围既有批准直接复用；用户在唯一待审节点说“确认”“继续”视为批准该节点并连续推进无需新艺术决定的技术步骤。
- 状态为 `待审核`、`已批准`、`需修改`、`已否决`；不适用节点标“不适用”。只有用户明确决定可将听感节点改为 `已批准`，工具成功或自动检查通过不得自动批准。
- 原始录音进训练前的材料审核（见 [04.voice-replace.entrypoint.md](04.voice-replace.entrypoint.md)）是训练前置条件，不计入以下五个歌曲审核点，也不代替审核点 3。
- 所有审核决定原话、资产版本/ID、检查结果与下一步统一追加写入 `制作审核记录.md`，不另建报告；多候选/多项目并存时用户只说“继续”须先确认目标对象。

## 3. 五大人工审核门禁

### 3.1 审核点 1：词曲企划

原创企划经内部五级规范检查（全局、通用歌词、曲风歌词、通用编曲、曲风编曲）后，呈报可审阅歌词、结构与声音方向。可接受决定：批准企划；修改歌词/结构/制作方向；终止项目。

### 3.2 审核点 2：旋律与编曲

提供本轮约定的可试听候选、编号及实测时长（先完成 K09 分级并隐藏 `nsfw`），不用文字替代试听。提交前运行 `scripts/analyze_tail.py` 检查实际时长、最后 4 秒至最后 1 秒能量坍缩与最后 250ms 硬切风险（低于预算 90%、最后 1 秒骤降或末尾高电平为试听线索，须披露但不能单凭阈值判死）。不因未填满最大生成时长判败，也不用“自然结束”掩盖缺段或突兀停机；影视固定窗口最低可用长度按[贴片配乐](picture-scoring.md)判断。对唱/合唱候选额外按[对唱与合唱编曲审核规范](编曲-对唱与合唱-审核规范.md)提供独唱、接唱、同唱与整曲预混试听。可接受决定：选定候选；局部重绘；按批注重生成；退回企划；终止项目。风险已披露仍选定时直接续做分轨与已批准模型转换，不重复确认。

### 3.3 审核点 3：人声模型

仅新训练或更换未经批准模型时提供模型 ID 与真实转换验证音频，核对音色、音域、咬字、底噪与伪影；既有批准模型记“不适用（复用既有批准）”。可接受决定：批准建库；补充录音并用新模型 ID 重训；改用另一已批准模型；终止人物音色制作。

### 3.4 审核点 4：转换后干声

分轨后核对格式与时长（无已知阻断问题且用已批准模型时直接转换，不另设分轨停点；若无法试听漏声残留须在本点一并提供伴奏与原始干声披露）。将转换干声与原始干声逐段对比快句、连续辅音、副歌高音与句尾气声；快句不可辨识吞字或新增持续明显金属音为阻断项，不得进对齐与母带。先分缺陷来源：原始清楚、转换恶化 → 降特征检索率、加强清辅音保护重转；原始含糊 → 回审核点 2 重做候选。可接受决定：批准某版干声；调参重转；回候选生成；回模型重训。

### 3.5 审核点 5：最终母带

提供最终 WAV、MP3、LRC 及实测时长、格式、码率、LUFS 与 True Peak（先完成 K09 分级）。试听检查融合、空间、动态、齿音、削波、首尾与跨设备质感，并对照选定候选核验和声/叠唱/氛围/编曲细节是否留存（缺失标 `需修改`，不以格式/响度合格替代）。换声混音返工多试听版提供等响度 A/B，选定后才出终版母带。可接受决定：终审归档；仅重做母带或歌词对齐；回上游明确阶段返工。

## 4. 确定性脚本验收口径

- `scripts/analyze_tail.py`：提供时长、尾部坍缩与硬切风险线索，不替代审核点 2 听审。
- `scripts/validate_duet.py` / `scripts/validate_performance_duet.py`：`qualification_scope` 固定为 `machine_only`，`qualified: true` 仅证明角色窗口、电平、交接、峰值或谱面契约，不代表歌词、音准、声纹、自然度或曲风通过；任一适用检查退出码非零时仅作诊断候选，禁止进母带或声部扩展。
- `scripts/audit_performance_voice_source.py`：`coverage_passed=false` 时回到声源或转换环节，不靠混音电平补救。
- `scripts/validate_score_plan.py`：退出 0 表示线性编排技术通过且引用无人声听审证据（仍非最终音质/选用批准）；退出 1 为技术失败或存在唱声；退出 2 为技术通过但听审缺失。
