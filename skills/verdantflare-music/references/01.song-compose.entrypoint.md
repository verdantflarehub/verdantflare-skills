# verdantflare-music：原创歌曲、曲风企划与影视器乐配乐

## 1. 输入与输出

- **输入**：原创歌曲需一句音乐灵感、人声来源（Music3 原始人声 / 获授权录音 / 已批准人声模型）及可选曲风、时长与参考约束；影视器乐配乐需剧本、画面/时间线、旁白窗口与停乐方案。
- **输出**：原创输出 `完整词曲企划.md`、`lyrics.txt`、`instructions.txt`、`创作预审报告.md`、候选音频（默认 `Demo_Candidate_1/2.*`）、尾部检查与 K09 分级记录、`Demo_Selected.*`；影视配乐输出独立音乐轨、cue 选用范围、`validate_score_plan.py` 报告与混音参数。
- **公共依据**：[公共规范](00.common.rules.md)、[公共工作流与预检](00.common.workflow.md)、[公共验收与审核门](00.common.acceptance.md)。

## 2. 分类

- **独立原创歌曲（一键独立生成）**：从歌词与风格描述由 Music3 直接生成新歌，不读取参考音频或曲谱（模型自行决定旋律、和声、编曲与结构）。
- **影视与宣传片器乐配乐**：为已有画面、旁白窗口和固定时间线编排纯器乐配乐，不套用歌词、歌手训练或五个完整审核点；详见[贴片配乐](picture-scoring.md)与[配乐计划检查](score-plan-checks.md)。
- **不适用场景**：保留参考旋律或按曲谱演唱转[02.cover-score.entrypoint.md](02.cover-score.entrypoint.md)；男女对唱或多人合唱转[03.duet-ensemble.entrypoint.md](03.duet-ensemble.entrypoint.md)；仅替换指定歌手声线转[04.voice-replace.entrypoint.md](04.voice-replace.entrypoint.md)；有界区间修复转[05.redraw-master.entrypoint.md](05.redraw-master.entrypoint.md)。

## 3. 工作流

### 3.1 原创歌曲企划与候选生成

1. **按需加载曲风规范**：先读[全局审核规范](全局-审核规范.md)、[通用歌词审核规范](歌词-审核规范.md)、[通用编曲审核规范](编曲-审核规范.md)，再仅加载当前需要的一组曲风专册（融合曲风先写清主风格与辅助元素；无专属文件用通用规范并记风格假设）：
   - R&B：[歌词](歌词-R&B-审核规范.md) / [编曲](编曲-R&B-审核规范.md)
   - 说唱：[歌词](歌词-说唱-审核规范.md) / [编曲](编曲-说唱-审核规范.md)
   - 华语流行摇滚：[歌词](歌词-华语流行摇滚-审核规范.md) / [编曲](编曲-华语流行摇滚-审核规范.md)
   - 英式摇滚：通用歌词 / [编曲](编曲-英式摇滚-审核规范.md)
   - 乡村音乐：通用歌词 / [编曲](编曲-乡村音乐-审核规范.md)
   - 现代电子：通用歌词 / [编曲](编曲-现代电子-审核规范.md)
   - 现代 J-pop／日系电子流行（含摇滚融合、轻细电子女声，不因动画用途自动走燃系）：[制作与返工](jpop-electronic-production.md)、[歌词](歌词-现代日系电子流行-审核规范.md) / [编曲](编曲-现代日系电子流行-审核规范.md)
   - 日式二次元燃系：通用歌词 / [编曲](编曲-日式二次元燃系-审核规范.md)
   - City Pop / Funk：[歌词](歌词-City%20Pop与Funk-审核规范.md) / [编曲](编曲-City%20Pop与Funk-审核规范.md)
   - 独立流行 / Dream Pop：[歌词](歌词-独立流行与Dream%20Pop-审核规范.md) / [编曲](编曲-独立流行与Dream%20Pop-审核规范.md)
   - 电影感流行：[歌词](歌词-电影感流行-审核规范.md) / [编曲](编曲-电影感流行-审核规范.md)
   - 朋克 / 金属：[歌词](歌词-朋克与金属-审核规范.md) / [编曲](编曲-朋克与金属-审核规范.md)
   - 对唱 / 合唱：通用或适用曲风歌词 / [编曲](编曲-对唱与合唱-审核规范.md)（制作流转 [03.duet-ensemble.entrypoint.md](03.duet-ensemble.entrypoint.md)）
2. **编写草案并五级内部预审**：补全一致创作选择，输出 `完整词曲企划.md`、`lyrics.txt`（Music3 段落标签）、`instructions.txt`（不含供应商/部署信息），按顺序执行全局 → 通用歌词 → 曲风歌词 → 通用编曲 → 曲风编曲检查并汇入 `创作预审报告.md`，提交审核点 1。
3. **预检与生成候选**：审核点 1 通过后按[公共工作流](00.common.workflow.md#3-技术能力预检与旧版兼容)执行预检；用 Music3 按批准数量（默认 2 个）与同一份批准企划、最大生成时长（默认 200s）生成候选，保存任务与 Artifact ID（短样评审从同一整曲取内部片段，不先出短歌再跨模型补长）。
4. **尾部检查、K09 分级与选定**：对每个候选运行 `scripts/analyze_tail.py` 并测量真实时长，完成[K09 分级](00.common.rules.md#5-生成后内容分级评估k09-强制步骤)，进入审核点 2；选定后登记 `Demo_Selected`。需指定人声换声时转[04.voice-replace.entrypoint.md](04.voice-replace.entrypoint.md)，需局部重绘或母带收尾时转[05.redraw-master.entrypoint.md](05.redraw-master.entrypoint.md)。

### 3.2 影视器乐配乐流程

按[贴片配乐](picture-scoring.md)先做画面内容与旁白窗口映射，再规划单曲或多 cue 编排（`music.generate` 纯器乐传非空 `[Instrumental]`，禁用伪造参数；生成模型不可用且宿主开放 `music.instrument_render` 时可制作原创音符分轨工作稿）。下载后核验真实解码长度与纯器乐听审，线性无重叠编排按[配乐计划检查](score-plan-checks.md)运行 `scripts/validate_score_plan.py`，保留未压低音乐轨并在剪辑混音层做对白避让。

## 4. 规范

- 新歌、整曲与新增段落统一由 Music3 生成；ACE 只做已有音频有界局部重绘，不作续写或整曲回退。当前 Music3 不支持参考音频续写，不得把同 seed/同提示词新曲冒充原表演。
- 独立生成不保证复现参考旋律；单轨生成结果不得标为男女对唱或多人合唱。
- 候选之间不得暗改歌词或制作目标；重生成须递增候选编号，不覆盖旧资产。
- 影视纯器乐不得为凑 `mix.master` 参数伪造静音人声或 LRC，也不得靠循环/拉伸/补静音伪造固定长度。

## 5. 验收

- 原创歌曲通过审核点 1（五级预审无未解阻断）与审核点 2（`analyze_tail.py` 风险已披露、K09 分级已提交且人工听审选定候选）。
- 影视配乐通过真实解码长度核验、人工纯器乐听审（ASR 空结果不等于纯音乐通过）及 `validate_score_plan.py` 校验（线性编排退出 0）。
- 仅请求企划或歌词时，交付经五级预审的草案与报告即结项，不擅自触发收费生成。
