# Music 生成后内容分级评估步骤（K09）

## 1. 当前依据

- [18+ 评估规范（rubric v1.0）](content-rating-rubric.md)：判定类别（S1–S4、V1）、音频与歌词文本判定标准及输出 JSON 格式。
- [工作流](workflow.md)：候选生成、翻唱、分轨、音色转换、母带与 Project 同步流程。

## 2. 步骤位置

评估放在“取得生成产物”之后、“交付摘要、人工审核点展示与项目同步”之前：

1. 音乐生成、翻唱、局部重绘、音色转换或母带任务完成，按原流程取得音频产物（此时尚未评估）。
2. 按第 3 节准备评估输入，对照 [18+ 评估规范（rubric v1.0）](content-rating-rubric.md) 判定，得到评估 JSON。
3. 调用 `music.rate_content` 提交评估结果；判定为 `general` 的产物也必须提交，以留下“已评估”记录。
4. 按第 5 节处理交付摘要、审核记录与 Studio 项目同步。

一次生成多个候选（如 `Demo_Candidate_1`、`Demo_Candidate_2`）或多条产物时，逐个评估并逐个调用 `music.rate_content` 提交。评估未完成前，不得把产物同步到 Studio 项目，也不得在审核点或交付摘要中展示。只读查询或恢复已完成且已评估的任务时，不重复评估。

## 3. 音频与歌词评估输入（含转写缺失处理）

- **评估输入**：
  - **歌词与文本**：直接评估送入模型的歌词（`lyrics.txt`）、制作指令与正向提示词（`instructions.txt`）、歌曲标题、LRC 字幕及企划正向描述；反向排除词不作为 `nsfw` 依据。
  - **音频与转写文本**：使用当前可用的转写或歌词对齐能力取得音频实际唱词，并检查是否存在以性兴奋为目的的非语言声音（计入 S1、S2）。
- **转写能力缺失时的处理**：当没有可用音频转写能力（或产物为纯器乐配乐、伴奏分轨）时，依据歌词、正向提示词、标题与可识别声音判定，并**必须在 `reasons` 中明确注明 `"未转写音频"`**（例如 `["未触发类别", "未转写音频"]`）。
- **不确定从严（O2）**：无法取得完整输入或隐喻/双关无法排除 18+ 时，按规范第 5.1 节**“不确定即标 nsfw”**处理，并在 `reasons` 中写明原因（不引用歌词露骨原句）。

## 4. 规范版本与 `music.rate_content` 调用

- **规范版本**：`rubric_version` 固定取自同目录 [content-rating-rubric.md](content-rating-rubric.md) 文首声明的版本号（当前为 `"rubric v1.0"`），不得自行编造版本号。
- **调用参数**：向 `music.rate_content` 传入 `task_id` 或 `content_ref`（二选一）及评估字段：

```json
{
  "task_id": "<音乐生成任务ID>",
  "rating": "general",
  "rubric_version": "rubric v1.0",
  "evaluator_model": "<执行评估的模型标识>",
  "reasons": ["未触发类别", "未转写音频"],
  "evaluated_at": "2026-10-24T00:00:00Z"
}
```

- **幂等与超时重试**：`music.rate_content` 是幂等的。若提交超时或响应未知，用相同产物标识和相同评估 JSON 重试，**严禁因此重新生成音乐候选或重跑收费阶段**。

## 5. 交付摘要与项目同步约束

- **交付摘要脱敏**：判定为 `nsfw` 的音乐产物，交付摘要与审核记录只写“N 个产物已标记为 NSFW 并隐藏”，**严禁展示音频试听、下载链接、`ContentRef`、文件路径、歌词原文或提示词全文**；`general` 产物照常进入审核门与交付。
- **项目同步与 World 阻断（H1 已确认）**：判定为 `nsfw` 的产物**不同步到 Studio 项目（不写入 `project.commit`），也不登记到 World（不调用 `world.register`）**。短剧配乐或 MV 阶段遇到 `nsfw` 产物时，在阶段记录中只写“已隐藏产物 N 个”，由用户决定是否改写歌词/提示词后重新生成。
- **不提供撤销**：MCP 与本技能均不提供、也不尝试撤销标记；若存在误标，提示用户可在 Studio 设置页开启本机“显示 NSFW 内容”开关（24 小时有效）后人工取消 NSFW 标记。
