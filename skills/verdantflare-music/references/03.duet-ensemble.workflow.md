## 2. 自然演唱源的逐句换声编排

适用于源歌曲已将全部问答歌词唱对、旋律编曲自然、每句角色可从时间轴明确划分的情况（如 2026-10-04《越过噪点》自然源 v7 及只换男声的 Mengsk v18 获认可为可用试听，**不等于无损或终版母带**；此路线不证明纯歌词自动双歌手已可用）：

1. **分轨能量预核**：先查干声、伴奏与原混音每段能量。若分轨把编曲或空间尾音放进人声轨导致伴奏句尾近静音，直接“分离伴奏 + 新声线”会让音乐骤降；未换声句保留原混音，换声句查分离损失、转换空洞、原声泄漏与交接，不用硬门控、整句增益或旧湿人声掩盖缺损。
2. **更换分离伴奏校准（按需）**：若新分离伴奏更完整，先对照原伴奏频带、侧声道与旧歌手泄漏；**仅当**获认可版伴奏可由原分离伴奏乘逐时增益重建时，运行校准脚本（不可拿人声残差校准）：

```bash
python3 verdantflare-skills/skills/verdantflare-music/scripts/prepare_duet_replacement_backing.py \
  --source-backing <原分离伴奏.wav> --approved-backing <获认可版伴奏.wav> \
  --replacement-backing <新分离伴奏.wav> --output <校准后伴奏.wav> --report <校准报告.json>
```

3. **目标声部覆盖审计**：替换男声用 `--role male`，女声改 `--role female`（两轨长差 `<= 30ms` 按尾补零，超出先对齐）；`coverage_passed=false` 时回声源或转换环节（旧 RVC 在 37–39s、88–89s 曾现缺口）。原混音减伴奏残差仅在同轴且单听无明显乐器污染时可作新转换输入，不得未转换直接混回：

```bash
python3 verdantflare-skills/skills/verdantflare-music/scripts/audit_performance_voice_source.py \
  --plan <plan.json> --source <source.wav> --backing <instrumental.wav> \
  --dry <separated_dry.wav> --candidate <converted.wav> --role male --report <audit.json>
```

4. **单声部替换与包络压制**：`--other-voice` 须为另一歌手全曲对齐实际轨（覆盖 `both` 句）；接唱处若原声近静音而转换轨提前冒声，平滑压住局部冒声而不整句压低：

```bash
python3 verdantflare-skills/skills/verdantflare-music/scripts/replace_performance_duet_voice.py \
  --plan <plan.json> --baseline <approved-preview.wav> --backing <aligned-backing.wav> \
  --other-voice <untouched-singer-track.wav> --converted <new-full-timeline-vocal.wav> \
  --role male --output-prefix <new-version>
```

5. **整曲电平与三轨重建校验**：以 `duet-performance-v1` JSON 及**上一版获认可试听**作 `--source`（候选自身不可充当参照），用 100–200ms 窗口核对全曲响度、交接、峰值及 `stems_reconstruct_preview`（需独立分轨重混时加 `--require-reconstructible`；实测 v7 残差 `-7.93 dB`、v18 `-10.03 dB`，均不具备无损重建资格）。不凭空填音符和弦凑 `duet-score-v1`：

```bash
python3 verdantflare-skills/skills/verdantflare-music/scripts/validate_performance_duet.py \
  --plan <plan.json> --female <female.wav> --male <male.wav> --backing <backing.wav> \
  --preview <mix.wav> --source <prior-approved-mix.wav> --report <validation.json>
```

运行上述脚本需 Python 环境具备 `numpy`、`scipy`、`soundfile`（掩膜脚本另需 `librosa`），缺依赖不写成歌曲通过或失败。

## 3. 原混音局部换声（已有完整男女对唱）

适用于原曲已唱全、男女职责可辨且有授权目标音色的单歌手替换（如 2026-10-04 `videoplayback` Mengsk 男声 v2 获试听认可，单曲认可不代表通用或无损）。MP4 等输入须先探测流类型、声道、采样率与时长再解码同轴 WAV，不凭扩展名推断有视频：

1. 提取整曲人声，建目标歌手逐句时间轴（`duration_seconds`、`male_phrases`/`female_phrases`，含 `start`/`end`/`source`(`solo`/`separated`)/`confidence`/备注及可选 `max_gain` 默认 `1.0` 范围 `1.0..1.5`）；低置信同唱句人工核对，另一歌手独唱禁入换声源。
2. 独唱句直接取目标人声；同唱句先取两人同采样率单声道低采样率估计，调用全频掩膜脚本（先用已知双独唱合成叠唱测分离器并单听两轨串音与漏字；掩膜互补不证明分对歌手，高频外推仍可能串音）：

```bash
python3 verdantflare-skills/skills/verdantflare-music/scripts/lift_duet_singer_mask.py \
  --source-vocals <整曲人声.wav> --target-estimate <目标低采样率.wav> \
  --other-estimate <另一歌手低采样率.wav> --start-seconds <起点> --end-seconds <终点> \
  --target-out <目标全频片段.wav> --other-out <另一歌手全频片段.wav> --report <分离报告.json>
```

3. 目标片段放回原采样率原样本位置做 F0 条件换声（通用 pYIN 八度跳变须用歌唱音高提取器复核，不可单凭一次检测降八度）。
4. 原混音、原目标歌手与换声轨同采样率同帧数执行局部减法替换（浮点非目标区逐样本与原曲一致，PCM24 仅量化误差；可选 `--wet` / `--wet-gain` 仅接受无原歌手泄漏的换声空间轨，禁混回原歌手湿声）：

```bash
python3 verdantflare-skills/skills/verdantflare-music/scripts/replace_singer_in_mix.py \
  --plan <逐句计划.json> --role male --source-mix <原混音.wav> \
  --target-singer <全曲同轴原男声.wav> --converted <全曲同轴换声.wav> \
  --output <新试听.wav> --report <换声报告.json>
```

5. 对照原曲等响度听完整首歌，重点查低置信同唱、接唱、漏字、原声泄漏、伪影、音准与短时电平；保留原曲、分轨、换声与报告，不覆盖已认可版本。

## 4. 实验性本地双轨路线（OpenUtau）与推荐三段式架构

- **OpenUtau 历史边界**：2026-10-03《越过噪点》179.2s 实验（`Qixuan_v2.7.0_DiffSinger_OpenUtau` 中文歌词 + `LongWei_Symphonia_zh` 逐字拼音，`.ustx` 双独立轨）仅验证双轨文件与角色时间窗，**完整混音已被听审否决**（旧失败资产含等长机械音长、固定音阶循环、单 `Am11` 标签与旧校验器误判 F 为和弦音，文件名 `Final` 非获批母带）。若做 12–20s 新探针须先核：① LongWei 完整 `oto.ini`/5 subbank/约 4161 OTO；② Qixuan `pc_nsf_hifigan_44.1k_hop512_128bin_2025.02` 与 Worldline 原生库；③ 等待 General Phonemizer 异步字典加载完成并用拼音探针验 VCCV（`?t y i N` 强制别名仅诊断）；④ 无头 `WaveMix.Mix` 每次调用前清零输出缓冲区；渲染后调音符与交接间隙，不以硬门控掩错。
- **推荐生产架构（三段式双轨）**：拆为“伴奏/旋律 → 女声干声与男声干声 → 混音母带”。伴奏负责曲风/和声/结构；歌声合成按逐字音素、音符、时值、休止、力度与气口分别用两套获授权声库渲染（优先评估 OpenVPI DiffSinger、Fish Diffusion、NNSVS，分别核查代码/声库/输出许可），或用两位获授权演唱者同步干声（`voice.convert` 仅统一已唱对干声的音色）。默认固定 **12–20 秒技术探针**（女独、男独、同唱、无重叠接唱对照），全部人耳通过后再扩整曲。
