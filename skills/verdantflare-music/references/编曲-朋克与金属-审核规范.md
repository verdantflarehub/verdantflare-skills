# 编曲朋克与金属审核规范

本规范是朋克、流行朋克、现代金属与金属核融合项目的第五级门禁，只在编曲通用规范通过后执行。它审核 riff、鼓贝斯推进、失真层级和高强度演唱的可实现性，不把更快、更响或更重当作风格充分条件。

## 适用边界

- 适用于以吉他 riff、强拍、失真乐队和明确段落冲击为核心的朋克与金属相邻风格。
- Thrash、Death、Black、Djent、后硬核等子风格必须先明确；不同子风格不能同时堆入一份 instructions。
- 不复制具体乐队的 riff、调弦、嗓音、歌词或标志性段落。

## Riff 与节奏组

- 至少有一条可识别 riff 或节奏动机，说明其在 Intro、Verse、Chorus、Breakdown 或 Bridge 的职责。
- 底鼓、军鼓、镲片与吉他重音形成稳定骨架；双踩、切分、停拍和齐奏必须与歌词及段落功能相容。
- 贝斯承担根音支撑、反向运动或 riff 加厚，不长期与底鼓和低调弦吉他形成无法分辨的低频墙。
- 失真层按节奏吉他、旋律/八度线、纹理或反馈分工；双轨加宽不能抹平拨弦和和弦轮廓。

## 结构、主唱与制作

- Verse 与 Chorus 在 riff、鼓型、音区、和声或密度上有可听见的对比；Breakdown 必须有真实节奏功能。
- 高潮不能在 Intro 就耗尽；Bridge、停拍或半速段为最终副歌保留冲击余量。
- 喊唱、嘶吼或高强度唱法需要独立核对歌词可辨度、音高中心、换气和连续演唱时长。
- 主唱核心中频从失真吉他和镲片中让出；过载、饱和和限制器不能掩盖音准、瞬态或段落差异。
- 结尾选择齐停、尾奏 riff、反馈回收或明确渐弱，不能在未解决的高能循环中突然停止。

## 阻断条件

只用“重型、快速、失真”描述风格；riff 无动机或段落职责；鼓贝吉他重音冲突；全曲持续满失真；主唱因极端唱法不可辨；Breakdown 与高潮没有对比；低频和镲片失控；或复制具体作品的声音与段落，均为阻断。
