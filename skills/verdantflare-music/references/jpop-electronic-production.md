# 现代日系电子流行制作与返工

## 1. 何时使用

用户要求现代 J-pop、电子流行与摇滚融合、动画宣传歌曲，或反馈“像中文抒情金曲、电子感不足、声线厚重粘连”时使用。它是 Music 内的曲风分支，不把所有日系音乐归为高速燃系，也不要求日语演唱。动画 OP、ED 和广告用途不自动决定速度、吉他重量或编制。

## 2. 先确定参考的作用

读取用户已有参考与反馈，记录本次要保留的旋律、节奏、人声和配器关系，以及不适用的特征。一个参考可以锚定情绪，另一个帮助判断编曲密度；不要求用户凑固定数量。已有明确参考不重复询问。

用户提供的 YOASOBI 歌单可作为叙事型电子 J-pop 的学习样本，不能代表全部 J-pop。《BABY》与《Idol》《Monster》等作品也不能混成一个固定配方。版本需核对：原版、英语重录、现场和 Ballade Ver. 不能互相冒充。中文歌词保留中文声调和语义重音，不直接套日语音节。

资料检索只能证明来源与可核实事实。没有实际音频听审时，明确写“资料学习／待听审”，不编造 BPM、调性、逐段时间码、修音速度或具体插件。不从唱片署名、MV 画面或乐器频谱反推真实效果链。学习旋律组织、声部关系和叙事方法，创作自己的旋律、歌词、音色组合与段落动机。

## 3. 把风格要求变成制作决定

先描述可听见的结果，再选提示词或独立处理：

- 旋律：紧凑短句与流动长句交替，弱拍进入、休止与句尾解决形成弹性；副歌短钩子接不同走向的回应句，不能只靠升高音区或加大音量。
- 电子编曲：合成器钩子／琶音、程序化鼓细分与低音连接承担实际音乐任务；主歌也听得到电子身份。零星 sparkle、pad、转场音效不足以说明电子主导。
- 乐队关系：钢琴、吉他和贝斯按段落分工。摇滚能量可来自节奏吉他、鼓贝重音及停拍，失真和速度按需求选择。
- 人声：分别处理源声线、节奏咬字和后期质感。轻细不等于尖、虚或全程气声；音高修正不等于换声。先保留清楚的主唱，再决定双轨、共振峰或声码器叠层的比例。
- 情绪推进：先用旋律、和声与节奏建立期待，再加宽频谱和和声。每段给新的信息，保留主唱空间。

用户要求强电子感时，把电子主体与主唱要求放在生成指令前部，删除互相抵消的“木吉他主导／folk ballad／全程克制铺底”等要求。负向约束遵循当前工具 Schema：没有 negative_prompt 字段时不得伪造。不要只延长形容词清单后重复同一生成。

## 4. 独立制作能力路由

先读取当前 Studio tools/list。只有实际出现 music.production_capabilities 后，才能读取其中的 config Schema 并调用 voice.tune、voice.process、music.instrument_render、mix.render；缺失时不能把文字描述写成已执行效果。

- voice.tune：独立单声部人声；目标音符或音阶、修正强度、过渡、颤音和共振峰分别调节。自动检测不等于已确认曲谱；低置信度、人声串音和辅音段先保留。
- voice.process：有序效果链。声码器需要明确载波音频；干湿比和主唱可懂度一起判断，不默认全湿。
- music.instrument_render：提交原创结构化音符事件及音色参数，保留独立轨。先确认实际节拍／调性及进入位置；不能凭生成提示词里的 BPM 给现有音频叠加固定网格。
- mix.render：有序独立轨、增益、声像、区间及侧链，生成预混。已混合伴奏上的叠加不能冒充重新编曲或精确替换乐器。

提交前保存 project_id、request_id、固定输入和配置。返回 queued／running 后只查询 music.production_status；超时或未知状态先恢复。取消活动任务的 cancelling 状态不等于 CPU 已停止。输出新版本；读取 report 和字节校验后归档到同一 Project。

首期事件以秒计时，所选人声区间输出独立片段，音符相对该片段计时。超过满幅的浮点轨需先降低混音增益；不把其当母带。旧 mix.master 自带默认人声链，已处理人声不要未经核对再次经过该链。前述服务能力以发现和当前 Schema 为准，技能版本不证明部署版本。

## 5. 验证与返工

先听主歌到第一遍副歌是否成立；用户要求整曲时，这只是内部验证切片，不缩减最终交付。保留同一音源和区间的等响度 A/B，分别比较干声、修音／电子叠层、加入合成器的预混，明确哪些因素改变。

按[编曲审核](编曲-现代日系电子流行-审核规范.md)和[歌词审核](歌词-现代日系电子流行-审核规范.md)记录“通过／需修改／未验证”及可定位证据。无法实际听到音频时只能报告技术检查，交用户试听，不凭提示词、非空文件、频谱或哈希批准风格。

连续反馈同类失败时，复查源演唱、旋律组织及后端可控性，选择分轨返工或重新作曲；不要反复提交越来越长的整曲提示词。不存在合格原声时，修音和加合成器不能作为保留失败候选的理由。
