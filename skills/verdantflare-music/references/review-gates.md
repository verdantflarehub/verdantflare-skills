# 人工审核门禁

只在当前任务实际涉及的审核点停下。同一版本与同一范围的既有批准直接复用；用户在唯一待审节点说“确认”“继续”可视为批准该节点，随后连续完成不需要新艺术决定的技术步骤。决定绑定具体资产版本，不能把执行授权写成尚未发生的听感终审。


适用审核点的状态为 `待审核`、`已批准`、`需修改` 或 `已否决`；不适用的标记“不适用”，不要制造待审项。只有用户的明确决定可以把需要听感判断的节点改为 `已批准`；工具成功或自动检查通过不得自动批准。

原始录音进入训练前还必须完成 `voice-preparation.md` 定义的训练材料审核。它是训练前置条件，不计入以下五个歌曲审核点，也不能代替审核点 3 的模型音色审核。

## 审核点 1：词曲企划

原创企划经适用的全局、歌词、编曲与曲风规范内部检查后，呈现可审阅的歌词、结构和声音方向。技术预检可在企划批准后、远端生成前进行；旧版 MCP 按 `preflight.md` 兼容。用户在此决定创作方向和是否生成，代理负责专业合规与可唱性检查。

可接受决定：批准企划；针对歌词、结构或制作方向提出修改；终止项目。

## 审核点 2：旋律与编曲

提供批准数量的可试听候选（默认两个）、编号及各自实际时长，不用文字评价替代试听。检查旋律记忆点、副歌力度、编曲层次、结构完整度和自然结尾；不得只因为候选没有填满最大生成时长而判定失败，也不得用“允许自然结束”掩盖缺段、尾奏不足或突兀停机。

对唱、合唱或主唱加和声的候选，额外按[对唱与合唱编曲审核规范](编曲-对唱与合唱-审核规范.md)提供独唱、接唱、同唱/合唱和整曲预混试听。审核声部身份、歌词与时间轴、交接、和声关系、伴奏避让、重叠平衡和高潮密度；结构校验通过不等于歌手身份、咬字、音准、自然度或曲风听审通过。多人声部不因轨道数量或响度匹配而自动批准。
提交前记录实际时长并检查尾部；可用时运行 `scripts/analyze_tail.py`。低于企划预算 90%、最后 1 秒能量骤降或末尾仍有高电平信号是试听线索，不能单凭阈值判定歌曲失败。把具体风险与候选一起告诉用户。

可接受决定：选择一个候选；在能力可用时局部重绘；按批注重新生成；返回企划修改；终止项目。风险已披露且用户仍选定候选时，记录该选择并继续分轨和已批准模型的转换；不再为同一风险单独索取确认。

## 审核点 3：人声模型

仅新训练或更换未经批准的模型时提供模型 ID 和真实转换的验证音频，检查音色、音域、咬字、底噪和伪影。既有批准模型直接复用，本点记录“不适用（复用既有批准）”，不重新等待用户批准。

可接受决定：批准建库；补充录音并用新模型 ID 重训；改用另一个已批准模型；终止人物音色制作。

## 审核点 4：转换后干声

分轨后先自动核对格式和时长；有试听或音频检测能力时检查伴奏漏声与干声残留。无法判断听感时如实标记，并在转换干声审核时一并提供伴奏和原始干声；不要仅凭哈希宣称分轨音质通过。没有已知阻断问题时可直接使用已批准模型转换，不另设分轨人工停点。

同时提供转换干声与原始干声，重点逐段对比快句、连续辅音、副歌高音和句尾气声。检查音色还原、高低音连续性、音准、咬字、换气和机械电音感；快句出现不可辨识的吞字，或转换后新增持续、明显的金属音，必须标记为阻断，不得进入歌词对齐和母带。

先判断缺陷来源：原始干声清楚、转换后恶化时，降低特征检索率并加强清辅音保护后重做转换；原始干声本身已含糊时返回审核点 2 重做歌曲候选；各组参数和试听资产必须分别记录。可接受决定：批准某一版干声；调整转换参数重做；返回候选生成；返回音色模型重训。

## 审核点 5：最终母带

提供最终 WAV、MP3、LRC、自动测得的时长、采样格式、码率、LUFS 和 True Peak。试听检查人声与伴奏融合、空间感、动态、齿音、削波、开头结尾以及跨设备播放质感；有选定候选时对照检查和声、叠唱、氛围层与编曲细节是否在换声后仍成立。用户指出这些层次缺失时标记“需修改”，不得以格式合格或响度合格代替听感批准。按 [换声混音返工](vocal-replacement-mix.md) 得到多个试听版时，在本审核点提供等响度 A/B 和差异说明；用户选定试听版后才制作其最终母带，不增加新的编号审核点。

可接受决定：终审归档；只重做混音母带或歌词对齐；返回上游明确阶段返工。

## 记录

在同一份 `制作审核记录.md` 中追加决定原话、所涉资产版本/ID、必要检查结果和下一步；`assets.json` 只维护资产映射。不为每个审核点或工具调用另建报告。存在多个候选、项目或待审决定时，用户只说“继续”不足以确定目标，先明确对象。
