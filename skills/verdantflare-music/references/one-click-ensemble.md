# 一键多人合唱

## 用途

装配三人及以上的团体合唱、轮唱或分组和声。每位成员都必须有独立的全曲对齐声部，不能从单条混音复制出多人。

## 输入

- 每位歌手的独立干声、模型 ID 或获授权录音。
- 每句角色、分组、齐唱/轮唱/和声标记和歌词时间轴。
- 伴奏、和声关系、声像与动态计划。

## 输出

- 每位歌手的独立轨和分组总线。
- 轮唱、齐唱、和声和整曲预混试听。
- 轨道覆盖、串音、响度、相位和歌词审计结果。

## 执行顺序

1. 先分别审核每位歌手的歌词、音准、音色和自然度。
2. 核对每个独唱、轮唱、齐唱窗口，避免未声明的重叠和缺席。
3. 进行等响度分组混音，检查齐唱相位、动态、声部遮蔽和第三位歌手可辨度。
4. 只有所有成员和整曲听审通过后才输出母带。

## 能力边界

- 当前技能没有把三人及以上自动生成标记为生产可用；历史三人样本未通过人耳验收。
- 轨道数量、声纹聚类或响度匹配不能证明第三位歌手清楚、歌词完整或合唱自然。
- 没有独立声源时，入口应停在诊断或请求补充录音，不调用母带冒充成品。
