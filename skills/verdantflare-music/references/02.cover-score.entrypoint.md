# verdantflare-music：翻唱、曲谱约束翻唱与扒谱

## 1. 输入与输出

- **输入**：用户有权处理的参考音频或视频音频流（以及可选原曲歌词/时间轴、已审核 `score.reviewed.json`）、匹配逐行歌词、目标歌手或已批准人声模型、风格与“保留原编曲 / 允许重编”选择。
- **输出**：导入音频 Artifact 与 SHA-256；扒谱输出 `score.raw.json`、`lyrics.raw.json`、`score.reviewed.json`；翻唱输出分轨、曲谱/覆盖校验报告、转换或渲染干声、对齐 LRC、最终母带与审核记录。
- **公共依据**：[公共规范](00.common.rules.md)、[公共工作流与预检](00.common.workflow.md)、[公共验收与审核门](00.common.acceptance.md)。

## 2. 分类

- **既有歌曲重新演绎（指定完整歌曲 + 已批准模型）**：用户指定有权处理的完整歌曲与已批准人声模型，跳过原创企划与双候选，导入为 `Demo_Selected` 后直接分轨与换声。
- **无曲谱翻唱（一键无曲谱翻唱）**：使用参考音频、目标风格与匹配歌词生成翻唱候选，不把自动曲谱作为硬约束，允许改变旋律、节奏与编曲。
- **曲谱提取（一键提取曲谱）**：从参考音频提取可编辑旋律、节奏、调性、和弦与歌词时间轴（本地前处理/研发能力），产出待审 `score.raw.json` 经人工修正为 `score.reviewed.json`。
- **曲谱约束翻唱（一键曲谱约束翻唱）**：基于已审核 `score.reviewed.json` 严格按旋律、歌词时值、节拍与和弦生成翻唱（未提供已审核曲谱时先执行曲谱提取与修谱审核）。
- **不适用场景**：生成全新原创歌曲转[01.song-compose.entrypoint.md](01.song-compose.entrypoint.md)；仅在既有完整歌曲/对唱基线上保留原混音替换单歌手声线转[04.voice-replace.entrypoint.md](04.voice-replace.entrypoint.md)。

## 3. 工作流

### 3.1 既有歌曲重新演绎与无曲谱翻唱

1. 按[公共工作流](00.common.workflow.md#3-技术能力预检与旧版兼容)执行 `workflow.preflight(workflow="cover", voice_source=...)`（禁用 `generated_voice`），核对音频流、版权/人声授权、真实模型 ID 与后端签名。
2. 客户端将原始音频上传至已批准外部 S3 并算 SHA-256（不入 Git），调用 `asset.import`（传项目 ID、临时可读 S3 URL、安全文件名、预期 SHA-256），完成后仅存 Artifact ID、文件名、大小与 SHA-256，不存签名 URL。
3. 指定既有歌曲重新演绎时，审核点 1、2 记为“已批准（用户指定既有歌曲）”，将导入 Artifact 登记为 `Demo_Selected`（不造伪企划或无意义双候选）；需要保留原编曲时调用 `stems.separate`。
4. 检查源人声歌词、音准与完整覆盖（若歌词不完整、参考漏字或男女混在单轨则停在源素材检查，不用翻唱模型补歌词），再执行 `voice.convert` 或实际可用翻唱后端，并完成[K09 分级](00.common.rules.md#5-生成后内容分级评估k09-强制步骤)。
5. 逐段对照原曲核查歌词、旋律、人声身份、编曲变化、残留与削波；过审核点 4 后转[05.redraw-master.entrypoint.md](05.redraw-master.entrypoint.md)完成 `lyrics.align` 与 `mix.master`。

### 3.2 曲谱提取与曲谱约束翻唱

1. **扒谱前处理**：探测真实音频流、采样率、声道、时长与授权（不凭扩展名判断），解码并存不可变副本；分离目标声部（分离失败或伴奏明显泄漏保留诊断状态）；提取 F0、音符起止、节拍、调性与歌词候选，输出 `score.raw.json` 与 `lyrics.raw.json`。
2. **人工修谱审核**：核查八度跳变、连音、装饰音、休止、跨句合并与和弦覆盖，人工确认修正后生成 `score.reviewed.json`（记录修正来源）。
3. **曲谱约束翻唱**：校验 `score.reviewed.json` 的覆盖、逐字音素、音符范围、休止、节拍与和弦；用独立歌手轨渲染或转换并存原始输入与模型 ID；核查音符音准、歌词完整、换气、声部静音窗与伴奏对齐。
4. 先通过短样试听再扩至全曲，完成 K09 分级后进入母带与审核点 5；失败时返回曲谱或歌手源，不用母带掩盖。

## 4. 规范

- 用户未确认有权处理来源歌曲或人声模型未批准时，停在导入/转换前，不用其他素材替代。
- 无曲谱翻唱不承诺保持原曲旋律；单条混合歌曲下 UVR/SVC/RVC 不能保证分出不同歌手，也不能修复源录音错词或跑调。
- 自动曲谱（`score.raw.json`）仅是候选，未经人工修正只能作诊断；只有 `score.reviewed.json` 可作翻唱约束输入，不得用 BPM、调性、单一 F0 曲线或凭空填写的和弦冒充完整曲谱。
- 当前扒谱与曲谱约束翻唱仍需人工修谱与听审，不得宣称“导入音频后全自动无人值守商业交付”。

## 5. 验收

- **导入与预检**：Artifact ID、大小、SHA-256 校验通过，无签名 URL 留存，授权与模型 ID 已核实。
- **曲谱质量（约束翻唱）**：`score.reviewed.json` 已人工修正并无八度误跳、漏句或未覆盖和弦；音符误差小不等于歌词自然或成品好听。
- **听审与交付**：所有新生成音频均完成 `music.rate_content` 提交，逐段对照原曲通过审核点 4 与审核点 5（自动转写正确或模型返回成功不替代逐句人耳听审）。
