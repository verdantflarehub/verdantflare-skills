# 制作工作流

## 既有歌曲重新演绎

当用户明确指定一首其有权处理的完整歌曲，并选择已批准的人声模型时，采用重新演绎分支：

1. 客户端将原始音频上传到批准的外部 S3，计算 SHA-256；不得将媒体提交 Git。
2. 调用 `asset.import`，只提供项目 ID、临时可读的 S3 对象 URL、安全文件名和预期 SHA-256。导入完成后只记录 Artifact ID、文件名、大小和 SHA-256，不记录签名 URL。
3. 用户指定该歌曲即明确批准制作范围和源歌曲选择。在审核记录中将审核点 1、2 分别记为“已批准（用户指定既有歌曲）”，保留用户原始决定；不创建伪企划、不调用 `music.generate`、不生成无意义的双候选。
4. 将导入 Artifact 登记为 `Demo_Selected`，从阶段 2 的 `stems.separate` 继续。分轨、已批准模型复用、音色转换、歌词对齐、母带和审核点 3 至 5 继续使用下述标准流程。

若用户未确认有权处理来源歌曲，或既有人声模型未批准，停在导入或转换前，不用其他素材替代。

## 阶段 1：企划与候选

输入是一句话音乐灵感，以及以下二选一的人声来源：用户有权使用的原始人声 MP3，或已批准的人声模型。参考素材与其他约束属于音乐灵感的补充内容，不构成新的必需输入。将非关键参数补全为一套内部一致的创作选择，输出：

- `完整词曲企划.md`：主题、叙事、曲式、最大生成时长、BPM、调式、配器、演唱设计、完整歌词和交付目标。
- `lyrics.txt`：使用 Music3 支持的段落标签，只包含送入生成模型的歌词。
- `instructions.txt`：描述风格、速度、调式、配器、声音表现、结构发展和制作质感，不写供应商或内部部署信息。

审核点 1 通过后调用 `music.generate` 两次或请求两个独立候选，得到 `Demo_Candidate_1` 与 `Demo_Candidate_2`。两个候选使用同一份批准企划和最大生成时长，不在候选之间暗改歌词或制作目标。模型可以在上限前自然结束；下载后测量并分别记录实际时长，不要求两个候选等长。

审核点 2 选定一个候选后登记 `Demo_Selected`。要求重新生成时保留此前候选及决定，生成新的候选编号，不覆盖旧资产。

## 阶段 2：分轨与音色

对 `Demo_Selected` 调用 `stems.separate`，预期得到：

- `instrumental.wav`
- `vocal_dry_original.wav`

若输入为已批准的人声模型，直接登记并复用。若输入为原始人声 MP3，将录音归档到 `<创作者>/voice/recordings/`，调用 `voice.train`，预期得到不可覆盖的新模型 ID、模型权重、检索索引和一段真实转换产生的验证音频，再归档到 `<创作者>/voice/models/<模型ID>/`。模型训练属于人物身份相关操作，必须确认录音属于用户本人或用户有权使用。

审核点 3 只评价音色模型，不把歌曲转换质量混入该结论。通过后调用 `voice.convert` 将 `vocal_dry_original.wav` 转换为 `vocal_dry_cloned.wav`，然后进入审核点 4。

## 阶段 3：歌词对齐与母带

以 `vocal_dry_cloned.wav` 为音频依据，将已批准歌词去除 Music3 段落标签和空行后，调用 `lyrics.align`，得到 `Aligned_Lyrics.lrc` Artifact。输出必须保持歌词行数和逐行文字完全一致，毫秒级时间戳严格递增且不超过实际人声时长。任一检查失败时停止，不使用原曲 LRC、线性缩放时间轴或手工伪造时间戳。

调用 `mix.master` 时提供：

- `instrumental.wav`
- `vocal_dry_cloned.wav`
- `Aligned_Lyrics.lrc` Artifact 的已校验文本
- 批准的 BPM、目标响度和峰值上限

输出 `Final_Song_Master.wav`、`<创作者显示名>-<歌曲名>.mp3` 和 `Final_Song.lrc`。如果工具 Artifact 的内部文件名为 `Final_Song.mp3`，下载到项目交付目录时直接使用新名称，不保留兼容副本。自动格式检查通过后进入审核点 5；人工终审通过后归档。

## 返工路由

- 企划、歌词或制作方向问题：返回阶段 1，重新经过审核点 1。
- 旋律或编曲问题：保留企划，从候选生成重做并重新经过审核点 2。
- 分轨污染：只重做 `stems.separate`。
- 人物音色不像或模型覆盖不足：补充授权录音，用新模型 ID 重训并重新经过审核点 3。
- 音高、咬字或机械感问题：调整转换参数，只重做 `voice.convert` 并重新经过审核点 4。
- 字幕时间问题：只重做 `lyrics.align`；人声融合、响度、峰值或编码问题：只重做 `mix.master`；两者都重新经过审核点 5。

不得为了方便返工而重复已经批准且与问题无关的昂贵阶段。
