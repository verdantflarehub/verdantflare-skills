# verdantflare-music：男女对唱与多人合唱编排

## 1. 输入与输出

- **输入**：逐句歌词与角色时间轴（`female`、`male`、`both`、`instrumental` 或三人及以上分组标记）、每位歌手独立的获授权声源或已批准人声模型、BPM、伴奏、旋律线、同唱区间及和声关系。
- **输出**：各歌手独立全曲对齐干声（或角色窗口诊断轨）、伴奏、预混试听、`duet-performance-v1` 或 `duet-score-v1` 计划、脚本校验/审计报告、多声部歌词时间轴与最终母带。
- **公共依据**：[公共规范](00.common.rules.md)、[公共工作流与预检](00.common.workflow.md)、[公共验收与审核门](00.common.acceptance.md)。
- **同能力专册与参考**：[对唱与合唱工作流](03.duet-ensemble.workflow.md)、[对唱与合唱规范与校验契约](03.duet-ensemble.rules.md)、[《水晶》对唱参考](duet-reference-water-crystal.md)、[对唱与合唱编曲审核规范](编曲-对唱与合唱-审核规范.md)。

## 2. 分类

- **男女对唱（自然演唱源逐句换声 / 原混音局部换声）**：已有歌词旋律完整的自然演唱源或完整男女对唱混音，通过分轨、同唱掩膜分离、单声部换声与局部减法替换装配；详见[对唱与合唱工作流](03.duet-ensemble.workflow.md)。
- **音符驱动双轨对唱 / 纯歌词研发探针**：先构建 `duet-score-v1` 计划并用独立声库或获授权演唱者干声渲染（三段式双轨架构），先做 12–20 秒短样探针再扩整曲；现有 ACE-Step `duet.*` 与 OpenUtau 旧整曲均未通过听审，详见[对唱与合唱规范与校验契约](03.duet-ensemble.rules.md)。
- **三人及以上多人合唱**：每位成员须有独立全曲对齐声部与轮唱/齐唱/和声标记，经等响度分组混音与逐人听审；当前三人及以上自动生成未达生产可用，无独立声源时停在诊断或请求补充录音。

## 3. 工作流

1. 先按[对唱与合唱编曲审核规范](编曲-对唱与合唱-审核规范.md)与[《水晶》对唱参考](duet-reference-water-crystal.md)明确声部职责、段落密度、和声关系与伴奏避让；默认采用“女声/男声接力，最后副歌合流”的 `call_response_final_merge` 模板（主歌、预副歌与前两轮副歌单一声部，`both` 仅用于终段合流、尾句或明确和声且占歌词时长 `<= 18%`）。
2. 按实际输入选择路线并执行[对唱与合唱工作流](03.duet-ensemble.workflow.md)对应步骤：
   - **自然演唱源逐句换声**：运行 `audit_performance_voice_source.py` →（需换伴奏时）`prepare_duet_replacement_backing.py` → `replace_performance_duet_voice.py` → 以**上一版获认可试听**作 `--source` 运行 `validate_performance_duet.py`（加 `--backing` 核 `stems_reconstruct_preview`）。
   - **原混音局部换声**：分人声建时间轴 → 同唱句用 `lift_duet_singer_mask.py` 做互补时频掩膜全频提升 → F0 条件换声 → `replace_singer_in_mix.py` 执行 `original_mix - isolated_original_singer + converted_singer`。
   - **音符驱动双轨 / 短样探针**：先以 12–20 秒短样（女独、男独、同唱、无重叠接唱对照）运行 `validate_duet.py` 并人耳听审通过，再扩至整曲。
   - **三人及以上合唱**：先逐人审歌词/音准/音色，再核独唱/轮唱/齐唱窗并做等响度分组混音。
3. 完成[K09 内容分级](00.common.rules.md#5-生成后内容分级评估k09-强制步骤)，经逐轨与整曲等响度 A/B 人耳听审通过后，方可执行最终母带（`mix.master(vocal_mode="duet"|"choir", ...)`）与审核点 5。

## 4. 规范

- 完整技术契约、模型边界（ACE-Step `duet.*`、OpenUtau、SoulX-Singer、YuE-2、Seed-VC）与 `duet-score-v1` 校验规则见[对唱与合唱规范与校验契约](03.duet-ensemble.rules.md)。
- 性别与声部是创作要求，不由 `vocal_mode` 自动推断；严禁复制同一条干声、降八度或只改声像冒充第二位歌手，严禁以单轨提示词生成结果冒充对唱。
- 角色窗口轨通过不等于可独立重混的纯净干声；`stems_reconstruct_preview=false` 时不得送入需独立分轨的 `mix.master`。
- 歌词时间轴须对应真实多声部内容，单人 `lyrics.align` 不会自动对齐多人重叠歌词，严禁伪造或线性缩放 LRC。

## 5. 验收

- 适用机器脚本（`validate_duet.py` / `validate_performance_duet.py` / `audit_performance_voice_source.py`）退出码必须为 0；任一非零仅作诊断候选，禁止进母带或声部扩展。
- 机器报告 `qualification_scope` 固定为 `machine_only`，通过后仍须逐轨与整曲等响度对照人耳听审（核验歌词、咬字、音准、男女/第三位歌手可辨度、交接、同唱平衡、原唱泄漏、伴奏避让与尾音）。
- 任一声部歌词、音质或同唱关系未通过时，整曲保持未通过状态。
